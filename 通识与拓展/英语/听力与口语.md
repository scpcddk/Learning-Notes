## 01 先选与目标匹配的材料

| 当前目标 | 选材依据 | 判断是否合适 |
| --- | --- | --- |
| 辨认发音和词边界 | 选有准确原文、语速自然、音质清楚的短片段 | 第一遍大致知道主题，反复卡在少数位置 |
| 听懂连续叙述 | 选话题熟悉、结构完整的几分钟材料 | 能追踪主线，遇到漏听仍能继续 |
| 适应真实对话 | 选包含轮流发言、插话和语气变化的材料 | 能区分说话者和各自的观点 |
| 听专业内容 | 先选对主题已有背景知识的讲解 | 能判断困难来自语言还是概念 |

用于精听的材料最好能方便定位和回放。只听到零散单词时，先缩短片段或降低语言难度。几乎每句都听得很轻松时，可以换说话人、话题或材料类型。

## 02 精听定位

1. **原速听一遍**。先记主旨、说话目的和信息顺序。第一遍听漏时继续往后听，保留对整段的理解。
2. **定点重听**。从最影响理解的位置向前后各留一点声音，听两三遍。标明是完全没辨认出来，还是辨认出了词却没理解意思。
3. **对照原文归因**。先看自己卡住的位置，再回看前后句，判断问题属于词义、声音、结构还是注意力。
4. **处理一个原因**。根据下表选择方法。解决后关掉原文，回到原速，从更早的地方开始播放。
5. **换新材料检查**。隔一段时间听同类型的新片段，观察原来的问题是否减少。熟悉片段可用于巩固，新材料更适合看能否迁移。

| 对照后发现 | 下一次怎么处理 |
| --- | --- |
| 原文里的词不认识 | 补该语境中的意思和读音。把词连同前后词一起听。 |
| 原文一看就认识，播放时却没辨认出 | 缩小到短语，关注重音、轻读和词边界，随后听回完整意群。 |
| 单词基本听对，整句仍然没懂 | 给文本分意群，找到主句动作、转折或条件，再关字幕重听。 |
| 理解一句后就跟丢下一句 | 减少边听边逐字翻译和记录的负担。保留关键词，按信息块继续听。 |
| 容易漏数字、日期或否定 | 定点核对这类信息与前后语境的对应关系。回放整句确认它影响的是哪一条结论。 |
| 换个说话人又听不懂 | 逐步增加说话人和口音的变化，先保持话题和难度相近。 |

## 03 泛听追踪主线

- 选能大致跟上、内容感兴趣的材料，用接近日常的速度连续听。
- 重点追踪话题切换、说话者立场和结论。漏掉细节时先用后文补足。
- 听完后只对照最影响整体理解的一两处。若整段没有形成主线，下次改选更短或背景更熟悉的材料。

## 04 字幕变速与复习

- **字幕用于核对**。先关字幕听，再打开英文原文定位问题，最后关掉回听。同一段连续看字幕容易变成阅读。
- **变速用于诊断**。需要时短暂减速确认音节和边界，然后回到自然语速。进步以自然语速下能否跟上来判断。
- **复习针对重复问题**。每次记下最常漏的类别，下一次优先听同类材料中的相同信息。比较几次新材料的主旨、关键细节和回放次数，看看最常漏的那一类有没有改善。

## 05 长材料怎么听

- **讲座和长解说**。播放前扫一遍题目、章节和提纲。播放时只记主题变化、讲者给的结论和定位时间。第一遍听完再回到最影响理解的片段做精听。
- **多人对话**。先区分说话者，再追踪各自的态度和信息。转话题或有人打断时，先重新确定当前在讨论哪件事。
- **专业内容**。先了解核心概念和高频术语，再听说明过程。概念没懂时回到背景材料。概念懂了仍跟不上时，定位是关键词没辨认出来，还是句间关系跟丢了。

## 06 怎么判断有没有进步

比较话题、时长和难度接近的新材料。先看是否一次就能抓住主题和结论，再看关键细节保留了多少，以及需要回放几次。用最近经常漏听的类别决定下一段材料的重点，避免每次都从头逐字听写。

## 07 连续语流与重点信息

| 听到的现象 | 处理方法 |
| --- | --- |
| 认识单词，却在整句里认不出 | 取一个完整意群，先找最清楚的重读音节，再向两侧定位轻读音节和词边界。 |
| 听到的音节比文字少 | 对照文本检查弱读、连读或辅音的发音方式。每次只定位一种变化，最后回到原速复听。 |
| 听懂了字面，没抓住说话人强调什么 | 对照句重音和前后语境，看说话人在纠正哪个信息、对比哪两个对象、把话题转向哪里。 |
| 漏掉数字或相似名称 | 同时记录单位、对象和比较方向。数值没听清时先留空，继续听后面的限定词。 |
| 遇到不熟悉的口音 | 先用有文字稿的短材料建立声音和词的对应，再换同类话题和另一位说话者。 |

留意说话人对已知信息和新信息的处理。人名、数值、否定和转折都可能改变句意。第一次听优先锁定主旨，第二次再回找影响结论的细节。

## 08 边听边记与听后复述

1. **按关系记**。记主题、变化和原因。遇到讨论时分开标各人的观点，遇到说明时分开标步骤、条件和结果。
2. **缩短记录**。用关键词或简写保留线索，标明数字的单位和比较基准。遇到缺漏留空，继续听下一意群。
3. **按顺序复述**。关掉字幕，只看笔记交代主旨、两个关键点和一条限制。再听原声核对自己是否混淆了事实、推测和意见。
4. **改进笔记**。若复述时漏了转折，下次重点标关系。若记下很多词却讲不清顺序，下次每个信息块只记一个动作或判断。

## 09 发音重音与节奏

先解决影响理解的发音，再处理节奏。说话时按意群停顿，把新信息、对比项或行动重点读清楚。初次录音可标出重读词和停顿位置，回听时检查它们是否对应你真正要表达的意思。

| 重点 | 做法 | 口语示例 |
| --- | --- | --- |
| 单词重音 | 查词典音频时同时听重读音节和其他音节的弱化。用整个词复述。 | **PRE**sent 表示礼物或在场，pre**SENT** 表示呈现。 |
| 句子焦点 | 根据需要澄清的信息调整重音。 | I said **Tuesday**, not Thursday. |
| 意群与停顿 | 在完整信息块之间停顿，保持介词和宾语、动词和补语的连贯。 | If the room is free / we can start at three. |
| 词尾与关键音 | 先检查会改变意思的词尾和音素，再回到自然语速。 | We **need** one copy. / We **needed** one copy. |

## 10 跟读与脱稿表达

1. 先听懂原段，再选择一个意群模仿重音、停顿和长度。能完整说清后，再试紧跟原声。
2. 关掉文本，保留几个关键词。先用自己的话复述，再换一个对象或时间，把同一结构用于新场景。
3. 说到一半卡住时，用简短定义、举例或改述维持交流。句子太长可以在信息块结束时收句，再补下一条。

> I can't remember the exact term. It's the part that keeps the door from closing too quickly.
>
> 我一时想不起确切的说法。就是让门不会关得太快的那个部件。

## 11 日常对话与澄清

| 情况 | 英文说法 | 作用 |
| --- | --- | --- |
| 确认时间或地点 | Do you mean this Friday or next Friday? | 提出两种具体理解，请对方确认。 |
| 请对方重说关键部分 | Could you repeat what you said about the deadline? | 指明卡在哪一部分。 |
| 复述以确认 | So we'll meet outside the library at six, right? | 把地点和时间一起说出来。 |
| 礼貌接话 | Can I add one point before we move on? | 说明打断的时机和目的。 |
| 主动修正 | Sorry, I meant the second page. | 快速改正指代，继续交流。 |
| 确认下一步 | I'll send you the link this afternoon. Could you let me know if it opens? | 交代自己的动作，再确认对方要做什么。 |

## 12 观点讨论与简短陈述

口头说明可以用「一句判断 → 一条理由 → 一个例子 → 适用条件」。回答追问时先给结论，再交代具体背景。表达保留意见时，指出同意的部分和仍需核实的部分。

> I'd keep the longer workshop for beginners. They need time to try each step on their own. For people who have done it before, a shorter session should be enough.
>
> 我会给初学者保留较长的工作坊。他们需要时间自己试过每一步。对有经验的人，较短的场次应该就够了。

## 13 技术口语与项目汇报

| 任务 | 组织顺序 | 口头示例 |
| --- | --- | --- |
| 汇报进度 | 已完成 → 卡点 → 下一步 | The export now works locally. I'm checking why it takes longer in staging. I'll compare the request logs this afternoon. |
| 描述问题 | 触发条件 → 预期 → 实际 | When I open the report without a date range, I expect to see a prompt. The page shows a blank table instead. |
| 解释流程 | 输入 → 关键处理 → 输出 | First, the user uploads a file. The server checks its format and returns a job ID. |
| 回答不确定的问题 | 已确认事实 → 未知点 → 验证动作 | I confirmed that the request reached the API. I haven't checked the database call yet. |

讲数字时先说量级、单位和时间窗口。对方需要做决定时，把问题与备选方案放在开头，再展开背景。

## 14 录音复盘与口语进度

先听一次内容，检查听者能否复述你的主旨和下一步。再听一次表达，标记会影响理解的停顿、语音或结构，每次选一处重录。定期换话题重新说一段，比较能否在少看提示的情况下把对象、理由和结论讲完整。
