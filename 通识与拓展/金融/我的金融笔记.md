## 一、宏观金融

### 1.1 经济运行基础

- **CPI**：消费者价格指数，跟踪普通家庭日常购买的典型商品与服务价格
- **通胀成因**：总需求超过供给、原材料与人工成本上升、供给受阻、货币与信用扩张等都可能推动物价上涨；不能只用“钱印多了”解释。
- **通胀对股市影响**：
  - 公司成本上升，盈利不确定性增加
  - 判断实际收益要看“价格涨跌 + 分红”的总回报，不能只拿股息率与通胀率比较
  - 央行介入提高利率 → 公司成本上升 → 估值承压
  - 现值公式：现值 = 未来价值 / (1 + 利率) ^ 期数
- **局部通胀 vs 整体通胀**：局部压力向整体传导，路径包括成本传导、需求传导、预期传导
- **影响通胀深度的因素**：行业权重、产业链位置、替代弹性
- **政策应对**：需区分需求过热与供给冲击；经济开放度会影响输入性通胀及政策传导。
- **通胀的“局限性”本质**：价格信号在经济网络中的扩散过程

- **PPI**：统计工厂企业产品第一次卖出去的出厂价格
- **PPIRM**：工厂买原材料、燃料的采购成本
- **PPI与CPI的关系**：
  - PPI：上游生产端
  - CPI：下游消费端
  - 传导并非一比一：企业能否提价、居民需求强弱、进口价格变化都会影响结果。
- **读数方法**：区分同比、环比与价格水平。CPI同比从3%降至1%，表示物价上涨放慢，不代表物价已经下降；还需留意去年同期基数。

### 1.2 货币政策与利率

#### 1.2.1 利率周期

1. **政策利率**：由央行确定，影响金融体系资金价格，并向存贷款和债券市场传导。
2. **市场利率**：包含贷款利率、国债收益率等，还受期限、信用风险和资金供求影响，不会与政策利率同步、等幅变化。
3. **降息周期（宽松放水）**：
   - 央行放水，市场借钱变得便宜
   - 可能受益：对融资成本、估值折现率敏感的资产；仍需看盈利、负债与买入价格
   - 存款新发生或到期续存的利率可能下降；银行表现还取决于存贷款利差和资产质量

> [!note]
> **传导链条**：利率下降 → 融资成本下降 → 企业投资增加 → 经济增长 → 股票估值提升
> **适用条件**：企业愿意投资、居民愿意消费、银行愿意放贷。降息也可能发生在盈利下滑阶段，不能直接推出股市必涨。

4. **加息周期（收紧资金）**：
   - 收紧流动性，贷款借贷变贵
   - 可能提高新存款和新发短期债券的收益率；已有债券仍可能因市场利率上升而跌价
   - 银行不一定受益；黄金还受实际利率、汇率和避险需求影响，不能归为“加息必然利好”
   - 利空：高负债行业、成长股

#### 1.2.2 通胀与通缩

- **通胀：物价持续上涨，钱变多货少**
  - ①温和通胀：较低且稳定的通胀有助于形成预期；2%~3%只是部分语境下的参考，不能单凭这一数字判断经济健康
  - ②恶性通胀：物价大幅飙升，企业成本压力极大
  - 利好：煤炭、有色、化工、食品等资源股、必选消费
  - 政策：收紧资金，加息压制通胀

- **通缩：物价持续下跌，货多钱少，需求不足**
  - 居民不愿消费，企业降价甩货，企业盈利承压；央行倾向降息宽松
  - 利好：短债、现金、高现金流防御板块（医药、公用事业）、国债
  - 利空：高负债行业，企业利润被挤压

#### 1.2.3 货币政策工具

1. **宽松货币政策（放水）**：
   - 工具：**降准、降息、逆回购投放资金、MLF、专项贷**
   - 目的：降低社会融资成本，刺激投资与消费，托底实体经济。
2. **紧缩货币政策（收水）**：
   - 工具：**加息、提高存款准备金率、正回购、逆回购到期不续作等**
   - 目的：抑制通胀，防止经济过热，挤压资产泡沫。
3. **中性货币政策**：小幅微调，经济平稳，既不强力刺激也不收紧。

- **逆回购看净额**：开展逆回购是投放资金，到期是回笼资金；若当天投放1000亿元、到期1500亿元，仅该工具净回笼500亿元。判断整体流动性还要合并其他工具。[央行工具投放与回笼统计](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/5727710/2026010517563068096/index.html)

#### 1.2.4 关键观测指标

- **PMI**（采购经理人指数）：
  - 制造业PMI：工厂生产、订单、就业
  - 非制造业PMI：服务业 + 建筑业
  - 经济先行指标，枯荣线50
    - `> 50`：经济扩张
    - `< 50`：经济收缩
  - 构成：新订单（需求，权重最高），生产（供给），从业人员（就业），供应商配送时间，主要原材料库存
  - 50是与上月相比的景气分界，不是GDP增速；从48升至49表示收缩程度减轻，仍未回到扩张区间。

- **社融**（社会融资规模）：
  - 构成：
    - 间接融资：
      - 人民币贷款（大头）、外币贷款
      - 表外：委托贷款、信托贷款、未贴现银行承兑汇票
    - 直接融资（资本市场）：
      - 企业债券融资
      - 非金融企业股票融资
    - 其他：政府债券
  - 解读：增速上行，实体信用扩张；回落，实体融资需求偏弱
  - 结构比总量重要：区分政府拉动，还是企业居民内生融资回暖

- **货币供应量**：
  - M0（流通中现金）：银行以外，全社会流通的现金
  - M1（狭义货币，2025年1月起新口径）：= M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金
    - 反映可较便利地用于交易支付的货币；新口径下不能仅理解为“企业活钱”
  - M2（广义货币）：= M1 + 单位和个人定期存款 + 其他存款
    - 代表整个社会货币总存量
  - M1‑M2剪刀差
    - M1增速相对M2回升：可作为资金活化的观察线索，仍需验证企业经营、居民行为和统计口径
    - M1增速相对M2偏弱：可能反映定期化等变化，不能直接等同于消费投资意愿下降
  - M2 vs 社融：
    - M2与社融统计对象不同，增速背离只能提示进一步检查，不能单凭它认定“货币空转”
  - 时钟联动：M2、社融看信用环境；PMI看增长；CPI/PPI看通胀，共同判断经济周期
  - 口径来源：[央行：狭义货币和广义货币](https://www.pbc.gov.cn/rmyh/109339/2025080818580470423/index.html)。比较跨期数据时应使用可比口径。

- **GDP国内生产总值**：
  - 定义：一定时期境内常住单位全部最终产品与服务市场价值，地域概念。
  - 三种核算：
    - ①生产法：总产出 ‑ 中间消耗（增加值）
    - ②收入法：劳动者报酬 + 生产税净额 + 折旧 + 营业盈余
    - ③支出法：GDP = C + I + G + NX
      - C居民消费；I资本投资；G政府购买；NX净出口（出口‑进口）
      - 注意：转移支付、二手交易、股票不计入GDP
  - 名义GDP：按现价，含物价变动
  - 实际GDP：剔除通胀，反映真实产出；经济增速看实际GDP
  - GDP平减指数 = 名义GDP / 实际GDP × 100（基期为100），衡量国内生产的最终产品与服务价格变动
  - 时钟联动：GDP代表经济增长；CPI/PPI代表通胀；PMI为月度先行指标

#### 1.2.5 补充宏观观测体系（原待学内容全部落地）

- **就业数据**：
  - 核心作用：验证实体经济真实冷暖，属于滞后确认指标
  - 逻辑关系：经济复苏扩张 → 企业招工需求提升 → 失业率下行、就业改善
  - 反向逻辑：经济下行压力大 → 企业降本裁员 → 就业走弱，进一步压制居民消费
- **消费数据（社会消费品零售总额）**：
  - 主要覆盖商品零售和餐饮收入，不等于全部居民消费，也不完整覆盖教育、医疗等服务消费
  - 消费走强：内需回暖，利好消费赛道、整体经济修复
  - 消费持续疲软：代表居民信心不足、总需求偏弱，经济内生动力不足
- **货币传导机制**:
  - 定义：央行货币政策从金融端传导至实体经济的完整链路
  - 宽松标准传导链：
    - 央行放水 / 降息 → 市场流动性变多、利率下行 → 企业融资成本降低、居民贷款成本降低 → 企业扩产投资、居民消费购房增加 → 总需求提升、GDP回暖、资产价格抬升
    - 现实阻滞：传导不畅、货币空转
    - 观察线索：M2与社融背离、企业居民贷款需求偏弱等；需结合融资结构与资金用途验证，不能直接断定资金没有进入实体。
- **流动性周期**：
  - 流动性宽松周期：市场资金充裕、利率偏低，成长股、科技、新能源占优
  - 流动性收紧周期：利率上行可能压制高估值成长，也会使已有债券承受跌价压力；现金和部分防御资产可能相对占优
  - 关键区分：流动性≠经济基本面
  - 可以出现：钱多（流动性松）但经济弱（基本面差）的背离行情

### 1.3 经济周期与资产轮动

- **美林投资时钟**：
  - **复苏**：
    - 状态：经济上行，通胀下行
    - 最优资产：股票
    - 主线：科技、高端制造、新能源、军工成长赛道
    - 货币政策：维持宽松
  - **过热**：
    - 状态：经济上行，通胀上行
    - 最优资产：大宗商品
    - 主线：有色煤炭石化化工等周期资源股，高通胀，将要加息
    - 货币政策：加息收紧
  - **滞胀**：
    - 状态：经济下行，通胀上行
    - 最优资产：现金
    - 主线：经济停滞+通胀居高不下，企业营收不涨原材料成本暴涨，成长股大跌，配置必选消费、黄金
    - 货币政策：高利率，很难降息
  - **衰退**：
    - 状态：经济下行，通胀下行
    - 最优资产：债券
    - 主线：公用事业、医药、高股息白马、国债
    - 货币政策：降息、宽松

- **宏观择时**：
  - 核心任务：判断当前经济周期，为资产轮动提供依据
  - 观测指标：
    - 增长维度：GDP、PMI、社融、就业数据
    - 通胀维度：CPI、PPI
    - 货币维度：M2、央行政策
  - 局限：指标经常出现信号冲突，现实不会完美顺时针走时钟，会出现“电风扇行情”
  - 使用顺序：先记录增长、通胀、信用指标的方向，再解释可能原因；上述“最优资产”是模型中的相对表现概括，不是固定买卖指令。

## 二、个人财富管理

### 2.1 财务基础

- **复利**：
  - 时间是最核心的变量
  - 成本是敌人
  - 稳定是关键
  - 控制费用、减少无依据的交易；指数基金也可能长期亏损，“长期持有”以标的和资金期限适合为前提
  - 计算：终值 = 本金 × (1 + 年收益率)^年数。投资收益率会变化，这个公式的固定收益率只是计算假设。
- **真实回报**：实际收益率 = (1 + 名义收益率) / (1 + 通胀率) - 1；如名义收益5%、通胀2%，实际约2.94%。
- **亏损与回本**：亏损20%后需上涨25%才能回本；先涨20%再跌20%，累计收益为-4%，涨跌不能直接相加。
- **预算**：
  - 找到财务基准线：实际记录财务，不要"心里记账"
  - 可用必要支出占收入的比例观察预算压力；50%是参考，需结合收入、城市和家庭责任，不能当统一要求
- **平均成本法**：固定金额分批买入，价格低时买到更多份额；不保证比一次性买入便宜，也不保证盈利
- **机会成本**：花小钱节省时间，将时间放在副业
- **决策疲劳**：财务自动化，节省时间精力，减少决策失误
- **省钱**：
  - 省下100元 = 实际赚到100元
  - 降低住房成本、交通花销、餐饮消费
  - 了解自身税收制度
  - 增加工作时间以获取更多薪酬

### 2.2 信用与债务管理

- **信用评分**：
  - 银行或其他贷款机构快速评估信用风险的方法
  - 美国FICO常见因素：付款历史(35%)、欠款金额(30%)、信用历史长度(15%)、信用组合(10%)、新增信用(10%)；这是特定评分体系，不能套用为中国人民银行征信的评分公式。[FICO官方说明](https://www.myfico.com/credit-education/whats-in-your-credit-score)
- **提升信用方法**：
  - 按时还款、控制负债、核对征信记录并及时提出错误异议
  - “添加授权用户、增加信用组合”等属于特定国家和评分体系的做法，不应为了养分刻意借贷
- **信用卡使用原则**：
  - 建立信用评分
  - 获得奖励，帮助攒钱
  - 培养财务责任感，学习理财
  - 紧急资金应来自自己可支取的现金储备，信用额度不是储蓄
  - 尽量在到期日前全额还款；最低还款通常不能保留全部免息待遇，需核对发卡行规则
  - 保持较低的信用额度使用率
  - 永远不要错过还款日期，设置自动还款
- **信用卡错误**：
  - 申请太多信用卡
  - 透支（考虑机会成本）
  - 用信用卡支付信用卡（以卡养卡）
  - 忽视利率优惠、消费陷阱
  - 不做预算、不记录开支
  - 不要花光所有钱，制定预算
  - 不要把过多钱储蓄而不投资
  - 不要背负信用卡债务
  - 不要忽视信用积分
  - 不要投资任何你完全不了解的东西
- **信贷与负债**：
  - 名义利率(账面标价) ≠ 真实成本
  - 比较成本要使用“实际到账金额 + 各期还款 + 直接相关费用”，并统一年化口径
  - 分期逐月还本时，本金占用不断减少；若手续费一直按初始本金收取，简单用总手续费除以初始本金会低估资金成本
  - “真实年化≈标价×1.8”只适用于部分还款结构的粗估，不能通用；IRR需按实际现金流计算
  - 央行允许以复利（IRR）或单利方法计算贷款年化利率，单利须明示；不能把IRR与所有产品的APR口径直接画等号。[央行2021年第3号公告](https://xining.pbc.gov.cn/goutongjiaoliu/113456/113469/2025092212551432728/index.html)
  - 消费贷、现金贷、随借随还产品都要逐一核对年化成本、费用、提前还款与逾期条款，不能只凭名称判断贵便宜
  - 商品分期：服务费、担保费、变相利息

### 2.3 保险规划

#### 2.3.1 保险作用与合同角色

- **保险作用**：通过支付保费，把约定范围内的风险转移给保险公司，减轻疾病、意外、身故或财产损失带来的经济冲击；保险只能承担合同约定的责任。
- **基本医保与商业保险**：基本医保是医疗保障体系的基础，商业医疗险用于补充约定范围内的费用缺口，不能据此忽视基本医保的连续参保。
- **保险合同中的角色**：
  - **保险人**：承保并按约承担赔偿或给付责任的保险公司；销售平台、代理人不等于保险人。
  - **投保人**：与保险公司订立合同、承担缴费义务的人。
  - **被保险人**：其人身或财产受到保障的人。
  - **受益人**：人身保险中依法或依约享有保险金请求权的人；不能简单认为“谁交钱，保险金就一定归谁”。
- **保费、保额、现金价值**：保费是为合同支付的费用；保额是确定赔偿或给付责任的重要尺度，实际赔多少还看具体责任；现金价值关系到相应保单退保时可取回多少，不能与保额、累计保费混用。

#### 2.3.2 常见险种：分别解决什么问题

| 险种 | 主要解决的问题 | 常见赔付方式 | 阅读重点 |
| --- | --- | --- | --- |
| 医疗险 | 约定范围内的医疗费用支出 | 费用报销，也有定额给付责任 | 医院范围、费用范围、免赔额、报销比例、续保 |
| 重疾险 | 达到约定疾病、手术或状态后的资金需要 | 按约定金额给付，通常不以医疗发票金额为限 | 疾病定义、严重程度、轻中症责任、赔付次数 |
| 意外险 | 符合约定的意外导致身故、伤残或医疗支出 | 身故/伤残给付，意外医疗通常报销 | 意外定义、职业限制、伤残标准、除外活动 |
| 寿险 | 被保险人身故等约定事件造成的经济影响 | 按合同给付；是否含全残另看条款 | 保障期间、给付条件、免责、受益人 |
| 车险 | 车辆损失、对第三者或车上人员的相应责任 | 按责任及损失赔偿 | 交强险、车损险、商业三者险等分别保什么 |
| 家财险 | 房屋、装修、室内财产及附加责任的损失 | 在约定责任和限额内赔偿 | 火灾、水损等事故范围，财产清单及分项限额 |

- **医疗险与重疾险不能混同**：医疗险重在解决合规医疗支出；重疾险给付的钱可用于康复、生活等，不等于所有住院都能触发赔付。
- **重疾不都是“确诊即赔”**：有的责任以疾病确诊为条件，有的要求实施特定手术，或达到约定程度、持续一定时间；疾病种类多，不一定说明核心保障更好。[保险业协会：重疾定义规范说明](https://wap.iachina.cn/art/2020/11/5/art_8616_104706.html)
- **意外不等于所有突然发生的事**：保险中的意外通常要求外来、突发、非本意、非疾病等特征；疾病导致的猝死是否保障，要看有无相应责任。伤残赔付常按伤残等级对应比例计算，不一定赔满保额。[保险公司投教案例：猝死与意外责任](https://www.aia.com.cn/zh-cn/jiaoyujifengxian/jiaoyufengxiantishi/cusiyinggailipeima)
- **定期寿险与终身寿险**：前者在约定期间内提供保障，后者提供终身保障；都不是“交完保费就马上领回保额”。年金险则通常按约定时间、存活等条件给付，需与寿险的身故责任区分。
- **车险的对象不同**：交强险和商业三者险主要涉及对第三者的相应赔偿责任，车损险主要涉及被保险车辆自身损失；“买了三者险”不等于自己的车也能获得车损赔偿。[保险业协会：商业车险示范条款](https://wap.iachina.cn/art/2020/9/4/art_24_104621.html)
- **家财险看具体风险**：火灾、水管破裂、盗抢、对邻居的责任等未必全部包含；房屋、装修、室内物品可能分别设限额，不能只看总保额。

#### 2.3.3 阅读条款时必须分清的项目

- **保障期间 vs 缴费期间**：保障持续多久，与保费要交多久是两件事；例如交20年、保终身，不等于20年后合同结束，也不等于全部责任都保终身。
- **等待期**：合同生效或复效后的一段约定期间，某些疾病责任可能尚未开始承担；意外责任、续保是否重新等待、等待期内发生疾病如何处理，都要分别看条款。
- **犹豫期**：相关人身保险合同约定的投保后重新考虑期间；起算点、天数和退费规则应查保单。它与等待期作用不同，不能混用。
- **免赔额**：符合条件的费用中，需要先由被保险人承担或按约定扣除的部分；核对按次还是按年累计，以及医保、其他保险的补偿能否抵扣免赔额。
- **赔付比例**：符合范围且扣除免赔额后，再按约定比例计算；宣传“100%报销”通常仍有医院、项目、用药及是否经过医保结算等前提。
- **限额**：区分年度总限额、单次限额、特定项目限额及保证续保期间累计限额；总保额高，不代表每个项目都能赔到这一数字。
- **责任免除与特别约定**：检查既往症、职业、运动活动等限制，以及核保后对个人单独作出的除外或加费约定；产品通用宣传不替代个人保单。
- **医院和费用范围**：核对医院等级、普通部/特需部、地域、院外药及指定药品条件；“住院花了钱”不等于都在保险责任范围内。
- **主险与附加险**：看各自的保障和缴费期间、附加险能否独立续保，以及主险终止后附加险如何处理。

上述项目应在条款、保单及相关说明中核对，尤其不能把销售页面上的一句宣传当作全部责任。[监管部门：短期健康保险规范](https://www.nfra.gov.cn/chinese/OFFICE/PDF/958198.pdf)

#### 2.3.4 医疗费用怎么赔，续保怎么看

- **报销型与给付型**：报销型通常不能通过多份保单重复报销超过实际合规支出的费用；给付型则按各份合同的触发条件判断，不宜一概认为只能赔一份。
- **报销计算例子**：假设经医保结算及其他补偿后，符合该商业医疗险责任的个人负担费用为1.2万元，剩余免赔额1万元，赔付比例80%，且未触及任何限额，则简化赔付为：
  - **(12000 - 10000) × 80% = 1600元**。
  - 这只适用于上述假设；实际还需核对免赔额抵扣顺序、费用分类和分项限额。剩余免赔额大于合规费用时，该责任可能不产生赔付。
- **保证续保要看合同**：一年一保不必然等于一年后一定不能续，也不必然等于保证续保；“可续保至某年龄”不能替代明确的保证续保条款。
- **保证续保期与终身保障不同**：例如条款约定保证续保20年，应分别检查期间内的续保条件，以及20年届满后的安排，不能自动理解为终身有效。
- **保证续保不等于保费不变**：保费可能随年龄变化；费率可调产品还可能按约定条件调整费率，需看费率表及调整规则。[健康保险管理办法](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1027050)、[长期医疗险费率调整说明](https://jrj.sh.gov.cn/ZCJD146/20200403/0031-158848.html)
- **换保前核对衔接**：新产品可能重新健康告知、核保和计算等待期；先确认新合同的承保结果及责任起点，再评估旧保障如何处理，避免只因首年便宜就忽视保障中断。

#### 2.3.5 储蓄型保险与投保核对

- **理财型/储蓄型保险**：是长期保险合同安排，不等同于基金定投或银行存款。看清哪些利益写入合同、哪些只是演示；分红通常不保证，万能险的演示或当期结算利率也不等于未来长期收益，投连险还需关注投资风险。[监管部门：正确认识人身保险新型产品](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1048816&generaltype=0&itemId=915)
- **现金价值与退保**：犹豫期后退保，通常按合同退还现金价值等应退金额，可能低于累计已交保费；对照自己可能用钱的年份，而不是只看几十年后的演示数字。保单贷款不是免费取钱，还涉及利息及合同约定的影响。
- **保额增长不等于本金收益率**：增额寿险所称基本保额增长比例，与以每笔保费及实际领取时间计算的收益不是同一个概念；比较时应看真实缴费和可领取金额。
- **财富传承**：终身寿险、年金险涉及投保人、被保险人、受益人安排，不能概括为统一的“三不碰”保障；保险金是否属于遗产等基本规则见6.2。
- **税优健康险**：只有符合政策的产品及支出才能按规定享受优惠，需核对税优识别码等凭证；“税前扣除”是减少计税基础，不是保费等额抵减应纳税款。[税务总局：税优识别码要求](https://www.chinatax.gov.cn/chinatax/n810356/n3255681/c5234212/content.html)
- **长期护理险**：关注达到约定失能状态后的照护需求；商业护理保险与各地长期护理保险制度试点不是同一个产品，触发标准、评估和待遇需分别核对。
- **原有配置步骤**：确定需求 → 确定预算 → 确定产品类型 → 确定保额 → 确定保障期限 → 挑选产品；具体计算和家庭组合仍保留为待学。
- **投保前核对**：谁承保、谁被保、保什么、不保什么、保多久、交多久、怎样赔、如何续保和退保；保存条款、健康告知及核保结果，通过保险公司官方渠道验单。判断责任主要看合同和事实，大公司、熟人推荐或平台承诺都不能替代条款。

## 三、投资金融

### 3.1 投资基础

- **资产分类**：现金/货币基金、债券基金、股票基金、混合基金、指数基金、ETF、公募REITs
- **风险收益关系**：承担更高风险不保证获得更高收益；产品风险需看底层资产、集中程度及交易规则，不能仅按名称排序
- **复利与实际收益率**
- **资产配置基础**：
  - 进攻资产：股票型基金、混合型基金（偏股）、宽指基金
  - 防守资产：纯债基金、中短债基金、一级债基
  - 稳健型配置：20/80（股/债）
  - 均衡型配置：50/50
  - 进取型：80/20
  - 股债搭配：在相关性较低时有助于分散波动，但股债也可能同时下跌，不能保证对冲亏损
  - 以上比例是理解股债搭配的示例，实际还要结合用钱时间、收入稳定性和能承受的亏损金额
- **房子净值**：资产与负债间的差额

### 3.2 基金投资

#### 3.2.1 基金核心概念

- **场内 vs 场外**：
  - 场内：通过证券账户在交易所买卖，成交价受供求影响，可能高于或低于基金净值
  - 场外：通过销售平台或基金公司开立基金账户，通常按适用交易日净值申赎；可随时提交委托，但受交易日、截止时间、暂停申赎等规则约束
  - **折溢价率** = (场内成交价格 / 对应参考净值 - 1) × 100%；两者时点要匹配，跨境产品尤其注意净值时差
  - **跟踪误差**：观察指数基金净值收益与标的指数收益的偏离，不是场外基金专属；场内价格偏离净值属于折溢价问题。[证监局案例说明](https://www.csrc.gov.cn/shenzhen/c105614/c7521980/content.shtml)
- **费用**：
  - A类：买入收申购费，卖出收赎回费（一次性），持有时间越长赎回费越低
  - C类：通常不收申购费，持续计提销售服务费；仍可能收赎回费，短期买卖未必便宜
  - Y类：个人养老基金，费率低，税收优惠
  - 管理费（支付给基金管理人）、托管费、销售服务费通常从基金资产中计提，已经影响净值；申购/赎回费通常由交易投资者承担
  - 比较同一基金A/C类，要把实际申购折扣、销售服务费、赎回费和预计持有期一起算；管理费等现行标准以最新产品资料概要为准
  - 例：假设A类申购费0.1%、C类销售服务费每年0.2%，其余费用相同且忽略净值变化，约持有半年后两者成本相当；实际不能只记“A长期、C短期”
- **单位净值**：基金单价
- **份额**：持仓数量 = (买入本金-手续费) ÷ 当天基金净值
- **申购/赎回时间规则**：
  - 场外：下午3点前申购按当天收盘净值算；3点后顺延下一交易日
  - 赎回同理，钱不会立刻到账，要等清算+回款
  - T指业务规则适用的交易日。普通境内开放式基金常见T+1确认，但收益计价起点与确认时间不是一回事；货币基金、跨境基金另看合同
  - 确认份额、可赎回、赎回确认、到账是不同时间节点。不要把所有债基、股票基金都记成统一的“T+1卖出、T+2到账”

#### 3.2.2 基金分类

- **货币基金**：风险极低，流动性强，收益低但稳定
- **债券基金**：
  - 纯债基金：主要投资债券等固定收益资产，通常不投股票、不打新，不含普通可转债；具体范围核对基金合同
  - 中短债基金：主要投向剩余期限较短的债券，通常比长期债券对利率变化更不敏感；仍可能持续下跌，收益和流动性都非保证
  - 可转债：兼有债权和转股权利，价格可能明显高于到期兑付金额；信用风险和高价买入都可能造成亏损，利息不等于本金保底
  - 债券基金投向：国债、地方债、企业债、金融债、短融、中票、同业存单
- **混合基金**：
  - 偏债混合型（债多股少）
  - 平衡混合型
  - 偏股混合型（股多债少）
- **股票基金**：股票仓位≥80%
- **主动基金**：基金经理选股调仓，赚的是选股调仓的钱
- **被动指数基金**：按既定规则跟踪指数，规则较透明；收益取决于指数对应资产，不保证长期盈利
- **分类不要混在一个层级**：股票/债券/混合侧重资产投向，主动/被动侧重管理方式，ETF侧重产品运作与交易形式；一只基金可以同时是“股票型、被动、ETF”。[基金业协会：债券基金分类说明](https://investor.amac.org.cn/investread/tzbdjczs/202405/t20240516_25547.html)

#### 3.2.3 指数基金细分

- **宽基指数**：行业分散
  - 沪深300：代表沪深市场中规模大、流动性好的300只证券，不等于质量最好的300家公司，也不代表全部A股
  - 中证500：主要反映沪深市场中盘证券表现；“中盘”不等于必然高成长
  - 中证1000：主要反映沪深市场小盘证券表现；“小盘”不等于细分龙头或一定有潜力
  - 中证2000：小微盘
- **行业指数基金**：集中于特定行业，容易受产业周期、政策及估值变化影响，不能统一视为“风险中等”
- **策略指数基金（Smart Beta）**：如红利、低波动

#### 3.2.4 基金选择与避坑

- **基金判断标准**：
  - 标准1：成立较久有更多可观察记录；成立3年只是筛选参考，不是质量保证
  - 标准2：规模须匹配策略；主动小盘策略可能受容量限制，宽基ETF规模大通常不是同样的问题，不存在通用的“2亿~50亿最优”
  - 标准3：看不同市场阶段的表现，不只看短期排名；3年不一定覆盖完整牛熊周期
  - 标准4：风控数据，最大回撤&波动率
  - 标准5：基金经理任职稳定，不频繁换人
  - 标准6：核对业绩由哪位经理、在什么策略和市场阶段实现，不能把基金全部历史收益归给现任经理
- **避坑指南**：
  - 新基金：成立时间短，无历史业绩参考，仓位在建，净值波动不稳定，费率不低，可能有封闭期
  - 行业基金：波动大，牛短熊长
  - 网红热点基：短期资金扎堆+情绪炒作
  - 短期暴涨、排名冲顶基：大多是赌对了不是实力，市场情绪最热，估值最贵，后期回跌风险大
  - 跟踪误差：通常在跟踪同一指数、相近区间和口径下比较，偏离较小更贴近目标；偏离大要查费用、现金仓位和调仓等原因
  - 规模太小：可能清盘，选股跑输，调仓不及时
  - 费率低：管理费等综合成本低
  - **最大回撤**：观察区间内从某个高点到之后低点的最大跌幅。例如净值从1.25跌至1.00，回撤20%；必须用相同观察区间比较，历史值也不是未来亏损上限。

#### 3.2.5 定投

- **原理**：固定金额投资→价格低时买到更多份额、价格高时买到更少份额；只有买入动作，不会自动实现“高抛”。
  - 例：先后用1000元在净值1元、0.8元时买入，合计2250份，平均成本约0.889元；若净值仍为0.8元，总资产1800元，依然亏损10%（未计费用）。
- **周投 vs 月投**：先保证现金流可持续、费用合适和执行稳定；频率本身不能决定收益，也不能保证月投比周投更平滑。
- **止盈与退出**：
  - 定投可以分散买入时点，但无法消除标的持续走弱的风险；“止盈不止损”不是通用原则
  - 长期买入逻辑被破坏、产品发生不适合自己的变化，或用钱期限改变，都需要重新评估，不能仅因亏损拒绝退出
  - 原记录的15%~20%、25%~30%分批卖出及回撤5%止盈，只能视为待验证的个人规则；需先明确适用标的、资金目标和回撤从哪个高点计算
  - 与复盘对应：买入前写清持有依据和退出条件；不能一面按长期逻辑买入，一面因短期盈利临时清仓。[证监局投教材料：定投不保证收益](https://www.csrc.gov.cn/shanghai/c105564/c6406639/6406639/files/权益类基金投资手册-投资时.pdf)

#### 3.2.6 红利基金

- **定义**：高股息红利策略基金，筛选连续多年稳定现金分红、股息率排名靠前的上市公司
- **收益来源**：股息分红收益 + 资本利得收益
- **按选股分类**：
  - 传统单因子红利：纯按股息率
  - 红利+低波动双因子
  - 红利+盈利质量
  - 红利+价值
  - 跨境港股红利：股息更高，波动大
- **产品类型**：
  - 场内ETF：股票账户买卖
  - 场外联接基金
  - 主动红利基金：管理费高
- **分红机制**：
  - 时间：以基金分红公告的权益登记日及份额登记规则为准；登记日当天申购、赎回是否享有分红要核对公告，不能只看收盘时是否提交买单
  - 除息日：基金净值扣除分红金额，净值主动下跌
  - 红利发放日：现金到账或自动增加基金份额
  - 两种形式：现金分红（份额通常不变、净值下调、收到现金）、红利再投资（分红转购份额）；忽略市场波动与费用，两者均不会凭空增加总资产
  - 除息：基金资产的一部分从净值转为现金分配或再投资份额，不会凭空创造收益；红利策略基金持有分红股票，也不代表基金必须按月分红
  - 例：持有1000份、净值1.20元，每份分红0.05元，忽略市场波动后变为净值1.15元的1000份加50元现金，总额仍是1200元
- **优缺点**：
  - 可能优势：偏向有分红记录的企业，在部分市场阶段较有防御性；是否分散、是否低估需看具体指数规则和持仓
  - 缺点：成长牛市大幅跑输、行业绑定周期（经济下行分红缩减）、弹性不足、分红不是刚性兜底
- **分红税规则**：
  - 境内证券投资基金从证券市场取得的规定范围内收入，适用暂不征收企业所得税等政策，不能推广到所有基金、所有收入
  - 境内公募基金向个人分配时通常不再另扣个税，不代表底层股票股息从未承担税负；跨境产品还需核对来源地税制。[税务总局：证券投资基金税收规定](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202736/content.html)

### 3.3 股票投资

- **普通股**：代表公司股权一定比例的证券
- **年底分红**：扣除各项开支后的利润实际属于股东
- **资本增值**：间接收益方法，公司盈利↑→股票价值↑→低买高卖获利
- **价值股**：成熟公司，股息更高
- **成长股**：规模较小，成立时间短，未来潜力大的公司
- **股息分红不是义务**
- **股票 vs 债券**：
  - 股票：公司所有权的一部分；公司总市值 = 股价 × 总股数，持仓市值 = 股价 × 持股数
  - 债券：成为贷款人，有固定收益的产品
  - 最佳情况：股票暴富/债券收取一定利息
  - 最差情况：股票可能归零；债券违约后也可能无法收回本金，清偿顺序优先不代表必能获偿
  - 股票风险更大，上涨潜力非常高，亏损相对容易；债券上涨潜力有限，收益可能大，损失可能小
- **资产配置**：x%股票+y%固收，决定投资组合的潜在风险和回报

### 3.4 债券投资

- **国债**：储蓄国债按发行条款还本付息，提前兑取可能扣息、收费；记账式国债可交易，卖出价格可能低于买入价
- **银行大额存单**：属于存款，不是债券；能否提前支取或转让、如何计息，以具体产品条款为准
- **债券基金**：持有债券的基金，不等于持有单只债券到期；净值和到账时间都会变化
- **公募REITs**：与基础设施项目收益及资产价值相关，可在交易所买卖；分派率不等于总收益率，价格下跌可能抵消现金分派
- **混合基金**：股债比例和策略差异很大，属于此处对照产品，不能当作债券或固定收益产品理解
- **收益口径**：原记录中的国债2.5%~3%、债基3%~5%等不能视为固定年化。国债和存单看当期发行条款，基金看对应期间的含分红总回报，历史收益不保证未来收益。

### 3.5 资产配置

- **大类资产配置**：现金/货币基金、债券基金、指数基金、主动权益基金、公募REITs
- **风险比较**：先看底层资产和持仓比例，再看集中程度、信用质量与流动性；不能机械使用“混合→指数→主动权益→REITs”的固定风险排序
- **股债配置比例**：20/80、50/50、80/20
- **把比例换成金额**：10万元组合中权益占50%，若仅假设权益下跌30%、其余资产不变，组合约亏1.5万元；这只是帮助理解风险的情景，实际股债可能一起下跌。

## 四、企业金融

### 4.1 会计基础

#### 4.1.1 资产负债表

- **会计恒等式**：资产 = 负债 + 所有者权益
- **资产**：企业过去的交易或事项形成的、由企业拥有或控制的、预期给企业带来经济利益的资源（能赚钱、变现、减少支出）
- **负债**：企业过去的交易或事项形成的、预期会导致经济利益流出企业的现时义务
- **所有者权益（股东权益）**：企业资产扣除负债后，由所有者享有的剩余权益
- **报表时点**：资产负债表看某一天的“家底”，利润表与现金流量表看一段时间的经营与收付款。分析时先统一期间、单位和合并报表口径。

#### 4.1.2 利润表

- 反映企业在一定会计期间的经营成果
- 营业利润：在营业收入扣除营业成本、税金及附加、期间费用等的基础上，再计入适用报表格式下的投资收益、减值等损益项目；读表时核对正负号，损失项目若已列负数，不能重复减一次
- 利润总额 = 营业利润 + 营业外收入 - 营业外支出
- 净利润 = 利润总额 - 所得税费用
- **扣非净利润**：扣除非经常性损益后的净利润，有助于观察盈利持续性；不等于只保留主营业务利润，仍需查看非经常性损益明细与具体认定
- **利润不等于到账**：赊销100万元，符合收入确认条件时可能先形成收入和应收账款；客户后来付款才形成收现，不能收到钱时再确认一遍收入。

#### 4.1.3 现金流量表

- 反映企业在一定会计期间现金及现金等价物的流入、流出与净变动情况
- 分为：经营活动现金流、投资活动现金流、筹资活动现金流
- **经营现金流净额的简化理解**：净利润 + 折旧摊销等非付现调整 - 经营性营运资本增加，还需调整投资、筹资相关损益等项目；不能用此式直接代表全部现金流
- 现金流帮助验证利润的收现质量，但现金流本身也需结合业务和报表附注分析

### 4.2 财务分析

#### 4.2.1 盈利能力

- **毛利率** = (营业收入 - 营业成本) / 营业收入 × 100%
  - 反映收入扣除营业成本后的空间；高毛利不自动等于高净利润或强竞争力，应与同行和自身历史比较
- **净利率** = 净利润 / 营业收入 × 100%
- **营收增长率** = (本期营收 - 上期营收) / 上期营收 × 100%
- **净利润增长率** = (本期净利润 - 上期净利润) / 上期净利润 × 100%
- **同比增长率** = (本期数 / 去年同期数 - 1) × 100%
- **环比增长率** = (本期数 / 上一相邻期间数 - 1) × 100%
  - 例：去年同期收入100万元、今年120万元，同比增20%，不是120%；基期为零或负数时，不能机械套用常规增长率解释
- **ROE（净资产收益率）** ≈ 净利润 / 平均净资产；比较上市公司时核对归母口径及加权平均口径。高ROE可能来自盈利强，也可能受高负债或净资产很小影响。
- **真实增长**：剔除季节、行业必看

#### 4.2.2 费用率

- **销售费用**：为了卖东西花的钱
- **管理费用**：公司运转的花销
- **财务费用**：借钱花的钱
- **单项费用率** = 单项费用 / 营业收入 × 100%
- **三项费用率** = (销售+管理+财务) / 营业收入 × 100%
  - 需结合行业、毛利率和企业阶段比较，不能用30%、50%等统一阈值判断优秀或亏损；研发费用单列时还需一并观察

#### 4.2.3 偿债能力

- **资产负债率** = 总负债 / 总资产 × 100%
  - 安全水平因行业和资产质量而异，不能跨行业套用40%或60%的阈值
  - >100%：账面净资产为负，说明资不抵债；是否已发生现金支付困难，还要看现金流、到期债务和融资安排
- **流动比率** = 流动资产 / 流动负债
  - 还要看流动资产中有多少可支配现金、应收款能否收回、存货能否卖出；大于2不保证安全，小于1也不自动等于爆雷
- **有息负债占比**：经营性负债（无息）vs 有息负债

#### 4.2.4 资产质量

- **流动资产**：
  - 货币资金：公司手里的现金+活期存款+随时能用的钱，长期过低企业抗风险差
  - 应收账款：销售等形成的待收款项；增速显著高于收入时，需查账龄、回款和坏账计提，不能直接认定营收造假
    - **账面余额**：客户尚未支付、账上记录的应收金额，尚未扣除坏账准备。
    - **坏账准备**：针对预计可能收不回的部分计提的抵减项目，不是另外存放的一笔现金，也不代表损失已经确定发生。
    - **应收账款账面净额 = 应收账款余额 - 坏账准备**，是资产负债表中列示的应收账款金额。
    - **例子**：应收账款余额100万元、坏账准备8万元，账面净额为92万元；不能把100万元全部当成可收回资产。
    - **注意**：净额92万元也不保证最终全部收回，仍需结合账龄、客户信用和实际回款判断。
  - 存货：原材料、半成品、没卖出去的成品、库存商品；风险：过时、损耗、贬值
- **非流动资产**：
  - 固定资产：长期使用的有形资产（厂房、设备等）；当期折旧按用途计入相关资产成本或费用，累计折旧是历年计提的累计额，不是当期全部费用
  - 无形资产：长期持有无实物形态（专利、商标、著作权、合同权）；商誉≠无形资产
  - 长期股权投资
  - 其他非流动金融资产/其他权益工具投资

- **负债**：
  - **流动负债**（1年内必须结清）：
    - 短期借款：临时周转或银行借贷，会拉低利润，加大短期偿债压力
    - 应付账款：欠供应商的钱；增加可能来自业务扩张、较强议价能力，也可能是拖欠货款，要结合账龄和采购分析
    - 预收款项/合同负债：先收钱、后履约；通常提示待履行的业务义务，但仍有交付、退款和成本风险，不能等同于未来利润有保障
  - **非流动负债**：
    - 长期借款：向银行/金融机构借入的长期贷款，长期借款↑→长期扩张意愿↑，长期偿债压力↑
    - 应付债券：发行债券形成的偿付义务；能发债不等于信用优秀，还要看偿债来源、期限和担保等信息
    - 长期应付款
    - 递延所得税负债等

#### 4.2.5 所有者权益

- 所有者权益通常包括股本/实收资本、资本公积、其他综合收益、盈余公积、未分配利润等；合并报表还需区分归母权益与少数股东权益
- **股本**：营业执照的注册资本
  - 实缴：股东初始投入的账面本金
  - 股份制公司称股本，有限公司叫实收资本
- **资本公积**：溢价发行，不属于企业经营利润
- **未分配利润**：公司经营攒下的留存净利润，可后续分红，也可留存扩大企业经营

#### 4.2.6 利润表造假识别

1. **提前确认收入**：货没发服务没做，提前算营收虚增利润
2. **虚构营收**：凭空造假客户、合同、流水
3. **延迟记录成本费用**：当期开销亏损不入账，压成本、升利润
4. **变卖资产凑利润**：收益可能真实但不可持续；非主营收益不自动等于造假，关键是会计处理和披露是否合规
5. **减值计提随意**：少提坏账、存货资产减值，少扣损失，虚抬利润
6. **关联交易做流水**：关联公司低买高卖虚假做大营收
7. **政府补助一次性入账**：补助非持续收益，算作常规盈利，误导盈利稳定性

#### 4.2.7 现金流分析

- **经营现金流**：
  - 正数：经营现金流入大于流出，不自动等于盈利真实或可持续
  - 三种利润表对照：
    - 利润正、经营现金流负：可能在赊销、备货、扩张，也可能回款恶化；需查持续时间和原因，不能直接认定坏账
    - 利润负、经营现金流正：可能受折旧减值、回收旧款或预收款影响，不代表现金一定安全
    - 同步同向增长：是较好的核对线索，仍需检查一次性因素和现金是否受限
- **投资现金流**：
  - 流入：变卖闲置设备、厂房、旧资产，收回对外投资本金、投资分红、理财项目回款
  - 流出：购置固定资产、设备、厂房、无形资产，对外股权投资、理财、收购其他公司
  - 持续大额流出：公司扩产，偏成长型
  - 大额流入、短期回血：警惕主业疲软
  - 长期净额为负：表示投资现金流出大于流入，可能来自持续投入；“靠变卖度日”对应的通常是处置资产形成流入，两者不能写反
- **融资现金流**：
  - 流入：银行借款、发行债券（举债融资）、增发股票、股东增资（股权融资）
  - 流出：偿还借款本金、兑付债券、支付股息分红、回购股票
- **三表联读例子**：赊销增加会同时影响收入和应收账款，却未必增加经营现金流；借款到账增加现金与负债，却不形成营业收入。[财政部：现金流量表准则](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46250.htm)

### 4.3 估值指标

- **PE市盈率** = 股价 / 每股净利润，表示股价相对于每股盈利的水平，不等于企业盈利能力本身
- **PB市净率** = 股价 / 每股净资产，衡量资产估值
- **PS市销率** = 市值 / 营业收入，适合成长型公司
- **股息率** = 年度每股现金分红 / 当前股价；也可用同口径现金分红总额 / 总市值
- **估值分位**：当前估值在历史区间的位置（0%~100%）
- **PE低但净利润来自非主营业务**：伪估值，回避
- **PB低**：可能意味着估值较低，也可能反映盈利能力弱或市场担忧资产质量；不能直接推出负债、商誉和应收账款一定高
- **估值比较先统一口径**：PE要区分过去一年、上年度与预测利润；亏损企业的PE通常不适合照常比较。历史估值分位低，也可能受盈利高点或样本区间影响，不等于价格必然低估。

## 五、商业与创业金融

### 5.1 商业模式

- **五步闭环**：获客 → 转化 → 成交 → 复购 → 裂变
- **获客（流量）**：让潜在客户看到产品
- **种草（信任）**：展示价值、案例、口碑打消客户顾虑
- **成交**：完成首次付费
- **复购/留存**：服务/品质落地，推动客户再次消费
- **裂变回流**：老客户推荐新客户

### 5.2 盈利模式

- 服务费模式：靠专业、劳务、广告，把控单位时间产值
- 差价模式：低买高卖，把控进货成本、流转速度
- 订阅模式：提前锁定应收，培养长期复购
- 流量变现：吸附流量，流量规模+精准度
- 增值服务模式：基础产品低价引流靠附加服务盈利

### 5.3 成本与定价

- **成本结构**：
  - 固定成本：不随业务变动，必须支出的费用
  - 可变成本：随业务量同步变动的支出
  - 盈亏平衡法：营收覆盖全部成本是盈利基准线，优先压低固定成本
  - 简化计算：盈亏平衡销量 = 固定成本 / (单价 - 单位可变成本)。假设每月固定成本1万元、单价100元、单位可变成本60元，则需卖250件；前提是这些成本和售价在该销量范围内不变，且未遗漏税费等支出。
- **定价策略**：
  - 成本加成定价：售价 = 单位总成本 × (1+期望利润率)
  - 随行就市定价：同质化严重产品，拼价格参考同行价格
  - 引流定价：爆款单品微利/保本定价，用来引流，靠其他产品盈利
  - 价值定价（高客单/服务）：按给用户创造的价值定价
  - 阶梯定价：量大价低
  - 撇脂定价：新品初期定高价，逐步降价
  - **加成率与毛利率**：成本80元、售价100元，加成率为25%，毛利率为20%；二者分母不同，不能混用。

### 5.4 融资

- **初始资金**：自有资金、亲友借款、政府补贴/创业扶持、个人经营贷/信用贷、天使投资/小额种子融资、合伙人出资
- **银行经营贷/企业授信逻辑**：
  - 个人经营贷：个体户、个人无限责任
  - 企业经营贷：公司作为借款人时承担还款义务；若股东或配偶另签个人保证，仍可能承担相应责任，不能只看“有限公司”名称
  - 银行授信关注：经营真实性、现金流、征信、抵押物担保
- **常见产品**：税贷、发票贷、流水贷、抵押经营贷
- **股权融资**：
  - 出资规则写入协议
  - 避免股权50:50
  - 权责与决策分明
  - 避免股权均分僵局
  - 锁定期与退出条件需要依法写入协议，不能把“1~2年不得退股”当作所有项目的法定规则

### 5.5 税务

- **两类纳税人**：小规模 vs 一般纳税人
  - 小规模：年应征增值税销售额未超过500万元，符合条件也可登记为一般纳税人；这是增值税分类，不等于企业所得税的“小型微利企业”
  - 一般纳税人：一般计税适用13%/9%/6%等税率，按规定凭合规扣税凭证抵扣进项税额，不是拿到任何发票都能抵扣
  - **2026~2027年小规模优惠**：按月、按季计税的起征点分别为月销售额10万元、季度销售额30万元；按现行增值税法，未达到起征点免税，达到则按规定全额计税。除销售、出租不动产或转让土地使用权之外的应税交易，适用3%征收率减按1%征收；专票等情形另核对规则。[增值税法](https://tianjin.chinatax.gov.cn/11200000000/0300/030004/03000418/p20241226144544917.shtml)、[2026年第10号公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5247434/content.html)
- **四大基础税种**：
  - 增值税：针对应税交易等征收，并非所有收入都要交；一般计税的简化理解为“销项税额 - 可抵扣进项税额”，简易计税另算
  - 企业所得税：应纳税所得额不等于会计利润，需按税法调整；个人独资、合伙企业本身不缴企业所得税，但其他适用主体不限于公司
  - 小型微利企业：从事非限制、非禁止行业，并同时满足年度应纳税所得额不超过300万元、从业人数不超过300人、资产总额不超过5000万元等条件；截至2027年底的现行优惠折算实际税负为5%，不是只看利润不超过300万元。[税务总局优惠说明](https://www.chinatax.gov.cn/chinatax/n810356/n3010387/c5220435/content.html)
  - 个人所得税：个体经营者、个人独资企业投资者及合伙企业自然人合伙人等按适用规则缴纳经营所得个税；6万元减除费用不是每个项目各免6万元，综合所得与经营所得之间不能重复扣除。[税务总局扣除规则](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/202502/t475327.html)
  - 附加税费：城建税、教育费附加、地方教育附加通常与实际缴纳的增值税、消费税等挂钩，还需核对减免规定
- **报税周期**：
  - 增值税常见小规模按季、一般纳税人按月，但实际以主管税务机关核定的计税期间为准，不能只凭纳税人标签判断
  - 企业所得税预缴、年度汇算，工资薪金个税代扣与经营所得个税预缴、汇算，属于不同申报事项；先区分税种、所得类型与主体，再看申报期限
- **流程**：收集票据 → 核算收入开票数据 → 申报期内在电子税务局线上填报 → 核对税款、对公账户自动扣款 → 每年5月31日前完成企业所得税年度汇算（多退少补）

## 六、金融风险与法律保护

### 6.1 征信与借贷

- **征信**：
  - 查询：每年免费2次，非本人必须书面授权
  - 不良记录：一般自不良行为或事件终止之日起保留5年，不是从首次逾期之日起倒计时；具体更正及适用政策另核对
  - 异议更正：身份被冒用、信息录错等可向信息提供者或征信机构提出异议，核实后更正；不能把异议申请当作删除真实逾期记录的工具。[征信中心说明](https://www.pbccrc.org.cn/zxfw/gr/bg/20210701/6ad6f4bb659acc3c652d5db9ab83a0ef.html)
  - 无任何机构可花钱洗白逾期
- **逾期分级影响**：
  - 逾期天数、次数、金额、是否结清都会影响机构评估，不能把“30天以内”统一视为影响小
  - **征信逾期不等于失信被执行人**：逾期超过90天不会自动进入法院失信名单；后者涉及执行程序及法定失信情形，由法院依法认定。[法院关于失信认定的说明](https://www.gdcourts.gov.cn/sfgk/zxxxgk/zxgf/content/post_1046327.html)
- **民间借贷**：
  - 利率司法保护上限：通常以合同成立时一年期LPR的四倍为基准，超出部分不受司法保护；不等于一超过就构成犯罪，也不能直接套用到持牌金融机构贷款。[最高法说明](https://www.court.gov.cn/zixun/xiangqing/249051.html)
  - 必备证据链：借条完整要素、转账流水、可辨认记录
  - 无效借贷：高利转贷、非法集资、信贷套现、套路贷
  - 催收与诉讼：时效3年内起诉，中断时效（书面催款、积极主张）
  - 自己对外享有的债权也可能涉及依法保全或执行，不能把“钱已借给别人”视为天然隔离

### 6.2 担保与保险法律

- **担保**：
  - 一般保证：有先诉抗辩权，先执行债务人名下财产
  - 连带保证：符合约定和法定条件时，债权人可在保证范围内直接请求保证人承担责任
  - 保证方式没有约定或约定不明确时，依民法典按**一般保证**承担责任；要结合全文判断，不能仅看有没有写“一般保证”四个字
  - 担保范围：看保证合同、主债务、约定限额和保证期间，不能概括为“签字即无限兜底”
  - 解除或免除责任：需依法结合清偿、免除、保证期间等判断；债权转让未通知保证人，是该转让对保证人不发生效力，不等于原保证责任全部消失。[民法典第686、691、692、696条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_60fb3863b7364b759123a42d1df568ca.html)
- **保险法律**：
  - **如实告知**：对保险人的投保询问如实、完整回答，涉及就诊、检查异常、既往病史等应按问题范围核对；有疑问通过保险公司正式渠道确认并留存结果，不把销售人员口头说“没事”当作承保结论。
  - **核保结果**：可能为正常承保、加费、除外、延期或拒保等；接受后应查看保单中的特别约定，不能把产品的一般保障范围当作自己全部适用的范围。
  - **免责条款**：保险人对免除其责任的格式条款负有提示和明确说明义务；是否发生争议，还需结合条款、提示说明证据及事故事实判断。
  - **“两年不可抗辩”误区**：保险法对解除权的限制有条件，不能理解为隐瞒病史满两年就必赔，更不会把不在合同责任范围内的事故自动变成可赔。[保险法第16、17条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_4c715a53f3d4402c89f62ae77809f638.html)
  - **理赔流程**：及时就医和报案 → 核对责任与申请材料 → 提交申请并留存回执 → 按要求补充材料 → 接收核定结果与款项。需要紧急救治时不能为了等待理赔答复而耽误治疗。
  - **材料举例**：病历、诊断或病理资料、费用清单及票据、医保结算单、事故或伤残证明、身份证明和收款账户；具体随险种与事故不同，不是每项都适用。费用报销与定额给付需要的证明也可能不同。
  - **核定与付款是不同节点**：依法应及时核定，复杂情形一般在30日内核定，但合同另有约定的除外；属于保险责任的，达成赔偿或给付协议后通常应在10日内履行，合同对期限有约定的按约履行。不能简化为“报案后10天必到账”。
  - **拒赔与争议**：要求书面拒赔通知及理由，逐项对照条款和证据；保险法规定对不属保险责任的，核定后3日内发出通知并说明理由。可先向保险公司申诉，再依法选择调解、监管投诉或举报、仲裁、诉讼等适用渠道；不轻信“代理退保”“保证全额退”的承诺。[保险法第21~24条](https://xzfy.moj.gov.cn/c/2021-01-06/487603.shtml)、[监管部门：保险销售和退保风险提示](https://www.nfra.gov.cn/branch/hainan/view/pages/common/ItemDetail.html?docId=1077959)
  - 财富类保险：不能统一认为保险金都不属于遗产；例如死亡保险金无指定受益人等法定情形下，会按遗产处理。保单现金价值、死亡保险金、年金领取款也应分别判断。[保险法第42条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_4c715a53f3d4402c89f62ae77809f638.html)
  - 法律隔离逻辑：投保人、被保人、受益人架构设计
  - 避坑：恶意负债后买保险无法隔离，属于可执行财产

### 6.3 资产隔离

- **婚前财产隔离**：
  - 婚前存款单独银行卡存放，婚后不转入不用于日常消费，流水完整留存
  - 婚后工资用于日常消费，婚前单独账户出资，婚后不追加共同资金
  - 可追工具：婚前财产协议（签字即生效，无需公证）
- **婚后**：
  - 夫妻共同债务判定：看双方共同签名、事后追认等共同意思表示，以及家庭日常生活需要等情形；超出日常生活需要的单方负债，还需看债权人能否证明法定共同用途，不能只看谁签字
  - 单方赌博负债不属于共同债务
  - 家人通常不因亲属关系自动承担债务，但共同借款、担保、夫妻共同债务等需另行判断；夫妻内部财产协议也不当然约束不知情债权人。[民法典第1064、1065条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_60fb3863b7364b759123a42d1df568ca.html)
- **经营隔离**：
  - 必须公私账户分离，禁止私卡收经营款
  - 签字前书面约定债务归属，留存证据

### 6.4 公司法与合伙协议

- **企业类型选择**：有限公司股东通常以认缴出资额为限承担责任；普通合伙人承担无限连带责任，有限合伙人通常以认缴出资额为限承担责任，不能把所有合伙人一概写成无限连带。[合伙企业法第2条](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5211810/content.html)
- **公司法核心**：
  - 认缴出资：认缴不等于不用实缴；2024年7月1日起新设有限责任公司，股东认缴出资原则上应自公司成立之日起5年内缴足，存量公司另有过渡安排。公司不能清偿到期债务时，还可能触发出资加速到期。[公司法第47、54条](https://www.samr.gov.cn/djzcj/zcfg/fl/art/2026/art_9b4263a169cf43c2aba950cfc9ac1af2.html)
  - 公私分离：严禁混同
  - 公司章程：约定分红、表决、退出股权稀释规则
- **合伙/股东协议**：
  - 必须书面约定，拒绝口头
  - 退出机制：中途撤资、业绩不达标、出轨同业→约定股权回购价
  - 不凑股份：谁管财务、谁管业务、重大决策投票规则
  - 股权代持规范：隐名股东显名股东书面协议，防止工商登记人独自背负债务

### 6.5 劳动合同与知识产权

- **劳动合同**：
  - 自用工之日起一个月内订立书面劳动合同，依法参保缴费；“一个月”不要一律换算成30天
  - 用人单位超过一个月不满一年未依法订立书面劳动合同，通常涉及相应期间的二倍工资责任，具体适用还需结合事实与法定例外
  - 辞退合规：区分解除原因、提出方、程序和补偿条件；协商解除不一定都有补偿。违法解除时，劳动者可依法主张继续履行或按经济补偿标准二倍计算的赔偿，不能将2N用于一切辞退。[劳动合同法第46、48、82、87条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_0abfdd261c03417b949df19d869add8d.html)
  - 证据留存：考勤记录、加班签字、绩效考核、工资签收文件
- **知识产权**：
  - 商标：品牌提前注册
  - 著作权：符合条件的文案、图片、软件、设计作品等依法享有著作权，登记可辅助举证，通常不是权利产生的前提
  - 专利：自有产品外观/技术，申请实用新型/外观专利
  - 红线：不随意使用网络图片、字体、素材

### 6.6 合同纠纷

- **全流程处理**：
  - 签约前审查：对方资质、格式合同免责条款、违约赔付、争议管辖法院
  - 履约留证：送货单、对账单、聊天记录、付款凭证全部归档
  - 违约处置：催告函、违约金计算、起诉流程、财产保全
- **公章管理**：专人保管、用印登记、禁止空白合同盖、杜绝盗用风险
