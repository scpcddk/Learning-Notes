### 简答题（每题5分）

**11. 列表与元组的主要区别（答出任意三点即可满分）**  
- 可变性：列表可变，元组不可变。  
- 语法：列表用 `[]`，元组用 `()`（单元素需加逗号）。  
- 性能：元组速度更快、内存更小。  
- 使用场景：列表用于动态数据，元组用于常量或字典键。  
- 可哈希性：元组可哈希（可作为字典键），列表不可。  

**12. 浅拷贝与深拷贝（定义+举例，各2.5分）**  
- **浅拷贝**：只复制最外层对象，内部嵌套元素仍共享引用。  
  例：`copy.copy(obj)` 或 `obj.copy()` 或 `obj[:]`。  
- **深拷贝**：递归复制所有层级，生成完全独立的新对象。  
  例：`copy.deepcopy(obj)`（需 `import copy`）。  

### 编程题（每题10分）

**13. 使用 Counter 实现（5分）**  
```python
from collections import Counter

def count_chars(s):
    return dict(Counter(s))
```
- 若使用普通字典实现（加 3 分）：  
```python
def count_chars(s):
    d = {}
    for ch in s:
        d[ch] = d.get(ch, 0) + 1
    return d
```
- 需正确遍历字符串并计数，返回字典格式正确。

**14. 两种去重并保持顺序的方法（每种5分）**  
- **方法一：利用字典（Python 3.7+ 保持顺序）**  
```python
lst = [3, 1, 2, 3, 1, 4, 2, 5]
result = list(dict.fromkeys(lst))
```
- **方法二：循环 + 集合辅助**  
```python
seen = set()
result = []
for x in lst:
    if x not in seen:
        seen.add(x)
        result.append(x)
```
- 其他可行方法（如使用 `OrderedDict`）也可得分。
