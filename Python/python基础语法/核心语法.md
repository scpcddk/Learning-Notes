## **一、入门基础**

### **(一).运行原理**

#### 1.运行方式

+ 交互式（REPL）：终端输入 `python`，逐行执行，即时反馈
+ 脚本式：编写 `.py` 文件，执行 `python filename.py`

#### 2.执行原理

+ 源码(.py) → 字节码(.pyc) → Python虚拟机(PVM) → 运行结果
+ Python 是==解释型语言==（严格说是"先编译后解释"）
+ 字节码是平台无关的中间代码

---

### **(二).动态类型特性**（变量即标签，类型随赋值改变）

+ **变量是标签，不是盒子**
+ **变量本身没有类型，对象才有类型**,无需声明类型，运行时动态确定
+ 赋值只是让变量"指向"对象,同一变量可先后指向**不同类型**的对象
+ 多个变量可以指向同一个对象：`a = b = [1, 2, 3]`

```python
a = 10      # a 标签贴在 10 这个对象上
a = "hello" # a 标签撕下来，贴到 "hello" 对象上
```

---

### **(三).==一切皆对象==**

#### 1.什么是"对象"

+ 对象 = 数据（属性）+ 行为（方法）
+ 对象存储在堆内存中，由垃圾回收器管理

#### 2.所有 Python 元素都是对象

+ 可以动态给对象添加属性
+ 可以将函数作为参数传递（高阶函数）
+ 所有类型都有统一的类型体系

## **二、数据存储与运算**

### ==**(一).字面量与变量**==

#### **1.字面量与c++对比**

+ 字面量是直接书写的**固定值**
+ `type()` 语句可得到数据类型，`type(要查看的数据类型)`
+ `isinstance()` 检查是否属于指定的类型，返回 `bool` 值，`isinstance(数据，类型)`

| 类别 | Python | C++ | 说明 |
| ------ | -------- | ----- | ------ |
| **整数精度** | **无限精度，无溢出** | 受类型范围限制 | Python可计算超大整数 |
| **数字分隔符** | 支持 `1_000_000` | 不支持 | 提高可读性 |
| **布尔值** | `True` / `False`（首字母大写） | `true` / `false` | Python中布尔是`int`子类 |
| **布尔运算** | `True + True == 2` | 不允许 | **Python布尔可参与算术** |
| **多行字符串** | **三引号** `"""..."""` | 需用 `\n` 或宏 | Python原生支持 |
| **原始字符串** | `r"C:\path"` | 无 | **原始字符串(r)** 转义字符失效，按原样输出 |
| **复数** | `3 + 4j` | 无内置 | Python原生支持复数 |
| **空值** | `None`（对象） | `nullptr` / `NULL`（指针） | `None`是单例，用 `is` 比较 |
| **类型后缀** | 不需要 | `100L` / `3.14f` | Python自动适配 |

#### **2.变量与c++对比**

+ 变量是用来存储单个数据的**容器**
+ 一条语句可以定义多个变量，也可以连续赋值(`a,b = 1,"Python"`)

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| **变量本质** | 标签（贴在对象上） | 内存容器（存储值） |
| **类型绑定** | 变量无类型，对象有类型 | 变量有固定类型 |
| **类型改变** | 允许，随时可指向不同类型 | 不允许 |
| **声明要求** | 不需要，直接赋值即创建 | 必须声明类型 |
| **未初始化** | **不存在（赋值才有变量）** | 存在（值不确定） |
| **指针 / 引用** | **所有变量都是引用语义** | 分值语义、指针、引用 |
| **内存管理** | 自动垃圾回收 | 手动 new/delete |

### **(三).逻辑运算符短路运算（and / or / not）**

#### 1. 逻辑运算符差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| **与** | `and` | `&&` |
| **或** | `or` | `\|\|` |
| **非** | `not` | `!` |
| **返回值** | 返回操作数本身（非布尔） | 返回布尔值（`true`/`false`） |
| **短路运算** | ✅ 支持 | ✅ 支持 |

+ **短路运算**:当表达式的左侧结果已经能决定整个逻辑表达式的最终值时，右侧的表达式将不再被执行或计算

#### 2.返回值对比示例

+ `and` 规则：返回**第一个假值**，否则返回**最后一个值**
+ `or` 规则：返回**第一个真值**，否则返回**最后一个值**

| 表达式 | Python | C++ |
| -------- | -------- | ----- |
| `10 and 20` | `20` | `true`(1) |
| `0 and 20` | `0` | `false`(0) |
| `10 or 20` | `10` | `true`(1) |
| `0 or 20` | `20` | `true`(1) |

### (二). `print()` 的 `sep` / `end` 参数

#### 1. `sep` 参数（分隔符）

+ **控制多个值之间的分隔字符串，默认为空格**

| 场景 | Python 代码 | 输出结果 |
| ------ | ----------- | --------- |
| 默认空格分隔 | `print("a", "b", "c")` | `a b c` |
| 自定义分隔符 | `print("a", "b", "c", sep="-")` | `a-b-c` |
| 无分隔符 | `print("a", "b", "c", sep="")` | `abc` |
| 换行分隔 | `print("a", "b", "c", sep="\n")` | `a`<br>`b`<br>`c` |
| 逗号+空格 | `print("2026", "07", "08", sep=", ")` | `2026, 07, 08` |

#### 2. `end` 参数（结尾符）

+ **控制输出末尾的字符，默认为换行符 `\n`**

| 场景 | Python 代码 | 输出结果 |
| ------ | ----------- | --------- |
| 默认换行 | `print("Hello")`<br>`print("World")` | `Hello`<br>`World` |
| 不换行 | `print("Hello", end="")`<br>`print("World")` | `HelloWorld` |
| 自定义结尾 | `print("Loading", end="...")` | `Loading...`（不换行） |
| 空格结尾 | `print("A", end=" ")`<br>`print("B")` | `A B` |

#### 3. `sep` 与 `end`组合使用

```python
# 输出：2026-07-08 16:52:00（不换行）
print(2026, 7, 8, sep="-", end=" ")
print(16, 52, 0, sep=":")

# 输出：姓名=张三, 年龄=20, 成绩=95.5
name, age, score = "张三", 20, 95.5
print(name, age, score, sep=", ", end="")
```

#### 4. Python vs C++ 对比

| 对比项 | Python (`print`) | C++ (`cout`) |
| -------- | ----------------- | -------------- |
| 默认分隔 | 空格（`sep=" "`） | 无分隔，需手动 `<< " "` |
| 默认结尾 | 换行（`end="\n"`） | 无换行，需手动 `<< endl` |
| 自定义分隔 | `sep` 参数 | 逐个 `<<` 拼接 |
| 自定义结尾 | `end` 参数 | 控制 `endl` 或 `""` |

```python
# Python
print("a", "b", "c", sep="-", end="!")
# 输出: a-b-c!
```

```cpp
// C++
cout << "a" << "-" << "b" << "-" << "c" << "!";
// 输出: a-b-c!
```

## **五、流程控制**

### **(一).缩进规则（无大括号）**

#### 1.缩进（Python vs C++ 核心差异）

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 代码块标记 | **缩进**（强制） | 大括号 `{}`（缩进仅用于可读性） |
| 缩进量 | 统一（通常4空格） | 无要求 |
| 混合缩进 | ❌ 禁止（Tab/空格混用报错） | ✅ 允许 |
| 代码块结束 | 缩进减少即结束 | 右大括号 `}` |

#### 2. 核心原理

> [!IMPORTANT]
> ==Python：缩进即语法==

+ 同一代码块必须缩进一致
+ 嵌套层级增加缩进
+ 建议使用4空格（PEP 8标准）

```python
# 缩进决定代码归属
if True:
    print("属于if")      # 4空格缩进
    print("也属于if")
print("不属于if")         # 缩进恢复，if块结束
```

### **(三).match-case**（模式匹配，Python 3.10+）

| 对比项 | Python `match-case` | C++ `switch` |
| -------- | --------------------- | -------------- |
| 语法 | `match 值:`<br>`case 模式:`<br>`代码`<br>`case _:`<br>`默认代码` | `switch (表达式) {`<br>`case 常量:`<br>`代码; break;`<br>`default:`<br>`默认代码; break;`<br>`}` |
| 匹配值类型 | **任意类型** | 整型、枚举、字符 |
| 字符串匹配 | ✅ 支持 | ❌ 不支持 |
| 类型匹配 | ✅ 支持 | ❌ 不支持 |
| 解包匹配 | ✅ 支持（列表、元组） | ❌ 不支持 |
| 条件守卫（guard） | ✅ 支持 | ❌ 不支持 |
| **多个值匹配** | `\|` 分隔 | 连续写多个 `case` |
| `break` 需要 | ❌ **不需要（不会贯穿）** | ✅ 需要 |
| 默认分支 | `case _:`(通配符，匹配任意值) | `default:` |

+ `case x:` 会将匹配到的值**绑定到变量 `x`**，后续代码可以使用该变量

```python
value = 42
# 使用 case _（不绑定）
match value:
    case 1:
        print("匹配到1")
    case _:
        print("匹配到其他值")   # 无法知道具体是什么值

# 使用 case x（变量绑定）    变量名可以任意取
match value:
    case 1:
        print("匹配到1")
    case other:
        print(f"匹配到: {other}")   # 可以使用 other，输出 42
```

| 对比项 | Python `range()` | C++ 循环控制 |

```python
range(stop)                # 0 到 stop-1，不包含stop本身

```

| 代码块标记 | 缩进 + 冒号 `:` | 大括号 `{}` |
| 条件括号 | 不需要 | 必须加 `()` |
| 条件类型 | 任意类型（自动转布尔） | 布尔表达式 |

### **(一).列表**

#### 1.基础性质

| 对比项 | Python `list` | C++ `std::vector` |
| -------- | --------------- | ------------------- |
| 可变性 | ✅ 可变 | ✅ 可变 |

#### 2.列表（list）操作

##### (1).增删改查

| 操作 | 方法/语法 | 说明 | 示例 |
| ------ | ---------- | ------ | ------ |
| **增** | `lst.append(x)` | 末尾添加 | `[1,2] → [1,2,x]` |
| | `lst.insert(i, x)` | 指定位置插入 | `[1,3] → insert(1,2) → [1,2,3]` |
| | `lst.extend(iter)` | 合并列表 | `[1,2] → extend([3,4]) → [1,2,3,4]` |
| **删** | `lst.pop()` | 移除并返回最后一个 | `[1,2,3] → pop() → 3, lst=[1,2]` |
| | `lst.pop(i)` | 移除并返回**索引** i | `[1,2,3] → pop(1) → 2, lst=[1,3]` |
| | `lst.remove(x)` | 移除第一个值为 x 的元素 | `[1,2,1] → remove(1) → [2,1]` |
| | `lst.clear()` | 清空所有元素 | `[1,2,3] → clear() → []` |
| | `del lst[i]` | 删除索引 i 的元素 | `[1,2,3] → del lst[1] → [1,3]` |
| **改** | `lst[i] = x` | 直接赋值修改 | `[1,2] → lst[1]=10 → [1,10]` |
| **查** | `lst[i]` | 访问索引 i 的元素 | `[1,2,3][1] → 2` |
| | `lst.index(x)` | 返回第一个值为 x 的索引 | `[1,2,3].index(2) → 1` |
| | `x in lst` | 判断是否存在 | `2 in [1,2,3] → True` |
| | `lst.count(x)` | 统计 x 出现次数 | `[1,2,1].count(1) → 2` |

##### (2).排序与反转

| 操作 | 方法/函数 | 说明 | 示例 |
| ------ | ---------- | ------ | ------ |
| 排序 | `lst.sort()` | 原地升序排序 | `[3,1,2] → sort() → [1,2,3]` |
| 降序 | `lst.sort(reverse=True)` | 原地降序排序 | `[1,2,3] → sort(reverse=True) → [3,2,1]` |
| 反转 | `lst.reverse()` | 原地反转 | `[1,2,3] → reverse() → [3,2,1]` |
| 排序（新） | `sorted(lst)` | 返回新列表，原列表不变 | `sorted([3,1,2]) → [1,2,3]` |

##### (3).复制

| 方法 | 说明 |
| ------ | ------ |
| `lst2 = lst.copy()` | 浅拷贝 |
| `lst2 = lst[:]` | 切片复制（浅拷贝） |
| `copy.deepcopy(lst)` | 深拷贝（需 `import copy`） |

##### (4).解包操作

| 操作 | 语法 | 示例 |
| ------ | ------ | ------ |
| 基础解包 | `a, b, c = [1,2,3]` | `a=1, b=2, c=3` |
| 变量交换 | `x, y = y, x` | `x=10, y=20 → x=20, y=10` |
| 星号解包 | `first, *rest = [1,2,3,4]` | `first=1, rest=[2,3,4]` |
| 星号解包（尾） | `*first, last = [1,2,3,4]` | `first=[1,2,3], last=4` |

+ 在元素解包时，`*`表示收集剩余所有元素，允许处理不定数量的元素

##### (5).列表推导式

| 类型 | 语法 | 示例 |
| ------ | ------ | ------ |
| 基础 | `[表达式 for 变量 in 可迭代对象]` | `[x**2 for x in range(5)] → [0,1,4,9,16]` |
| 带条件 | `[表达式 for 变量 in 可迭代对象 if 条件]` | `[x for x in range(10) if x%2==0] → [0,2,4,6,8]` |

| 嵌套 | `[表达式 for 变量1 in 可迭代1 for 变量2 in 可迭代2]` | `[(x,y) for x in range(2) for y in range(2)] → [(0,0),(0,1),(1,0),(1,1)]` |

##### (6).其他常用操作

| 操作 | 语法 | 说明 | 示例 |
| ------ | ------ | ------ | ------ |
| 拼接 | `lst1 + lst2` | 合并两个列表，返回新列表 | `[1,2] + [3,4] → [1,2,3,4]` |

| 长度 | `len(lst)` | 返回列表元素个数 | `len([1,2,3]) → 3` |
| 遍历元素 | `for item in lst:` | 遍历每个元素 | 输出 `1,2,3` |
| 遍历索引+元素 | `for i, item in enumerate(lst):` | 同时获取索引和值 | `0:1, 1:2, 2:3` |

### **(二).元组（不可变，组包解包，多返回值的本质）**

> [!IMPORTANT]
> **元组与列表最大区别是不可变**

| 对比项 | 元组（tuple） | 列表（list） |
| -------- | -------------- | -------------- |
| 可变性 | ❌ 不可变 | ✅ 可变 |
| 语法 | `(1, 2, 3)` | `[1, 2, 3]` |
| 速度 | 更快 | 较慢 |
| 内存 | 更小 | 较大 |
| 可哈希 | ✅ 是（可作为字典键） | ❌ 否 |
| 使用场景 | 常量数据、函数返回值 | 动态数据、频繁增删改 |

#### 1.tuple对比

| 对比项 | Python `tuple` | C++ `std::tuple` |
| -------- | ---------------- | ------------------- |
| 可变性 | **❌ 不可变** | ❌ 不可变 |
| 元素类型 | 任意类型混合 | 编译时确定 |
| 语法 | `(1, "a", 3.14)` | `std::tuple<int, string, double>` |
| 解包 | ✅ 原生支持 | ✅ `std::get` / 结构化绑定 (C++17) |

#### 2.创建元组

```python
# 基本创建
t1 = (1, 2, 3)
t2 = 1, 2, 3           # 括号可省略
t3 = (1,)              # 单元素元组（逗号必须）
t4 = ()                # 空元组
t5 = tuple([1, 2, 3])  # 从列表转换
t6 = tuple("abc")      # ('a', 'b', 'c')

# 混合类型
t = (1, "hello", 3.14, True)
```

#### 3.元组（tuple）常用操作

| 操作 | 代码 | 结果 |
| ------ | ------ | ------ |
| 长度 | `len(t)` | `4` |
| 统计次数 | `t.count(2)` | `2` |
| 查找索引 | `t.index(2)` | `1` |
| 判断存在 | `2 in t` | `True` |
| 拼接 | `(1,2) + (3,4)` | `(1,2,3,4)` |
| 重复 | `(1,2) * 3` | `(1,2,1,2,1,2)` |
| 遍历元素 | `for item in t: print(item)` | `1 2 2 3` |
| **遍历索引+元素** | `for i,item in enumerate(t): print(f"{i}:{item}")` | `0:1 1:2 2:2 3:3` |
| 更新 | `namedtuple._replace()` | 返回一个新元组，只更新指定字段的值，其他字段保持不变——兼顾了“不可变性”和“部分可变”的需求 |

+ enumerate是 Python 内置函数，用于在遍历可迭代对象时同时获取索引和值
+ 支持负向索引
+ 支持切片

#### 4.组包与解包

**组包**：多个值自动打包成元组
**解包**：将元组中的元素分别赋值给多个变量

> [!NOTE]
> 列表与元组的组包、解包区别：元组默认组包成**元组**，列表需要显式使用 `[]`

| 操作 | 代码 | 结果 |
| ------ | ------ | ------ |
| 组包 | `t = 1, 2, 3` | `(1, 2, 3)` |
| 解包 | `a, b, c = (1, 2, 3)` | `a=1, b=2, c=3` |
| 变量交换 | `x, y = y, x` | 交换 x 和 y |
| 剩余收集 | `a, *b = (1, 2, 3)` | `a=1, b=[2,3]` |
| 函数返回 | `return a, b` | 返回元组 |
| 参数解包 | `func(*tup)` | 元组分拆为参数 |

#### 1.set对比

| 对比项 | Python `set` | C++ `std::unordered_set` |
| -------- | -------------- | -------------------------- |
| 可变性 | ✅ 可变 | ✅ 可变 |
| 有序性 | ❌ 无序(无法通过索引访问) | ❌ 无序 |

#### 2.创建集合

`s = set()`

#### 3.**常用操作**

##### (1).添加与删除

| ------ | ------ | ------ | ------ |

| 删除**安全** | `s.discard(x)` | `s.discard(10)` | 移除元素，不存在不报错 |
| **随机**删除 | `s.pop()` | `s.pop()` | **随机移除并返回**一个元素 |
| **清空** | `s.clear()` | `s.clear()` | 清空所有元素 |

##### (2). 其他操作

| ------ | ------ | ------ |
| 长度 | `len(s)` | `5` |
| 判断存在 | `3 in s` | `True` |
| 判断不存在 | `10 in s` | `False` |
| 遍历 | `for item in s: print(item)` | **顺序不确定** |
| 浅拷贝 | `s2 = s.copy()` | 复制集合 |
| 浅拷贝 | `s2 = set(s)` | 同上 |
| 不可变集合 | `frozenset([1,2,3])` | 可作为字典键 |

##### (3).**集合运算**

`a = {1, 2, 3, 4}`
`b = {3, 4, 5, 6}`

##### (4).列表去重

| 集合去重 | `list(set(lst))` | `[1, 2, 3, 4]` | ❌ 否 |
| 传统循环 | 手动判断追加 | `[3, 1, 2, 4]` | ✅ 是 |

#### 4.集合推导式

| 类型 | 代码 | 结果 |
| ------ | ------ | ------ |
| 基本用法 | `{x**2 for x in range(5)}` | `{0, 1, 4, 9, 16}` |

### **(四).字典**

#### 1.dict对比

| 对比项 | Python `dict` | C++ `std::unordered_map` |
| -------- | --------------- | -------------------------- |
| 键类型 | **任意可哈希类型（不可变）** | 同类型 |
| 值类型 | **任意类型** | 同类型 |
| 有序性 | Python 3.7+ **插入有序** | 无序 |
| 语法 | `{key: value}` | `{{key, value}}` |
| 访问不存在的键 | 抛出 `KeyError` | 插入默认值（`operator[]`） |

#### 2.创建字典

```python
# 空字典
字典名称 = {}
字典名称 = dict()

# 直接创建
字典名称 = {key: value, key: value···}
字典名称 = {"name": "Alice", "age": 25, "city": "Beijing"}

# dict() 构造
字典名称 = dict(name="Alice", age=25)   # 键自动为字符串
字典名称 = dict([("name", "Alice"), ("age", 25)])  # 从键值对列表

# 字典推导式
squares = {x: x**2 for x in range(5)}  # {0:0, 1:1, 2:4, 3:9, 4:16}
```

#### 3.字典（dict）常用操作

##### (1)**增删改查**

| 分类 | 操作 | 方法/语法 | 说明 | 示例 |
| ------ | ------ | ---------- | ------ | ------ |
| **增** | 添加/修改 | `d[key] = value` | 键不存在则添加 | `d["city"] = "Beijing"` → `{"city":"Beijing"}` |
| | 批量更新 | `d.update(other)` | 批量添加或更新 | `d.update({"age":26})` → `{"age":26}` |
| **删** | 删除键 | `del d[key]` | 删除指定键，不存在则 KeyError | `del d["city"]` |
| | 删除并返回值 | `d.pop(key)` | 删除并返回值 | `value = d.pop("age")` |
| | 删除最后一项 | `d.popitem()` | 删除并返回最后插入的键值对 | `k, v = d.popitem()` |
| | 清空 | `d.clear()` | 清空所有键值对 | `d.clear()` |
| **改** | 修改已存在的键 | `d[key] = value` | 键必须已存在（与添加语法相同） | `d["age"] = 26`（假设 age 已存在） |
| **查** | 直接访问 | `d[key]` | 键不存在→KeyError | `print(d["name"])` |
| | **安全**访问 | `d.get(key)` | 不存在返回 None | `d.get("name")` |
| | 带默认值 | `d.get(key, default)` | 不存在返回默认值 | `d.get("salary", 0)` |
| | 判断键存在 | `key in d` | 返回 True/False | `"name" in d` |

##### (2)常用方法

| 方法 | 说明 | 示例 |
| ------ | ------ | ------ |
| `d.keys()` | 返回所有键的视图 | `for k in d.keys():` |
| `d.values()` | 返回所有值的视图 | `for v in d.values():` |
| `d.items()` | 返回所有键值对的视图 | `for k, v in d.items():` |
| `d.get(k, default)` | 安全取值，可指定默认值 | `d.get("x", 0)` |
| `d.setdefault(k, default)` | 键不存在则设置默认值并返回 | `d.setdefault("count", 0)` |
| `d.update(other)` | 合并另一个字典 | `d.update({"a":1})` |
| `d.pop(k, default)` | 删除并返回值，可指定默认 | `d.pop("x", None)` |
| `d.copy()` | 浅拷贝 | `d2 = d.copy()` |

+ **视图**：
  + **动态**：视图会随原字典变化而变化
  + **可迭代**：可直接用于 `for` 循环
  + **支持成员测试**：`key in d.keys()` 等价于 `key in d`
  + **可转换为列表**：`list(d.keys())` 获取键列表

##### (3)遍历字典

| 遍历方式 | 代码 | 说明 |
| ---------- | ------ | ------ |
| 遍历键 | `for key in d:` | 直接遍历字典，默认识别键 |
| 遍历值 | `for value in d.values():` | 遍历所有值 |
| 遍历键值对 | `for key, value in d.items():` | 同时获取键和值（推荐） |

#### 4.字典合并

```Python
d1 = {"a": 1, "b": 2}
d2 = {"c": 3, "d": 4}
```

+ 方法1：使用 | 运算符（Python 3.9+）
`merged = d1 | d2`          # 新建字典
`d1 |= d2`                 # 原地更新

+ 方法2：解包（Python 3.5+）
`merged = {**d1, **d2}`

+ 方法3：update
`d1.update(d2)`

#### 5.字典推导式

| 类型 | 代码 | 结果/说明 |
| ------ | ------ | ---------- |
| 基础 | `{name: len(name) for name in ["Alice", "Bob", "Charlie"]}` | `{'Alice':5, 'Bob':3, 'Charlie':7}` |
| 带条件 | `{x: x**2 for x in range(10) if x % 2 == 0}` | `{0:0, 2:4, 4:16, 6:36, 8:64}` |
| 反转键值 | `{v: k for k, v in original.items()}` | 值重复会被覆盖（如 `{'a':1, 'b':2, 'c':1}` → `{1:'c', 2:'b'}`） |

#### 6.**字典注意事项**

+ **键必须可哈希**  
  + ✅ **元组、字符串、数字**等不可变类型  
  + ❌ 列表、字典等可变类型  
+ **Python 3.7+ 字典保持插入顺序**  
  + 遍历时按键添加的顺序输出  
+ **遍历时不要修改字典大小**  
  + 错误：`for k in d: del d[k]`  
  + 正确：遍历键的副本 `for k in list(d.keys()):`  
+ **浅拷贝 vs 深拷贝**  
  + `copy()` 只复制一层，嵌套可变对象会被共享  
  + 需要完全独立时用 `copy.deepcopy()`

### ==**(五).容器对比与选择**==

| **容器** | 是否可变 | 是否有序 | 是否允许重复 | 元素类型 | 典型应用场景 | 索引访问(切片操作) |
| ------ | ---------- | ---------- | -------------- | ---------- | -------------- | ------- |
| **列表**（list） | ✅ 可变 | ✅ 有序 | ✅ 允许 | 任意 | 存储序列数据、动态增删改查 | ✅ 支持 |
| **元组**（tuple） | ❌ 不可变 | ✅ 有序 | ✅ 允许 | 任意 | 常量数据、函数多返回值、字典键 | ✅ 支持 |
| **字符串**（str） | ❌ 不可变 | ✅ 有序 | ✅ 允许 | 字符 | 文本处理 | ✅ 支持 |
| **集合**（set） | ✅ 可变 | ❌ 无序 | ❌ 不允许 | 可哈希类型 | 去重、集合运算（并/交/差） | ❌ 不支持 |
| **字典**（dict） | ✅ 可变 | ✅ 有序（3.7+） | 键不允许重复，值允许 | 键可哈希，值任意 | 键值对存储、快速查找、分组统计 | ❌ 不支持 |

#### 1.选择指南

| 需求 | 推荐容器 | 示例 |
| ------ | ---------- | ------ |
| 需要存储**有序、可重复、可修改**的数据 | **列表** | `[1, 2, 3, 4]` |
| 需要存储**有序、可重复、不可修改**的数据 | **元组** | `(1, 2, 3)` |
| 需要**去重**或**集合运算** | **集合** | `{1, 2, 3}` |
| 需要**键值对映射、快速查找** | **字典** | `{"name": "Alice"}` |
| 需要**文本处理** | **字符串** | `"hello"` |
| 作为**字典的键** | **元组** 或 **字符串** | `{(1,2): "point"}` |
| 函数**多返回值** | **元组** | `return a, b` |
| 存储**同一类可枚举**数据 | **元组** 或 **列表** | `COLORS = ("red", "green")` |
| 需要**频繁增删**元素 | **列表** 或 **集合** | — |

#### 2.性能对比

| 操作 | 列表 | 元组 | 集合 | 字典 |
| ------ | ------ | ------ | ------ | ------ |
| 索引访问 | O(1) | O(1) | ❌ | O(1)（通过键） |
| 成员判断（`in`） | O(n) | O(n) | O(1) | O(1)（判断键） |
| 追加/插入 | O(1) / O(n) | ❌ | O(1) | O(1) |
| 删除 | O(n) | ❌ | O(1) | O(1) |
| 内存占用 | 中等 | 较小 | 较大 | 较大 |

### **(六).深拷贝与浅拷贝（copy 模块）**

| 对比项 | 浅拷贝（shallow copy） | 深拷贝（deep copy） |
| -------- | ------------------------ | --------------------- |
| 内存 | 只复制最外层对象，**内部元素仍是原对象的引用** | 递归复制所有层级的对象，**完全独立** |
| 源对象与副本 | 嵌套对象会共享 | 完全独立，互不影响 |
| 速度 | 快 | 慢 |
| 使用场景 | 对象只有一层或嵌套对象无需修改 | 对象有嵌套且需要完全独立修改 |

#### 1.浅拷贝方法

```python
import copy

original = {"a": [1, 2], "b": 3}

# 方法1：copy() 方法
copied = original.copy()

# 方法2：切片（列表专用）
lst = [1, 2, 3]
copied_lst = lst[:]

# 方法3：构造方法
copied = dict(original)

# 方法4：copy模块的浅拷贝
copied = copy.copy(original)
```

#### 2.深拷贝方法

```python
import copy

original = {"a": [1, 2], "b": 3}
deep_copied = copy.deepcopy(original)

# 修改深拷贝的嵌套对象，不影响原对象
deep_copied["a"].append(3)
print(original["a"])   # [1, 2]（不变）
```

#### 3.**赋值、浅拷贝、深拷贝对比**

| 数据类型 | 赋值 `=` | 浅拷贝（`copy()` / `[:]`） | 深拷贝（`copy.deepcopy()`） |
| ---------- | ---------- | --------------------------- | ---------------------------- |
| **不可变对象**（int, str, tuple） | 共享引用 | 共享引用 | 共享引用 |
| **可变对象**（list, dict, set） | 共享引用 | 新对象（内层共享） | 全新独立对象 |

+ **不可变对象**：无论哪种方式，修改原对象不影响副本（因为不可变对象无法原地修改，会创建新对象）
+ **赋值**：多个变量指向同一对象
+ **浅拷贝**：外层是新对象，内层仍共享
+ **深拷贝**：完全独立的新对象

### **(七).collections**

`collections` 是 Python 内置的标准库，提供了除基础容器（list、dict、set、tuple）之外的扩展容器类型。

#### 1.defaultdict(带默认值的字典)

##### (1)**defaultdict作用**

访问不存在的键时，自动返回默认值，避免 `KeyError`

##### (2)与dict对比

| 对比项 | 普通 `dict` | `defaultdict` |
| -------- | ------------- | --------------- |
| 访问不存在的键 | `KeyError` | **自动创建默认值** |
| **需要手动判断** | `if key not in d: d[key] = []` | 无需判断 |

##### (3)基础操作

```python
from collections import defaultdict

# 创建默认值为列表的字典
d = defaultdict(list)

# 直接追加，不需要判断键是否存在
d["a"].append(1)
d["a"].append(2)
d["b"].append(3)

print(d)  # defaultdict(<class 'list'>, {'a': [1, 2], 'b': [3]})

# 默认值为 int（初始值 0）
count = defaultdict(int)
count["apple"] += 1
count["banana"] += 2
print(count)  # defaultdict(<class 'int'>, {'apple': 1, 'banana': 2})

# 自定义默认值函数
def default_value():
    return "N/A"

d = defaultdict(default_value)
print(d["missing"])  # "N/A"
```

##### (4)应用

+ defaultdict 省去了 if key not in d: d[key] = 默认值 的判断，让代码更简洁

```python
# 普通字典写法
students = [("Alice", "A"), ("Bob", "B"), ("Charlie", "A")]
groups = {}
for name, grade in students:
    if grade not in groups:
        groups[grade] = []
    groups[grade].append(name)

# defaultdict 写法
groups = defaultdict(list)
for name, grade in students:
    groups[grade].append(name)
# {'A': ['Alice', 'Charlie'], 'B': ['Bob']}
```

#### 2.Counter(计数器)

##### (1)Counter作用

快速统计可哈希对象的出现次数。

##### (2)基础操作

```python
from collections import Counter

# 创建 Counter
c = Counter("hello world")
print(c)  # Counter({'l': 3, 'o': 2, 'h': 1, 'e': 1, ' ': 1, 'w': 1, 'r': 1, 'd': 1})

# 从列表统计
c = Counter(["a", "b", "a", "c", "b", "a"])
print(c)  # Counter({'a': 3, 'b': 2, 'c': 1})

# 手动增加
c = Counter()
c["apple"] += 1
c["banana"] += 2
c.update(["apple", "orange"])  # 批量增加

# 常用方法
c = Counter("abracadabra")
print(c.most_common(2))   # [('a', 5), ('b', 2)]（出现最多的2个）
print(c["a"])             # 5（访问）
print(list(c.elements())) # 按次数展开元素

# 算术运算
c1 = Counter("abc")
c2 = Counter("bcd")
print(c1 + c2)   # Counter({'b': 2, 'c': 2, 'a': 1, 'd': 1})
print(c1 - c2)   # Counter({'a': 1})
print(c1 & c2)   # 交集：Counter({'b': 1, 'c': 1})
print(c1 | c2)   # 并集：Counter({'a': 1, 'b': 1, 'c': 1, 'd': 1})
```

#### 3.deque(双端队列)

##### (1)deque作用

两端都可以高效添加和删除元素的队列（O(1)）

##### (2)与list性能对比

| 操作 | 列表 `list` | `deque` |
| ------ | ------------- | --------- |
| 左侧追加 | O(n) | O(1) |
| 左侧弹出 | O(n) | O(1) |
| 右侧追加 | O(1) | O(1) |
| 右侧弹出 | O(1) | O(1) |

+ **列表**：底层是**连续数组**，左侧插入/删除需要移动所有元素 → O(n)
+ **deque**：底层是**双向链表**或**分块数组**，两端操作都是 O(1)

##### (3)deque基础操作

```python
from collections import deque

# 创建
dq = deque([1, 2, 3])
dq = deque(maxlen=5)   # 固定长度，超出时自动丢弃旧元素

# 右侧操作
dq.append(4)           # 右侧添加
dq.append(5)
dq.pop()               # 右侧弹出，返回 5

# 左侧操作
dq.appendleft(0)       # 左侧添加
dq.popleft()           # 左侧弹出，返回 0

# 扩展
dq.extend([6, 7])       # 右侧扩展
dq.extendleft([-1, -2]) # 左侧扩展（注意顺序：-2, -1）

# 旋转
dq = deque([1, 2, 3, 4, 5])
dq.rotate(2)            # 右旋2步 → [4, 5, 1, 2, 3]
dq.rotate(-1)           # 左旋1步 → [2, 3, 4, 5, 1]

# 其他操作
dq.remove(3)            # 删除指定值
dq.count(2)             # 统计次数
dq.clear()              # 清空
dq.reverse()            # 反转
```

##### (4)典型应用：滑动窗口、队列、栈

```python
# 固定长度队列（保留最近 N 条记录）
history = deque(maxlen=3)
for i in range(5):
    history.append(i)
    print(history)  # deque([0,1,2]) → deque([1,2,3]) → deque([2,3,4])

# 高效栈（用 deque 代替 list）
stack = deque()
stack.append("a")
stack.append("b")
stack.pop()   # "b"

# 双向队列
dq = deque([1, 2, 3])
dq.appendleft(0)   # [0, 1, 2, 3]
dq.popleft()       # 1
```

### **(二).参数**

| -------- | -------- | ----- |

```python
def bad(item, lst=[]):   # ❌ 默认列表在多次调用间共享

print(bad(2))   # [1, 2]（不是 [2]）

# 正确做法
def good(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

### **(十).装饰器**

在不修改原函数代码的情况下，增强函数功能。

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)

@log
def say_hello(name):
    return f"Hello, {name}"

# 调用 say_hello
# Hello, Alice
```

带参数的装饰器：

```python
def repeat(times):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def greet():
    print("Hi")

greet()   # 打印 Hi 三次
```

### **(十一).生成器（yield）**

| 对比项 | 普通函数 | 生成器函数 |
| -------- | -------- | ----- |
| 返回 | `return` 返回值 | `yield` 产生值 |
| 执行 | 调用时执行完返回 | 每次 `next()` 执行到下一个 `yield` |
| 内存 | 一次性生成所有结果 | 惰性求值，节省内存 |

```python
def count_up(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for num in count_up(5):
    print(num)   # 1 2 3 4 5

# 生成器表达式
squares = (x**2 for x in range(5))
print(next(squares))   # 0
print(list(squares))   # [1, 4, 9, 16]
```

```python
    return a + b
```

### **(一).open() 与文件模式**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 打开文件 | `open(file, mode)` | `std::ifstream` / `std::ofstream` |

### **(二).with 上下文管理器**

#### 1.作用

自动管理资源（如文件、网络连接、锁），无需手动 `close()`。

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 资源管理 | `with` 语句 | RAII（构造/析构） |
| 自动释放 | ✅ 自动 | ✅ 自动（作用域结束时） |
| 手动控制 | `__enter__` / `__exit__` | 构造函数 / 析构函数 |

#### 2.代码

```python
# 读取文件（推荐）
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 离开 with 块后自动关闭

# 写入文件
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello World")

# 同时打开多个文件
with open("a.txt", "r") as f1, open("b.txt", "w") as f2:
    f2.write(f1.read())
```

#### 3.自定义上下文管理器

```python
class MyContext:
    def __enter__(self):
        print("进入上下文")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("退出上下文")
        return False    # False 表示不吞掉异常

with MyContext() as ctx:
    print("执行中")

# 输出：
# 进入上下文
# 执行中
# 退出上下文
```

### **(三).异常处理（try / except / else / finally）**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 捕获异常 | `try / except` | `try / catch` |
| 异常类型 | 内置异常类 | 任意类型（通常 `std::exception`） |
| 捕获所有 | `except Exception:` | `catch (...)` |
| `else` 子句 | ✅ 支持 | ❌ 不支持 |
| `finally` | ✅ 支持 | ❌ 无（RAII 替代） |

#### 2.完整语法

```python
try:
    # 可能出错的代码
    result = 10 / 0
except ZeroDivisionError as e:
    # 捕获特定异常
    print(f"除零错误: {e}")
except (TypeError, ValueError) as e:
    # 捕获多个异常
    print(f"类型或值错误: {e}")
except Exception as e:
    # 捕获其他所有异常
    print(f"未知错误: {e}")
else:
    # 没有异常时执行
    print(f"结果: {result}")
finally:
    # 无论是否异常都会执行
    print("清理工作")
```

#### 3.常见异常类型

| 异常 | 说明 |
| -------- | ----- |
| `ValueError` | 值错误（如 `int("abc")`） |
| `TypeError` | 类型错误 |
| `KeyError` | 字典键不存在 |
| `IndexError` | 索引超出范围 |
| `FileNotFoundError` | 文件不存在 |
| `ZeroDivisionError` | 除零错误 |
| `AttributeError` | 属性不存在 |

```python
# 示例：安全的整数输入
try:
    num = int(input("请输入数字："))
except ValueError:
    print("输入的不是有效数字")
else:
    print(f"输入成功: {num}")
finally:
    print("程序结束")
```

### **(四).raise 与自定义异常**

#### 1.raise 抛出异常

```python
# 抛出现有异常
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")
    return a / b

# 重新抛出当前异常
try:
    divide(10, 0)
except ValueError as e:
    print(f"捕获: {e}")
    raise    # 重新抛出，交给上层处理
```

#### 2.自定义异常

```python
# 定义异常类（继承 Exception）
class AgeError(Exception):
    def __init__(self, message, age):
        super().__init__(message)
        self.age = age

# 使用自定义异常
def check_age(age):
    if age < 0:
        raise AgeError("年龄不能为负数", age)
    if age > 150:
        raise AgeError("年龄过大", age)
    return age

try:
    check_age(-5)
except AgeError as e:
    print(f"错误: {e}, 输入的年龄: {e.age}")
```

#### 3.异常链（raise from）

```python
try:
    num = int("abc")
except ValueError as e:
    raise RuntimeError("解析失败") from e
# 会同时保留原始异常信息
```

> [!TIP]
> ==最佳实践==：
> + 只捕获能处理的异常，不要滥用 `except Exception`
> + 使用 `finally` 或 `with` 确保资源释放
> + 自定义异常继承 `Exception`，命名以 `Error` 结尾
> + 用 `raise ... from ...` 保留异常链，便于调试

### **(七).@property（替代 getter/setter）**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 属性访问 | `obj.attr` | `obj.getAttr()` / `obj.setAttr()` |
| 实现方式 | `@property` 装饰器 | 手动写 getter/setter |
| 调用方式 | 像属性一样访问 | 方法调用 |

#### 2.代码

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("半径不能为负")
        self._radius = value

    @property
    def area(self):
        return 3.14 * self._radius ** 2

c = Circle(5)
print(c.radius)    # 5（像属性一样访问）
c.radius = 10      # 调用 setter
print(c.area)      # 314.0
```

### **(八).魔法方法**

#### 1.常用魔法方法

| 方法 | 触发时机 | 示例 |
| -------- | -------- | ----- |
| `__str__` | `str(obj)` / `print(obj)` | 返回用户友好字符串 |
| `__repr__` | `repr(obj)` / 交互式显示 | 返回开发者字符串 |
| `__len__` | `len(obj)` | 返回长度 |
| `__add__` | `obj + other` | 定义加法 |
| `__eq__` | `obj == other` | 定义相等比较 |
| `__getitem__` | `obj[key]` | 索引访问 |

#### 2.代码

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __str__(self):
        return f"《{self.title}》"

    def __repr__(self):
        return f"Book('{self.title}', {self.pages})"

    def __len__(self):
        return self.pages

    def __add__(self, other):
        return Book(self.title + " & " + other.title, self.pages + other.pages)

b1 = Book("Python", 300)
b2 = Book("C++", 400)

print(b1)           # 《Python》
print(repr(b1))     # Book('Python', 300)
print(len(b1))      # 300
b3 = b1 + b2
print(b3)           # 《Python & C++》
print(len(b3))      # 700
```

### **(九).继承（单继承 / 多继承 / super / MRO）**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 继承语法 | `class 子类(父类):` | `class 子类 : public 父类 { };` |
| 多继承 | ✅ 支持 | ✅ 支持 |
| 调用父类方法 | `super().method()` | `父类::method()` |
| 方法解析顺序 | MRO（C3 算法） | 复杂，需手动处理 |

#### 2.代码

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

d = Dog("旺财")
print(d.name)       # 旺财
print(d.speak())    # 汪汪

# 多继承
class A:
    def method(self):
        print("A")

class B:
    def method(self):
        print("B")

class C(A, B):
    pass

c = C()
c.method()          # A（按 MRO 顺序）
print(C.__mro__)    # (<class 'C'>, <class 'A'>, <class 'B'>, <class 'object'>)
```

> [!TIP]
> 使用 `super()` 调用父类方法，遵循 MRO 顺序。

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 调用父类构造
        self.breed = breed
```

### **(一).threading（多线程）**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 线程库 | `threading` 模块 | `<thread>` (C++11) |
| 创建线程 | `Thread(target=func)` | `std::thread t(func);` |
| 启动线程 | `t.start()` | 自动启动 |
| 等待结束 | `t.join()` | `t.join()` |
| 锁 | `threading.Lock()` | `std::mutex` |
| GIL | ✅ 有（限制多线程并行） | ❌ 无 |

#### 2.基础用法

```python
import threading
import time

def worker(name):
    print(f"线程 {name} 开始")
    time.sleep(1)
    print(f"线程 {name} 结束")

# 创建并启动线程
t1 = threading.Thread(target=worker, args=("A",))
t2 = threading.Thread(target=worker, args=("B",))

t1.start()
t2.start()

# 等待线程结束
t1.join()
t2.join()

print("所有线程结束")
```

#### 3.线程锁（防止数据竞争）

```python
import threading

counter = 0
lock = threading.Lock()

def increment():
    global counter
    for _ in range(100000):
        with lock:          # 加锁
            counter += 1

threads = [threading.Thread(target=increment) for _ in range(5)]
for t in threads:
    t.start()
for t in threads:
    t.join()

print(counter)   # 500000（加锁后结果正确）
```

#### 4.线程池

```python
from concurrent.futures import ThreadPoolExecutor

def task(n):
    return n * n

# 创建线程池
with ThreadPoolExecutor(max_workers=4) as executor:
    results = executor.map(task, range(10))
    print(list(results))   # [0, 1, 4, 9, 16, ..., 81]
```

> [!WARNING]
> ==GIL 限制==：Python 的全局解释器锁导致多线程无法真正并行执行 CPU 密集型任务。多线程适合 **IO 密集型** 任务（如网络请求、文件读写）。

### **(二).multiprocessing（多进程）**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 进程库 | `multiprocessing` 模块 | `<cstdlib>` + fork / `CreateProcess` |
| 创建进程 | `Process(target=func)` | 平台相关 API |
| 通信 | `Queue` / `Pipe` | 管道 / 共享内存 |
| GIL 限制 | ❌ 无（每个进程独立解释器） | ❌ 无 |

#### 2.基础用法

```python
import multiprocessing
import os

def worker(name):
    print(f"进程 {name} (PID: {os.getpid()}) 开始")
    return name.upper()

if __name__ == "__main__":
    p1 = multiprocessing.Process(target=worker, args=("A",))
    p2 = multiprocessing.Process(target=worker, args=("B",))

    p1.start()
    p2.start()

    p1.join()
    p2.join()
```

#### 3.进程间通信（Queue）

```python
import multiprocessing

def producer(queue):
    for i in range(5):
        queue.put(f"数据{i}")

def consumer(queue):
    while not queue.empty():
        print(queue.get())

if __name__ == "__main__":
    q = multiprocessing.Queue()

    p1 = multiprocessing.Process(target=producer, args=(q,))
    p2 = multiprocessing.Process(target=consumer, args=(q,))

    p1.start()
    p1.join()
    p2.start()
    p2.join()
```

#### 4.进程池

```python
from multiprocessing import Pool

def square(n):
    return n * n

if __name__ == "__main__":
    with Pool(4) as pool:
        results = pool.map(square, range(10))
        print(results)   # [0, 1, 4, 9, 16, ..., 81]
```

> [!TIP]
> ==适用场景==：多进程适合 **CPU 密集型** 任务（如科学计算、图像处理），可以绕过 GIL 真正并行。

### **(三).asyncio（异步 IO）**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 异步库 | `asyncio` | `<coroutine>` (C++20) |
| 关键字 | `async` / `await` | `co_await` |
| 事件循环 | `asyncio.run()` | 需手动实现 |
| 适用场景 | IO 密集型 | IO 密集型 |

#### 2.基础用法

```python
import asyncio

async def say_hello(name, delay):
    print(f"{name} 开始")
    await asyncio.sleep(delay)   # 模拟 IO 等待
    print(f"{name} 结束")

async def main():
    # 并发执行多个协程
    await asyncio.gather(
        say_hello("A", 2),
        say_hello("B", 1),
        say_hello("C", 3),
    )

asyncio.run(main())
# 输出顺序：
# A 开始
# B 开始
# C 开始
# B 结束（1秒后）
# A 结束（2秒后）
# C 结束（3秒后）
# 总耗时约 3 秒（而非 6 秒）
```

#### 3.异步任务

```python
import asyncio

async def task(n):
    await asyncio.sleep(1)
    return n * n

async def main():
    # 创建任务（立即开始调度）
    tasks = [asyncio.create_task(task(i)) for i in range(5)]

    # 等待所有任务完成
    results = await asyncio.gather(*tasks)
    print(results)   # [0, 1, 4, 9, 16]

asyncio.run(main())
```

#### 4.异步超时控制

```python
import asyncio

async def slow_task():
    await asyncio.sleep(10)
    return "完成"

async def main():
    try:
        result = await asyncio.wait_for(slow_task(), timeout=2)
    except asyncio.TimeoutError:
        print("任务超时")

asyncio.run(main())   # 任务超时
```

### **(四).三种并发方式对比**

| 对比项 | threading | multiprocessing | asyncio |
| -------- | -------- | -------- | -------- |
| 并发单元 | 线程 | 进程 | 协程 |
| 适用场景 | IO 密集型 | CPU 密集型 | IO 密集型 |
| 是否受 GIL 限制 | ✅ 是 | ❌ 否 | ✅ 是（但自动切换） |
| 内存开销 | 中 | 大 | 小 |
| 切换开销 | 中 | 大 | 小 |
| 通信方式 | 共享内存 + 锁 | Queue / Pipe | `await` |
| 使用难度 | 中 | 中 | 较高 |
| 能否真正并行 | ❌ | ✅ | ❌ |

#### 选择建议

| 场景 | 推荐 |
| -------- | -------- |
| 大量网络请求 | `asyncio` 或 `threading` |
| 文件批量读写 | `threading` |
| 图像处理 / 科学计算 | `multiprocessing` |
| 爬虫 | `asyncio` + `aiohttp` |
| CPU 密集 + 简单实现 | `multiprocessing` |

> [!IMPORTANT]
> ==Python 并发的核心结论==：
> + **IO 密集**：用 `asyncio`（推荐）或 `threading`
> + **CPU 密集**：用 `multiprocessing`
> + **不要用 threading 处理 CPU 密集任务**（GIL 会导致性能下降）

### **(一).PEP 8**

#### 2.核心规范

| 导入 | 每行一个导入，分组（标准库/第三方/本地） | `import os` |
| 空格 | 运算符两侧加空格 | `a = b + c` |
| | 逗号后加空格 | `[1, 2, 3]` |

#### 3.导入顺序

| 变量 | `snake_case` | `user_name = "Alice"` |

| 类 | `PascalCase` | `class UserAccount:` |
| 常量 | `UPPER_CASE` | `MAX_RETRY = 3` |
| 私有变量 | `_prefix` | `self._internal = 1` |
| 模块 | `snake_case` | `my_module.py` |
| 包 | `snake_case` | `my_package/` |

> [!TIP]

### **(二).mypy 类型检查**

#### 1.作用

mypy 是 Python 的静态类型检查工具，在运行前发现类型错误。

| 对比项 | Python（无 mypy） | Python + mypy |
| -------- | -------- | ----- |
| 类型检查时机 | 运行时 | 编写/编译时 |
| 错误发现 | 运行时崩溃 | 提前发现 |
| 类型注解 | 可选 | 推荐使用 |

#### 2.安装与使用

```bash
# 安装
pip install mypy

# 检查文件
mypy my_script.py

# 检查整个目录
mypy src/
```

#### 3.代码示例

```python
# 有类型注解的代码
def add(a: int, b: int) -> int:
    return a + b

# mypy 能检测出的错误
result = add("hello", "world")   # ❌ mypy 报错：参数类型不匹配
result = add(1, 2)               # ✅ 正确
```

#### 4.常用类型注解

```python
from typing import List, Dict, Optional, Union, Callable

# 基础类型
name: str = "Alice"
age: int = 25
scores: List[int] = [90, 85]

# 可选类型
def find_user(user_id: int) -> Optional[str]:
    return "Alice" if user_id == 1 else None

# 联合类型
def parse(value: Union[int, str]) -> str:
    return str(value)

# 函数类型
def apply(func: Callable[[int], int], x: int) -> int:
    return func(x)

# Python 3.10+ 简化写法
def find_user(user_id: int) -> str | None:
    return "Alice" if user_id == 1 else None

nums: list[int] = [1, 2, 3]
users: dict[str, int] = {"age": 25}
```

```ini
[mypy]
python_version = 3.10
warn_return_any = True
warn_unused_configs = True
disallow_untyped_defs = True
ignore_missing_imports = True
```

> [!TIP]
> ==渐进式类型注解==：不需要一开始就全部加注解，可以从核心模块开始，逐步完善。

### **(三).unittest / pytest**

#### 1.Python vs C++ 差异

| 对比项 | Python | C++ |
| -------- | -------- | ----- |
| 测试框架 | `unittest` / `pytest` | Google Test / Catch2 |
| 测试文件命名 | `test_*.py` / `*_test.py` | 自定义 |
| 测试函数 | `def test_xxx():` | `TEST(Suite, Name) { }` |
| 断言 | `assert` / `self.assertEqual()` | `EXPECT_EQ` / `ASSERT_EQ` |
| 运行 | `pytest` / `python -m unittest` | 编译后运行 |

#### 2.unittest（标准库）

```python
import unittest

def add(a, b):
    return a + b

class TestAdd(unittest.TestCase):
    def test_positive(self):
        self.assertEqual(add(1, 2), 3)

    def test_negative(self):
        self.assertEqual(add(-1, -2), -3)

    def test_zero(self):
        self.assertEqual(add(0, 0), 0)

    def test_raises(self):
        with self.assertRaises(TypeError):
            add("a", "b")

if __name__ == "__main__":
    unittest.main()
```

```bash
# 运行
python -m unittest test_add.py
python -m unittest discover    # 自动发现所有测试
```

#### 3.pytest（推荐）

```python
# test_add.py
def add(a, b):
    return a + b

# 简单断言即可（不需要 self.assertEqual）
def test_add_positive():
    assert add(1, 2) == 3

def test_add_negative():
    assert add(-1, -2) == -3

def test_add_zero():
    assert add(0, 0) == 0

# 测试异常
import pytest

def test_add_type_error():
    with pytest.raises(TypeError):
        add("a", "b")
```

```bash
# 安装
pip install pytest

# 运行
pytest                          # 运行当前目录所有测试
pytest test_add.py              # 运行指定文件
pytest -v                       # 详细输出
pytest -k "test_add"            # 只运行匹配的测试
pytest --cov=my_module          # 覆盖率报告
```

#### 4.pytest 参数化

```python
import pytest

@pytest.mark.parametrize("a, b, expected", [
    (1, 2, 3),
    (-1, -2, -3),
    (0, 0, 0),
    (100, 200, 300),
])
def test_add(a, b, expected):
    assert add(a, b) == expected
```

#### 5.常用断言

| 场景 | unittest | pytest |
| -------- | -------- | ----- |
| 相等 | `assertEqual(a, b)` | `assert a == b` |
| 不等 | `assertNotEqual(a, b)` | `assert a != b` |
| 为真 | `assertTrue(x)` | `assert x` |
| 为假 | `assertFalse(x)` | `assert not x` |
| 包含 | `assertIn(a, b)` | `assert a in b` |
| 抛出异常 | `assertRaises(Error)` | `pytest.raises(Error)` |
| 近似相等 | `assertAlmostEqual(a, b)` | `pytest.approx(a) == b` |

#### 6.测试组织

```
project/
├── src/
│   └── my_module.py
├── tests/
│   ├── __init__.py
│   ├── test_module1.py
│   ├── test_module2.py
│   └── conftest.py        # pytest 共享配置
├── pytest.ini             # pytest 配置
└── requirements.txt
```

#### 7.测试覆盖率

```bash
# 安装
pip install pytest-cov

# 运行并生成覆盖率报告
pytest --cov=src --cov-report=html

# 输出示例：
# Name              Stmts   Miss  Cover
# -----------------------------------------
# src/my_module.py     20      2    90%
```

> [!IMPORTANT]
> ==测试最佳实践==：
> + 每个函数只测试一个行为
> + 测试函数名以 `test_` 开头
> + 使用参数化减少重复代码
> + 测试覆盖边界情况（0、空、负数、超大值）
> + 保持测试独立，不依赖执行顺序
> + 推荐使用 `pytest`（更简洁，功能更强）

### **(二).布局管理器**

> [!IMPORTANT]
> ==三种布局管理器不能在同一父容器中混用==：`pack`、`grid`、`place`。

#### 1.pack

+ 按添加顺序沿边堆放。
+ 常用参数：`side`、`fill`、`expand`、`anchor`、`padx/pady`、`ipadx/ipady`。

```python
tk.Label(root, text="Red", bg="red").pack(side="left", fill="y")
tk.Label(root, text="Green", bg="green").pack(side="left", fill="both", expand=True)
```

| 参数 | 可选值 | 说明 |
|------|--------|------|
| `side` | `top`(默认)、`bottom`、`left`、`right` | 停靠边 |
| `fill` | `x`、`y`、`both`、`none` | 是否拉伸填充 |
| `expand` | `0/1` | 是否占据额外空间 |
| `anchor` | `n/s/e/w/nw/.../center` | 锚点 |
| `padx/pady` | 数值 | 外部间距 |
| `ipadx/ipady` | 数值 | 内部间距 |

#### 2.grid

+ 按二维表格排列，适合计算器、表单。
+ 常用参数：`row`、`column`、`rowspan`、`columnspan`、`sticky`、`padx/pady`。

```python
for i in range(1, 10):
    tk.Button(root, text=str(i), width=5).grid(
        row=(i-1)//3, column=(i-1)%3
    )

tk.Button(root, text="0").grid(row=3, column=0, columnspan=2, sticky="ew")
tk.Button(root, text=".").grid(row=3, column=2, sticky="ew")
```

| 参数 | 说明 |
|------|------|
| `row` / `column` | 行号、列号，从 0 开始 |
| `rowspan` / `columnspan` | 跨行、跨列 |
| `sticky` | 单元格内对齐/拉伸：`n/s/e/w` 组合，`ew` 表示左右贴紧 |
| `padx/pady` | 外部间距 |
| `ipadx/ipady` | 内部间距 |

#### 3.place

+ 绝对或相对定位，精确控制位置。
+ 常用参数：`x/y`、`relx/rely`、`width/height`、`anchor`。

```python
tk.Label(root, text="用户名").place(x=1, y=5)
tk.Entry(root, width=20).place(x=60, y=5)
```

| 参数 | 说明 |
|------|------|
| `x/y` | 绝对像素坐标 |
| `relx/rely` | 相对坐标，0.0~1.0，0.5 为居中 |
| `width/height` | 组件宽高 |
| `anchor` | 锚点，默认 `nw` |

### **(五).事件处理**

#### 1.事件类型格式

`<[modifier-]...type[-detail]>`

+ 必须放在尖括号内。
+ `modifier`：`Control`、`Alt`、`Shift` 等组合键。
+ `type`：`Button`、`KeyPress`、`Motion` 等。
+ `detail`：`1` 左键、`2` 中键、`3` 右键。

#### 2.常见事件

| 类别 | 事件 | 说明 |
|------|------|------|
| 鼠标 | `<Button-1>` | 左键单击 |
| | `<ButtonRelease-1>` | 左键释放 |
| | `<Double-Button-1>` | 左键双击 |
| | `<B1-Motion>` | 左键拖动 |
| | `<Enter>` / `<Leave>` | 鼠标进入/离开组件 |
| | `<MouseWheel>` | 滚轮 |
| 键盘 | `<KeyPress>` / `<Key>` | 键盘按下 |
| | `<KeyRelease>` | 键盘释放 |
| | `<Return>`、`<Escape>`、`<Left>`、`<Up>` | 具体键 |
| 窗体 | `<Configure>` | 组件大小改变 |
| | `<FocusIn>` / `<FocusOut>` | 获得/失去焦点 |
| | `<Destroy>` | 组件销毁 |

#### 3.绑定方式

| 方式 | 语法 | 说明 |
|------|------|------|
| 创建时指定 | `tk.Button(root, command=callback)` | 按钮命令 |
| 实例绑定 | `widget.bind("<Button-1>", callback)` | 最常用 |
| 类绑定 | `widget.bind_class("Canvas", "<Button-1>", callback)` | 整个组件类 |
| 程序界面绑定 | `widget.bind_all("<Key-Print>", callback)` | 整个应用 |
| 标识绑定 | `canvas.tag_bind("tag", "<Button-1>", callback)` | Canvas 图形 |

```python
def on_click(event):
    print("点击位置：", event.x, event.y)

widget.bind("<Button-1>", on_click)
```

#### 4.Event 对象属性

| 属性 | 说明 |
|------|------|
| `x, y` | 鼠标相对组件左上角坐标 |
| `x_root, y_root` | 鼠标相对屏幕左上角坐标 |
| `keysym` | 按键字符串名 |
| `keycode` | 按键数字代码 |
| `char` | 按键字符 |
| `widget` | 触发事件的组件 |
| `time` | 事件时间 |
| `type` | 事件类型 |

### **(十).事件循环与界面刷新**

+ `root.mainloop()` 是阻塞式事件循环。
+ 如果回调函数执行时间过长，事件队列会堆积，界面卡死。
+ 用 `root.after(ms, callback)` 非阻塞定时执行，保持界面响应。

```python
def showpro():
    pro_var.set(pro_var.get() + 1)
    if pro_var.get() < 200:
        root.after(100, showpro)

root.after(100, showpro)
```

> [!CAUTION]
> ==不要在 GUI 主线程中执行耗时循环==；应使用 `after` 分步执行，或放到子线程/进程中，再通过队列更新界面。

### **(十一).综合案例：猜数字游戏（简版）**

```python
import tkinter as tk
import random

number = random.randint(0, 1024)
nmaxn, nminn, num = 1024, 0, 0
running = True

def guess(event=None):
    global nmaxn, nminn, num, running
    if not running:
        return
    try:
        val = int(entry.get())
    except ValueError:
        label.config(text="请输入整数")
        return

    num += 1
    if val == number:
        label.config(text=f"恭喜答对了！尝试次数：{num}")
        running = False
    elif val < number:
        if val > nminn:
            nminn = val
        label.config(text=f"小了，请输入{nminn}到{nmaxn}之间任意整数")
    else:
        if val < nmaxn:
            nmaxn = val
        label.config(text=f"大了，请输入{nminn}到{nmaxn}之间任意整数")

root = tk.Tk()
root.title("猜数字游戏")
root.geometry("400x90+200+200")

label = tk.Label(root, width=80)
label.pack(side="top")
entry = tk.Entry(root, width=40)
entry.pack(side="left")
entry.bind("<Return>", guess)
tk.Button(root, text="猜", command=guess).pack(side="left")
tk.Button(root, text="关闭", command=root.destroy).pack(side="left")
label.config(text="请输入0到1024之间任意整数：")
entry.focus_set()
root.mainloop()
```

### **(十二).Tkinter 学习要点**

> [!TIP]
> 
> + 先选布局：简单堆叠用 `pack`，表单/计算器用 `grid`，精确定位用 `place`。
> + 组件状态用 `variable` / `textvariable` 绑定，界面自动更新。
> + 事件处理函数通常接收 `event` 参数。
> + 耗时任务不要阻塞 `mainloop()`，用 `after` 或后台线程。
> + Tkinter 适合小型工具、教学、原型；大型 GUI 可考虑 PyQt / PySide / Kivy。
