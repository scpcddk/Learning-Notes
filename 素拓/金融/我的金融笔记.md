## 一、宏观金融

### 1.1 经济运行基础

- **CPI**：消费者价格指数，跟踪普通家庭日常购买的典型商品与服务价格
- **通胀成因**：货币超发是动力，钱变多→价格上涨
- **通胀对股市影响**：
  - 公司成本上升，盈利不确定性增加
  - 股息收益率低于通胀率时，股民实际收益为负
  - 央行介入提高利率→公司成本上升→估值承压
  - 现值公式：现值 = 未来价值 / (1+利率)^期数
- **局部通胀 vs 整体通胀**：局部压力向整体传导，路径包括成本传导、需求传导、预期传导
- **影响通胀深度的因素**：行业权重、产业链位置、替代弹性
- **政策应对**：经济开放度
- **通胀的"局限性"本质**：价格信号在经济网络中的扩散过程

- **PPI**：生产价格（笔记中提及，未展开）

### 1.2 货币政策与利率

- **宽松货币政策**：降息、降准、放水
- **紧缩货币政策**：加息、收紧流动性
- **利率周期影响链**：
  ```
  利率下降 → 融资成本下降 → 企业投资增加 → 经济增长 → 股票估值提升
  ```
- **利率与通胀关系**：
  - 通胀周期：收紧资金，贷款变贵，利空银行、黄金
  - 降息周期：央行放水，借钱便宜，利好成长股、地产消费科技可转债
- **通缩**：物价持续下跌，钱变少，利好短债现金，利空负债行业

`【待学】` PMI、社融、M2、GDP、就业数据、消费数据、央行工具体系、货币传导机制、流动性周期

### 1.3 经济周期与资产轮动

- **四阶段映射**：
  - **复苏**：科技、高端制造、新能源、军工成长赛道
  - **过热**：有色煤炭石化化工等周期资源股，高通胀，将要加息
  - **滞胀**：经济停滞+通胀居高不下，企业营收不涨原材料成本暴涨，成长股大跌，必选消费、黄金
  - **衰退**：公用事业、医药、高股息白马、国债

## 二、个人财富管理

### 2.1 财务基础

- **复利**：
  - 时间是最核心的变量
  - 成本是敌人
  - 稳定是关键
  - 买入低成本稳定的指数基金，长期持有，不频繁交易
- **真实回报**：扣除通胀后的实际购买力增长
- **预算**：
  - 找到财务基准线：实际记录财务，不要"心里记账"
  - 每月维持生活所需的最低限度，需在总收入50%以下
- **平均成本法**：长期定投，降低每只股票的成本
- **机会成本**：花小钱节省时间，将时间放在副业
- **决策疲劳**：财务自动化，节省时间精力，减少决策失误
- **省钱**：
  - 省下100元 = 实际赚到100元
  - 降低住房成本、交通花销、餐饮消费
  - 了解自身税收制度
  - 增加工作时间以获取更多薪酬

### 2.2 信用与债务管理

- **信用评分**：
  - 银行或其他贷款机构快速评估信用风险的方法
  - 五大影响因素：付款历史(35%)、欠款金额(30%)、信用历史长度(15%)、信用组合(10%)、新增信用(10%)
- **提升信用方法**：
  - 添加为信用卡账户授权用户
  - 增加信用组合和信用历史长度
  - 降低信用账户使用率
- **信用卡使用原则**：
  - 建立信用评分
  - 获得奖励，帮助攒钱
  - 培养财务责任感，学习理财
  - 建立紧急资金
  - 每月全额还款（忽略最低还款额）
  - 保持较低的信用额度使用率
  - 永远不要错过还款日期，设置自动还款
- **信用卡错误**：
  - 申请太多信用卡
  - 透支（考虑机会成本）
  - 用信用卡支付信用卡（以卡养卡）
  - 忽视利率优惠、消费陷阱
  - 不做预算、不记录开支
  - 不要花光所有钱，制定预算
  - 不要把过多钱储蓄而不投资
  - 不要背负信用卡债务
  - 不要忽视信用积分
  - 不要投资任何你完全不了解的东西
- **信贷与负债**：
  - 名义利率(账面标价) ≠ 真实成本
  - 实际年化IRR(真实资金成本，法定口径APR)
  - 实际年化 = 逐月还本，本金减少，手续费/利息按初始全额交，资金实际占用时间减少
  - 信用卡账单分期：真实年化 ≈ 名义年化 × 1.8
  - 消费贷/现金贷：真实年化远高于名义
  - 网贷/随借随还：真实年化高
  - 商品分期：服务费、担保费、变相利息

### 2.3 保险规划

- **保险作用**：对冲风险
- **人身险**：
  - 医疗险：报销型
  - 重疾险：给付型，长期保障
  - 意外险：一次性赔付
  - 寿险：一次性赔付
- **财产险**：车险（交强险、商业车险）
- **家财险**：保房屋、保室内、保物品、保责任、附加险
- **理财型保险**：强制储蓄，类似定投
- **财富传承**："三不碰"（终身寿险、年金险）
- **特殊情况**：税优健康险（可抵税）、长期护理险
- **配置步骤**：确定需求 → 确定预算 → 确定产品类型 → 确定保额 → 确定保障期限 → 挑选产品
- **注意点**：如实告知、理赔、保险公司、内地居民

## 三、投资金融

### 3.1 投资基础

- **资产分类**：现金/货币基金、债券基金、股票基金、混合基金、指数基金、ETF、公募REITs
- **风险收益关系**：风险由低到高排列
- **复利与实际收益率**
- **资产配置基础**：
  - 进攻资产：股票型基金、混合型基金（偏股）、宽指基金
  - 防守资产：纯债基金、中短债基金、一级债基
  - 稳健型配置：20/80（股/债）
  - 均衡型配置：50/50
  - 进取型：80/20
  - 股债搭配：降低回撤、对冲亏损、提高持有体验、长期收益更稳
- **房子净值**：资产与负债间的差额

### 3.2 基金投资

#### 基金核心概念
- **场内 vs 场外**：
  - 场内：证券交易市场，需账户，投资者间交易，交易时间有限，有溢价率
  - 场外：不需账户，与基金公司交易，交易时间不限，有跟踪误差
- **费用**：
  - A类：买入收申购费，卖出收赎回费（一次性），持有时间越长赎回费越低
  - C类：按持有时间收销售服务费，不收申购费，短期买卖更灵活
  - Y类：个人养老基金，费率低，税收优惠
  - 管理费（给基金经理）、托管费（银行收）、申购/赎回费
  - 宽基指数基金：管理费每年0.15%~0.5%
  - 主动股票基金：管理费每年1.2%~1.8%
- **单位净值**：基金单价
- **份额**：持仓数量 = (买入本金-手续费) ÷ 当天基金净值
- **申购/赎回时间规则**：
  - 场外：下午3点前申购按当天收盘净值算；3点后顺延下一交易日
  - 赎回同理，钱不会立刻到账，要等清算+回款
  - T+1：T=交易日（周一~周五，节假日不算），当天买第二天确认份额算涨跌
  - 货币基金：T+1确认；债券/混合/股票：T+1卖出，T+2~T+4提现

#### 基金分类
- **货币基金**：风险极低，流动性强，收益低但稳定
- **债券基金**：
  - 纯债基金：只投债券，不投股票，不打新，不投可转债
  - 中短债基金：投资剩余期限较短的债券，流动性好，波动略高，收益更高，几乎不会连续大跌
  - 可转债：跌时像债券有利息保底，涨时像股票跟涨，波动大，可能暴跌，风险大
  - 债券基金投向：国债、地方债、企业债、金融债、短融、中票、同业存单
- **混合基金**：
  - 偏债混合型（债多股少）
  - 平衡混合型
  - 偏股混合型（股多债少）
- **股票基金**：股票仓位≥80%
- **主动基金**：基金经理选股调仓，赚的是选股调仓的钱
- **被动指数基金**：无脑复制大盘/行业指数，规则透明，长期收益稳

#### 指数基金细分
- **宽基指数**：行业分散
  - 沪深300：大盘蓝筹，A股前300家顶级，稳，大盘整体行情
  - 中证500：中盘成长，剔除沪深300后500家，中等规模企业，比300波动大
  - 中证1000：小盘潜力，再往下的1000家，更精选细分小龙头，波动大
  - 中证2000：小微盘
- **行业指数基金**：单一行业，波动大，风险中等，暴涨暴跌
- **策略指数基金（Smart Beta）**：如红利、低波动

#### 基金选择与避坑
- **基金判断标准**：
  - 标准1：成立时间>3年
  - 标准2：基金规模2亿~100亿区间（2亿~50亿最优），<2亿易清盘风险，>100亿经理难操作
  - 标准3：看长期历史数据，不只看短期业绩，3年以上能穿越一轮牛熊
  - 标准4：风控数据，最大回撤&波动率
  - 标准5：基金经理任职稳定，不频繁换人
  - 标准6：基金经理任职>3年，全程带队穿越牛熊
- **避坑指南**：
  - 新基金：成立时间短，无历史业绩参考，仓位在建，净值波动不稳定，费率不低，可能有封闭期
  - 行业基金：波动大，牛短熊长
  - 网红热点基：短期资金扎堆+情绪炒作
  - 短期暴涨、排名冲顶基：大多是赌对了不是实力，市场情绪最热，估值最贵，后期回跌风险大
  - 跟踪误差大：基金经理没乱搞，严格复制指数
  - 规模太小：可能清盘，选股跑输，调仓不及时
  - 费率低：管理费等综合成本低

#### 定投
- **原理**：固定金额投资→价格↓份额↑，价格↑份额↓，实现"低吸高抛"的被动执行
- **周投 vs 月投**：长期下收益率差异几乎可以忽略；月投更平滑，周投对短期波动更敏感
- **行为差异**：月投远离市场噪音
- **止盈不止损**：
  - 定投收益来源于熊市积累份额+牛市收获
  - 止损=在低位割肉，是"错误的负向择时"
  - 止盈：A股牛短熊长，不止盈收益会大幅回吐
  - 收益到15%~20%：卖出一半；收益到25%~30%：再出一半；分成12个月定投回去；最大回撤超过5%：止盈

#### 红利基金
- **定义**：高股息红利策略基金，筛选连续多年稳定现金分红、股息率排名靠前的上市公司
- **收益来源**：股息分红收益 + 资本利得收益
- **按选股分类**：
  - 传统单因子红利：纯按股息率
  - 红利+低波动双因子
  - 红利+盈利质量
  - 红利+价值
  - 跨境港股红利：股息更高，波动大
- **产品类型**：
  - 场内ETF：股票账户买卖
  - 场外联接基金
  - 主动红利基金：管理费高
- **分红机制**：
  - 时间：当天收盘持有就能参与，之后买入不享受
  - 除息日：基金净值扣除分红金额，净值主动下跌
  - 红利发放日：现金到账或自动增加基金份额
  - 两种形式：现金分红（资产不变，份额变现金）、红利再投资（资产不变，份额不断增长）
  - 除息：分红后净值下调，把持仓股票市值一部分以现金返还，本质是资产转移
- **优缺点**：
  - 优点：熊市抗跌、回撤小、现金流稳定、省心被动指数、估值长期低位、行业分散
  - 缺点：成长牛市大幅跑输、行业绑定周期（经济下行分红缩减）、弹性不足、分红不是刚性兜底
- **分红税规则**：
  - 基金本身免收企业所得税
  - 个人投资者现金分红、红利再投资不需缴纳个税

### 3.3 股票投资

- **普通股**：代表公司股权一定比例的证券
- **年底分红**：扣除各项开支后的利润实际属于股东
- **资本增值**：间接收益方法，公司盈利↑→股票价值↑→低买高卖获利
- **价值股**：成熟公司，股息更高
- **成长股**：规模较小，成立时间短，未来潜力大的公司
- **股息分红不是义务**
- **股票 vs 债券**：
  - 股票：公司所有权，股价=股票×股数，成为股东
  - 债券：成为贷款人，有固定收益的产品
  - 最佳情况：股票暴富/债券收取一定利息
  - 最差情况：股票一无所有/债券收回本金的一部分
  - 股票风险更大，上涨潜力非常高，亏损相对容易；债券上涨潜力有限，收益可能大，损失可能小
- **资产配置**：x%股票+y%固收，决定投资组合的潜在风险和回报

### 3.4 债券投资

- **国债**：流动性高，储蓄国债持有期满可兑，提前支取付利息；记账式国债可场内交易，年化2.5%~3%
- **银行大额存单**：流动性中等，大多可提前支取转让，年化2.3%~3.0%
- **债券基金**：流动性优秀，T+1赎回，年化3%~5%
- **公募REITs**：流动性中等，场内交易，交易日可买卖，封闭期无法赎回，年化4%~7%
- **混合基金**：流动性优秀，长期年化8%~12%

## 四、企业金融

### 4.1 会计基础

#### 资产负债表
- **会计恒等式**：资产 = 负债 + 所有者权益
- **资产**：企业过去的交易或事项形成的、由企业拥有或控制的、预期给企业带来经济利益的资源（能赚钱、变现、减少支出）
- **负债**：企业过去的交易或事项形成的、预期会导致经济利益流出企业的现时义务
- **所有者权益（股东权益）**：企业资产扣除负债后，由所有者享有的剩余权益

#### 利润表
- 反映企业在一定会计期间的经营成果
- 营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 研发费用 - 财务费用 + 其他收益 + 投资收益 + 净敞口套期收益 + 公允价值变动收益 - 信用减值损失 - 资产减值损失 + 资产处置收益
- 利润总额 = 营业利润 + 营业外收入 - 营业外支出
- 净利润 = 利润总额 - 所得税费用
- **扣非净利润**：扣除非经常性损益后的净利润，剔除偶然、不具备持续性的收支，仅保留主营业务带来的利润，反映企业核心主业赚钱能力

#### 现金流量表
- 反映企业在一定会计期间现金及现金等价物的流入、流出与净变动情况
- 分为：经营活动现金流、投资活动现金流、筹资活动现金流
- **现金流 ≈ 净利润 + 折旧摊销等非付现费用 - 营运资本增加**
- 现金流反映真实经营状况

### 4.2 财务分析

#### 盈利能力
- **毛利率** = (营业收入 - 营业成本) / 营业收入 × 100%
  - >70%：高毛利，竞争力强
  - 20%~40%：正常
  - <20%：薄利行业
- **净利率** = 净利润 / 营业收入 × 100%
- **营收增长率** = (本期营收 - 上期营收) / 上期营收 × 100%
- **净利润增长率** = (本期净利润 - 上期净利润) / 上期净利润 × 100%
- **同比** = 本期数 / 去年同期数 × 100%
- **环比** = 与上一个相邻期间比
- **真实增长**：剔除季节、行业必看

#### 费用率
- **销售费用**：为了卖东西花的钱
- **管理费用**：公司运转的花销
- **财务费用**：借钱花的钱
- **单项费用率** = 单项费用 / 营业收入 × 100%
- **三项费用率** = (销售+管理+财务) / 营业收入 × 100%
  - <30%：优秀
  - 30%~50%：正常
  - 50%~70%：偏高
  - >70%：易亏损

#### 偿债能力
- **资产负债率** = 总负债 / 总资产 × 100%
  - 40%：低负债
  - 40%~60%：合理区间
  - 60%~80%：经营风险高
  - >100%：资不抵债，资金链断裂
- **流动比率** = 流动资产 / 流动负债
  - >2：短期安全
  - <1：易爆雷
- **有息负债占比**：经营性负债（无息）vs 有息负债

#### 资产质量
- **流动资产**：
  - 货币资金：公司手里的现金+活期存款+随时能用的钱，长期过低企业抗风险差
  - 应收账款：别人欠公司的钱，账面收入；应收账款暴增=营收虚高、现金流变差
  - 存货：原材料、半成品、没卖出去的成品、库存商品；风险：过时、损耗、贬值
- **非流动资产**：
  - 固定资产：长期持有实物形态的资产（厂房、设备），累计折旧计入成本，减少利润
  - 无形资产：长期持有无实物形态（专利、商标、著作权、合同权）；商誉≠无形资产
  - 长期股权投资
  - 其他非流动金融资产/其他权益工具投资

- **负债**：
  - **流动负债**（1年内必须结清）：
    - 短期借款：临时周转或银行借贷，会拉低利润，加大短期偿债压力
    - 应付账款：欠供应商的钱，预收款项↑→公司话语权↑
    - 预收款项：收钱未发货、待提供服务，有订单、公司话语权↑、未来收入有保障
  - **非流动负债**：
    - 长期借款：向银行/金融机构借入的长期贷款，长期借款↑→长期扩张意愿↑，长期偿债压力↑
    - 应付债券：对外发债券，向市场融资，代表企业信用资质优秀
    - 长期应付款
    - 递延所得税负债等

#### 所有者权益
- 所有者权益 = 股本 + 资本公积 + 未分配利润
- **股本**：营业执照的注册资本
  - 实缴：股东初始投入的账面本金
  - 股份制公司称股本，有限公司叫实收资本
- **资本公积**：溢价发行，不属于企业经营利润
- **未分配利润**：公司经营攒下的留存净利润，可后续分红，也可留存扩大企业经营

#### 利润表造假识别
1. **提前确认收入**：货没发服务没做，提前算营收虚增利润
2. **虚构营收**：凭空造假客户、合同、流水
3. **延迟记录成本费用**：当期开销亏损不入账，压成本、升利润
4. **变卖资产凑利润**：非主营虚假利润
5. **减值计提随意**：少提坏账、存货资产减值，少扣损失，虚抬利润
6. **关联交易做流水**：关联公司低买高卖虚假做大营收
7. **政府补助一次性入账**：补助非持续收益，算作常规盈利，误导盈利稳定性

#### 现金流分析
- **经营现金流**：
  - 正数：主业收现>付现，真盈利
  - 三种利润表对照：
    - 利润正、经营现金流负：盈利应收坏账，资金链安全0
    - 利润负、经营现金流正：账面亏损，现金安全
    - 同步同向增长：盈利真实
- **投资现金流**：
  - 流入：变卖闲置设备、厂房、旧资产，收回对外投资本金、投资分红、理财项目回款
  - 流出：购置固定资产、设备、厂房、无形资产，对外股权投资、理财、收购其他公司
  - 持续大额流出：公司扩产，偏成长型
  - 大额流入、短期回血：警惕主业疲软
  - 长期净额为负：靠变卖度日
- **融资现金流**：
  - 流入：银行借款、发行债券（举债融资）、增发股票、股东增资（股权融资）
  - 流出：偿还借款本金、兑付债券、支付股息分红、回购股票

### 4.3 估值指标
- **PE市盈率** = 股价 / 每股净利润，衡量赚钱能力
- **PB市净率** = 股价 / 每股净资产，衡量资产估值
- **PS市销率** = 市值 / 营业收入，适合成长型公司
- **股息率** = 年度现金分红 / 当前股价
- **估值分位**：当前估值在历史区间的位置（0%~100%）
- **PE低但净利润来自非主营业务**：伪估值，回避
- **PB低**：负债率↑、商誉↑、应收账款↑、资产质量差

## 五、商业与创业金融

### 5.1 商业模式

- **五步闭环**：获客 → 转化 → 成交 → 复购 → 裂变
- **获客（流量）**：让潜在客户看到产品
- **种草（信任）**：展示价值、案例、口碑打消客户顾虑
- **成交**：完成首次付费
- **复购/留存**：服务/品质落地，推动客户再次消费
- **裂变回流**：老客户推荐新客户

### 5.2 盈利模式
- 服务费模式：靠专业、劳务、广告，把控单位时间产值
- 差价模式：低买高卖，把控进货成本、流转速度
- 订阅模式：提前锁定应收，培养长期复购
- 流量变现：吸附流量，流量规模+精准度
- 增值服务模式：基础产品低价引流靠附加服务盈利

### 5.3 成本与定价

- **成本结构**：
  - 固定成本：不随业务变动，必须支出的费用
  - 可变成本：随业务量同步变动的支出
  - 盈亏平衡法：营收覆盖全部成本是盈利基准线，优先压低固定成本
- **定价策略**：
  - 成本加成定价：售价 = 单位总成本 × (1+期望利润率)
  - 随行就市定价：同质化严重产品，拼价格参考同行价格
  - 引流定价：爆款单品微利/保本定价，用来引流，靠其他产品盈利
  - 价值定价（高客单/服务）：按给用户创造的价值定价
  - 阶梯定价：量大价低
  - 撇脂定价：新品初期定高价，逐步降价

### 5.4 融资

- **初始资金**：自有资金、亲友借款、政府补贴/创业扶持、个人经营贷/信用贷、天使投资/小额种子融资、合伙人出资
- **银行经营贷/企业授信逻辑**：
  - 个人经营贷：个体户、个人无限责任
  - 企业经营贷：有限公司、公司有限责任
  - 银行授信关注：经营真实性、现金流、征信、抵押物担保
- **常见产品**：税贷、发票贷、流水贷、抵押经营贷
- **股权融资**：
  - 出资规则写入协议
  - 避免股权50:50
  - 权责与决策分明
  - 避免股权均分僵局
  - 1~2年不得退股

### 5.5 税务

- **两类纳税人**：小规模 vs 一般纳税人
  - 小规模：连续12个月不含税销售额<500万，一般3%征收率，月销售额10万内免征增值税（季度30万），超过全额交税，专票不免
  - 一般纳税人：年销售额>500万，税率13%/9%/6%等，可抵扣进项发票
- **四大基础税种**：
  - 增值税：流转税，有收入就要交；应交增值税 = 销项税额 - 进项税额
  - 企业所得税：公司主体才交；小微企业优惠（年应纳税≤300万）实际税负5%；利润 = 全年收入 - 全部合规成本
  - 个人所得税：个体户、个人独资、合伙企业按经营所得五级累进税率交税，可扣除经营成本，每年6万免征额；附加税费：城建税、教育附加、地方教育附加，交增值税才交附加税
- **报税周期**：
  - 小规模：增值税、附加税按季度申报；企业所得税季报+年报；个税按月申报；企业外报税季报+年报
  - 一般纳税人：增值税、附加税按月报；企业所得税季报+年报；个税按月；企业外报税季报+年报
- **流程**：收集票据 → 核算收入开票数据 → 申报期内在电子税务局线上填报 → 核对税款、对公账户自动扣款 → 每年5月31日前完成企业所得税年度汇算（多退少补）

## 六、金融风险与法律保护

### 6.1 征信与借贷

- **征信**：
  - 查询：每年免费2次，非本人必须书面授权
  - 不良记录：还清欠款当日起，逾期记录保留5年自动消除
  - 异议更正：被盗用身份、银行录错逾期可向央行申请删除
  - 无任何机构可花钱洗白逾期
- **逾期分级影响**：
  - 1~30天：影响小，留下记录，信贷审批小幅扣分
  - 31~90天：影响明显，无缘信用提额、低息贷款利率
  - >90天：征信黑名单，列入失信被执行人
- **民间借贷**：
  - 合法利率红线：LPR四倍为司法保护上限，超出的违法
  - 必备证据链：借条完整要素、转账流水、可辨认记录
  - 无效借贷：高利转贷、非法集资、信贷套现、套路贷
  - 催收与诉讼：时效3年内起诉，中断时效（书面催款、积极主张）
  - 反向风险：如何保全对外借出的钱被起诉扣划

### 6.2 担保与保险法律

- **担保**：
  - 一般保证：有先诉抗辩权，先执行债务人名下财产
  - 连带保证：以全部财产兜底，债权人可直接起诉担保人
  - 合同没写"一般保证"，默认连带担保
  - 担保范围：签字即无限兜底
  - 解除担保条件：债务还清、债权人书面免除担保权、转让未通知担保人
- **保险法律**：
  - 保障类保险（医疗/重疾/意外险）理赔规则：免责条款、等待期、举证要求、拒赔维权路径
  - 财富类保险：保险金不作为遗产、不轻易被分割（增额寿、年金）
  - 法律隔离逻辑：投保人、被保人、受益人架构设计
  - 避坑：恶意负债后买保险无法隔离，属于可执行财产

### 6.3 资产隔离

- **婚前财产隔离**：
  - 婚前存款单独银行卡存放，婚后不转入不用于日常消费，流水完整留存
  - 婚后工资用于日常消费，婚前单独账户出资，婚后不追加共同资金
  - 可追工具：婚前财产协议（签字即生效，无需公证）
- **婚后**：
  - 夫妻共同债务判定：用于家庭共同生活/共同经营才共同承担
  - 单方赌博负债不属于共同债务
  - 个人欠债不牵连家人
- **经营隔离**：
  - 必须公私账户分离，禁止私卡收经营款
  - 签字前书面约定债务归属，留存证据

### 6.4 公司法与合伙协议

- **企业类型选择**：有限公司（有限责任）/ 合伙企业（无限连带）
- **公司法核心**：
  - 认缴出资：注册资本不虚实缴，公司欠债股东在认缴范围内承担清偿责任
  - 公私分离：严禁混同
  - 公司章程：约定分红、表决、退出股权稀释规则
- **合伙/股东协议**：
  - 必须书面约定，拒绝口头
  - 退出机制：中途撤资、业绩不达标、出轨同业→约定股权回购价
  - 不凑股份：谁管财务、谁管业务、重大决策投票规则
  - 股权代持规范：隐名股东显名股东书面协议，防止工商登记人独自背负债务

### 6.5 劳动合同与知识产权

- **劳动合同**：
  - 入职30日内签书面合同、足额缴社保
  - 不签合同赔付双倍工资
  - 辞退合规：不能随意开除，协商解除给补偿金；违法辞退付2N赔偿金
  - 证据留存：考勤记录、加班签字、绩效考核、工资签收文件
- **知识产权**：
  - 商标：品牌提前注册
  - 著作权：宣传文案、图片、小程序、设计稿，登记版权
  - 专利：自有产品外观/技术，申请实用新型/外观专利
  - 红线：不随意使用网络图片、字体、素材

### 6.6 合同纠纷

- **全流程处理**：
  - 签约前审查：对方资质、格式合同免责条款、违约赔付、争议管辖法院
  - 履约留证：送货单、对账单、聊天记录、付款凭证全部归档
  - 违约处置：催告函、违约金计算、起诉流程、财产保全
- **公章管理**：专人保管、用印登记、禁止空白合同盖、杜绝盗用风险
