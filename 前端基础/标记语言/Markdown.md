# (一)基础语法

## 1.标题

示例：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

---

## 2.段落与换行

### (1) 强制换行

例如：`第一行<br>第二行`。
### (2) 软换行与分段

普通回车在 CommonMark 中通常是软换行，渲染后未必换行；空一行用于分段。强制换行可在行末放两个空格、一个反斜杠，或使用允许的 HTML `<br>`；具体效果还取决于平台设置。

## 4.文本格式

|效果|语法|
|:--:|:--:|
|**加粗**|`**文本**` 或 `__文本__`|
|*斜体*|`*文本*` 或 `_文本_`|
|***加粗斜体***|`***文本***` 或 `___文本___`|
|~~删除线~~|`~~文本~~`（GFM 等扩展）|
|<u>下划线</u>|`<u>文本</u>`（需平台允许 HTML）|
|高亮|`==文本==`（部分笔记工具扩展）|
|上标|`^文本^`（扩展）或 `<sup>文本</sup>`|
|下标|`~文本~`（扩展）或 `<sub>文本</sub>`|

## 6.链接

### (1) 行内式链接

+ 语法：`[链接显示文本](链接地址 "可选标题")`
+ 示例：[GitHub](https://github.com "GitHub官网")

### (2) 参考式链接

+ 适合多次引用同一个链接，分离链接地址和文本，提高可读性。
+ 语法：

```markdown
[链接显示文本][标记]

[标记]: https://example.com "可选标题"
```

+ 示例：

[Markdown指南][1]

[1]: https://www.markdownguide.org "Markdown指南"

### (3) 自动链接

+ 直接用  <>  包裹网址或邮箱，自动生成可点击链接。
+ 示例：
<https://www.baidu.com>
<example@mail.com>

### (4)锚点/页内跳转

`[点我跳转到目标位置](#目标标题)`

标题锚点由渲染平台决定，CommonMark 本身不规定自动标题 ID。GitHub 常把空格改为 - 并处理标点，重复标题还会追加后缀；优先复制实际生成的章节链接，不把一套规则套用于所有平台。

## 7.图片

### (1) 行内式图片

+ 语法：`![图片alt文本](图片地址 "可选标题")` 
-  alt文本 ：图片加载失败时显示的文字
-  标题 ：鼠标悬停在图片上显示的文字
- 示例：
![Markdown Logo](https://markdown-here.com/img/icon256.png "Markdown图标")

### (2) 参考式图片

+ 语法：

```markdown
![图片alt文本][标记]

[标记]: https://example.com/image.png "可选标题"
```

+ 示例：

![C++ Logo][cpp]

[cpp]: https://cppreference.com/favicon.ico "C++参考资料图标"

---

## 8.代码块

### (1) 单行代码

+ 用反引号  `  包裹代码片段。
+ 语法： `代码内容`
+ 示例：C++ 的 `std::vector` 是动态数组容器

### (2) 多行代码

#### a.方法1

用 3 个反引号  ```  包裹，开头可指定编程语言实现语法高亮

#### b.方法2

缩进 4 个空格或 1 个制表符，适合简单代码块（不推荐，无语法高亮）

---

## 9.分隔线

使用至少 3 个相同的 -、* 或 _，例如 ---、***、___；它们之间允许空格或 Tab（如 * * *），但不能混用不同符号。为避免 --- 紧跟段落被解析为二级标题，示例前后保留空行。

---
***
___

---

## 10.引用

用  >  表示引用，支持嵌套和嵌套其他语法。
> 这是一级引用
>> 这是嵌套的二级引用
>>> 嵌套三级引用，还可以加 **加粗** 和 *斜体*

## 12.Callout

> [!NOTE]
> 这是一条普通提示，用于补充说明。

> [!TIP]
> 这是技巧提示，用于给出小妙招。

> [!IMPORTANT]
> 这是重要内容，需要重点关注。

> [!WARNING]
> 这是警告，提醒注意风险。

> [!CAUTION]
> 这是危险提醒，强调必须谨慎。

下面的扩展类型及别名表按 Obsidian Callout 整理，不是所有 Markdown 平台通用；GitHub 原生 Alerts 主要支持 NOTE、TIP、IMPORTANT、WARNING、CAUTION。

| 类型 | 常见别名 (Aliases) | 描述 |
| :--- | :--- | :--- |
| `note` | - | 基本的笔记或信息提示。 |
| `info` | - | 提供一般性信息。 |
| `tip` | `hint`, `important` | 提供小贴士或建议。 |
| `important` | Obsidian 中是 tip 的别名 | GitHub 中是独立 Alerts 类型。 |
| `warning` | `caution`, `attention` | 发出警告。 |
| `danger` | `error` | 表示危险或错误。 |
| `abstract` | `summary`, `tldr` | 用于摘要或总结。 |
| `todo` | - | 用于待办事项。 |
| `success` | `check`, `done` | 表示成功或已完成。 |
| `question` | `help`, `faq` | 用于问题或FAQ区域。 |
| `failure` | `fail`, `missing` | 表示失败或缺失。 |
| `bug` | - | 用于报告Bug。 |
| `example` | - | 用于展示示例。 |
| `quote` | `cite` | 用于引用。 |
