## 五、参考答案

**选择题**：1.B 2.B 3.C 4.A 5.C。原第 4 题的 `adduser alice developers` 在 Debian/Ubuntu 也能加组，故已替换该选项以保持单选。

**填空题**：

1. `whoami`（查询有效用户，不一定是最初登录者）。
2. `sudo -i`（需获得相应授权）。
3. `-m`。
4. `-r`。
5. `640`。
6. 所有者（owner）、所属组（group）。
7. 文件所属组的用户。
8. 以 root 身份创建 alice 用户；`sudo` 或 `wheel`，需有相应 sudoers 授权。
9. 能；不能。root 并非无条件绕过所有安全机制。
10. `rwx`；`r-x`；`r-x`。

**简答题**：

1. `用户名:密码占位符:UID:GID:描述:家目录:登录Shell`。
2. 给文件所有者增加执行权限。
3. 不需要主动切换组。检查访问权限时使用进程的用户身份、有效组和附加组；新加入的附加组通常需要重新登录后才能被已有会话使用。传统权限按所有者、所属组、其他用户依次选择匹配类别，并非把三类权限叠加。

**实操题**（在练习环境中执行）：

```bash
sudo useradd -m student
sudo passwd student  # 按提示交互输入密码
sudo groupadd interns
sudo usermod -aG interns student
sudo touch /home/student/readme.txt
sudo chown student:interns /home/student/readme.txt
sudo chmod 640 /home/student/readme.txt
```

# ==笔记==

## 1.文件删除

+ 删除普通文件通常需要**父目录的 `w+x` 权限**及路径上的目录搜索权限，不要求文件本身可写；粘滞位、immutable 属性、只读挂载等仍可能限制删除
+ 父目录的 w 权限允许修改目录项，但实际增、删、重命名通常还需要 x 搜索权限
+ 文件自己的 w 权限 = 允许修改这个文件的内容
+ **删除文件 = 修改父目录的内容**（把文件名从目录列表中移除），不需要对文件本身有写权限。

## 2.usermod vs useradd

| 命令 | 作用 | 适用场景 |
|------|------|----------|
| `useradd` | 创建新用户 | 用户还不存在时 |
| `usermod` | 修改已存在的用户 | 用户已经存在时 |

+ -a = append（追加，不覆盖原有组）
+ -G = 附加组列表
+ -aG = 加组不覆盖

## 3.su - root 切换用户；sudo 是提权执行命令

| 命令 | 作用 | 是否切换用户 | 环境变量 |
|------|------|--------------|----------|
| `sudo command` | 按策略以 root 身份执行单条命令 | 命令进程使用 root 身份，原 Shell 不变 | 由 sudoers/PAM 等策略过滤或重置 |
| `su -` | 启动 root 的登录 Shell | 新 Shell 使用 root 身份 | 初始化目标用户的登录环境 |
| `sudo -i` | 按授权启动 root 的登录 Shell | 新 Shell 使用 root 身份 | 初始化目标环境，并以 `SUDO_USER` 等记录调用者 |
