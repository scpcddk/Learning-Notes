### 简答题

**18.**  

- **交互式确认**：`rm -i test.txt`（删除前逐一询问）  
- **强制删除不确认**：`rm -f test.txt`（直接删除，不提示）  
- *（若要递归删除目录则加 `-r`，如 `rm -rf dir/`）*

**19.**  

- **`pwd`（默认）**：输出逻辑路径，例如 `/home/username/mylink`（显示符号链接本身的路径）。  
- **`pwd -P`**：输出物理路径，例如 `/var/log`（强制解析所有符号链接，显示真实的物理目录）。  
- **原因**：在Bash内置命令中，默认不解析符号链接以保持逻辑视图；`-P` 选项则通过访问物理文件系统来返回绝对路径。

**20.**  

两条命令完全等价，均将文件 `file` 的权限设置为：  

- **所有者（u）**：`rwx`（读、写、执行）  
- **组（g）**：`r-x`（读、执行）  
- **其他用户（o）**：`r-x`（读、执行）  
- `chmod 755` 使用八进制数字模式（7=rwx，5=r-x）；`chmod u=rwx,go=rx` 使用符号模式，二者表达的含义完全一致。

**21.**  
（1）向下搜索：在命令模式下输入 `/error` 并回车。  
（2）全文替换：在底线命令模式下输入 `:%s/old/new/g` 并回车。  
（3）撤销上一次操作：在命令模式下按 `u`。

**22.**  
`grep -in "Exception" app.log`

- `-i`：忽略大小写  
- `-n`：显示匹配行的行号

**23.**（以下任选三点）  
① **可视化CPU/内存条形图**：在顶部直观显示每个CPU核心的使用率和内存占用百分比。  
② **鼠标点击支持**：可直接用鼠标点击选择进程或操作菜单项。  
③ **无需输入PID即可发送信号**：选中进程后直接按 `F9` 发送终止信号（如SIGKILL）。  
④ **支持水平和垂直滚动**：可左右滚动查看被终端截断的完整命令行，上下滚动浏览进程列表。

**24.**  

- **首选方案（现代Linux通用）**：`ss -tlnp`（来自 `iproute2` 套件，默认安装）。  
- **备选方案**：`netstat -tlnp`（需系统安装 `net-tools` 包；Ubuntu/Debian：`sudo apt install net-tools`，CentOS/RHEL：`sudo yum install net-tools`）。

**25.**

- **`sudo apt update`**：从软件源仓库获取最新的软件包列表（仅更新索引，不升级任何软件）。  
- **`sudo apt upgrade`**：根据已更新的索引，升级所有已安装的软件包到最新版本。  
- **组合一键升级**：`sudo apt update && sudo apt upgrade -y`（`-y` 自动确认所有升级提示）。

**26.**（以下三种任选，需包含覆盖和追加）

- **方式一（覆盖写入）**：`echo "Hello, Linux" > test.txt`  
- **方式二（追加写入）**：`echo "Hello, Linux" >> test.txt`  
- **方式三（覆盖写入，使用printf）**：`printf "Hello, Linux\n" > test.txt`  
- *（或使用 `tee`：`echo "Hello, Linux" | tee test.txt` 覆盖写入；`echo "Hello, Linux" | tee -a test.txt` 追加写入）*

**27.**  

- **相同点**：两者都启动 **login shell**，会读取 `/etc/profile`、`~/.bash_profile` 等登录环境配置文件。  
- **关键区别**：  
  ① **认证方式不同**：`su -` 需要**目标用户（如root）的密码**；`sudo -i` 需要**当前用户自己的密码**（且当前用户必须在 `/etc/sudoers` 中有执行权限）。  
  ② **环境变量继承差异**：`sudo -i` 会重置 `$HOME` 为目标用户的home目录，但 `$USER`、`$LOGNAME` 等环境变量可能仍保留原用户的值（取决于PAM配置）；而 `su -` 则完整、纯净地切换为目标的全部环境变量。  
  ③ **超时机制**：`sudo` 默认有 **15分钟** 的免密缓存（可配置），在超时内再次执行无需重复输入密码；`su -` 没有超时机制，切换后持续生效直至执行 `exit` 退出。
