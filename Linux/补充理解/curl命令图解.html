curl 命令详解

命令行网络工具 | 下载文件 | 调试 API | 自动化脚本

一、curl 是什么？一句话理解
curl = 命令行版的"浏览器"，用代码发 HTTP 请求、下载文件、调试接口
核心特点：
• 支持 HTTP/HTTPS/FTP 等 100+ 协议
• 纯命令行，无图形界面，适合脚本自动化
• 跨平台：Linux/macOS/Windows 都能用
• 底层基于 libcurl 库，功能极其丰富
curl 能做什么？
下载文件：从服务器下载图片、视频、安装包
调试 API：测试 RESTful 接口（GET/POST/PUT/DELETE）
发送数据：提交表单、上传 JSON、上传文件
认证登录：Basic Auth、Bearer Token、Cookie 会话
网络诊断：查看响应头、测试响应时间、排查问题
二、基本语法：curl [选项] [URL]
# 最简单的用法：获取网页内容并打印到终端 curl https://www.example.com # 下载文件并保存为指定名称 curl -o myfile.html https://www.example.com # 下载文件，使用远程服务器的文件名 curl -O https://www.example.com/file.zip
三、请求控制（面试/开发最常用）
选项全称作用典型场景
-X--request指定 HTTP 方法curl -X POST url
-d--data发送 POST 数据（表单或 JSON）curl -d "name=John" url
-H--header添加自定义请求头curl -H "Content-Type: application/json" url
-G--get将 -d 数据作为 GET 参数curl -G -d "q=keyword" url
-F--form上传文件（multipart/form-data）curl -F "file=@local.txt" url
-u--user用户名密码认证curl -u admin:123 url
-L--location跟随重定向（301/302）curl -L http://short.url
-I--head只获取响应头curl -I url
记忆口诀：
X 方法 | d 数据 | H 头部 | G GET参数 | F 文件上传 | u 认证 | L 重定向 | I 只看头
四、输出控制
选项作用示例
-o保存到指定文件名curl -o backup.zip url
-O使用远程文件名保存curl -O url/file.zip
-s静默模式（不显示进度条）curl -s url
-S配合 -s，静默但显示错误curl -sS url
-v显示详细通信过程（调试神器）curl -v url
-w自定义输出格式（如状态码）curl -w "%{http_code}" url
-o vs -O 区别：
-o：你自己指定文件名（如 -o myfile.html）
-O：curl 自动用服务器上的文件名（如 file.zip）
类比：-o 像"另存为"，-O 像"直接下载"
五、实战场景（按开发流程）
场景1：GET 请求获取数据
# 普通 GET curl https://api.example.com/users # GET 带查询参数 curl -G -d "page=1" -d "size=10" \ https://api.example.com/users # 等价于： # https://api.example.com/users?page=1&size=10
场景2：POST 提交 JSON
# 发送 JSON 数据（最常用） curl -X POST \ -H "Content-Type: application/json" \ -d '{"name":"Alice","age":30}' \ https://api.example.com/users # 从文件读取 JSON curl -X POST \ -H "Content-Type: application/json" \ -d @data.json \ https://api.example.com/users
场景3：提交表单
# 表单数据（application/x-www-form-urlencoded） curl -X POST \ -d "username=admin&password=123" \ https://api.example.com/login # 文件上传（multipart/form-data） curl -X POST \ -F "file=@/path/to/report.pdf" \ -F "description=季度报告" \ https://api.example.com/upload
场景4：认证与授权
# Basic Auth（用户名+密码） curl -u admin:password123 \ https://api.example.com/admin # Bearer Token（JWT/API Key） curl -H "Authorization: Bearer eyJhbG..." \ https://api.example.com/protected # Cookie 会话（登录后保持状态） # 1. 登录保存 cookie curl -c cookies.txt -X POST \ -d "user=alice&pass=secret" \ https://example.com/login # 2. 后续请求携带 cookie curl -b cookies.txt \ https://example.com/dashboard
场景5：下载文件
# 下载并指定文件名 curl -o nginx.tar.gz \ https://nginx.org/download/nginx-1.24.0.tar.gz # 断点续传（下载中断后继续） curl -C - -O \ https://example.com/large.iso # 限制下载速度（避免占满带宽） curl --limit-rate 500K \ -O https://example.com/large.iso
场景6：调试与诊断
# 查看响应头（不下载内容） curl -I https://api.example.com/status # 查看完整通信过程（调试神器） curl -v https://api.example.com/users # 只获取 HTTP 状态码 curl -s -o /dev/null \ -w "%{http_code}" \ https://api.example.com/health # 测试响应时间 curl -o /dev/null -s \ -w "DNS:%{time_namelookup}\n\ Connect:%{time_connect}\n\ TTFB:%{time_starttransfer}\n\ Total:%{time_total}\n" \ https://example.com
六、安全与代理
选项作用注意
-k忽略 SSL 证书验证仅测试用，生产环境禁用
--cacert指定自定义 CA 证书解决自签名证书问题
-x使用代理服务器curl -x http://proxy:8080 url
--proxy同上，更完整的代理配置支持 HTTP/SOCKS5
⚠️ 安全警告：不要在脚本中明文写密码！
优先使用环境变量、.netrc 文件（权限设为 600）或密钥管理服务
七、常见问题速查
问题现象解决
SSL 证书错误curl: (60) SSL certificate problem--cacert 指定证书，或 -k 临时忽略（不推荐）
301/302 跳转返回 HTML 而非 JSON加 -L 跟随重定向
415 错误Unsupported Media Type加 -H "Content-Type: application/json"
401 错误Unauthorized检查 -u 或 Authorization 头是否正确
中文乱码响应内容乱码检查响应头 charset，或管道给 iconv
下载中断大文件下载到一半失败加 -C - 断点续传
八、curl vs wget 怎么选？
curl

适合：API 调试、HTTP 请求控制
支持：自定义 Header、多种方法、上传
特点：功能丰富、协议支持多
开发/测试首选
wget

适合：递归下载、网站镜像
支持：断点续传、递归下载、后台下载
特点：下载功能更强、批量获取简单
下载/爬虫首选
