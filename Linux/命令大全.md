## **一.文件管理**

### **(一).rm**

* **注意**：文件通过rm命令删除，则无法恢复

#### 1.rm的作用

**删除一个文件或者目录**

#### 2.rm的语法

rm [options] name...

#### 3.rm的参数

| 参数 | 作用 |
| ------ | ------ |
| **`-i`** | 删除前逐一询问确认 |
| **`-f`** | 原档案属性设为唯读，亦直接删除，无需逐一确认 |
| **`-r`** | 将目录及以下之档案逐一删除 |

#### 4.rm的示例

* 删除文件与目录

```Linux
# rm  test.txt 
rm：是否删除文件 "test.txt"? y  
# rm  homework  
rm: 无法删除目录"homework": 是一个目录  
# rm  -r  homework  
rm：是否删除 目录 "homework"? y 
# rm  -r  *     ( * 代表当前目录下所有非隐藏文件与目录)
删除当前目录下文件与目录
```

### **(二).mv**

#### 1.mv的作用

**为文件或目录改名、或将文件或目录移入其它位置**

#### 2.mv的语法

| 命令格式 | 运行结果 |
| :--- | :--- |
| `mv source_file` (文件) `dest_file` (文件) | 将源文件名 `source_file` 改为目标文件名 `dest_file` |
| `mv source_file` (文件) `dest_directory` (目录) | 将文件 `source_file` 移动到目标目录 `dest_directory` 中 |
| `mv source_directory` (目录) `dest_directory` (目录) | - 若目录名 `dest_directory` **已存在**，将 `source_directory` 移动到目录 `dest_directory` 中<br>- 若目录名 `dest_directory` **不存在**，则将 `source_directory` 改名为 `dest_directory` |
| `mv source_directory` (目录) `dest_file` (文件) | **出错** |

* **注意**：需要先执行显示隐藏文件命令，否则，隐藏文件以及隐藏文件夹不会被移动到新目录。（英语点号开头的文件/夹会被作为隐藏文件/夹处理）

#### 3.mv的参数

| 参数 | 作用 |
| ------ | ------ |
| **`-b`** | 当目标文件或目录存在时，在执行覆盖前，会为其创建一个备份 |
| **`-i`** | 如果指定移动的源目录或文件与目标的目录或文件同名，则会先询问是否覆盖旧文件，输入 `y` 表示直接覆盖，输入 `n` 表示取消该操作 |
| **`-f`** | 如果指定移动的源目录或文件与目标的目录或文件同名，不会询问，直接覆盖旧文件 |
| **`-n`** | 不要覆盖任何已存在的文件或目录 |
| **`-u`** | 当源文件比目标文件新或者目标文件不存在时，才执行移动操作 |

### **(三).cp**

#### 1.cp的作用

**用于复制文件或目录**

#### 2.cp的语法

cp [options] source dest     `//文件或目录路径`

#### 3.cp的参数

| 参数 | 作用 |
| ------ | ------ |
| **-r** 或 **-R** | 递归复制目录及其内容（用于复制目录） |
| **-i** | 交互模式，覆盖前提示用户确认 |
| **-f** | 强制复制，覆盖目标文件而不提示 |

| **-s** | 创建符号链接（软链接）而不是复制文件 |

### **(四).cat**

#### 1.cat的作用

**连接文件并打印到标准输出设备上，查看和连接文件**

#### 2.cat的语法

cat [选项] [文件]

#### 3.cat的参数

| 参数 | 作用 |
| ------ | ------ |
| **-n** | 显示行号，会在输出的每一行前加上行号 |
| **-b** | 显示行号，但只对非空行进行编号 |
| **-s** | 压缩连续的空行，只显示一个空行 |
| **-E** | 在每一行的末尾显示 `$` 符号 |
| **-T** | 将 Tab 字符显示为 `^I` |
| **-v** | 显示一些非打印字符 |

#### 4.cat的使用

+ **显示文件内容**：cat filename 将指定文件的内容输出到终端上(可多个)
+ **连接文件**：cat file1 file2 > combined_file 将 file1 和 file2 的内容连接，并将结果输出到 combined_file 中
+ **创建文件**：cat > filename，输入文本，按 Ctrl+D 保存并退出
+ **在终端显示文件**：将 cat 与管道（|）结合使用，显示其他命令的输出，例如 ls -l | cat 会将 ls -l 的输出通过 cat 打印到终端上
+ **追加重定向**：cat >> filename，将标准输入追加到文件 filename 的末尾
+ **覆盖写入**:cat > filename ，清空原内容，写入新内容（文件不存在则新建）
+ **清空 /etc/test.txt 文档内容**：cat /dev/null > /etc/test.txt

#### 5.echo写入

+ 覆盖写入（新建/替换）
  `echo -e "2026-04-29\n今天学了Linux基础命令，很有成就感！" > diary/day1.txt`

+ 追加写入（补充内容）
  `echo -e "2026-04-30\n今天搞懂了>和>>" >> diary/day1.txt`

### **(五).chmod**

#### 1.chmod的作用

**控制用户对文件或目录的权限**（文件所有者、所属组和其他用户对文件的访问权限）（只有文件所有者和超级用户可以修改文件或目录的权限）。

#### **2.chmod的使用权限**

##### (1).权限身份分类

| 身份 | 代号 | 说明 |
| :--- | :--- | :--- |
| 文件所有者 | u (user) | 文件的创建者或拥有者 |
| 所属组 | g (group) | 文件所有者所在的用户组 |
| 其他用户 | o (others) | 除了 u 和 g 以外的所有用户 |
| 所有用户 | a (all) | 等同于 u + g + o |

##### (2).权限位与数字对应

每个权限位对应一个数字（八进制）：**r=4, w=2, x=1**。无权限为 **0**。将一组的三位相加得到一个 0-7 的数字。

| 二进制 | 八进制 | 权限 | 说明 |
| :--- | :--- | :--- | :--- |
| 111 | 7 | rwx | 读 + 写 + 执行 |
| 110 | 6 | rw- | 读 + 写 |
| 101 | 5 | r-x | 读 + 执行 |
| 100 | 4 | r-- | 只读 |
| 011 | 3 | -wx | 写 + 执行 |
| 010 | 2 | -w- | 只写 |
| 001 | 1 | --x | 只执行 |
| 000 | 0 | --- | 无权限 |

#### 3.chmod的语法

`chmod [选项] 权限模式 文件...`
`chmod [选项] --reference=参考文件 文件...`

| 选项 | 说明 |
| :--- | :--- |
| `-c` | 仅在该文件权限**确实被更改**时，才显示其更改动作 |
| `-f` | 若该文件权限无法被更改，**不要显示错误讯息**（静默模式） |
| `-v` | 显示权限变更的**详细资料**（无论是否更改都显示） |
| `-R` | **递归**修改：对当前目录下的所有文件与子目录进行相同的权限变更 |
| `--help` | 显示辅助说明 |
| `--version` | 显示版本信息 |

#### **4.chmod的权限模式**

##### (1).符号模式（ugoa+/-权限）

`[ugoa...][[+-=][rwxX]...][,...]`

+ **`+` 表示增加权限、`-` 表示取消权限、`=` 表示唯一设定权限**
+ **`r` 表示可读取，`w` 表示可写入，`x` 表示可执行**，`X` 表示只有当该文件是个子目录或者该文件已经被设定过为可执行

##### (2).八进制语法

+ 组合方式:
  - 所有者权限(第一位)
  - 组权限(第二位)
  - 其他用户权限(第三位)

##### ==**(3).示例**==

+ **符号模式实例**

| 命令 | 说明 |
| :--- | :--- |
| `chmod a+r file` | 给 **所有用户** 增加 **读** 权限 |
| `chmod a-x file` | 删除 **所有用户** 的 **执行** 权限 |
| `chmod a+rw file` | 给 **所有用户** 增加 **读写** 权限 |
| `chmod +rwx file` | 给 **所有用户** 增加 **读写执行** 权限（**`+` 等价于 `a+`**） |
| `chmod u=rw,go= file` | 所有者设为 **读写**，**清空** 组和其他用户的**所有权限** |
| `chmod -R u+r,go-r docs` | **递归**：对 `docs` 目录：所有者 **增加读**，组和其他用户 **删除读** |

+ **数字模式实例**

| 命令 | 权限分解 | 说明 |
| :--- | :--- | :--- |
| `chmod 664 file` | `u=rw-` (6), `g=rw-` (6), `o=r--` (4) | 所有者/组：读写；其他：只读 |
| `chmod 0755 file` | `u=rwx` (7), `g=r-x` (5), `o=r-x` (5) | 所有者：读写执行；组/其他：读执行（前导 `0` 表示无特殊权限） |
| `chmod 4755 file` | `4` (SetUID) + `755` | 设置 **SetUID** 位，其他同 `755`。执行时临时拥有所有者权限 |

+ **高级组合（配合 `find`）**

| 命令 | 说明 |
| :--- | :--- |
| `find path/ -type d -exec chmod a-x {} \;` | 递归删除 **所有目录** 的执行权限（不影响文件） |
| `find path/ -type d -exec chmod a+x {} \;` | 递归允许所有用户 **浏览/进入** 目录 |
| `find path/ -type f -exec chmod 644 {} \;` | 递归将所有 **文件** 权限设为 `644` |

### **(六) 重定向与管道**

#### 1. 重定向

| 符号 | 作用 | 示例 |
| ------ | ------ | ------ |
| `>` | 覆盖写入文件 | `echo "hello" > file.txt` |
| `>>` | 追加写入文件 | `echo "world" >> file.txt` |
| `<` | 从文件读取输入 | `sort < names.txt` |
| `2>` | 重定向错误输出 | `ls /nofile 2> error.log` |
| `&>` | 同时重定向标准输出和错误 | `java -jar app.jar &> app.log` |

#### 2. 管道 `|`

把一个命令的**输出**作为下一个命令的**输入**，常用于组合过滤和分析

```bash
# 查找 Java 进程
ps aux | grep java

# 统计 ERROR 日志行数
cat app.log | grep ERROR | wc -l

# 实时查看 SpringBoot 日志中带 "Exception" 的部分
tail -f app.log | grep Exception
```

`grep [选项] "pattern" [文件...]`

#### 3. 常用选项

| 选项 | 说明 |

## **四.磁盘管理**

### **(一).ls**

#### 1.ls的作用

**列出目前工作目录所含的文件及子目录**

#### 2.ls的语法

 ls [-alrtAFR] [name...]

#### 3.==ls的参数==

**可以N个一起拼**，例：
ls -l -a -h =ls - lah

| 参数 | 说明 |
| ------ | ------ |
| `-a` 或 `--all` | **显示所有文件（包括以 `.` 开头的隐藏文件）** |
| `-A` 或 `--almost-all` | 显示除 `.` 和 `..` 外的所有文件（包括隐藏文件） |
| `-l` | **以长格式（详细信息）列出文件**(权限、所有者、大小、修改时间等)|
| `-h` 或 `--human-readable` | 与 `-l` 一起使用时，以人类可读的格式显示**文件大小**（如 KB、MB） |
| `-t` | 按**修改时间**排序（最新优先） |
| `-r` 或 `--reverse` | 反向排序（配合 `-t`、`-S` 等使用） |
| `-S` | 按文件大小排序（大文件优先） |
| `-R` 或 `--recursive` | 递归列出子目录内容 |
| `-F` 或 `--classify` | 在文件名后附加标识符（`/` 表示目录，`*` 表示可执行文件） |
| `--color` | 彩色输出（通常默认启用，`--color=auto`） |
| `-i` 或 `--inode` | 显示文件的 inode 编号 |
| `-n` 或 `--numeric-uid-gid` | 以数字形式显示 UID 和 GID（替代用户名和组名） |
| `-d` 或 `--directory` | 仅显示目录本身，而非其内容（常用于配合 `-l`） |
| `-1` | 每行只显示一个文件（默认在终端宽度不足时自动启用） |
| `-m` | 以逗号分隔的列表形式显示文件 |
| `-Q` 或 `--quote-name` | 用引号括住文件名（适用于含空格的文件名） |
| `--group-directories-first` | 先显示目录，后显示文件 |
| `--time-style=<格式>` | 自定义时间显示格式（如 `+%Y-%m-%d`） |

### **(二).cd**

#### 1.cd的作用

- **改变当前工作目录的命令，切换到指定的路径**

- 若目录名称省略，则变换至使用者的 home 目录 (也就是刚 login 时所在的目录)。
- **~ 表示为 home 目录** 的意思
- **. 表示目前所在的目录**
- **.. 表示目前目录位置的上一层目录**(可以通过连续多次使用来切换到更高级的目录)
- 用 **cd - 可以切换到上次访问的目录**
- 用**环境变量**来指定目标目录，并用cd命令切换到该目录(例：`cd $VAR_NAME`)

#### 2.cd的语法

`cd [dirName]`  
(dirName：要切换的目标目录,相对路径或绝对路径)

+ 换到**绝对路径**：指定完整的目录路径来切换到目标目录。
  - cd /path/to/directory
+ 换到**相对路径**：指定相对于当前目录的路径来切换到目标目录。
  - cd relative/path/to/directory

### **(三).pwd**

#### 1.pwd的作用

**显示当前用户所在的工作目录的完整路径**

#### 2.pwd的语法

`pwd [--help][--version]`

#### 3.pwd的参数

| 选项 | 说明 |
| :--- | :--- |
| `-L` | 显示逻辑路径（默认行为），解析符号链接 |
| `-P` | 显示物理路径，不解析符号链接 |
| `--help` | 显示帮助信息 |
| `--version` | 显示版本信息 |

#### 4.pwd 命令的实际应用

+ 检查环境变量 PWD 的值（当使用 -L 选项时）
+ 通过遍历父目录来物理确定路径（当使用 -P 选项时）

#### 5.**pwd的实际应用**

* **符号链接目录中时**：

```linux
$ ln -s /var/www/html myweb
$ cd myweb
$ pwd   //直接输入命令
/home/username/myweb    # 逻辑路径
$ pwd -P
/var/www/html          # 物理路径
```

* 脚本中使用:

```linux
#!/bin/bash
CURRENT_DIR=$(pwd)
echo "当前目录是: $CURRENT_DIR"
```

#### 6.pwd的注意

+ `pwd` 和 `echo $PWD`有什么区别? 
  pwd 是内置命令，而 `$PWD` 是环境变量。大多数情况，它们输出相同，但 pwd 命令可以带选项（如 -P），而 $PWD 总是显示逻辑路径。
+ 为什么需要 -P 选项？
  当你在一个符号链接目录中工作时，有时需要知道实际的物理位置而不是符号链接路径，这时 -P 选项就很有用。
+ pwd 命令会失败吗？
  正常情况下不会，但如果当前目录被删除（在另一个终端会话中）,可能会显示错误。

#### 7.pwd的实践建议

* **在脚本中使用 pwd -P**：确保脚本在任何情况下都能获取到正确的物理路径
* **结合其他命令使用**：常与 cd、ls 等命令配合使用
* **注意符号链接**：当路径中有符号链接时，明确知道自己需要的是逻辑路径还是物理路径

#### 8.pwd的逻辑路径与物理路径区别

| 维度 | 逻辑路径 | 物理路径 |
| :--- | :--- | :--- |
| **定义** | 通过盘符、挂载点、符号链接等逻辑标识的路径 | 硬件存储设备上的真实区块、扇区、磁道等地址 |
| **是否依赖文件系统** | 是，是文件系统层面的抽象 | 是，是存储介质层面的具体位置 |
| **用户是否直接感知** | 是（如 `C:\Users\123\a.txt`） | 否（如磁盘第 1000～2000 号扇区） |
| **是否可变** | 会变（如更换盘符、软链接、挂载点） | 相对稳定（同一文件物理位置一般不随意变动） |
| **映射关系** | 逻辑路径 → 文件系统 → 物理路径 | 直接对应硬件地址 |
| ==核心总结== | 方便人机交互，屏蔽硬件细节，支持灵活的组织结构（如分区、移动、软链接） | 用于底层存储管理、数据恢复、性能优化（如考虑磁盘寻道时间、扇区布局） |

## **七.系统管理**

### **(一).sudo**

#### 1.sudo的作用

**授权用户以其他用户（通常是 root 用户）的身份执行命令**

#### 2.sudo的语法

`sudo [选项] 命令`

#### 3.sudo的参数

+ **-i**: 模拟初始登录，加载目标用户的环境
+ **-s**: 运行shell
+ **-u** user: 以指定用户身份运行
+ **-l**: 列出当前用户可执行的sud、
+ **-v**: 验证用户凭据（延长sudo会话）
+ **-k**: 撤销sudo凭据缓存

#### 4.sudo的配置文件

sudo 的配置存储在 /etc/sudoers 文件中，应该使用 visudo 命令编辑：
`sudo visudo`

+ 常见配置示例：

```Linux
# 允许用户免密码执行所有命令
username ALL=(ALL) NOPASSWD: ALL
# 允许用户组执行特定命令
%wheel ALL=(ALL) /bin/systemctl, /usr/bin/apt
```

#### 5.sudo的常见问题

用户不在 sudoers 文件：

```Linux
# 需要 root 用户将目标用户加入 sudo 组：
usermod -aG sudo username  # Ubuntu/Debian
usermod -aG wheel username # CentOS/RHEL
```

缓存时间调整：
修改 /etc/sudoers 中的 timestamp_timeout（单位：分钟）：
`Defaults timestamp_timeout=30`

#### 6.**su vs sudo**

##### (1).区别

| 特性                | `su`                                      | `sudo`                                        |
| :------------------ | :---------------------------------------- | :-------------------------------------------- |
| **需要密码** | **目标用户**密码（如 root 密码）              | **当前用户**密码                                  |
| **会话持续**           | 直到手动执行 `exit`                       | 单次命令或短时间缓存（默认5分钟）             |
| **配置复杂度**          | 简单，无需配置                            | 需要配置 `/etc/sudoers`                       |
| **安全性**              | 需共享 root 密码，风险高                  | 更细粒度的权限控制，遵循最小权限原则          |
| **审计**                | 有限，仅记录切换动作                      | 更详细的日志（记录每条命令、参数、结果）      |
| **切换用户**        | **完整切换用户环境**（相当于重新登录）        | 仅以目标用户身份执行命令，**不切换环境变量**      |
| **执行粒度**        | 切换后***所有命令**都具备目标用户权限          | 可**精确控制**能执行哪些命令（如 `sudo /bin/ls`） |
| **日志记录**        | 仅记录切换动作（如 `su: session opened`） | 记录每次执行的命令、参数、工作目录、结果      |
| **免密配置**        | 无法免密                                  | 可在 `/etc/sudoers` 配置 `NOPASSWD`           |
| **回退风险**        | 容易忘记退出 root 会话，长时间保持高风险  | 默认单条命令有效，缓存超时后自动失效          |

##### (2).核心选择建议

- **日常管理** → **`sudo`**：细粒度、可审计、不需要知道 root 密码，提供了更好的安全性和审计能力
- **临时批量操作** → **`su -`**：连续执行多个系统维护命令时更高效
- **安全敏感环境** → **禁用 `su`**，只允许 `sudo` 并记录所有操作日志

##### (3).常见误区说明

+ `su` 默认**不加载目标用户的环境变量**（如 `PATH`、`$HOME`），推荐使用 **`su -`**（带连字符）才会完整切换环境。
+ `sudo` 默认**保留当前用户的部分环境变量**（如 `$PATH`），除非使用 `sudo -i` 或 `sudo -s` 模拟登录环境。

### **(二).top**

#### 1.top的作用

提供了一个动态的、交互式的实时视图，**显示系统的整体性能信息以及正在运行的进程的相关信息**

#### 2.top的语法

`top [-] [d delay] [q] [c] [S] [s] [i] [n] [b]`

#### 3.top的参数

| 参数 | 作用 |
| ------ | ------ |
| **`-d <秒数>`** | 指定 top 命令的刷新时间间隔，单位为秒 |
| **`-n <次数>`** | 指定 top 命令运行的次数后自动退出 |
| **`-p <进程ID>`** | 仅显示指定进程ID的信息 |
| **`-u <用户名>`** | 仅显示指定用户名的进程信息 |
| **`-H`** | 在进程信息中显示线程详细信息 |
| **`-i`** | 不显示闲置（idle）或无用的进程 |
| **`-b`** | 以批处理（batch）模式运行，直接将结果输出到文件 |
| **`-c`** | 显示完整的命令行而不截断 |
| **`-S`** | 累计显示进程的 CPU 使用时间 |

#### 4.top的显示信息

##### (1)总体系统信息

* **uptime**：系统的运行时间和平均负载
* **tasks**：当前运行的进程和线程数目
* **CPU**：总体 CPU 使用率和各个核心的使用情况
* **内存**（Memory）：总体内存使用情况、可用

##### (2)进程信息

* **PID**：进程的标识符
* **USER**：运行进程的用户名
* **PR**（优先级）：进程的优先
* **NI**（Nice值）：进程的优先级调整值
* **VIRT**（虚拟内存）：进程使用的虚拟内存大小
* **RES**（常驻内存）：进程实际使用的物理内存大小
* **SHR**（共享内存）：进程共享的内存大
* **%CPU**：进程占用 CPU 的使用率
* **%MEM**：进程占用内存的使用率
* **TIME+**：进程的累计 CPU 时间

##### (3)功能和交互操作

* **按键命令**：在 top 运行时可以使用一些按键命令进行操作，如按下 "k" 可以终止一个进程，按下 "h" 可以显示帮助信息等
* **排序**：可以按照 CPU 使用率、内存使用率、进程 ID 等对进程进行排序
* **刷新频率**：可以设置 top 的刷新频率，以便动态查看系统信息

### **(三).kill**

#### 1.kill的作用

**用于终止正在运行的进程**

#### 2.kill的语法

`kill [options] <PID>`

* `<PID>` 是要终止进程的进程 ID

#### 3.kill的参数

* **-l**：列出所有可用的信号
  * **SIGKILL（信号9）**：立即结束进程，不能被捕获或忽略
  * **SIGTERM（信号15）**：正常结束进程，可以被捕获或忽略
  * **SIGSTOP（信号19）**：暂停进程，不能被捕获、忽略或结束
  * **SIGCONT（信号18）**：继续执行被暂停的进程
  * **SIGINT（信号2）**：通常是Ctrl+C产生的信号，可以被进程捕获或忽略
* **-<signal>**：发送特定的信号给目标进程，如 -9 表示发送 KILL 信号，即强制终止进程

#### 4.**kill的基本用法**

##### (1)**终止进程**

默认情况下，kill命令发送SIGTERM（信号15），这可以请求进程终止。如果进程没有捕获这个信号，它将被终止
`kill PID`

##### (2)**发送指定信号**

通过 -s 选项可以发送指定的信号
`kill -s SIGNAL PID`

##### (3)**杀死进程组**

使用 -9 选项可以杀死整个进程组
`kill -9 -PID`

#### 5.kill的注意事项

* 在使用 kill 命令时，需要具有相应的权限，否则可能无法终止进程
* 某些进程可能需要发送多次信号才能终止，比如一些守护进
* 强制杀死进程可能会导致数据丢失或其他副作用，因此应谨慎使用

### **(四).ps**

#### 1.ps的作用

**显示当前进程的状态**，类似于 windows 的任务管理器

#### 2.ps的语法

`ps [options] [--help]`

#### 3.ps的参数

| 参数 | 作用 |
| ------ | ------ |
| **`-A`** | 列出所有的进程 |
| **`-w`** | 显示加宽，可以显示较多的资讯 |
| **`-au`** | 显示较详细的资讯 |

#### 4.ps的显示信息

  + USER: 行程拥有者
  + PID: pid
  + %CPU: 占用的 CPU 使用率
  + %MEM: 占用的记忆体使用率
  + VSZ: 占用的虚拟记忆体大小
  + RSS: 占用的记忆体大小
  + TTY: 终端的次要装置号码 (minor device number of tty)
  + STAT: 该行程的状态:
    + D: 无法中断的休眠状态 (通常 IO 的进程)

    + Z: 不存在但暂时无法消除
    + W: 没有足够的记忆体分页可分配
    + <: 高优先序的行程
    + N: 低优先序的行程
    + L: 有记忆体分页分配并锁在记忆体内 (实时系统或捱A I/O)
  + START: 行程开始时间
  + TIME: 执行的时间
  + COMMAND:所执行的指令

### **(一).apt**

+ 一个在 Debian 和 Ubuntu 中的 Shell 前端**软件包管理器**

#### 1.apt 语法

`apt [options] [command] [package ...]`

+ **command**：要进行的操作
+ **package**：安装的包名

#### 2.apt 常用命令

| 分类 | 命令 | 作用 |
| ------ | ------ | ------ |
| **更新软件源** | `sudo apt update` | 从仓库获取最新的软件包列表（不安装/升级） |
| **升级软件包** | `sudo apt upgrade` | 升级所有已安装的软件包（保留旧依赖关系） |
| | `sudo apt full-upgrade` | 升级软件包，必要时删除冲突包以完成升级 |
| | `sudo apt update <package_name>` ⚠️ | 更新指定的软件包（注：该命令非标准，通常使用 `install --only-upgrade`） |
| **安装软件包** | `sudo apt install <package_name>` | 安装单个软件包 |
| | `sudo apt install <pkg1> <pkg2> <pkg3>` | 同时安装多个软件包 |
| **删除软件包** | `sudo apt remove <package_name>` | 删除软件包（保留配置文件） |
| | `sudo apt purge <package_name>` | 删除软件包并清除配置文件 |
| | `sudo apt autoremove` | 自动清理不再需要的依赖和库文件 |
| **查询与显示** | `apt list --upgradable` | 列出所有可更新的软件包及版本信息 |
| | `apt list --installed` | 列出所有已安装的软件包 |
| | `apt list --all-versions` | 列出所有已安装包的全部可用版本 |
| | `sudo apt show <package_name>` | 显示软件包的详细信息（版本、大小、依赖等） |
| | `sudo apt search <keyword>` | 在仓库中搜索匹配关键字的软件包 |

+ `sudo apt update && sudo apt upgrade -y`两个命令**组合**起来，一键升级
+ `sudo apt install <package_name> --no-upgrade` 想安装一个软件包，但软件包已经存在，不升级它,可以使用`–no-upgrade`
+ `sudo apt install <package_name> --only-upgrade`只想升级，不要安装可以使用`--only-upgrade`

| 进程树视图 | 支持 | 不支持 |
| 排序方式 | 多种，可动态调整 | 有限 |
| 进程操作 | 更丰富 | 基本 |
| 自定义 | 高度可配置 | 有限 |
| 资源占用 | 稍高 | 较低 |

+ htop 提供了更丰富的功能和更友好的界面，适合交互式使用；top 更轻量，适合脚本中使用
+ 绿色通常表示正常运行的进程，红色可能表示高资源占用或僵尸进程
+ 按 F2 进入设置，在 "Display options" 中调整 "Show program path" 选项查看完整的命令行

### **(三).curl**

命令行工具，用于在 Linux/Unix 系统中**传输数据**，支持多种协议

#### 1.curl 的主要特点

* **多协议支持**：支持几乎所有主流网络协议
* **无界面操作**：纯命令行工具，适合脚本和自动化任务
* **功能丰富**：支持文件上传下载、表单提交、Cookie 处理等
* **跨平台**：在 Linux、macOS、Windows 上均可使用

#### 2.curl语法

`curl [options] [URL...]`

+ options：各种可选参数，用于控制 curl 的行为
+ URL：要访问的一个或多个网址

#### 3.常用参数

##### (1)基本请求控制

| 选项 | 说明 | 示例 |
| ------ | ------ | ------ |
| `-X` | 指定 HTTP 方法 | `curl -X POST https://example.com` |
| `-d` | 发送 POST 数据 | `curl -d "name=John" https://example.com` |
| `-G` | 将 `-d` 数据作为 GET 参数发送 | `curl -G -d "q=keyword" https://search.com` |
| `-H` | 添加请求头 | `curl -H "Content-Type: application/json" https://api.com` |

##### (2)输出控制

| 选项 | 说明 | 示例 |
| ------ | ------ | ------ |
| `-o` | 将输出保存到文件 | `curl -o output.html https://example.com` |
| `-O` | 使用远程文件名保存 | `curl -O https://example.com/file.zip` |
| `-s` | 静默模式（不显示进度） | `curl -s https://api.com/data.json` |
| `-v` | 显示详细通信过程 | `curl -v https://example.com` |

##### (3)认证与安全

| 选项 | 说明 | 示例 |
| ------ | ------ | ------ |
| `-u` | 用户名密码认证 | `curl -u user:pass https://secure.com` |
| `-k` | 忽略 SSL 证书验证 | `curl -k https://self-signed.com` |
| `--cacert` | 指定 CA 证书 | `curl --cacert cert.pem https://secure.com` |

##### (4)其他实用选项

| 选项 | 说明 | 示例 |
| ------ | ------ | ------ |
| `-L` | 跟随重定向 | `curl -L https://short.url` |
| `-I` | 只获取头部信息 | `curl -I https://example.com` |
| `--limit-rate` | 限制传输速度 | `curl --limit-rate 100K https://largefile.com` |

### **(四).echo**

#### 1.echo的作用

* 在终端显示文本信息
* 输出变量的值
* 生成格式化的字符串
* 向文件追加内容

#### 2.echo的语法

`echo [选项] [字符串]`

#### 3.echo的参数

`echo` 命令的常用选项与转义字符整理如下：

##### 常用选项

| 选项 | 说明 |
|------|------|
| `-n` | 不输出换行符 |
| `-e` | 启用转义字符解释|
| `-E` | 禁用转义字符解释（默认）|

> 默认情况下，echo 会在输出后添加换行符

##### 转义字符（需配合 `-e` 使用）

| 转义序列 | 含义 |
| ---------- | ------ |
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\b` | 退格 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\a` | 响铃 |

#### 4.echo用法

* 简单文本输出,直接输出字符串
`echo "Hello, World!"`
* 输出变量,显示变量的值

```bash
name="Linux User"
echo "Welcome, $name!"
# 输出结果
Welcome, Linux User!
```

* 不带引号的输出，引号不是必须的，但建议使用以避免特殊字符问题
* 输出到文件，详见[写入](#5echo写入)
* 命令替换:输出其他命令的执行结果
* 格式化输出

### **(五).tail**

#### 1.tail作用

用于**查看文件的内容**

#### 2.tail语法

`tail [参数] [文件]`

#### 3.参数

`tail` 命令的常用选项整理如下：

| 选项 | 说明 |
| ------ | ------ |
| `-f` | **循环读取**，实时追踪文件新增内容 |
| `-q` | 不显示处理信息（安静模式） |
| `-v` | 显示详细的处理信息 |
| `-c <数目>` | 显示指定字节数的内容 |
| `-n <行数>` | 显示文件尾部的 n 行内容 |
| `--pid=PID` | 与 `-f` 合用，在指定进程 ID 终止后结束追踪 |
| `-q, --quiet, --silent` | 从不输出给出文件名的首部 |
| `-s, --sleep-interval=S` | 与 `-f` 合用，每次反复间隔休眠 S 秒 |
