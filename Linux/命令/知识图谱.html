Linux 命令复习速查图

文件管理 | 文档编辑 | 磁盘管理 | 网络通讯 | 系统管理 | 高频场景

一、文件管理
核心命令：ls cd pwd mkdir rm cp mv cat chmod
命令常用参数作用
ls-lahtr列出目录内容；-l长格式 -a隐藏文件 -h人类可读 -t按时间 -r反向
cd~ / - ..切换目录；~home目录 /根目录 -上次目录 ..上级目录
pwd-L -P显示当前路径；-L逻辑路径(默认) -P物理路径(不解析软链)
mkdir-p创建目录；-p递归创建父目录
rm-rfi删除；-r递归 -f强制 -i确认
cp-ravi复制；-r递归 -a归档(保留属性) -v详细 -i确认
mv-fi移动/重命名；-f强制 -i确认
cat-nbs查看/连接文件；-n行号 -b非空行号 -s压缩空行
chmod 权限：r=4 w=2 x=1
符号模式：chmod u+x file (所有者加执行) | chmod a+r file (所有人加读)
数字模式：chmod 755 file (u=rwx g=rx o=rx) | chmod 644 file (u=rw g=r o=r)
重定向与管道：
> 覆盖写入 | >> 追加写入 | 2> 错误重定向 | &> 同时重定向标准输出和错误
| 管道：左边输出送给右边当输入
例：ps aux | grep java | wc -l
二、文档编辑 (vi/vim + grep)
vim 三种模式：命令模式 → i/a/o 进入输入模式 → Esc 返回 → : 进入底线命令模式
模式命令功能
命令模式h/j/k/l左下上右移动
gg / G文件首行 / 末行
dd / yy / p删除(剪切)行 / 复制行 / 粘贴
u / Ctrl+r撤销 / 重做
/word / ?word向下/向上搜索
n / N下一个/上一个匹配
底线命令:w / :q / :wq保存 / 退出 / 保存退出
:q!强制退出不保存
:%s/old/new/g全文替换
输入模式i / a / o光标前/后/下插入
I / A / O行首/行尾/上插入
Esc返回命令模式
grep 文本搜索：
grep "ERROR" app.log — 搜索ERROR
grep -i "null" app.log — 忽略大小写
grep -v "DEBUG" app.log — 排除DEBUG行
grep -n "error" app.log — 显示行号
grep -r "pattern" dir/ — 递归搜索目录
三、磁盘管理
命令参数作用
df-h显示磁盘空间使用；-h人类可读
free-h -s 2显示内存使用；-h人类可读 -s 2每2秒刷新
du-sh dir查看目录大小；-s汇总 -h人类可读
df -h /var — 查看指定目录所在分区空间
du -sh * | sort -rh | head -10 — 查看当前目录下最大的10个文件/目录
四、网络通讯
命令参数作用
ping-c 4测试连通性；-c 4发4个包后停止
ss-tlnp查看网络连接；-t TCP -l监听 -n数字 -p进程名
netstat-ano查看端口占用(Windows: netstat -ano | findstr :8080)
nslookupDNS查询域名对应IP
dig更详细的DNS信息
curl 命令行网络工具：
curl -X POST -d "name=John" url — POST请求
curl -H "Content-Type: application/json" url — 自定义请求头
curl -o file.html url — 保存到文件
curl -L url — 跟随重定向
curl -I url — 只获取响应头
curl -u user:pass url — 基本认证
五、系统管理
命令参数作用
psaux / -ef静态显示进程状态；aux显示所有含其他用户
top-d 3 -p PID实时进程信息；-d刷新间隔 -p指定进程
htop交互式进程查看器(彩色/鼠标/进程树)
kill-9 / -15终止进程；-9 SIGKILL强制 -15 SIGTERM正常
sudo-i -u user提升权限；-i模拟登录 -u指定用户
systemctlstart/stop/enable/status服务管理；enable开机自启
journalctl-u service -f查看系统日志；-f实时追踪
su vs sudo：
su — 需要目标用户密码，完整切换环境，会话持续到exit
sudo — 需要当前用户密码，单次命令或5分钟缓存，更细粒度权限控制
ps 进程状态 STAT：
R=运行 S=休眠 T=暂停 Z=僵尸 D=不可中断IO
<=高优先级 N=低优先级 L=锁在内存
六、其他命令 (apt / echo / tail)
apt 包管理（Debian/Ubuntu）：
sudo apt update — 更新软件源列表
sudo apt upgrade — 升级已安装软件包
sudo apt install pkg — 安装
sudo apt remove pkg — 删除(保留配置)
sudo apt purge pkg — 删除并清除配置
sudo apt autoremove — 自动清理无用依赖
echo 输出：
echo "hello" — 输出字符串
echo $VAR — 输出变量
echo -e "line1\nline2" — 启用转义(-e)
echo "text" > file.txt — 覆盖写入
echo "text" >> file.txt — 追加写入
tail 查看文件尾部：
tail -n 20 file — 显示最后20行
tail -f file — 实时追踪新增内容(常用看日志)
tail -f app.log | grep ERROR — 实时过滤日志中的ERROR

# 查看端口占用(Linux) ss -tlnp | grep 8080 # 查看端口占用(Windows) netstat -ano | findstr :8080 tasklist | findstr <PID> # 实时查看日志 tail -f /var/log/app.log | grep ERROR # 杀死进程 kill -9 $(pgrep -f "java") # 查看系统负载 uptime # 查看当前登录用户 who / w
rm -rf 慎用
rm -rf / 会删除整个系统！删除前先用 ls 确认，或用 -i 交互模式
权限不足
Permission denied -> 检查文件权限(ls -l)或用 sudo 执行
命令找不到
command not found -> 检查PATH环境变量，或安装对应软件包
端口被占
Address already in use -> ss -tlnp | grep 端口 找到进程后 kill
磁盘满了
No space left on device -> df -h 查看，du -sh 找大文件清理
