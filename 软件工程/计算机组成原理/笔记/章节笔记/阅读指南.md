# 计算机组成原理：第 1、2、3、5 章阅读指南

这四章以《Digital Design and Computer Architecture》课件为主线：先用位串和电平表示信息，再搭建计算逻辑，加入保存状态的元件，最后组合成算术与存储模块。第 5 章的算术部分可以直接衔接第 1～3 章，不必先读第 4 章才能理解。

|---|---|---|
| 第 1 章 数字逻辑基础 | 位串怎样表示数值？模拟电压怎样可靠地表示 0/1？ | [第一章笔记](<第一章 数字逻辑基础/第一章.md>) |
| 第 2 章 组合逻辑设计 | 给定输入和功能需求，怎样得到正确、可实现的计算电路？ | [第二章笔记](<第二章 组合逻辑设计/第二章.md>) |
| 第 3 章 时序逻辑设计 | 怎样保存历史、按时钟更新状态，并避免采样错误？ | [第三章笔记](<第三章 时序逻辑设计/第三章.md>) |
| 第 5 章 常见数字模块 | 怎样构成运算器、乘除法器和存储系统？ | [第五章笔记](<第五章 常见数字模块/第五章.md>) |

## 建议的阅读方法

1. **先读功能与接口**：列出输入、输出、位宽、控制信号，以及是否要记住历史。看到“使能、复位、片选”先确认有效电平。
2. **再推导一个完整例子**：数制题写位权，组合逻辑列真值表，FSM 列状态转移表，乘除法逐轮记录寄存器值。
3. **检查适用前提**：有符号/无符号、整数/小数、位宽、是否溢出、是否有时钟；相同位串在不同规则下可能代表不同数值。
4. **最后检查时间**：功能正确后，计算最长和最短路径；涉及寄存器时同时检查建立与保持时间。

## 跨章易混淆点

| 问题 | 应怎样区分 |
|---|---|
| 进位与溢出 | 无符号加法看向外进位；补码有符号加法看符号关系或符号位输入/输出进位异或 |
| 组合移位器与移位寄存器 | 前者是组合变换，后者在时钟沿保存移位后的状态 |
| 最小延迟与传输延迟 | 前者决定最早何时可能改变，后者决定最晚何时保证稳定 |
| 建立与保持 | 分别防止下一拍数据来得太晚、本拍新数据来得太早 |
| Moore 与 Mealy | 区别是输出依赖状态，还是同时依赖状态与输入；不能只背“早一拍” |
| 纯小数除法与整数除法 | 课件纯小数算法的范围约束与余数缩放，不能直接套到整数除法 |
| 浮点符号与补码符号 | 浮点负数不是把整个位串取补，需按符号/阶码/小数字段解释 |
| 存储深度与位宽 | 字扩展增加地址数量，位扩展增加每个地址的数据位数 |
| 字地址与字节地址 | 先确定一个地址对应多少数据，再算地址位数和交叉存储的选体位 |

## 自测清单

- 第 1 章：能把负数写成指定位宽补码，并区分有无进位和有无溢出；能检查高低电平接口兼容。
- 第 2 章：能独立做一个三/四变量卡诺图；能用 MUX 或译码器实现同一函数；能解释毛刺例中两条路径为什么不同步。
- 第 3 章：能从交通灯状态表推导下一状态；能解释售糖机出货后为何保留 5 分余额；能同时检查建立/保持约束并计算流水吞吐量。
- 第 5 章：能手算乘除法并用原式验算；能解码正规/非规格化浮点数；能算刷新时间、扩展片数、地址范围和低位交叉的体号。

各章文末提供课件 PDF 页码定位与练习。补充解释用于展开课件中省略的步骤；涉及具体接口时，以该例明确写出的条件为准。
