1行列式

1.1 基本定义

概念要点
n阶行列式D = Σ a1jA1j，按第一行展开
余子式 Mij划去第i行第j列后的n-1阶行列式
代数余子式 AijAij = (-1)i+jMij

1.2 核心性质（计算必用）

性质内容
转置不变D = DT
按行/列展开D = ai1Ai1 + ai2Ai2 + ... + ainAin
提取公因子某行有公因子k，可提到行列式外
拆行相加某行元素为两数之和，可拆成两个行列式之和
两行相同→0两行元素相同，行列式为0
两行成比例→0两行元素成比例，行列式为0
倍加不变某行k倍加到另一行，行列式值不变
互换变号互换两行，行列式变号

1.3 特殊行列式

  • 对角/三角行列式 = 对角线元素乘积
  • 反对称行列式（奇数阶）：D = 0
  • 范德蒙德行列式：Dn = ∏1≤i<j≤n(aj-ai)

1.4 Cramer法则

📐定理
条件：n个方程n个未知数，且系数行列式 D ≠ 0
结论：唯一解 xi = Di/D，其中 Di 是将D的第i列换为常数列

2矩阵及其运算

2.1 基本运算

运算法则注意
加法对应元素相加必须同型
数乘每个元素乘k(k+l)A = kA+lA；k(A+B)=kA+kB
乘法行×列★ 不满足交换律！ AB ≠ BA
转置(AB)T = BTAT(AT)T = A
幂Ak · Al = Ak+l(AB)k ≠ AkBk（一般情况）

2.2 逆矩阵 ★重点

定义：AB = BA = E，则 B = A-1

判定定理：A 可逆 ⇔ |A| ≠ 0

求法：

A-1 = (1/|A|) A*

其中 伴随矩阵 A* 的元素是代数余子式的转置：

A* = [ A11 A21 ...
       A12 A22 ...
       ...   ...   ... ]
💡速记技巧
2阶速记：A = [a b; c d]，则 A* = [d -b; -c a]
口诀：对角互换，非对角变号

逆矩阵性质：

  • (A-1)-1 = A
  • (kA)-1 = (1/k)A-1
  • (AT)-1 = (A-1)T
  • ★ (AB)-1 = B-1A-1 —— 顺序颠倒

2.3 分块矩阵

类型特点
分块对角阵 [A1   ;   A2]，则 |A|=|A1||A2|，A-1=[A1-1   ;   A2-1]
📌高频考点：上（下）三角分块
若 M = [A B; 0 C]（或 [A 0; B C]），其中 A, C 可逆，则：

• 行列式：|M| = |A| · |C|
• 逆矩阵：[A B; 0 C]-1 = [A-1   -A-1BC-1; 0   C-1]
★ 务必记住！

2.4 初等变换与初等矩阵 ★重点

三种初等行变换：

  1. 互换两行：ri ↔ rj
  2. 某行乘非零常数：kri
  3. 某行k倍加到另一行：ri + krj
🔗核心关系
对A做一次初等行变换 = 左乘对应的初等矩阵
对A做一次初等列变换 = 右乘对应的初等矩阵

求逆的初等变换法：

(A | E)  →(初等行变换)→  (E | A-1)
⚠️初等变换使用禁区（超级易错点）
1. 求矩阵的秩：行变换和列变换均可使用。
2. 解线性方程组（求通解/特解）：只能使用初等行变换（列变换会改变解空间！）
3. 求向量组的极大无关组并保留原向量组合关系：只能使用初等行变换（列变换会打乱向量的分量位置）
4. 求逆矩阵：只能使用初等行变换（即 (A|E)→(E|A-1)），若用列变换需改为竖排形式，极易搞混，建议统一只用行变换。

3向量组的线性相关性

3.1 线性相关/无关

概念定义判定
线性相关存在不全为零的ki，使 Σkiαi = 0齐次方程组有非零解
线性无关仅当所有ki=0时，Σkiαi = 0齐次方程组只有零解

重要结论：

  • 含有零向量的向量组必线性相关
  • 部分相关则整体相关；整体无关则部分无关
  • n+1个n维向量必线性相关
  • 正交向量组必线性无关

3.2 极大无关组与秩

概念定义
极大无关组线性无关，且能表示向量组中所有向量
向量组的秩极大无关组所含向量的个数
💡求法
将向量组排成矩阵，做初等行变换化为行阶梯形，非零行数=秩，主元所在列对应原向量组的极大无关组

3.3 矩阵的秩

R(A) = A的行秩 = A的列秩 = A的非零子式的最高阶数

性质：

  • R(A) = R(AT)
  • R(AB) ≤ min{R(A), R(B)}
  • R(A+B) ≤ R(A) + R(B)
  • 若 AB = O，则 R(A) + R(B) ≤ n

3.4 Schmidt正交化 ★方法

给定线性无关向量组 α1, α2, ...：

β1 = α1

β2 = α2 - [β1,α2]/[β1,β1] · β1

β3 = α3 - [β1,α3]/[β1,β1] · β1 - [β2,α3]/[β2,β2] · β2

再单位化：εi = βi / ‖βi‖（注意：向量范数用双竖线 ‖·‖）

3.5 正交矩阵

定义：ATA = E（即 A-1 = AT）

等价条件：

  • A的行向量组是规范正交向量组
  • A的列向量组是规范正交向量组

4线性方程组

4.1 解的判定 ★核心定理

非齐次方程组 Ax = β：

条件结论
R(A) ≠ R(A|β)无解
R(A) = R(A|β) = n（未知数个数）唯一解
R(A) = R(A|β) = r < n无穷多解，含 n-r 个自由参数

齐次方程组 Ax = 0：

  • R(A) = n：只有零解
  • R(A) = r < n：有非零解，基础解系含 n-r 个向量

4.2 解的结构

📐齐次方程组
基础解系 ξ1, ξ2, ..., ξn-r（解空间的极大无关组）
通解：x = k1ξ1 + k2ξ2 + ... + kn-rξn-r
📐非齐次方程组
通解 = 特解 η0 + 导出组（对应齐次）的通解
x = η0 + k1ξ1 + ... + kn-rξn-r

5矩阵的相似对角化

5.1 特征值与特征向量 ★重点

定义：Aξ = λξ（ξ ≠ 0）

求法：

  1. 解特征方程 |λE - A| = 0 → 得特征值 λi
  2. 对每个 λi，解 (λiE - A)x = 0 → 得特征向量

性质：

  • λ1 + λ2 + ... + λn = tr(A) = a11 + a22 + ... + ann
  • λ1λ2...λn = |A|
  • A 可逆 ⇔ 所有特征值非零
  • 若 λ 是A的特征值，则：
    • λk 是 Ak 的特征值
    • p(λ) 是 p(A) 的特征值
    • 1/λ 是 A-1 的特征值（A可逆时）

特征向量性质：

  • 不同特征值对应的特征向量线性无关
  • 同一特征值的特征向量的非零线性组合仍是该特征值的特征向量

5.2 相似对角化 ★重点

定义：P-1AP = Λ = diag(λ1, λ2, ..., λn)

📐判定定理
A 可对角化 ⇔ A 有 n个线性无关的特征向量
💡推论
A 有 n个互异特征值 → A 必可对角化
📌对角化判定实操步骤
1. 求出全部特征值，若有 n个互异 特征值 → 直接可对角化
2. 若有重根（如 λ 是 k 重根）：
    • 必须验证：n - R(λE - A) = k（即几何重数 = 代数重数）
    • 若小于 k，则不可对角化

求相似变换矩阵P：

  1. 求出n个线性无关的特征向量 ξ1, ξ2, ..., ξn
  2. 令 P = (ξ1, ξ2, ..., ξn)
  3. 则 P-1AP = diag(λ1, λ2, ..., λn)
💡应用
若 A = PΛP-1，则 Ak = PΛkP-1

★三大关系对比表（易混淆必背）

关系定义式变换矩阵条件不变/同量适用对象
等价 B = PAQ P,Q 可逆（任意） 秩相同 任意矩阵
相似 B = P-1AP P 可逆（同一矩阵及其逆） 特征值、迹、行列式相同 同阶方阵
合同 B = CTAC C 可逆（转置形式） 正/负惯性指数相同 实对称矩阵
🧠核心记忆口诀
等价看秩，相似看特征值，合同看正负惯性指数。

6二次型

⚠️前提强调
二次型 f = xTAx 中的矩阵 A 一定是实对称矩阵（AT=A），否则特征值正负无法判定正定。

6.1 基本概念

  • 二次型：f = xTAx，其中 A 是实对称矩阵
  • 标准形：f = d1y12 + d2y22 + ... + dnyn2（只含平方项）
  • 规范形：f = y12 + ... + yp2 - yp+12 - ... - yr2（系数为±1或0）

6.2 合同变换

定义：B = CTAC（C可逆），称A与B合同

性质：合同 → 等价 → 等秩；但等价/等秩 ⇏ 合同

6.3 化标准形的方法

方法特点
正交变换 x = Qy（Q正交矩阵）标准形系数 = 特征值；保持几何形状不变
配方法不一定得到特征值，但计算简单
初等变换法（合同对角化）对A同时做相同的行列初等变换

6.4 惯性定理 ★重点

📐定理
标准形中正系数的个数（正惯性指数p）和负系数的个数（负惯性指数q）是唯一确定的

合同判定：两实对称矩阵合同 ⇔ 正惯性指数相同且负惯性指数相同

6.5 正定二次型 ★重点

类型定义判定条件
正定 ∀x ≠ 0, f > 0 ① 正惯性指数 = n；② 特征值全>0；③ 顺序主子式全>0
负定 ∀x ≠ 0, f < 0 奇数阶顺序主子式<0，偶数阶顺序主子式>0
半正定 ∀x ≠ 0, f ≥ 0 负惯性指数 = 0；无负特征值

顺序主子式：

Dk = | a11 ... a1k |
        | ...  ...  ... |
        | ak1 ... akk |，  k=1,2,...,n

Q快速查询表：核心公式与方法

场景方法
求逆矩阵① 伴随矩阵法（2、3阶）；② 初等行变换法 (A|E)→(E|A-1)
求矩阵的秩初等行变换化为行阶梯形，数非零行
求向量组的秩/极大无关组排成矩阵，初等行变换
解线性方程组增广矩阵初等行变换 → 行最简形
求特征值/特征向量|λE-A|=0 → (λiE-A)x=0
