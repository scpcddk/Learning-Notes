# 可微性证明笔记

---

## 1. 可微的定义（核心）

### (1) 一元函数

$$f(x_0+\Delta x)-f(x_0)=A\Delta x+o(\Delta x)$$
其中 $A=f'(x_0)$。

### (2) **二元函数**（重点）

$f$ 在 $(x_0,y_0)$ **可微** $\Leftrightarrow$ 存在常数 $A,B$，使得：

$$f(x_0+\Delta x,\ y_0+\Delta y)-f(x_0,y_0)=A\Delta x+B\Delta y+o\left(\sqrt{(\Delta x)^2+(\Delta y)^2}\right)$$

即：
$$\lim_{(\Delta x,\Delta y)\to(0,0)}\frac{f(x_0+\Delta x,y_0+\Delta y)-f(x_0,y_0)-A\Delta x-B\Delta y}{\sqrt{(\Delta x)^2+(\Delta y)^2}}=0$$

**若可微，则 $A=f_x(x_0,y_0),\ B=f_y(x_0,y_0)$。**

---

## 2. 可微、可偏导、连续的关系

```text
可微  ⇒  可偏导  （且 A=fx, B=fy）
  ↓
连续
```

| 关系 | 方向 | 是否成立 |
| :--- | :--- | :---: |
| 可微 $\Rightarrow$ 可偏导 | ✅ | 成立 |
| 可微 $\Rightarrow$ 连续 | ✅ | 成立 |
| 可偏导 $\Rightarrow$ 可微 | ❌ | **不成立**（经典反例见下） |
| 连续 $\Rightarrow$ 可微 | ❌ | 不成立 |
| 连续 $\Rightarrow$ 可偏导 | ❌ | 不成立 |

### 经典反例：可偏导但不可微

$$f(x,y)=\begin{cases}\dfrac{xy}{\sqrt{x^2+y^2}},&(x,y)\neq(0,0)\\0,&(x,y)=(0,0)\end{cases}$$

- $f_x(0,0)=0,\ f_y(0,0)=0$（可偏导）
- 但 $\dfrac{f(x,y)-0-0x-0y}{\sqrt{x^2+y^2}}=\dfrac{xy}{x^2+y^2}$ 极限不存在（沿 $y=x$ 趋于 $\frac12$）
- **不可微！**

> [!IMPORTANT]
> **关键：可偏导只是可微的必要条件，不是充分条件**

---

## 3. **证明可微的标准方法**

### (1) 方法一：直接用定义（最通用）

**步骤：**

1. 求 $f(x_0,y_0)$（通常用连续性）
2. 求 $f_x(x_0,y_0),\ f_y(x_0,y_0)$（用偏导数定义）
3. 验证：
   $$\lim_{(x,y)\to(x_0,y_0)}\frac{f(x,y)-f(x_0,y_0)-f_x(x_0,y_0)(x-x_0)-f_y(x_0,y_0)(y-y_0)}{\sqrt{(x-x_0)^2+(y-y_0)^2}}=0$$

**适用场景：** 分段函数在分界点、抽象函数

---

### (2) 方法二：利用充分条件（计算简单）

**定理：** 若 $f_x,\ f_y$ 在 $(x_0,y_0)$ 的某邻域内**存在且连续**，则 $f$ 在 $(x_0,y_0)$ 可微

**适用场景：** 具体函数，偏导数好算且连续。

**注意：** 这只是充分条件，不是必要条件。有些函数可微但偏导数不连续

---

## 4. 证明不可微的方法

| 方法 | 操作 |
| :--- | :--- |
| **法一** | 证明 $f$ 在 $(x_0,y_0)$ **不连续** |
| **法二** | 证明 $f_x(x_0,y_0)$ 或 $f_y(x_0,y_0)$ **不存在** |
| **法三** | 偏导数存在，但定义式极限 **不存在** 或 **不为0** |
| **法四** | 沿不同路径趋于 $(x_0,y_0)$，定义式极限 **不同** |

---

## 5. **常见题型与技巧**

### (1) 题型一：抽象函数

**题目特征：** 给出极限条件，证明可微

**技巧：** 从条件中"读出" $f(0,0)$、$f_x(0,0)$、$f_y(0,0)$，再验证定义

---

### (2) 题型二：分段函数在分界点

**标准套路：**

1. 先求 $f(x_0,y_0)$
2. 用定义求 $f_x(x_0,y_0),\ f_y(x_0,y_0)$
3. 若偏导数不存在 $\Rightarrow$ 不可微
4. 若偏导数存在，代入定义式验证极限是否为0

---

### (3) 题型三：偏导数连续 $\Rightarrow$ 可微

**直接验证：**

1. 求 $f_x(x,y),\ f_y(x,y)$（在 $(x_0,y_0)$ 附近）
2. 证明 $\lim_{(x,y)\to(x_0,y_0)}f_x(x,y)=f_x(x_0,y_0)$（即 $f_x$ 连续）
3. 同理 $f_y$ 连续
4. 由充分条件，得可微

---

## 6. 易错点提醒

| 错误 | 正确做法 |
| :--- | :--- |
| 把可偏导当成可微 | 可偏导只是必要条件，必须验证定义式 |
| 求 $f_x(0,0)$ 时直接代入 $y=0$ 求导 | 必须用定义：$\lim_{x\to 0}\frac{f(x,0)-f(0,0)}{x}$ |
| 忽略 $\sqrt{x^2}=\vert x\vert$ | 沿坐标轴路径时，分母是 $\vert x\vert$ 不是 $x$ |
| 验证定义时分子漏掉 $f(x_0,y_0)$ | 完整分子：$f(x,y)-f(x_0,y_0)-f_x(x-x_0)-f_y(y-y_0)$ |

---

## 7. 一句话总结

> [!NOTE]
> **证明可微就三句话：先求函数值，再求偏导数，最后代入定义验证极限为0**
