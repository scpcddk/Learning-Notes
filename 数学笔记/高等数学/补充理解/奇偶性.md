# 🔥 奇偶性积分总结（第6~9章通用）

## 核心思想

> **奇函数 × 对称区域 = 0**
> **偶函数 × 对称区域 = 2倍半区域**

关键是搞清楚：**谁关于谁对称？函数关于哪个变量是奇/偶？**

---

## 一、定积分（第6章基础）

| 条件 | 结论 |
| ------ | ------ |
| $f(x)$ 是**奇函数**，$[-a,a]$ 关于原点对称 | $\int_{-a}^{a} f(x)dx = 0$ |
| $f(x)$ 是**偶函数**，$[-a,a]$ 关于原点对称 | $\int_{-a}^{a} f(x)dx = 2\int_{0}^{a} f(x)dx$ |

> **判断奇偶**：$f(-x) = -f(x)$ → 奇；$f(-x) = f(x)$ → 偶

---

## 二、二重积分（第8章）

| 区域 $D$ 的对称性 | 函数 $f(x,y)$ 的奇偶性 | 结论 |
| ------------------ | ---------------------- | ------ |
| 关于 **$y$ 轴** 对称（即 $(x,y)$ 和 $(-x,y)$ 都在 $D$） | $f$ 关于 $x$ 是**奇函数**（$f(-x,y)=-f(x,y)$） | $\iint_D f d\sigma = 0$ |
| 关于 **$y$ 轴** 对称 | $f$ 关于 $x$ 是**偶函数**（$f(-x,y)=f(x,y)$） | $\iint_D f d\sigma = 2\iint_{D_右} f d\sigma$ |
| 关于 **$x$ 轴** 对称（即 $(x,y)$ 和 $(x,-y)$ 都在 $D$） | $f$ 关于 $y$ 是**奇函数**（$f(x,-y)=-f(x,y)$） | $\iint_D f d\sigma = 0$ |
| 关于 **$x$ 轴** 对称 | $f$ 关于 $y$ 是**偶函数**（$f(x,-y)=f(x,y)$） | $\iint_D f d\sigma = 2\iint_{D_上} f d\sigma$ |

> **记忆口诀**：区域关于谁对称，就看函数**关于另一个变量是奇是偶**
>
> - 区域关于 $y$ 轴对称 → 看 $f$ 关于 $x$ 的奇偶性
> - 区域关于 $x$ 轴对称 → 看 $f$ 关于 $y$ 的奇偶性

---

## 三、三重积分（第8章）

| 区域 $\Omega$ 的对称性 | 函数 $f(x,y,z)$ 的奇偶性 | 结论 |
| ---------------------- | ------------------------ | ------ |
| 关于 **$xOy$ 面** 对称（$z$ 变号） | $f$ 关于 $z$ 是**奇函数** | $\iiint_\Omega f dV = 0$ |
| 关于 **$xOy$ 面** 对称 | $f$ 关于 $z$ 是**偶函数** | $\iiint_\Omega f dV = 2\iiint_{\Omega_上} f dV$ |
| 关于 **$yOz$ 面** 对称（$x$ 变号） | $f$ 关于 $x$ 是**奇函数** | $\iiint_\Omega f dV = 0$ |
| 关于 **$zOx$ 面** 对称（$y$ 变号） | $f$ 关于 $y$ 是**奇函数** | $\iiint_\Omega f dV = 0$ |

> **记忆口诀**：区域关于哪个坐标面对称，就看函数关于**垂直于该面的那个变量**（第三个变量）的奇偶性

---

## 四、第一型曲线积分（第9章）

| 曲线 $L$ 的对称性 | 函数 $f(x,y)$ 的奇偶性 | 结论 |
| ------------------ | ---------------------- | ------ |
| 关于 **$x$ 轴** 对称 | $f$ 关于 $y$ 是**奇函数** | $\int_L f ds = 0$ |
| 关于 **$x$ 轴** 对称 | $f$ 关于 $y$ 是**偶函数** | $\int_L f ds = 2\int_{L_上} f ds$ |
| 关于 **$y$ 轴** 对称 | $f$ 关于 $x$ 是**奇函数** | $\int_L f ds = 0$ |
| 关于 **$y$ 轴** 对称 | $f$ 关于 $x$ 是**偶函数** | $\int_L f ds = 2\int_{L_右} f ds$ |

---

## 五、第一型曲面积分（第9章）

| 曲面 $\Sigma$ 的对称性 | 函数 $f(x,y,z)$ 的奇偶性 | 结论 |
| ---------------------- | ------------------------ | ------ |
| 关于 **$xOy$ 面** 对称 | $f$ 关于 $z$ 是**奇函数** | $\iint_\Sigma f dS = 0$ |
| 关于 **$xOy$ 面** 对称 | $f$ 关于 $z$ 是**偶函数** | $\iint_\Sigma f dS = 2\iint_{\Sigma_上} f dS$ |

---

## 六、第二型曲线/曲面积分（第9章）

> ⚠️ **第二型积分一般不能直接用奇偶性简化**，因为第二型积分与方向有关，奇偶性结论不成立或需要额外考虑方向

---

## 总结表：一张图记住所有奇偶性

```text
┌───────────────────────────────────────────────────────┐
│  积分类型    │  区域对称性        │  看函数的奇偶性      │
├───────────────────────────────────────────────────────┤
│  定积分      │  关于原点对称      │  f(x) 关于 x        │
│  二重积分    │  关于 y 轴对称     │  f 关于 x           │
│  二重积分    │  关于 x 轴对称     │  f 关于 y           │
│  三重积分    │  关于 xOy 面对称   │  f 关于 z           │
│  三重积分    │  关于 yOz 面对称   │  f 关于 x           │
│  三重积分    │  关于 zOx 面对称   │  f 关于 y           │
│  曲线积分    │  关于 x 轴对称     │  f 关于 y           │
│  曲线积分    │  关于 y 轴对称     │  f 关于 x           │
│  曲面积分    │  关于 xOy 面对称   │  f 关于 z           │
└───────────────────────────────────────────────────────┘
```

> [!TIP]
> **统一规律**：区域关于某个轴/面对称 → 函数关于**垂直于该轴/面的变量**是奇是偶

---

## 快速判断技巧

1. **画草图**：先看积分区域是否对称
2. **找变量**：确定区域关于哪个轴/面对称
3. **验函数**：把对称变量的相反数代入函数，看是否变号
4. **下结论**：奇函数→0，偶函数→2倍
