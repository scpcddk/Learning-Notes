# 命题符号化

## 一 谓词逻辑符号化的核心技巧

### 1. 先识别"骨架"，再填"血肉"

| 自然语言信号 | 逻辑符号 | 读法 |
| --- | --- | --- |
| "所有...都..." "凡是...都..." | ∀ | 全称量词 |
| "有些..." "存在..." "至少有一个..." | ∃ | 存在量词 |
| "如果...那么..." "只要...就..." | → | 蕴含 |
| "...并且..." "...而且..." | ∧ | 合取 |
| "...或者..." | ∨ | 析取 |
| "不是..." "并非..." | ¬ | 否定 |

### 2. 三步拆解法

**第一步：找主语范围** → 确定量词（∀ 还是 ∃）

**第二步：找"如果...那么..."结构** → 确定蕴含关系

**第三步：找属性或关系** → 确定谓词

### 3. 两个黄金规则

| 规则 | 说明 | 例子 |
|---|---|---|
| **全称量词 + 蕴含** | ∀x (条件 → 结论) | "所有学生都要考试" = ∀x(S(x)→E(x)) |
| **存在量词 + 合取** | ∃x (属性₁ ∧ 属性₂) | "有些学生是党员" = ∃x(S(x)∧D(x)) |

> ⚠️ 千万别写成 ∀x(S(x)∧E(x))，这表示"所有对象都是学生且都要考试"，范围错了！

## 二 针对这道题的具体分析

### 1. 先整理谓词

- S(x): x是学生；L(x): x是校领导；G(x): x是好的
- T(x): x是老师；P(x): x受过处分；C(x,y): y表扬x

### 2. 逐句符号化

- **前提1："没有受过处分的学生，都受到过校领导的表扬"**

```math
拆解：所有 x，如果(x是学生 且 x没受过处分)，那么(存在 y，y是校领导 且 y表扬x)
符号化：∀x((S(x)∧¬P(x)) → ∃y(L(y)∧C(x,y)))
```

- **前提2："有些好学生，仅仅受到过老师的表扬"**

```math
拆解：存在 x，(x是学生 且 x是好的) 且 (对于所有 y，如果 y表扬x，那么 y是老师)
注意"仅仅" = "所有表扬x的人都是老师"
符号化：∃x((S(x)∧G(x)) ∧ ∀y(C(x,y)→T(y)))
```

- **前提3："所有好学生，都没有受过处分"**

```math
拆解：所有 x，如果(x是学生 且 x是好的)，那么 x没受过处分
符号化：∀x((S(x)∧G(x)) → ¬P(x))
```

- **结论："有的老师是校领导"**

```math
符号化：∃y(T(y)∧L(y))
```

## 三 形式化证明（自然演绎法）

| 步骤 | 公式 | 依据 |
| :--- | :--- | :--- |
| 1 | ∀x((S(x)∧¬P(x)) → ∃y(L(y)∧C(x,y))) | 前提 |
| 2 | ∃x((S(x)∧G(x)) ∧ ∀y(C(x,y)→T(y))) | 前提 |
| 3 | ∀x((S(x)∧G(x)) → ¬P(x)) | 前提 |
| 4 | (S(a)∧G(a)) ∧ ∀y(C(a,y)→T(y)) | 2, ES(存在特例)，设a为满足条件的特定学生 |
| 5 | S(a) ∧ G(a) | 4, 化简 |
| 6 | ∀y(C(a,y)→T(y)) | 4, 化简 |
| 7 | (S(a)∧G(a)) → ¬P(a) | 3, US(全称代入) |
| 8 | ¬P(a) | 5, 7, MP(假言推理) |
| 9 | S(a) | 5, 化简 |
| 10 | S(a) ∧ ¬P(a) | 8, 9, 合取 |
| 11 | (S(a)∧¬P(a)) → ∃y(L(y)∧C(a,y)) | 1, US |
| 12 | ∃y(L(y)∧C(a,y)) | 10, 11, MP |

## 四 快速检查清单

| 检查项 | 你的公式 | 正确吗？ |
| :--- | :--- | :---: |
| 全称命题用了 → 而不是 ∧？ | ∀x(A→B) ✓ | |
| 存在命题用了 ∧ 而不是 →？ | ∃x(A∧B) ✓ | |
| "仅仅"翻译成了 ∀y(C→T) 而不是 ∃？ | ∀y(C(x,y)→T(y)) ✓ | |
| 否定符号 ¬ 位置正确？ | ¬P(x) 而不是 P(¬x) ✓ | |

掌握了这些技巧，谓词符号化就不难了。核心就是：**先找量词，再找蕴含，最后填谓词**。
