
# 📚 Learning-Notes

> 一个迷茫但坚定的羔羊，从零构建计算机完整知识体系的不断探索 ✨

本仓库是我的个人专属学习归档库，完整记录从大一下学期开始的全部学习轨迹。所有笔记、代码、题解均为本人学习过程中手写整理，拒绝搬运，持续更新。

---

## 🎯 仓库定位

- **核心目标**：对标互联网大厂校招要求，夯实计算机基础，同步拓展前沿技术能力
- **内容特点**：代码可直接运行，笔记兼顾原理深度与应试性，包含大量个人踩坑记录
- **适用人群**：同专业低年级同学、准备计算机校招的学习者、对云原生与大模型感兴趣的入门者

## ✨ 仓库特色

1. **体系化**：完全按照计算机专业培养方案 + 校招要求构建知识树，从基础到前沿循序渐进
2. **实战性**：所有代码均经过本地运行测试，笔记包含大量个人踩坑记录与解决方案
3. **规范化**：统一使用 Markdown 编写，数学公式采用 LaTeX 排版，代码带详细注释
4. **时效性**：紧跟技术趋势，同步更新云原生、大模型等当前热门方向内容
5. **可复用**：所有笔记与模板均可直接下载使用，适合作为个人学习仓库的参考

## 📝 个人笔记规范

1. 所有笔记使用 Markdown 格式，标题层级清晰（# 一级 → ##### 五级）
2. 数学公式统一使用 LaTeX 语法，行内公式用 `$...$`，块级公式用 `$$...$$`
3. 代码块指定语言类型，添加必要的注释与运行说明
