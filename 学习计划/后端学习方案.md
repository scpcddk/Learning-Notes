# 二、总目标

未来这一阶段，不要把目标定成：

> “学完 Spring Boot。”

也不要定成：

> “学完 MySQL。”

> **能够独立完成一个中小型 Spring Boot + MyBatis + MySQL 后端，并能够独立定位常见问题，再能够读懂和分析真实项目。**

## 1. 索引

先回答：

> 为什么需要索引？

从：

```sql
SELECT *
FROM student
WHERE student_name = '张三';
```

开始。

假设：

```text
10 条数据
1000 条
100 万条
1000 万条
```

让你思考：

> 数据库怎么找到这一行？

然后进入：

```text
全表扫描
        ↓
索引
        ↓
B+Tree
```

---

## 2. B+Tree

重点不是背定义。

你要理解：

```text
为什么是树？

为什么不是数组？

为什么不是二叉树？

为什么不是 Hash？

为什么 MySQL 常用 B+Tree？

数据放在哪里？

叶子节点为什么重要？

叶子节点为什么可以连接？
```

最终能够解释：

> **MySQL 为什么使用 B+Tree 作为常见索引结构。**

# 六、联合索引

重点：

```text
INDEX(a,b,c)
```

理解：

```text
(a)
(a,b)
(a,b,c)
```

以及为什么：

```text
(b)
(c)
```

通常不能等价利用这个联合索引。

然后学习：

> **最左匹配原则**

# 七、覆盖索引


这个闭环和你上传方案里的核心学习闭环是一致的。

# 三十五、每个知识点都使用“三问法”

以后判断自己是否真正掌握，不要问：

> “我看过这个吗？”

问：

### 第一问：能不能写？

例如：

> 能不能不用教程写一个 MyBatis 动态查询？

### 第二问：能不能查？

例如：

> SQL 慢了，我能不能用 EXPLAIN 开始排查？

### 第三问：能不能解释？

例如：

> 为什么这里需要联合索引？

如果：

```text
能写
+
能查
+
能解释
```

才算真正掌握。

# 三十六、学习时间怎么分配

如果你每天大约有 **2～3 小时**，建议：

```text
60～90 分钟

45～60 分钟
实际编码

20～30 分钟
复盘 / Debug / 总结
```

如果只有 1 小时：

```text
25 分钟
理论

30 分钟
编码

5 分钟
总结
```

**编码时间尽量不要长期低于理论时间。**

你目前最大的风险就是：

> 输入很多，输出太少。

所以随着学习深入，应该逐渐变成：

```text
理论 40%
实践 60%
```

# 三十七、不要追求每天“学很多”

你的学习单位应该从：

> 今天学了 3 个知识点。

> 今天解决了一个问题。

例如：


你可能最终学会：

```text

最左匹配

```

这比一天背 10 个知识点有效。
