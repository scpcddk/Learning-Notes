# 一、当前定位与学习目标

## 1.1 当前学习定位

我已经接触过较多 Java 后端知识，但目前最大的短板不是知识储备不足，而是独立编码训练不足，以及各项知识之间尚未形成稳定的工程能力。

| 领域 | 当前状态 | 学习策略 |
|---|---|---|
| Java | 有基础 | 通过项目补充编码能力 |
| Spring IOC/AOP | 学过 | 结合实际问题复习 |
| Spring MVC | 学过，有遗忘 | 恢复请求处理流程 |
| Spring Boot | 学过基础 | 小练习恢复使用手感 |
| MySQL SQL、表设计 | 已有较好基础 | 不重复学习基础 SQL |
| MySQL 索引、B+Tree、EXPLAIN | 需要结合实际操作核验 | 实验与查询优化 |
| MyBatis | 正在学习 | 当前主要学习方向 |
| Spring + MyBatis 事务 | 已学习核心协作机制 | 转入代码验证与 Debug |
| Linux | 有基础 | 后续与部署结合 |
| Docker、Nginx | 有基础和接触经验 | 通过项目部署强化 |
| Git | 基础较薄弱 | 贯穿整个学习过程 |
| 真实项目 | 有参与经验 | 后期按业务链路逆向分析 |
| 独立编码 | 练习不足 | 全阶段重点训练 |

## 1.2 总体目标

最终目标不是单纯学完 Spring Boot、MyBatis 或 MySQL，而是形成完整的后端工程能力。

需要逐步具备以下能力：

- [ ] 独立设计数据库表与后端 API。
- [ ] 独立实现 Controller、Service、Mapper 和 SQL。
- [ ] 能够开发常见 CRUD、多表查询、分页与业务事务。
- [ ] 能够通过日志、断点、SQL 和配置定位常见 Bug。
- [ ] 能够阅读真实项目，并追踪一个完整业务链路。
- [ ] 能够使用 Git 管理代码。
- [ ] 能够使用 Docker、Linux、Nginx 完成基本部署。
- [ ] 能够将后端知识与后续 AI 应用开发结合。

核心能力闭环：

**理解 → 设计 → 编码 → 运行 → 测试 → Debug → Review → 总结 → 独立复现。**

## 1.3 学习原则

1. 不重复系统学习已经掌握的内容。
2. 已掌握的知识先快速测试，确认后跳过。
3. 遗忘的知识通过复习和小练习恢复。
4. 薄弱知识通过实际任务重点补强。
5. 未学习的知识按照依赖关系逐步学习。
6. 不为了学框架而学框架，始终围绕实际业务。
7. 理论学习逐步调整为理论约 40%、实践约 60%。
8. 不追求每个阶段的所有知识都达到专家水平。
9. 不在第一个独立项目完成前追求复杂架构。
10. 以能够独立解决问题作为进度判断标准，而不是观看课程的数量。

# 十一、AI 辅助学习规范

AI 的定位是教练、设计评审、Code Reviewer、Debug 辅助和概念解释工具，而不是替代自己的代码生成器。

5. 自己运行和排查问题。

每周至少完成：

- [ ] 一次代码 Review 和自行修改。
- [ ] 一次脱离参考代码的复现或口头讲解。

使用 AI 时要求自己能够回答：

- [ ] 为什么采用这个实现？
- [ ] 输入异常时会发生什么？
- [ ] 如何验证实现正确？

- [ ] 不依赖 AI，能否重新实现核心逻辑？
