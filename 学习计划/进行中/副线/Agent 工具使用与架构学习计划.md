# Agent 工具使用与架构学习计划

## 一、学习目标

- 熟练使用主流 Coding Agent 辅助实际开发。
- 理解 Agent 的工具调用、执行循环与扩展机制。
- 兼顾编程效率和 Agent 架构学习。
- **低频学习，每周约 30～45 分钟，不影响 Java 后端与 AI 学习主线。**

---

## 二、阶段 1：Codex CLI

**目标：掌握 Codex CLI 基础操作，能够独立完成开发任务。**

### 基础使用
- [x] 环境安装与登录
- [x] CLI 启动及工作目录
- [x] `read-only` 权限模式
- [x] `/status` 状态检查
- [x] 真实项目文件分析
- [x] 工具调用与基础故障排查
- [x] `workspace-write` 权限与代码修改
- [ ] Git diff 与测试验证

### 后续按需掌握
- [ ] `/review` 代码审查
- [ ] 会话恢复与上下文管理
- [ ] `AGENTS.md` 项目指令

**验收：** 能独立使用 Codex CLI 修改小范围代码，并检查修改结果。

---

## 三、阶段 2：Pi Coding Agent

**目标：体验轻量 Agent，初步理解其运行机制。**

### 基础使用
- [ ] 安装与模型配置
- [ ] CLI 基础操作
- [ ] 文件读取、修改与工具执行
- [ ] 会话与上下文管理

### 架构理解
- [ ] Agent Loop 执行过程
- [ ] 工具调用与结果反馈

### 基础使用
- [ ] 安装与启动

### 架构理解

## 五、阶段 4：综合实践与总结

**目标：形成自己的 Agent 使用方法和基础架构认知。**

- [ ] 使用不同 Agent 完成同类任务
- [ ] 比较开发效率与操作体验
- [ ] 对比工具调用与扩展机制
- [ ] 总结 Agent 选型原则
- [ ] 将有价值的实践记录到笔记

## 六、最终验收标准
