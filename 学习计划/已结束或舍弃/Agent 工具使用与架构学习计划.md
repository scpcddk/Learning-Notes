# Agent 工具使用与架构学习计划

---

## 一、学习目标

- 掌握 Codex、Pi、DSH 的基本使用，提升实际编程效率。
- 理解 Agent Loop、Tool Calling、上下文管理与扩展机制。
- 掌握会话分支、多方案探索、任务委派和结果验证等工作流。
- 建立 Agent 工具选型能力，为后续自主开发 Agent 打基础。

**学习原则：**

- 以实际操作为主，原理理解为辅，不重复机械练习。
- 基础体验争取一周内完成，不强制固定天数。
- 不影响 Java 后端、Python + LLM API 等主要学习任务。
- 只记录经过验证的操作和有复用价值的经验。
