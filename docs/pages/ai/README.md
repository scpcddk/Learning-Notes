# AI 阅读页

访问 `/ai/` 阅读 AI 笔记。页面复用编程语言阅读模板，首页按基础知识、Agent、实践记录、提示词模板和错题与易错点展示目录。首页 AI 卡片与阅读页共用新版封面。[编程语言阅读模板](../programming/阅读页模板.html) · [AI 封面](阅读资源/ai-hero-v2.webp)

左侧目录列出各板块的全部篇目。主笔记提供可展开的章节目录，章节入口定位到正文标题，同篇跳转保留已绘制的公式和流程图，当前小节随阅读位置高亮。桌面显示固定侧栏，手机通过顶部目录按钮展开。

构建脚本直接读取仓库 `AI/` 下的 Markdown 笔记与 Python 实践代码。新增、修改或删除原笔记后会在下次构建时更新。Python 实践代码可全文搜索、高亮和复制，也可打开原源码。

支持目录速览与完整笔记、全文搜索、本篇目录、相邻篇目、深色模式、打印、移动端导航和上次阅读记录。已有笔记及源码之间的相对链接转换为站内入口。公式使用本地 MathJax，Mermaid 图解使用本地组件渲染，图解下方可展开并复制源码；代码块和行内代码中的公式符号保持原样。

封面使用内置图像生成工具制作，采用暖白纸面背景、墨绿与浅鼠尾草绿玻璃及黄铜连接线。图像为 1536 × 1024 的不透明 WebP，仅芯片上保留「AI」标识。

[新版最终提示词](阅读资源/ai-hero-v2.prompt.txt) 与图片一起保存，统一构建脚本负责打包并接入首页和 AI 阅读页。

上一版 [对话气泡与书本封面](阅读资源/ai-hero.webp) 及其 [提示词](阅读资源/ai-hero.prompt.txt) 保留用于比较。

构建：`python docs/pages/build_site.py --output docs/site`。
预览：`python docs/pages/build_site.py --output docs/site --serve`，打开 `http://127.0.0.1:8768/ai/`。
回归检查：`python -m unittest discover -s docs/pages -p 'test_*.py'`。
