# AI 阅读页

访问 `/ai/` 阅读 AI 笔记。页面复用 [编程语言阅读模板](../programming/阅读页模板.html)，首页按「基础知识、实践记录、提示词模板、错题与易错点」展示文字卡片，左侧保留原目录与全部篇目，可直接选择内容。首页 AI 卡片与阅读页共用新版 [ai-hero-v2.png](阅读资源/ai-hero-v2.png)，内部目录不添加配图。

左侧目录参考算法页，始终列出四个板块下的全部篇目，首页和阅读时均可直接切换。主笔记进一步展示 18 篇、121 节的可展开目录，章节入口使用正文的真实锚点；同篇跳转保留已绘制的公式和流程图，当前小节随阅读位置高亮。桌面固定显示侧栏，手机通过顶部目录按钮展开。

构建脚本直接读取仓库 `AI/`，当前包含 8 篇 Markdown 与 1 份 Python 实践代码。新增、修改或删除原笔记后会在下次构建时更新；`test_*.py` 与 `conftest.py` 不作为学习内容收录。Python 代码保留原始内容，可全文搜索、高亮、复制，并提供原源码入口；页面不会执行代码。

支持目录速览与完整笔记、全文搜索、本篇目录、相邻篇目、深色模式、打印、移动端导航和上次阅读记录。已有笔记及源码之间的相对链接转换为站内入口。公式使用本地 MathJax，Mermaid 图解使用本地组件渲染，图解下方可展开并复制源码；代码块和行内代码中的公式符号保持原样。

封面使用内置图像生成工具制作：暖白纸面背景、墨绿与浅鼠尾草绿玻璃、黄铜连接线。带有「AI」标识的处理器与发光脑形神经网络共同突出人工智能和智能计算主题，同时与现有数学、编程语言等封面保持同一材质和配色。图像为 1536 × 1024 的不透明 PNG，仅芯片上保留「AI」标识。

[新版最终提示词](阅读资源/ai-hero-v2.prompt.txt) 与图片一起保存，统一构建脚本负责打包并接入首页和 AI 阅读页。

上一版 [对话气泡与书本封面](阅读资源/ai-hero.png) 及其 [提示词](阅读资源/ai-hero.prompt.txt) 保留用于比较。

构建：`python docs/pages/build_site.py --output docs/site`。
预览：`python docs/pages/build_site.py --output docs/site --serve`，打开 `http://127.0.0.1:8768/ai/`。
回归检查：`python -m unittest discover -s docs/pages -p 'test_*.py'`。
