## 怎么阅读

1. **建立框架**：从科目导航和章节主线开始。
2. **理解方法**：结合完整例题与补充专题，留意适用条件和反例。
3. **检验掌握**：独立完成习题，再对照解析记录卡点。

三个科目的导航都提供在线阅读入口，也可以直接选择：

- [在线阅读高等数学](https://scpcddk.github.io/Learning-Notes/calculus/)
