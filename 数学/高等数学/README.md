## 4. 更新阅读页面

修改章节、专题或自测题后，在仓库根目录运行：

~~~powershell
python docs/pages/build_site.py --output "$env:TEMP/LearningNotes-math-site"
~~~

脚本需要 markdown-it-py；生成后的网页可直接打开，不需要 Python 或本地服务器。页面结构、离线资源与维护方式见：[阅读页面说明](../../docs/pages/README.md)。
