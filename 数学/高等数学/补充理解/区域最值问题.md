# 区域最值问题笔记：多元函数在有界闭区域上的最值

---

## 1. 核心思想

**有界闭区域上的连续函数必有最值**（最值存在定理）

最值只可能出现在两类点：

- ==**区域内部**的驻点==（偏导数为0的点）
- ==**边界**上的极值点==（包括边界的端点/交点）

> [!WARNING]
> **只算内部驻点一定错！边界必须单独讨论**

---

## 2. **标准解题流程**（三步法）

```text
┌─────────────────────────────────────────┐
│  第一步：求区域内部驻点                   │
│  ∂f/∂x = 0, ∂f/∂y = 0                   │
│  → 解出驻点，筛选在区域严格内部的点        │
├─────────────────────────────────────────┤
│  第二步：求边界上的极值                   │
│  把边界方程代入，化为一元函数求极值        │
│  或：拉格朗日乘数法（约束极值）            │
│  → 别忘了边界端点！                      │
├─────────────────────────────────────────┤
│  第三步：比较所有候选点                   │
│  内部驻点 + 边界极值点 + 边界端点          │
│  → 比大小，最大的就是最大值，最小就是最小值 │
└─────────────────────────────────────────┘
```

---

## 3. 第一步详解：内部驻点

### (1) 操作方法

1. 求偏导数 $\dfrac{\partial f}{\partial x},\ \dfrac{\partial f}{\partial y}$
2. 解方程组 $\begin{cases} f_x=0 \\ f_y=0 \end{cases}$
3. **筛选**：保留严格在区域内部的点（不在边界上）

### (2) 示例

$f(x,y)=x^2+2y^2-x^2y^2$，区域 $D: x^2+y^2\le 4,\ y\ge 0$

- $f_x=2x(1-y^2)=0$
- $f_y=2y(2-x^2)=0$

解得驻点：$(0,0),\ (\pm\sqrt{2},1),\ (\pm\sqrt{2},-1)$

**筛选结果：**

- $(0,0)$：在边界 $y=0$ 上，**舍去**
- $(\pm\sqrt{2},-1)$：$y<0$ 不在区域内，**舍去**
- $(\pm\sqrt{2},1)$：$y>0$ 且 $x^2+y^2=3<4$，**保留** ✅

内部候选值：$f(\pm\sqrt{2},1)=2$

---

## 4. 第二步详解：边界上的极值

### (1) 边界分类处理

| 边界类型 | 处理方法 | 关键技巧 |
| :--- | :--- | :--- |
| **直线段**（如 $y=0, x=a$） | **代入化为一元函数** | 直接代入，求导找极值 |
| **曲线段**（如 $x^2+y^2=R^2$） | **参数法或消元法** | 用约束条件消去一个变量 |
| **多条边界** | **每条分别处理** | 别漏边！别漏端点！ |

### (2)示例

**边界 ①：$y=0,\ x\in[-2,2]$**

代入：$f(x,0)=x^2$

- 最小值：$f(0,0)=0$
- 最大值：$f(\pm2,0)=4$

**边界 ②：$x^2+y^2=4,\ y\ge 0$（上半圆弧）**

用 $x^2=4-y^2$ 消去 $x$（$y\in[0,2]$）：

$$f=(4-y^2)+2y^2-(4-y^2)y^2=y^4-3y^2+4$$

令 $g(y)=y^4-3y^2+4$，求导 $g'(y)=2y(2y^2-3)=0$

临界点：$y=0,\ y=\dfrac{\sqrt{6}}{2}$

| $y$ | 对应点 | $f$ 值 |
|:---|:---|:---:|
| $0$ | $(\pm2,0)$ | $4$ |
| $\dfrac{\sqrt{6}}{2}$ | $\left(\pm\dfrac{\sqrt{10}}{2},\dfrac{\sqrt{6}}{2}\right)$ | $\dfrac{7}{4}$ |
| $2$（端点） | $(0,2)$ | $8$ |

---

## 5. 第三步：比较所有候选点

汇总所有候选点，**直接比大小**：

| 点 | 类型 | $f$ 值 |
| :--- | :--- | :---: |
| $(\pm\sqrt{2},1)$ | 内部驻点 | $2$ |
| $(0,0)$ | 边界交点 | $0$ |
| $(\pm2,0)$ | 边界端点 | $4$ |
| $\left(\pm\dfrac{\sqrt{10}}{2},\dfrac{\sqrt{6}}{2}\right)$ | 圆弧临界点 | $\dfrac{7}{4}$ |
| $(0,2)$ | 圆弧端点 | $8$ |

**结果：**
$$\boxed{f_{\min}=0\ (\text{在 }(0,0)),\quad f_{\max}=8\ (\text{在 }(0,2))}$$

---

## 6. **边界处理的常用技巧**

### (1) 技巧一：代入消元（显式边界）

边界方程能解出 $y=g(x)$ 或 $x=h(y)$，直接代入 $f$ 化为一元函数

### (2) 技巧二：参数法（圆/椭圆）

- 圆 $x^2+y^2=R^2$：令 $x=R\cos t,\ y=R\sin t$
- 椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$：令 $x=a\cos t,\ y=b\sin t$

### (3) 技巧三：拉格朗日乘数法（复杂约束）

边界 $g(x,y)=0$，构造 $L=f+\lambda g$，解 $\begin{cases} L_x=0 \\ L_y=0 \\ g=0 \end{cases}$

---

## 7. **常见错误清单**

| 错误 | 后果 | 避免方法 |
| :--- | :--- | :--- |
| **只算内部驻点** | 漏掉边界上的最值 | 记住：区域最值 = 内部 + 边界 |
| **漏掉某条边界** | 区域有多个边界，只算了一个 | 画图，把边界列全 |
| **边界端点没算** | 端点可能恰好是最值 | 每条边界都算端点 |
| **把边界上的点当内部点** | 如 $(0,0)$ 在 $y=0$ 边界上 | 严格内部要求：不在任何边界上 |
| **边界化一元后忘求导** | 只算了端点，漏了临界点 | 一元函数也要求导找极值 |
| **参数范围搞错** | 如上半圆 $t\in[0,\pi]$ 不是 $[0,2\pi]$ | 根据区域确定参数范围 |

---

## 8. 快速检查清单

做完题后对照检查：

- [ ] 内部驻点都找到了吗？偏导数解全了吗？
- [ ] 内部驻点都严格在区域内部吗？（不在边界上）
- [ ] 边界有几条？都单独处理了吗？
- [ ] 每条边界都求导找临界点了吗？
- [ ] 每条边界的端点都代入了吗？
- [ ] 所有候选点的函数值都计算了吗？
- [ ] 最后比较大小了吗？

---

## 9. 一句话总结

> [!TIP]
> **区域最值三步走：内部驻点求一遍，每条边界单独算，端点千万别漏掉，全部放在一起比大小**
