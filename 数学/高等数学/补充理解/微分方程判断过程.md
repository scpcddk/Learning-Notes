## 🗺️ 拿到题先看什么？判断流程

```text
┌─────────────────────────────────────────────────────────┐
│  第一步：看是几阶？                                       │
│  ├─ 一阶 → 进入第二步                                    │
│  └─ 二阶及以上 → 进入第三步                               │
└─────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┴─────────────────────┐
        ▼                                               ▼
┌───────────────┐                           ┌─────────────────┐
│ 第二步：一阶方程│                          │ 第三步：高阶方程  │
│ 看能不能写成：  │                          │ 看右边有没有f(x) │
│ dy/dx = ...   │                           │ （非齐次项）     │
└───────────────┘                           └─────────────────┘
        │                                               │
        ▼                                               ▼
┌─────────────────────────────────────┐    ┌─────────────────────────┐
│ 右边是 f(x)·g(y) 的乘积形式？        │    │ y" = f(x) 或 y" = f(x,y')│
│  ✓ 是 → 【可分离变量】               │    │  或 y" = f(y,y')？       │
│  ✗ 否 → 继续看                      │    │  ✓ 是 → 【可降阶】        │
│                                     │    │  ✗ 否 → 看系数           │
│ 右边是 φ(y/x) 的形式？               │    │    常系数 → 【特征方程法】 │
│  ✓ 是 → 【齐次方程】令 u=y/x         │    │    变系数 → 超纲/其他方法  │
│  ✗ 否 → 继续看                      │    └─────────────────────────┘
│                                     │
│ 能写成 y' + P(x)y = Q(x)？           │
│  ✓ 是 → 【一阶线性】套公式           │
│  ✗ 否 → 继续看                      │
│                                     │
│ 能写成 y' + P(x)y = Q(x)y^α？       │
│  ✓ 是 → 【伯努利方程】令 z=y^(1-α)   │
│  ✗ 否 → 继续看                      │
│                                     │
│ Pdx + Qdy = 0，且 ∂P/∂y = ∂Q/∂x？   │
│  ✓ 是 → 【全微分方程】求 u(x,y)=C    │
│  ✗ 否 → 尝试找【积分因子】           │
└─────────────────────────────────────┘
```

## 📋 **公式速查卡**

| 类型 | 识别标志 | 核心公式/操作 |
| :--- | :--- | :--- |
| **可分离变量** | $\frac{dy}{dx}=f(x)\cdot g(y)$ | $\int\frac{dy}{g(y)}=\int f(x)dx+C$ |
| **齐次方程** | $\frac{dy}{dx}=\varphi(\frac{y}{x})$ | 令 $u=\frac{y}{x}$，则 $y=ux$，$\frac{dy}{dx}=u+x\frac{du}{dx}$ |
| **一阶线性** | $y'+P(x)y=Q(x)$ | $\boxed{y=e^{-\int Pdx}\left[\int Qe^{\int Pdx}dx+C\right]}$ |
| **伯努利** | $y'+P(x)y=Q(x)y^\alpha$ | 令 $z=y^{1-\alpha}$，化为一阶线性 |
| **全微分** | $Pdx+Qdy=0$ 且 $\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}$ | 求 $u(x,y)$ 使 $du=Pdx+Qdy$，通解 $u=C$ |
| **缺 $y$ 型** | $y''=f(x,y')$ | 令 $p=y'$，则 $y''=\frac{dp}{dx}$ |
| **缺 $x$ 型** | $y''=f(y,y')$ | 令 $p=y'$，则 $\boxed{y''=p\frac{dp}{dy}}$ |
| **二阶常系数齐次** | $y''+py'+qy=0$ | 特征方程 $r^2+pr+q=0$，按 $\Delta>0/\!=0/<0$ 写通解 |
| **二阶常系数非齐次** | $y''+py'+qy=f(x)$ | 通解 = 齐次通解 $Y$ + 特解 $y^*$（待定系数法） |

## 🎯 二阶常系数非齐次特解怎么设？

| $f(x)$ 的形式 | 特解 $y^*$ 怎么设 |
| :--- | :--- |
| $P_m(x)e^{\lambda x}$ | $x^k \cdot Q_m(x) \cdot e^{\lambda x}$ |
| $e^{\alpha x}[P_l\cos\beta x + P_n\sin\beta x]$ | $x^k \cdot e^{\alpha x}[R_m\cos\beta x + S_m\sin\beta x]$ |

**$k$ 的取值规则：**

- $k=0$：$\lambda$（或 $\alpha+i\beta$）**不是**特征根
- $k=1$：$\lambda$（或 $\alpha+i\beta$）**是单根**
- $k=2$：$\lambda$ 是**二重根**（仅第一种情形）

## 🔑 一句话口诀

> [!TIP]
> **一阶看形式，高阶看系数；齐次看特征，非齐次待定系数**

| 场景 | 口诀 |
| :--- | :--- |
| 一阶方程不会分 | "分离、齐次换元、线性套公式、伯努利换 $z$" |
| 高阶方程第一步 | "缺谁换谁"（缺 $y$ 换 $p=y'$，缺 $x$ 换 $p=y'$ 且 $y''=p\frac{dp}{dy}$） |
| 二阶常系数 | "先写特征方程，再找根，最后待定系数凑特解" |
| 非齐次通解 | "齐次通解 + 非齐次特解 = 全部" |
