# 第1章 极限与连续

> [!IMPORTANT]
> **核心思想**：极限是微积分的基础，连续是极限的应用

## 1.1 函数

### 1.1.1 集合与常用记号

| 记号 | 含义 |
| ------ | ------ |
| $\mathbb{R}$ | 实数集 |
| $\mathbb{Q}$ | 有理数集 |
| $\mathbb{N}$ | 自然数集（非负整数） |
| $[a,b]$ | 闭区间 |
| $(a,b)$ | 开区间 |
| $\mathring{U}(x_0, \delta)$ | **去心邻域**：$0 < \vert x - x_0 \vert < \delta$ |
| $U(x_0, \delta)$ | 邻域：$\vert x - x_0 \vert < \delta$ |

### 1.1.2 函数的基本特性

| 特性 | 定义要点 |
| ------ | --------- |
| **有界性** | $\exists M>0, \forall x\in I, \vert f(x) \vert \leq M$ |
| **奇偶性** | 奇：$f(-x)=-f(x)$（关于原点对称）；偶：$f(-x)=f(x)$（关于y轴对称） |
| **单调性** | 递增/递减/不增/不减 |
| **周期性** | $f(x+T)=f(x)$，最小正周期 $T_0$ |

> [!TIP]
> 🔴 **奇偶函数运算**：奇+奇=奇，偶+偶=偶，奇×偶=奇，偶×偶=偶，奇×奇=偶

### 1.1.3 **反函数**

- $y=f(x)$ 的反函数记为 $y=f^{-1}(x)$
- **关键**：$y=f(x)$ 与 $x=f^{-1}(y)$ 是**同一个图像**；$y=f(x)$ 与 $y=f^{-1}(x)$ **关于 $y=x$ 对称**
- 单调函数必有反函数，反函数与原函数单调性相同

### 1.1.4 初等函数

**基本初等函数**（5类）：

1. 幂函数：$y=x^\alpha$
2. 指数函数：$y=a^x$（$a>0, a\neq 1$），特别 $y=e^x$
3. 对数函数：$y=\log_a x$，特别 $y=\ln x$
4. 三角函数：$\sin x, \cos x, \tan x, \cot x$
5. 反三角函数：$\arcsin x, \arccos x, \arctan x$

**双曲函数**（🔴 你标记的重点）：

- $y=\text{sh }x = \frac{e^x-e^{-x}}{2}$（双曲正弦）
- $y=\text{ch }x = \frac{e^x+e^{-x}}{2}$（双曲余弦）
- $y=\text{th }x = \frac{\text{sh }x}{\text{ch }x}$（双曲正切）
- 反双曲函数：$\text{arsh }x, \text{arch }x, \text{arth }x$

> **初等函数**：由基本初等函数经有限次四则运算和复合运算得到的函数

### 1.5 **万能公式**

$$
t = \tan\left(\frac{x}{2}\right)
$$

$$
\sin x = \frac{2t}{1 + t^2}, \qquad
\cos x = \frac{1 - t^2}{1 + t^2}, \qquad
\tan x = \frac{2t}{1 - t^2}
$$

$$
\mathrm{d}x = \frac{2}{1 + t^2}\,\mathrm{d}t
$$

## 1.2 数列的极限

### 1.2.1 数列极限的定义（ε-N语言）

> [!NOTE]
> 🔴 **定义**：设 $\{x_n\}$ 为数列，$a$ 为常数。若 $\forall \varepsilon>0, \exists N\in\mathbb{N}^+$，当 $n>N$ 时，有 $|x_n-a|<\varepsilon$，则称 $\{x_n\}$ **收敛于 $a$**(或称 $a$ 为 $\{x_n\}$ 边界)，记作
> $$\lim_{n\to\infty} x_n = a$$

- 若数列不收敛，则称其**发散**。

### 1.2.2 收敛数列的性质

| 性质 | 内容 |
| ------ | ------ |
| **唯一性** | 收敛数列的极限唯一 |
| **有界性** | 收敛数列必有界 |
| **保号性** | 若 $\lim x_n = a > 0$，则 $\exists N$，当 $n>N$ 时 $x_n > 0$ |
| **保序性** | 若 $x_n \leq y_n$ 且都收敛，则 $\lim x_n \leq \lim y_n$ |
| **夹逼定理** | 若 $x_n \leq z_n \leq y_n$ 且 $\lim x_n = \lim y_n = a$，则 $\lim z_n = a$ |
| **子列收敛性** | 若数列 $\{x_n\}$ 收敛于 $a$，则其任意子列 $\{x_{n_k}\}$ 均收敛于 $a$。 |
| ==**判定发散**== | 若数列存在两个子列收敛于不同的极限，或存在一个发散的子列，则原数列必发散 |

> 子列就是从原数列中按顺序挑出部分项组成的新数列

## 1.3 函数的极限

### 1.3.1 $x \to x_0$ 时的极限（ε-δ语言）

> [!NOTE]
> 🔴 **定义**：设 $f(x)$ 在 $x_0$ 的某去心邻域有定义，$A$ 为常数。若 $\forall \varepsilon>0, \exists \delta>0$，当 $0<|x-x_0|<\delta$ 时，有 $|f(x)-A|<\varepsilon$，则
> $$\lim_{x\to x_0} f(x) = A$$

### 1.3.2 单侧极限

| 类型 | 记号 | 含义 |
| ------ | ------ | ------ |
| **左极限** | $f(x_0^-)$ 或 $\lim_{x\to x_0^-}f(x)$ | $x$ 从左侧趋近 $x_0$ |
| **右极限** | $f(x_0^+)$ 或 $\lim_{x\to x_0^+}f(x)$ | $x$ 从右侧趋近 $x_0$ |

**极限存在的充要条件**：$\lim_{x\to x_0}f(x)=A \iff f(x_0^-)=f(x_0^+)=A$

### 1.3.3 $x \to \infty$ 时的极限

若 $\forall \varepsilon>0, \exists X>0$，当 $|x|>X$ 时 $|f(x)-A|<\varepsilon$，则 $\lim_{x\to\infty}f(x)=A$

- 类似可定义 $x\to+\infty$ 和 $x\to-\infty$

### 1.3.4 函数极限的性质

与数列极限类似：**唯一性、局部有界性、局部保号性、夹逼定理**

## 1.4 极限的运算法则

### 1.4.1 四则运算

若 $\lim f(x)=A, \lim g(x)=B$ 都存在，则：

| 运算 | 结果 |
| ------ | ------ |
| 和差 | $\lim[f(x)\pm g(x)] = A \pm B$ |
| 乘积 | $\lim[f(x)\cdot g(x)] = A \cdot B$ |
| 商 | $\lim\frac{f(x)}{g(x)} = \frac{A}{B}$（要求 $B\neq 0$） |

### 1.4.2 复合函数极限

> [!NOTE]
> 若 $\lim_{x\to x_0}g(x)=u_0$，$\lim_{u\to u_0}f(u)=A$，且 $g(x)\neq u_0$ 在 $x_0$ 去心邻域内，则
> $$\lim_{x\to x_0}f(g(x)) = A$$

### 1.4.3 **分式函数极限**（看最高次）

> [!NOTE]
> 🔴 设 $P(x)=a_0x^m+\cdots$, $Q(x)=b_0x^n+\cdots$，则
> $$\lim_{x\to\infty}\frac{P(x)}{Q(x)} = \begin{cases} \frac{a_0}{b_0}, & m=n \\ 0, & m<n \\ \infty, & m>n \end{cases}$$

## 1.5 **单调有界原理和两个重要极限**

### 1.5.1 **单调有界原理**

> [!NOTE]
> 🔴 **定理**：单调有界数列必有极限
>
> - 单调递增 + 有上界 $\Rightarrow$ 收敛
> - 单调递减 + 有下界 $\Rightarrow$ 收敛

### 1.5.2 **两个重要极限**

> [!NOTE]
> 🔴 ==**重要极限1**==：$$\lim_{x\to 0}\frac{\sin x}{x} = 1$$
>
> - 推导依据：$\sin x < x < \tan x$（$0<x<\frac{\pi}{2}$）
> - 推广：$\lim_{x\to 0}\frac{\tan x}{x}=1$, $\lim_{x\to 0}\frac{\arcsin x}{x}=1$, $\lim_{x\to 0}\frac{\arctan x}{x}=1$

> [!NOTE]
> 🔴 ==**重要极限2**==：$$\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x = e \quad\text{或}\quad \lim_{x\to 0}(1+x)^{\frac{1}{x}} = e$$
> $e \approx 2.71828\cdots$（无理数）

> [!NOTE]
> 🔴 ==**幂指函数极限**==：
> 若 $\lim u(x)=A>0$, $\lim v(x)=B$，则
> **法1**：$$\lim u(x)^{v(x)} = A^B$$
> **法2**：$\lim u^v = \lim e^{v\ln u} = e^{\lim v(u-1)}$（当 $u\to 1$ 时，$\ln u \sim u-1$）

### 1.5.3 **极限计算技巧**

> [!TIP]
> 🔴 **拆极限的原则**：
>
> 1. 若拆开两项极限都**不存在**，则**不能拆**
> 2. 若拆开两项极限都**存在**，则**可以拆**
> 3. 只要极限有一项存在，拆开后的极限存在，则**可以拆**

> [!TIP]
> 🔴 **提前求极限的条件**：
>
> 1. 是整个函数的**乘除因子**
> 2. 极限**非0**
> 例：$\lim_{x\to 0}\frac{x\cos x}{\sin x} = \lim_{x\to 0}\frac{x}{\sin x} \cdot 1 = 1$（$\cos x$ 是非0因子）

## 1.6 无穷小与无穷大

### 1.6.1 无穷小

> [!NOTE]
> **定义**：极限为 0 的变量称为无穷小
>
> - 即 $\lim_{x\to x_0}f(x)=0$，则 $f(x)$ 是 $x\to x_0$ 时的无穷小

> [!NOTE]
> 🔴 **无穷小与极限的关系**：$\lim f(x)=A \iff f(x)=A+\alpha$，其中 $\alpha$ 是无穷小

### 1.6.2 无穷大

- 若 $|f(x)|$ 无限增大，则称 $f(x)$ 为无穷大
- **关系**：在同一过程中，若 $f(x)$ 为无穷大，则 $\frac{1}{f(x)}$ 为无穷小；反之亦然

### 1.6.3 **无穷小的运算**

| 定理 | 内容 |
| ------ | ------ |
| 有限个无穷小的和 | 仍为无穷小 |
| 有界函数 × 无穷小 | 仍为无穷小 |
| 有限个无穷小的积 | 仍为无穷小 |

### 1.6.4 **无穷小的比较**

设 $\lim\alpha=0, \lim\beta=0$：

| 关系 | 定义 | 记号 |
| ------ | ------ | ------ |
| 高阶无穷小 | $\lim\frac{\beta}{\alpha}=0$ | $\beta=o(\alpha)$ |
| 同阶无穷小 | $\lim\frac{\beta}{\alpha}=c\neq 0$ | $\beta=O(\alpha)$ |
| **等价无穷小** | $\lim\frac{\beta}{\alpha}=1$ | $\beta\sim\alpha$ |
| k阶无穷小 | $\lim\frac{\beta}{\alpha^k}=c\neq 0$ | $\beta$ 是 $\alpha$ 的k阶无穷小 |

> [!TIP]
> 🔴 **等价无穷小替换定理**：若 $\alpha\sim\alpha'$, $\beta\sim\beta'$，则 $\lim\frac{\beta}{\alpha}=\lim\frac{\beta'}{\alpha'}$
>
> - **注意**：只能对**因子**进行替换，**不能**对和差中的项替换！

### 1.6.5 **常用等价无穷小**（x→0时）

$$\sin x \sim x \sim \tan x \sim \arcsin x \sim \arctan x$$
$$1-\cos x \sim \frac{1}{2}x^2$$
$$\ln(1+x) \sim x, \quad \log_a(1+x) \sim \frac{x}{\ln a}$$
$$e^x-1 \sim x, \quad a^x-1 \sim x\ln a$$
$$(1+x)^\alpha-1 \sim \alpha x, \quad \sqrt[n]{1+x}-1 \sim \frac{x}{n}$$
$$x-\sin x \sim \frac{1}{6}x^3$$
$$x-\arcsin x \sim -\frac{1}{6}x^3$$
$$x-\tan x \sim -\frac{1}{3}x^3$$
$$x-\arctan x \sim \frac{1}{3}x^3$$
$$x-\ln(1+x) \sim \frac{1}{2}x^2$$
**诱导公式**：$\sin(A+n\pi)=(-1)^n\sin A$

## 1.7 函数的连续性

### 1.7.1 连续的定义

> [!NOTE]
> 🔴 **定义**：$f(x)$ 在 $x_0$ 处连续 $\iff \lim_{x\to x_0}f(x)=f(x_0)$

**三要素**：

1. $f(x)$ 在 $x_0$ 处有定义
2. $\lim_{x\to x_0}f(x)$ 存在（即左右极限存在且相等）
3. 极限值 = 函数值

**增量形式**：$\lim_{\Delta x\to 0}\Delta y = 0$，其中 $\Delta y = f(x_0+\Delta x)-f(x_0)$

**左/右连续**：

- 左连续：$\lim_{x\to x_0^-}f(x)=f(x_0)$
- 右连续：$\lim_{x\to x_0^+}f(x)=f(x_0)$
- **连续 $\iff$ 左连续且右连续**

### 1.7.2 连续函数的运算性质

| 定理 | 内容 |
| ------ | ------ |
| 四则运算 | 连续函数的和、差、积、商（分母非0）仍连续 |
| 反函数 | 单调连续函数的反函数也单调连续 |
| 复合函数 | 连续函数的复合函数仍连续 |

**结论**：基本初等函数在其定义域内连续；初等函数在其**定义区间**内连续

> 🔴 **极限符号与函数符号可交换**：若 $f$ 连续，$\lim g(x)=x_0$，则
> $$\lim f(g(x)) = f(\lim g(x))$$

### 1.7.3 **函数的间断点**

**定义**：$f(x)$ 在 $x_0$ 处不连续，则 $x_0$ 为间断点

**间断点分类**（🔴 重点）：

| 类型 | 条件 | 子类 |
| ------ | ------ | ------ |
| **第一类间断点** | 左右极限**都存在** | **可去间断点**：左右极限相等但不等于函数值（或函数无定义） |
| | | **跳跃间断点**：左右极限存在但不相等 |
| **第二类间断点** | 左右极限**至少一个不存在** | 无穷间断点：极限为 $\infty$ |
| | | 振荡间断点：极限振荡不存在（如 $\sin\frac{1}{x}$ 在 $x=0$） |

> [!TIP]
> 🔴 **判断步骤**：
>
> 1. 找无定义点或分段点
> 2. 求左右极限
> 3. 根据极限情况分类

## 1.8 **闭区间上连续函数的性质**

### 1.8.1 有界性定理

> [!NOTE]
> 🔴 **定理**：若 $f(x)$ 在 $[a,b]$ 上连续，则 $f(x)$ 在 $[a,b]$ 上有界
>
> - 即 $\exists M>0, \forall x\in[a,b], |f(x)|\leq M$

### 1.8.2 最值定理

> [!NOTE]
> 🔴 **定理**：若 $f(x)$ 在 $[a,b]$ 上连续，则 $f(x)$ 在 $[a,b]$ 上必取得最大值和最小值
>
> - $\exists x_1,x_2\in[a,b]$，使 $f(x_1)=\max f(x)$, $f(x_2)=\min f(x)$

### 1.8.3 **零点定理**

> [!NOTE]
> 🔴 **定理**：若 $f(x)$ 在 $[a,b]$ 上连续，且 $f(a)\cdot f(b)<0$，则 $\exists \xi\in(a,b)$，使 $f(\xi)=0$
>
> - **用途**：**证明方程根的存在性**

### 1.8.4 介值定理

> [!NOTE]
> 🔴 **定理**：若 $f(x)$ 在 $[a,b]$ 上连续，$f(a)\neq f(b)$，$c$ 为介于 $f(a)$ 与 $f(b)$ 之间的任意值，则 $\exists \xi\in(a,b)$，使 $f(\xi)=c$
>
> - **推论**：连续函数必取得最大值与最小值之间的一切值

> [!WARNING]
> 🔴 **注意**：以上定理的条件"闭区间"和"连续"缺一不可！

## 本章核心公式速查

### 两个重要极限

$$\lim_{x\to 0}\frac{\sin x}{x}=1, \quad \lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x=e$$

### 等价无穷小（x→0）

$$\sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim x \sim \ln(1+x) \sim e^x-1$$
$$1-\cos x \sim \frac{x^2}{2}, \quad (1+x)^\alpha-1 \sim \alpha x, \quad a^x-1 \sim x\ln a$$

### 连续性

$$\text{连续} \iff \lim_{x\to x_0}f(x)=f(x_0) \iff f(x_0^-)=f(x_0^+)=f(x_0)$$
