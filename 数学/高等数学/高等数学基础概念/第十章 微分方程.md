## 10.1 常微分方程模型与基本概念

### 10.1.1 常微分方程的基本概念

#### 1. **核心定义**

| 概念 | 定义 |
| :--- | :--- |
| **微分方程的阶** | 方程中出现的未知函数的**最高阶导数的阶数** |
| **线性微分方程** | 未知函数 $y$ 及其各阶导数都是**一次的**（幂指数为1），系数只是 $x$ 的函数 |
| **齐次** | $f(x) \equiv 0$ |
| **非齐次** | $f(x) \neq 0$ |

**n阶线性微分方程标准形式：**
$$y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_{n-1}(x)y' + a_n(x)y = f(x)$$

#### 2. 解的概念

- **通解**：含有与方程阶数**相同个数**的**独立任意常数**的解
- **特解**：不含任意常数的解（由初值条件确定常数后得到）
- **初值条件**：用于确定通解中任意常数的条件，n阶方程需要n个初值条件

> ⚠️ **注意**：通解未必是全部解！

---

### 10.1.2 **线性微分方程解的性质**

#### 1. 定理10.1（叠加原理）

若 $y_1, y_2$ 是**齐次方程**的解，则 $y = C_1y_1 + C_2y_2$ 也是齐次方程的解

#### 2. 定理10.2（通解结构）

若 $y_1, y_2, \ldots, y_n$ 是n阶齐次方程的 $n$ 个**线性无关**的解，则通解为：
$$\boxed{y = C_1y_1 + C_2y_2 + \cdots + C_ny_n}$$

**线性无关的判定：**

- 函数组 $y_1, y_2, \ldots, y_n$ 线性无关 ⟺ 不存在不全为零的常数 $k_1, k_2, \ldots, k_n$，使得 $k_1y_1 + k_2y_2 + \cdots + k_ny_n \equiv 0$
- **两个函数**：$y_1, y_2$ 线性无关 ⟺ **$y_1/y_2 \neq$ 常数**（比值不恒等于常数）

#### 3. 定理10.3（**非齐次通解结构**）

若 $y^*$ 是非齐次方程的特解，$Y$ 是对应齐次方程的通解，则：
$$\boxed{y = Y + y^*}$$
> **齐次通解 + 非齐次特解 = 非齐次通解** —— 这是贯穿整章的**核心思想**！

#### 4. 定理10.4

若 $y_1^*$ 和 $y_2^*$ 分别是非齐次方程对应 $f_1(x)$ 和 $f_2(x)$ 的特解，则 $y_1^* + y_2^*$ 是方程对应 $f_1(x)+f_2(x)$ 的特解。

#### 5. 定理10.5

若 $y_1, y_2$ 是非齐次方程的两个解，则 $y_1 - y_2$ 是对应**齐次方程**的解

## 10.2 **可分离变量的微分方程**

### 10.2.1 **可分离变量**

**标准型：**
$$\frac{dy}{dx} = f(x) \cdot \varphi(y)$$

**解法步骤：**

1. 分离变量：$\frac{dy}{\varphi(y)} = f(x)dx$（假设 $\varphi(y) \neq 0$）
2. 两边积分：$\int \frac{dy}{\varphi(y)} = \int f(x)dx + C$
3. 得到隐式或显式通解

> [!WARNING]
> 分离变量时假设 $\varphi(y) \neq 0$，可能漏掉使 $\varphi(y) = 0$ 的解（如 $y=0$），需单独验证

---

### 10.2.2 **可化为可分离变量型**

#### **1. 齐次方程：** $\frac{dy}{dx} = \varphi\left(\frac{y}{x}\right)$

🔴 **==换元==：令 $u = \frac{y}{x}$，则 $y = ux$，$\frac{dy}{dx} = u + x\frac{du}{dx}$**

代入后化为可分离变量方程

#### **2. 形如** $\frac{dy}{dx} = f(ax+by+c)\ (b \neq 0)$ **的方程**

🔴 **==换元==：设 $u = ax+by+c$，则 $y = \frac{1}{b}(u-ax-c)$，$\frac{dy}{dx} = \frac{1}{b}\left(\frac{du}{dx}-a\right)$**

代入方程，得到可分离变量的方程：

$$\frac{du}{bf(u)+a} = dx$$

#### 3. 形如 $\frac{dy}{dx} = f\left(\frac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}\right)$

- 若 $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} \neq 0$：令 $x = X+h, y = Y+k$ 消去常数项
- 若行列式 $= 0$：令 $u = a_1x+b_1y$ 化为可分离变量

## 10.3 一阶线性微分方程

### 10.3.1 **一阶线性微分方程**

**标准型：**
$$y' + P(x)y = Q(x)$$

- $Q(x) \equiv 0$ → **齐次**
- $Q(x) \neq 0$ → **非齐次**

🔴 ==**通解公式：**==
$$\boxed{y = e^{-\int P(x)dx} \left[ \int Q(x) \cdot e^{\int P(x)dx} dx + C \right]}$$

> [!TIP]
> **记忆口诀**：先积 $P$ 得指数，$Q$ 乘指数再积分，最后乘指数负

**推导思路**：常数变易法

- 先求齐次通解 $y = Ce^{-\int Pdx}$
- 将 $C$ 改为 $C(x)$ 代入原方程求出 $C(x)$

---

### 10.3.2 **伯努利方程**

**标准型：**
$$\frac{dy}{dx} + P(x)y = Q(x) \cdot y^\alpha \quad (\alpha \neq 0, 1)$$

🔴 **解法**：两边除以 $y^\alpha$，令 $\boxed{z = y^{1-\alpha}}$，化为一阶线性方程：
$$\frac{dz}{dx} + (1-\alpha)P(x)z = (1-\alpha)Q(x)$$

> ⚠️ 当 $\alpha > 0$ 时，$y = 0$ 也是原方程的解（可能漏掉）

---

## 10.4 全微分方程与积分因子

### 10.4.1 **全微分方程**

**标准型：**
$$P(x,y)dx + Q(x,y)dy = 0$$

🔴 **判定条件（充要条件）：**
$$\boxed{\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}}$$

满足时称为**全微分方程**（恰当方程），存在 $u(x,y)$ 使得 $du = Pdx + Qdy$

**求 $u(x,y)$ 的三种方法：**

1. **曲线积分法**：$u(x,y) = \int_{(0,0)}^{(x,y)} Pdx + Qdy$（与路径无关）
2. **凑微分法**：将 $Pdx+Qdy$ 凑成某个函数的全微分
3. ==**不定积分法**==：**由 $\frac{\partial u}{\partial x} = P$ 积分得 $u = \int Pdx + \varphi(y)$，再对 $y$ 求导与 $Q$ 比较确定 $\varphi(y)$**

**通解：** $\boxed{u(x,y) = C}$

---

### 10.4.2 **积分因子 🔴**

若 $\frac{\partial P}{\partial y} \neq \frac{\partial Q}{\partial x}$，寻找 $\mu(x,y)$ 使得 $\mu Pdx + \mu Qdy = 0$ 成为全微分方程

==**特殊情形：**==

① 若 $\displaystyle\frac{\frac{\partial P}{\partial y} - \frac{\partial Q}{\partial x}}{Q}$ **只与 $x$ 有关**，则：
$$\mu(x) = e^{\int \frac{P_y - Q_x}{Q} dx}$$

② 若 $\displaystyle\frac{\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}}{P}$ **只与 $y$ 有关**，则：
$$\mu(y) = e^{\int \frac{Q_x - P_y}{P} dy}$$

> [!NOTE]
> 🔴 **积分因子不唯一，通解唯一**

## 10.5 **可降阶的高阶微分方程**

| 类型 | 形式 | 换元 | 降阶后 |
| :--- | :--- | :--- | :--- |
| **类型1** | $y^{(n)} = f(x)$ | 逐次积分 | 积分 $n$ 次得通解 |
| **类型2** | $y'' = f(x, y')$（缺 $y$） | 令 $\boxed{p = y'}$ | $\frac{dp}{dx} = f(x,p)$（一阶方程） |
| **类型3** | $y'' = f(y, y')$（缺 $x$） | 令 $\boxed{p = y'}$，则 $\boxed{y'' = p\frac{dp}{dy}}$ | $p\frac{dp}{dy} = f(y,p)$（一阶方程） |

> [!IMPORTANT]
> ⚠️ **关键区别**：类型2缺 $y$，类型3缺 $x$。**类型3中 $y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p\frac{dp}{dy}$**，这是核心变换！

---

## 10.6 **二阶常系数线性微分方程** ⭐⭐⭐

### 标准型

$$y'' + py' + qy = f(x)$$
其中 $p, q$ 为常数

### 10.6.1 **齐次方程 $y'' + py' + qy = 0$**

🔴 ==**特征方程：**==
$$\boxed{r^2 + pr + q = 0}$$

设特征根为 $r_1, r_2$，通解如下：

| 判别式 $\Delta = p^2 - 4q$ | 特征根 | 两个线性无关解 | 通解 |
| :--- | :--- | :--- | :--- |
| $\Delta > 0$ | $r_1 \neq r_2$（相异实根） | $e^{r_1x}, e^{r_2x}$ | $\boxed{y = C_1e^{r_1x} + C_2e^{r_2x}}$ |
| $\Delta = 0$ | $r_1 = r_2 = r$（重根） | $e^{rx}, xe^{rx}$ | $\boxed{y = (C_1 + C_2x)e^{rx}}$ |
| $\Delta < 0$ | $r = \alpha \pm i\beta$（共轭复根） | $e^{\alpha x}\cos\beta x, e^{\alpha x}\sin\beta x$ | $\boxed{y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)}$ |

> [!NOTE]
> **推广到 $n$ 阶**：
>
> - $k$ 重实根 $r$ → 贡献：$e^{rx}, xe^{rx}, \ldots, x^{k-1}e^{rx}$
> - $k$ 重复根 $\alpha \pm i\beta$ → 贡献：$e^{\alpha x}\cos\beta x, e^{\alpha x}\sin\beta x, \ldots, x^{k-1}e^{\alpha x}\cos\beta x, x^{k-1}e^{\alpha x}\sin\beta x$

---

### 10.6.2 **非齐次方程 — 待定系数法求特解**

**通解 = 齐次通解 $Y$ + 特解 $y^*$**

#### 1. **情形1：$f(x) = P_m(x) \cdot e^{\lambda x}$**（$P_m$ 为 $m$ 次多项式）

设特解形式：
$$\boxed{y^* = x^k \cdot Q_m(x) \cdot e^{\lambda x}}$$

其中 ==**$Q_m(x)$ 是与 $P_m(x)$ 同次的待定多项式**==，$k$ 的取值：

- $k = 0$：$\lambda$ **不是**特征根
- $k = 1$：$\lambda$ 是**单**特征根
- $k = 2$：$\lambda$ 是**二重**特征根

#### 2. **情形2：$f(x) = e^{\alpha x}[P_l(x)\cos\beta x + P_n(x)\sin\beta x]$**

设特解形式：
$$\boxed{y^* = x^k \cdot e^{\alpha x}[R_m(x)\cos\beta x + S_m(x)\sin\beta x]}$$

其中 ==**$m = \max(l, n)$，$R_m, S_m$ 为待定 $m$ 次多项式**==，$k$ 的取值：

- $k = 0$：$\alpha + i\beta$ **不是**特征根
- $k = 1$：$\alpha + i\beta$ **是**特征根

## *10.7 欧拉方程（选学）

**标准型：**
$$x^2y'' + pxy' + qy = f(x)$$

**解法**：令 $\boxed{x = e^t}$（即 $t = \ln x$），化为常系数线性方程：

- $xy' = \frac{dy}{dt}$
- $x^2y'' = \frac{d^2y}{dt^2} - \frac{dy}{dt}$

---

## *10.8 一阶常系数线性微分方程组（选学）

**消元法**：通过求导、加减消去未知函数，化为高阶常系数线性微分方程求解。

## 📋 解题思路总览

| 看到方程形式 | 第一步判断 | 选用方法 |
| :--- | :--- | :--- |
| $\frac{dy}{dx} = f(x)g(y)$ | 可分离变量 | 分离 → 积分 |
| $\frac{dy}{dx} = \varphi(\frac{y}{x})$ | 齐次方程 | 令 $u = \frac{y}{x}$ |
| $y' + P(x)y = Q(x)$ | 一阶线性 | 通解公式 / 常数变易法 |
| $y' + P(x)y = Q(x)y^\alpha$ | 伯努利方程 | 令 $z = y^{1-\alpha}$ |
| $Pdx + Qdy = 0$ 且 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ | 全微分方程 | 求 $u(x,y) = C$ |
| $y^{(n)} = f(x)$ | 直接积分型 | 积分 $n$ 次 |
| $y'' = f(x,y')$（缺 $y$） | 可降阶 | 令 $p = y'$ |
| $y'' = f(y,y')$（缺 $x$） | 可降阶 | 令 $p = y'$，$y'' = p\frac{dp}{dy}$ |
| $y'' + py' + qy = f(x)$ | 二阶常系数 | 特征根 → 齐次通解 + 待定系数求特解 |
