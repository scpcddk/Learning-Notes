# 高等数学 · 阅读页面

**阅读入口：[速查笔记.html](速查笔记.html)**

参照线性代数阅读页的纸面配色、衬线标题、章节卡片与双栏阅读结构制作。页面收录十章笔记、16 篇补充理解、30 道分章自测，以及公式速查。

## 阅读功能

- 首页章节卡片与分组侧边目录。
- 章节的“精要速查 / 完整笔记”切换。
- 专题与自测解析直接在页内阅读，相关 Markdown 链接自动转换为页内跳转。
- 全文搜索，支持 Ctrl K 打开、Esc 关闭。
- 本篇目录与阅读进度，目录跳转时自动展开对应例题。
- 自测题的分章折叠解析，可一次展开或收起全部解析。
- 深色模式、窄屏目录与打印；打印时自动展开解析和例题，结束后恢复。
- 公式使用随页附带的 MathJax SVG 组件，在离线状态下排版。

最近阅读篇目、阅读模式和主题偏好只保存在当前浏览器，不发送到服务器。

## 文件与更新

| 文件 | 用途 |
| --- | --- |
| [速查笔记.html](速查笔记.html) | 可直接打开的生成结果，嵌入全部正文数据 |
| [阅读页模板.html](阅读页模板.html) | 页面布局与样式 |
| [阅读交互.js](阅读交互.js) | 路由、搜索、主题、例题与打印交互 |
| [速查提要.md](速查提要.md) | 十章精要模式的内容 |
| [生成阅读页.py](生成阅读页.py) | 从原始 Markdown 生成正文、路由与页面 |
| [阅读资源说明](阅读资源/README.md) | MathJax、离线图片与插图生成记录 |

在仓库根目录运行：

~~~powershell
python "数学/高等数学/阅读页面/生成阅读页.py"
~~~

生成脚本依赖 markdown-it-py。脚本按所在位置定位笔记，不要求当前工作目录固定；重复运行会更新生成的 HTML，并按内容复制正文插图。

修改原章节、补充专题或自测题后重新运行脚本即可。新增篇目需要同时更新脚本中的篇目列表；新增基础章还需在速查提要中提供同名二级标题。

## 离线使用

直接打开 HTML，无需启动服务器。移动阅读页时，请携带整个“阅读页面”文件夹，保留阅读交互脚本与“阅读资源”；正文已经嵌入，阅读与搜索不依赖源 Markdown。

“查看 Markdown 原笔记”、学习导航、历年题目目录和线性代数阅读页属于仓库内链接；离开原仓库单独复制时，这些外部入口不保证存在。

原始题目与自测 Markdown 统一保留在：[题目目录](../题目/)。
