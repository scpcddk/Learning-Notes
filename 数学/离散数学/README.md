## 本次勘误

Codex 校订个人 Markdown，保留原始课件内容：

- 异或统一为 ⊕；补充偏序极值、函数映射、Dijkstra、平面图等结论的适用条件。
- 区分关系与函数复合的读取方向、正长度可达与自反可达、关键事件与关键活动。
- 修正充分条件符号化、选择题多解、前束范式答案和排课约束。
- 两份试卷中的 `(P→Q)↔R` 主析取范式统一为 `m₁∨m₃∨m₄∨m₇`，主合取范式为 `M₀∧M₂∧M₅∧M₆`；编号按 P、Q、R 的二进制顺序。
- 补全关系平方的遗漏序偶，并用明确构造证明给定度数序列可以连通；统一相关评分说明。
