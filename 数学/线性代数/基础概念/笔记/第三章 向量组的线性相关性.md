# 第三章 向量组的线性相关性

## 第一节 $n$ 维向量及其运算

### 一、向量的定义

**定义 3.1** 由 $n$ 个数 $a_1, a_2, \cdots, a_n$ 组成的有序数组称为 **$n$ 维向量**，记为
$$\boldsymbol{\alpha} = (a_1, a_2, \cdots, a_n) \quad \text{或} \quad \boldsymbol{\alpha} = \begin{pmatrix} a_1 \\ a_2 \\ \vdots \\ a_n \end{pmatrix}$$

- 写成 $(a_1, a_2, \cdots, a_n)$ 的形式，称为**行向量**，可看成是 $1 \times n$ 矩阵
- 写成列的形式，称为**列向量**，可看成是 $n \times 1$ 矩阵，可用转置记为 $\boldsymbol{\alpha} = (a_1, a_2, \cdots, a_n)^\mathrm{T}$
  - 组成向量的数称为向量的**分量**，$a_i$ 称为向量 $\boldsymbol{\alpha}$ 的第 $i$ 个分量。

- 如果向量的所有分量全是 0，称其为**零向量**，记为 $\boldsymbol{0} = (0, 0, \cdots, 0)^\mathrm{T}$

### 二、向量空间

- **$n$ 维向量空间**：$\mathbb{R}^n = \{(x_1, x_2, \cdots, x_n)^\mathrm{T} \mid x_1, x_2, \cdots, x_n \in \mathbb{R}\}$
- **$n-1$ 维超平面**：$\pi = \{(x_1, x_2, \cdots, x_n)^\mathrm{T} \mid a_1x_1 + a_2x_2 + \cdots + a_nx_n = b\}$

### 三、**向量的线性运算**

设 $\boldsymbol{\alpha} = (a_1, a_2, \cdots, a_n)^\mathrm{T}$，$\boldsymbol{\beta} = (b_1, b_2, \cdots, b_n)^\mathrm{T}$，$k$ 是实数：

| 运算 | 定义 |
|------|------|
| 相等 | $\boldsymbol{\alpha} = \boldsymbol{\beta} \iff a_i = b_i$（$i=1,2,\cdots,n$） |
| 加法 | $\boldsymbol{\alpha} + \boldsymbol{\beta} = (a_1+b_1, a_2+b_2, \cdots, a_n+b_n)^\mathrm{T}$ |
| 数乘 | $k\boldsymbol{\alpha} = (ka_1, ka_2, \cdots, ka_n)^\mathrm{T}$ |
| 负向量 | $-\boldsymbol{\alpha} = (-a_1, -a_2, \cdots, -a_n)^\mathrm{T}$ |
| 减法 | $\boldsymbol{\alpha} - \boldsymbol{\beta} = \boldsymbol{\alpha} + (-\boldsymbol{\beta})$ |

**运算规律**（与矩阵相同）：
- (i) $\boldsymbol{\alpha}+\boldsymbol{\beta}=\boldsymbol{\beta}+\boldsymbol{\alpha}$（交换律）
- (ii) $(\boldsymbol{\alpha}+\boldsymbol{\beta})+\boldsymbol{\gamma}=\boldsymbol{\alpha}+(\boldsymbol{\beta}+\boldsymbol{\gamma})$（结合律）
- (iii) $\boldsymbol{\alpha}+\boldsymbol{0}=\boldsymbol{\alpha}$
- (iv) $\boldsymbol{\alpha}+(-\boldsymbol{\alpha})=\boldsymbol{0}$
- (v) $1\boldsymbol{\alpha}=\boldsymbol{\alpha}$
- (vi) $k(l\boldsymbol{\alpha})=(kl)\boldsymbol{\alpha}$
- (vii) $(k+l)\boldsymbol{\alpha}=k\boldsymbol{\alpha}+l\boldsymbol{\alpha}$
- (viii) $k(\boldsymbol{\alpha}+\boldsymbol{\beta})=k\boldsymbol{\alpha}+k\boldsymbol{\beta}$

### 四、**向量的内积**

**定义 3.3** 设有 $n$ 维向量 $\boldsymbol{\alpha}=(a_1,a_2,\cdots,a_n)^\mathrm{T}$，$\boldsymbol{\beta}=(b_1,b_2,\cdots,b_n)^\mathrm{T}$，令
$$[\boldsymbol{\alpha}, \boldsymbol{\beta}] = a_1b_1 + a_2b_2 + \cdots + a_nb_n$$

称 $[\boldsymbol{\alpha}, \boldsymbol{\beta}]$ 为向量 $\boldsymbol{\alpha}$ 与 $\boldsymbol{\beta}$ 的**内积**

> [!TIP]
> **内积**是两个向量之间的一种运算，其结果是一个**实数**
> **矩阵表示**：$[\boldsymbol{\alpha}, \boldsymbol{\beta}] = \boldsymbol{\alpha}^\mathrm{T}\boldsymbol{\beta} = \boldsymbol{\beta}^\mathrm{T}\boldsymbol{\alpha}$

**内积性质**($\boldsymbol{\alpha}, \boldsymbol{\beta}$为列向量)：
- (i) $[\boldsymbol{\alpha}, \boldsymbol{\beta}] = [\boldsymbol{\beta}, \boldsymbol{\alpha}]$
- (ii) $[\boldsymbol{\alpha}+\boldsymbol{\beta}, \boldsymbol{\gamma}] = [\boldsymbol{\alpha}, \boldsymbol{\gamma}] + [\boldsymbol{\beta}, \boldsymbol{\gamma}]$
- (iii) $[k\boldsymbol{\alpha}, \boldsymbol{\beta}] = k[\boldsymbol{\alpha}, \boldsymbol{\beta}]$
- (iv) $[\boldsymbol{\alpha}, \boldsymbol{\alpha}] \ge 0$，且仅当 $\boldsymbol{\alpha}=\boldsymbol{0}$ 时 $[\boldsymbol{\alpha}, \boldsymbol{\alpha}]=0$

==**Schwarz（施瓦茨）不等式**==：
$$[\boldsymbol{\alpha}, \boldsymbol{\beta}]^2 \le [\boldsymbol{\alpha}, \boldsymbol{\alpha}][\boldsymbol{\beta}, \boldsymbol{\beta}]$$

### 五、**向量的长度与夹角**

**定义 3.4** 给定 $n$ 维向量 $\boldsymbol{\alpha}=(a_1,a_2,\cdots,a_n)^\mathrm{T}$，称非负实数
$$|\boldsymbol{\alpha}| = \sqrt{[\boldsymbol{\alpha}, \boldsymbol{\alpha}]} = \sqrt{a_1^2 + a_2^2 + \cdots + a_n^2}$$

为向量 $\boldsymbol{\alpha}$ 的**长度**（或范数），记为 $|\boldsymbol{\alpha}|$（或 $\|\boldsymbol{\alpha}\|$）

- 当 $|\boldsymbol{\alpha}|=1$ 时，称 $\boldsymbol{\alpha}$ 为**单位向量**
- 若 $\boldsymbol{\alpha} \neq \boldsymbol{0}$，则 $\frac{1}{|\boldsymbol{\alpha}|}\boldsymbol{\alpha}$ 是与 $\boldsymbol{\alpha}$ 同方向的单位向量

**Schwarz 不等式：**
$|[\boldsymbol{\alpha}, \boldsymbol{\beta}]| \le |\boldsymbol{\alpha}||\boldsymbol{\beta}|$，即 $\left|\frac{[\boldsymbol{\alpha}, \boldsymbol{\beta}]}{|\boldsymbol{\alpha}||\boldsymbol{\beta}|}\right| \le 1$

**定义 3.5** 对任意非零向量 $\boldsymbol{\alpha}$ 和 $\boldsymbol{\beta}$，称
$$\langle \boldsymbol{\alpha}, \boldsymbol{\beta} \rangle = \arccos\frac{[\boldsymbol{\alpha}, \boldsymbol{\beta}]}{|\boldsymbol{\alpha}||\boldsymbol{\beta}|} \quad (0 \le \langle \boldsymbol{\alpha}, \boldsymbol{\beta} \rangle \le \pi)$$

为向量 $\boldsymbol{\alpha}$ 和 $\boldsymbol{\beta}$ 的 ==**夹角**==

==**定义 3.6** 如果 $[\boldsymbol{\alpha}, \boldsymbol{\beta}] = 0$，则称 $\boldsymbol{\alpha}$ 与 $\boldsymbol{\beta}$ **正交**==

> [!NOTE]
> 🔴 **零向量与任何向量都正交**
> 🔴 **正交向量组不含零向量**

## 第二节 向量组的线性相关性

### 一、向量组与线性表示

**定义**（向量组）：若干个同维数的列向量（或同维数的行向量）所组成的集合叫做**向量组**

一个 $m \times n$ 矩阵可以写成：
$$\boldsymbol{A} = \begin{pmatrix} \boldsymbol{\alpha}_1^\mathrm{T} \\ \boldsymbol{\alpha}_2^\mathrm{T} \\ \vdots \\ \boldsymbol{\alpha}_m^\mathrm{T} \end{pmatrix} = (\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_n)$$

- $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_m$ 是 $\boldsymbol{A}$ 的 $m$ 个行，叫做 $\boldsymbol{A}$ 的**行向量组**
- $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_n$ 是 $\boldsymbol{A}$ 的 $n$ 个列，叫做 $\boldsymbol{A}$ 的**列向量组**

> 反之，由有限个向量所组成的向量组可以构成一个矩阵

**定义 3.7** 对向量 $\boldsymbol{\beta}$ 和向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$，如果存在一组数 $k_1, k_2, \cdots, k_s$，使
$$\boldsymbol{\beta} = k_1\boldsymbol{\alpha}_1 + k_2\boldsymbol{\alpha}_2 + \cdots + k_s\boldsymbol{\alpha}_s$$

则称向量 $\boldsymbol{\beta}$ **可由向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$  ==线性表示==** ，也称向量 $\boldsymbol{\beta}$ 是向量组的一个**线性组合**

> [!NOTE]
> 🔴 矩阵形式：$\boldsymbol{\beta} = (\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s)\begin{pmatrix} k_1 \\ k_2 \\ \vdots \\ k_s \end{pmatrix}$

> [!TIP]
> 🔴 线性方程组 $\boldsymbol{A}\boldsymbol{x}=\boldsymbol{\beta}$ 有解 $\iff$ 常向量 $\boldsymbol{\beta}$ 可由系数矩阵 $\boldsymbol{A}$ 的列向量组线性表示

> [!NOTE]
> 1. 零向量可由任意向量组表示
> 2. 向量组中任一向量可由向量组自身表示
> 3. 任意向量都可用 $n$ 维标准单位向量组表示

#### 系数矩阵与增广矩阵

对于线性方程组 $\boldsymbol{A}\boldsymbol{x} = \boldsymbol{\beta}$：

| 名称 | 定义 |
|------|------|
| **系数矩阵** | $\boldsymbol{A}$（由方程组未知量的系数构成的矩阵） |
| **常数项向量** | $\boldsymbol{\beta}$ |
| **增广矩阵** | $\boldsymbol{B} = (\boldsymbol{A} \mid \boldsymbol{\beta})$（在系数矩阵右侧添加常数项列构成的矩阵） |

**矩阵形式**：
$$\boldsymbol{A}\boldsymbol{x} = \boldsymbol{\beta}$$

其中 $\boldsymbol{A} = (\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_n)$，$\boldsymbol{x} = (x_1, x_2, \cdots, x_n)^\mathrm{T}$，可写成：
$$(\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_n)\begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{pmatrix} = \boldsymbol{\beta}$$

即：
$$x_1\boldsymbol{\alpha}_1 + x_2\boldsymbol{\alpha}_2 + \cdots + x_n\boldsymbol{\alpha}_n = \boldsymbol{\beta}$$

**重要结论**：
- 线性方程组 $\boldsymbol{A}\boldsymbol{x} = \boldsymbol{\beta}$ **有解** $\iff$ 向量 $\boldsymbol{\beta}$ 可由 $\boldsymbol{A}$ 的列向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_n$ **线性表示**
- 线性方程组 $\boldsymbol{A}\boldsymbol{x} = \boldsymbol{\beta}$ **无解** $\iff$ 向量 $\boldsymbol{\beta}$ **不能**由 $\boldsymbol{A}$ 的列向量组线性表示







### 二、**线性相关与线性无关**

**定义 3.8** 对向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$，如果存在一组**不全为零**的数 $k_1, k_2, \cdots, k_s$，使
$$k_1\boldsymbol{\alpha}_1 + k_2\boldsymbol{\alpha}_2 + \cdots + k_s\boldsymbol{\alpha}_s = \boldsymbol{0}$$

则称向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$ **线性相关**；否则，称向量组 **线性无关**

> [!TIP]
> 🔴 **换句话说**：向量组线性无关的充要条件是：只要 $k_1\boldsymbol{\alpha}_1 + k_2\boldsymbol{\alpha}_2 + \cdots + k_s\boldsymbol{\alpha}_s = \boldsymbol{0}$，则必有 $k_1=k_2=\cdots=k_s=0$

> [!NOTE]
> 🔴 **等价表述**：
> - 向量组线性相关 $\iff$ 齐次线性方程组 $x_1\boldsymbol{\alpha}_1 + x_2\boldsymbol{\alpha}_2 + \cdots + x_s\boldsymbol{\alpha}_s = \boldsymbol{0}$ **有非零解**
> - 向量组线性无关 $\iff$ 上述齐次线性方程组**只有零解**

> [!IMPORTANT]
> 1. 向量组中**两向量成比例**，则相关
> 2. **含零向量**的向量组必线性相关
> 3. 一个非零向量必线性无关

### 三、标准单位向量组

**定义** $n$ 维标准单位向量组：
$$\boldsymbol{e}_1 = (1,0,\cdots,0)^\mathrm{T}, \boldsymbol{e}_2 = (0,1,\cdots,0)^\mathrm{T}, \cdots, \boldsymbol{e}_n = (0,0,\cdots,1)^\mathrm{T}$$

**性质**：
- $\boldsymbol{e}_1, \boldsymbol{e}_2, \cdots, \boldsymbol{e}_n$ **线性无关**
- 任意 $n$ 维向量 $\boldsymbol{\alpha}=(a_1,a_2,\cdots,a_n)^\mathrm{T}$ 都可由它们线性表示：$\boldsymbol{\alpha} = a_1\boldsymbol{e}_1 + a_2\boldsymbol{e}_2 + \cdots + a_n\boldsymbol{e}_n$

### 四、**正交向量组**

**定义 3.9**：

一组两两正交的非零向量称为**正交向量组**。由单位向量构成的正交向量组称为**规范正交向量组**

$n$ 维标准单位向量组 $\boldsymbol{e}_1, \boldsymbol{e}_2, \cdots, \boldsymbol{e}_n$ 就是一个规范正交向量组

**定理 3.1**：

**正交向量组必线性无关**

> [!WARNING]
> 线性无关组未必正交

### 五、==**线性相关性的重要定理**==

**定理 3.2**：
若向量组有一个**部分组线性相关**，则该**向量组线性相关**

> [!IMPORTANT]
> 等价说法：线性无关向量组的任一部分组也线性无关

> [!NOTE]
**推论 1** 含有零向量的向量组必线性相关
**推论 2** 线性无关向量组的任一部分组也线性无关

**定理 3.3**:

向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$（$s \ge 2$）**线性相关的充要条件**是其中**至少有一个向量可由其余向量线性表示**

**定理 3.4**:

设向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r$ 线性无关，$\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r, \boldsymbol{\beta}$ 线性相关，则 $\boldsymbol{\beta}$ 可由 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r$ 线性表示，且**表示式系数唯一**

**定理 3.5**:

**线性无关向量组的加长向量组也线性无关**

> 即：若 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$ 线性无关，在每个向量后面添加分量得到 $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_s$，则 $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_s$ 也线性无关

> [!NOTE]
> 相关向量组缩短向量也相关

> [!IMPORTANT]
> $m > n$ 时，$m$ 个 $n$ 维向量一定线性相关（**向量个数 > 向量维数**）

### 六、向量组的等价

**定义 3.10**：

若向量组（I）中的每个向量都可以由向量组（II）线性表示，则称向量组（I）**可由向量组（II）线性表示**；若向量组（I）与向量组（II）可以互相线性表示，则称向量组（I）与向量组（II）**等价**

**等价关系的性质**：
- (i) **反身性**：任一向量组都与自身等价
- (ii) **对称性**：若（I）与（II）等价，则（II）与（I）等价
- (iii) **传递性**：若（I）与（II）等价，（II）与（III）等价，则（I）与（III）等价

**定理 3.6**：

如果向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_m$ 线性无关，则有规范正交向量组 $\boldsymbol{\varepsilon}_1, \boldsymbol{\varepsilon}_2, \cdots, \boldsymbol{\varepsilon}_m$ 与之等价

> [!TIP]
> 即：**线性无关向量组可以通过 Schmidt 正交化得到等价的规范正交向量组**

### 七、==**Schmidt 正交化过程**==

将线性无关向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_m$ 正交化：

**第一步：正交化**
$$\boldsymbol{\beta}_1 = \boldsymbol{\alpha}_1$$
$$\boldsymbol{\beta}_2 = \boldsymbol{\alpha}_2 - \frac{[\boldsymbol{\beta}_1, \boldsymbol{\alpha}_2]}{[\boldsymbol{\beta}_1, \boldsymbol{\beta}_1]}\boldsymbol{\beta}_1$$
$$\boldsymbol{\beta}_3 = \boldsymbol{\alpha}_3 - \frac{[\boldsymbol{\beta}_1, \boldsymbol{\alpha}_3]}{[\boldsymbol{\beta}_1, \boldsymbol{\beta}_1]}\boldsymbol{\beta}_1 - \frac{[\boldsymbol{\beta}_2, \boldsymbol{\alpha}_3]}{[\boldsymbol{\beta}_2, \boldsymbol{\beta}_2]}\boldsymbol{\beta}_2$$
$$\vdots$$
$$\boldsymbol{\beta}_m = \boldsymbol{\alpha}_m - \sum_{i=1}^{m-1}\frac{[\boldsymbol{\beta}_i, \boldsymbol{\alpha}_m]}{[\boldsymbol{\beta}_i, \boldsymbol{\beta}_i]}\boldsymbol{\beta}_i$$

**第二步：单位化**
$$\boldsymbol{\varepsilon}_i = \frac{1}{|\boldsymbol{\beta}_i|}\boldsymbol{\beta}_i \quad (i=1,2,\cdots,m)$$

则 $\boldsymbol{\varepsilon}_1, \boldsymbol{\varepsilon}_2, \cdots, \boldsymbol{\varepsilon}_m$ 就是与 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_m$ 等价的**规范正交向量组**

### 八、正交矩阵

**定义 3.11**:

如果实方阵 $\boldsymbol{A}$ 满足 $\boldsymbol{AA}^\mathrm{T} = \boldsymbol{E}$（即 $\boldsymbol{A}^{-1} = \boldsymbol{A}^\mathrm{T}$），那么称 $\boldsymbol{A}$ 为**正交矩阵**

> [!IMPORTANT]
> n阶实矩阵A为**正交矩阵**的充**分必要条件**是A的行(列)向量组是一组**规范正交向量组**

> [!NOTE]
> 🔴 **正交矩阵的性质**：
> 1. $\boldsymbol{A}$ 正交 $\Rightarrow |\boldsymbol{A}| = 1$ 或 $-1$（由 $|\boldsymbol{A}||\boldsymbol{A}^\mathrm{T}| = |\boldsymbol{E}| = 1$ 得 $|\boldsymbol{A}|^2 = 1$）
> 2. $\boldsymbol{A}$ 正交 $\Rightarrow \boldsymbol{A}^{-1} = \boldsymbol{A}^\mathrm{T}$，且 $\boldsymbol{A}^{-1}$ 和 $\boldsymbol{A}^\mathrm{T}$ 均为正交矩阵
> 3. 若 $\boldsymbol{A},\boldsymbol{B}$ 正交，则 $\boldsymbol{AB}$ 也正交
> 4. 若 $\boldsymbol{A}$ 正交，$\boldsymbol{\alpha},\boldsymbol{\beta}$ 为列向量，则 $[\boldsymbol{A}\boldsymbol{\alpha}, \boldsymbol{A}\boldsymbol{\beta}] = [\boldsymbol{\alpha}, \boldsymbol{\beta}]$（保持内积不变）

## 第三节 **向量组的秩**

### 一、**极大线性无关组**

**定义 3.12** 向量组 $T$ 中如果有一部分组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r$ 满足：
1. $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r$ **线性无关**
2. 任取向量组 $T$ 中向量 $\boldsymbol{\beta}$，有 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r, \boldsymbol{\beta}$ **线性相关**

则称 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r$ 为向量组 $T$ 的一个**极大线性无关向量组**，简称为**极大无关组**

> [!TIP]
> **极大无关组**：向量组中所有独立的向量构成的子向量组

> 一般地，向量组的极大无关组是**不唯一的**

**定理 3.7**:

向量组与它的任一极大无关组等价

**推论**： 向量组中任意两个极大无关组是等价的

**定理 3.8**:

若列向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r$ 线性无关，则当 $(\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_r)\boldsymbol{A} = \boldsymbol{O}$ 时（其中 $\boldsymbol{A}$ 为矩阵），有 $\boldsymbol{A} = \boldsymbol{O}$

**定理 3.9**:

**等价的线性无关向量组含有相同个数的向量**

> [!NOTE]
> 若（I）可由（II）表示，且（II）也可由（I）表示，则（I）和（II）等价，$r(\text{I}) = r(\text{II}) = r(\text{I,II})$

**推论**: 一向量组的极大无关组所含向量的个数是**唯一的**

### 二、**向量组的秩**

**定义 3.13**:

一向量组的==极大无关组所含向量的个数==，称为==向量组的**秩**==。若向量组的向量都是零向量，则规定其秩为 0

向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$ 的秩记为 $R\{\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s\}$（或 $\text{rank}\{\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s\}$）

> [!NOTE]
> 向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$ 线性无关 $\iff R\{\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s\} = s$

**定理 3.10** 若向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$ 可被向量组 $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_t$ 线性表示，则
$$R\{\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s\} \le R\{\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_t\}$$

> [!NOTE]
> 替换定理——向量组 $\boldsymbol{\alpha}_1, \cdots, \boldsymbol{\alpha}_n$ 无关，可由 $\boldsymbol{\beta}_1, \cdots, \boldsymbol{\beta}_t$ 线性表示，则 $n \le t$。
> 若 $\boldsymbol{\alpha}_1, \cdots, \boldsymbol{\alpha}_n$ 可由 $\boldsymbol{\beta}_1, \cdots, \boldsymbol{\beta}_t$ 线性表示，且 $n > t$，则 $\boldsymbol{\alpha}_1, \cdots, \boldsymbol{\alpha}_n$ 一定相关。

**推论 1** 等价的向量组具有相等的秩

**推论 2** 若向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_p$ 线性无关，且可被向量组 $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_q$ 线性表示，**则 $p \le q$**

**推论 3** 向量组 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_p$ 可被向量组 $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2, \cdots, \boldsymbol{\beta}_q$ 线性表示，且 $p > q$，则 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_p$ 线性相关

**推论 4** **任意 $n+1$ 个 $n$ 维向量线性相关**

> [!IMPORTANT]
> 🔴 **初等变换不会改变向量组的秩**（对矩阵也成立）
> 🔴 **初等行/列变换，不会改变列/行向量组的相关性和表示系数**

> [!NOTE]
**1. 线性表示判定**
$\boldsymbol{\beta} 可由 \boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_n 线性表示
\iff r(\boldsymbol{\alpha}_1\cdots\boldsymbol{\alpha}_n)=r(\boldsymbol{\alpha}_1\cdots\boldsymbol{\alpha}_n,\boldsymbol{\beta})$
$\boldsymbol{\beta} 不可由 \boldsymbol{\alpha}_1,\dots,\boldsymbol{\alpha}_n 线性表示
\iff r(\boldsymbol{\alpha}_1\cdots\boldsymbol{\alpha}_n,\boldsymbol{\beta})=r(\boldsymbol{\alpha}_1\cdots\boldsymbol{\alpha}_n)+1$
**2. 秩的范围**
$0 \le r(\boldsymbol{\alpha}_1,\boldsymbol{\alpha}_2,\dots,\boldsymbol{\alpha}_n) \le \min\{\text{向量数量},\text{向量维数}\}$

## 第四节 矩阵的秩

### 一、矩阵秩的定义

**定义 3.14**:

在一个 $m \times n$ 矩阵 $\boldsymbol{A}$ 中任选 $k$ 个行与 $k$ 个列（$k \le m, k \le n$），位于这些行、列交叉处的 $k^2$ 个元素，按原相互位置关系所形成的 $k$ 阶行列式称为 $\boldsymbol{A}$ 的一个 **$k$ 阶子式**

一个 $m \times n$ 矩阵 $\boldsymbol{A}$ 的 $k$ 阶子式共有 $C_m^k C_n^k$ 个

**定义 3.15**:

设在矩阵 $\boldsymbol{A}$ 中有一个不等于零的 $r$ 阶子式 $D$，且 $\boldsymbol{A}$ 的所有 $r+1$ 阶子式（如果存在的话）全等于零，那么 $D$ 称为矩阵 $\boldsymbol{A}$ 的**最高阶非零子式**，==$r$ 称为矩阵 $\boldsymbol{A}$ 的**秩**==，记为 $R(\boldsymbol{A})$。并且规定零矩阵的秩等于零

> 🔴 矩阵的秩 $R(\boldsymbol{A})$ 就是 $\boldsymbol{A}$ 的**最高阶非零子式**的阶数

**基本性质**：
- 对任意 $m \times n$ 矩阵 $\boldsymbol{A}$ 都有 $0 \le R(\boldsymbol{A}) \le \min(m, n)$
- $R(\boldsymbol{A}^\mathrm{T}) = R(\boldsymbol{A})$

对于 $n$ 阶方阵 $\boldsymbol{A}$：由于方阵 $\boldsymbol{A}$ 的 $n$ 阶子式只有 $|\boldsymbol{A}|$ 一个，故：
- 当 $|\boldsymbol{A}| \neq 0$ 时，$R(\boldsymbol{A}) = n$
- 当 $|\boldsymbol{A}| = 0$ 时，$R(\boldsymbol{A}) < n$

于是：
- **可逆矩阵**（非奇异矩阵）的秩等于矩阵的阶数，称为**满秩矩阵**
- **不可逆矩阵**（奇异矩阵）的秩小于矩阵的阶数，称为**降秩矩阵**

即：
$$|\boldsymbol{A}| \neq 0 \iff R(\boldsymbol{A}) = n \iff \boldsymbol{A} \text{ 可逆} \iff \boldsymbol{A} \text{ 满秩}$$
$$|\boldsymbol{A}| = 0 \iff R(\boldsymbol{A}) < n \iff \boldsymbol{A} \text{ 不可逆} \iff \boldsymbol{A} \text{ 降秩}$$


> [!NOTE]
> $\boldsymbol{A} \in \mathbb{R}^{n \times n}$，$|\boldsymbol{A}| \neq 0 \iff R(\boldsymbol{A}) = n$；$|\boldsymbol{A}| = 0 \iff R(\boldsymbol{A}) < n$

### 二、求矩阵秩的方法

**定理 3.11**：

**初等变换不改变矩阵的秩**

> [!NOTE]
> **阶梯形矩阵的秩：**
> 1. 若有零行，零行在非零行下方
> 2. 左起首个非零元，左边 0 的个数随行数增加而严格增加

**推论** 若 $\boldsymbol{A} \sim \boldsymbol{B}$，则 $R(\boldsymbol{A}) = R(\boldsymbol{B})$

> [!NOTE]
> 1. 矩阵乘可逆矩阵，秩不变
> 2. $\boldsymbol{A}_{m \times n}$，$\boldsymbol{P}$ 是 $m$ 阶可逆方阵，$\boldsymbol{Q}$ 是 $n$ 阶可逆方阵，则 $R(\boldsymbol{A}) = R(\boldsymbol{PA}) = R(\boldsymbol{AQ}) = R(\boldsymbol{PAQ})$

==**求秩方法**：先对矩阵作初等行变换将其化为阶梯形矩阵，然后判断阶梯形矩阵的秩（即非零行的行数），该数即为所求矩阵的秩==

### 三、矩阵秩的重要不等式

> [!NOTE]
> 1. $R(\boldsymbol{A}+\boldsymbol{B}) \le R(\boldsymbol{A}) + R(\boldsymbol{B})$
> 2. $R(\boldsymbol{AB}) \le \min\{R(\boldsymbol{A}), R(\boldsymbol{B})\}$
> 3. 若 $\boldsymbol{A} \in \mathbb{R}^{m \times n}$，$\boldsymbol{B} \in \mathbb{R}^{n \times p}$，若 $\boldsymbol{AB} = \boldsymbol{O}$，则 $R(\boldsymbol{A}) + R(\boldsymbol{B}) \le n$

### 四、矩阵的秩与向量组的秩的关系

**定理 3.12**：

**矩阵的秩等于矩阵的行向量组的秩，也等于矩阵的列向量组的秩**

> 即：$R(\boldsymbol{A}) = R\{\text{行向量组}\} = R\{\text{列向量组}\}$

### 五、**寻找列向量组的极大无关组**

寻找列向量组的极大无关组，一般做**初等行变换**

**方法**：将向量组按列排成矩阵 $\boldsymbol{A}$，==对 $\boldsymbol{A}$ 作初等行变换化为行最简形矩阵 $\boldsymbol{B}$==，则：
- $\boldsymbol{A}$ 的列向量组与 $\boldsymbol{B}$ 的列向量组有相同的线性关系
- ==$\boldsymbol{B}$ 中主元所在的列对应 $\boldsymbol{A}$ 中相应的列即为一个极大无关组==

### 六、**伴随矩阵的秩**

> [!NOTE]
> 设 $\boldsymbol{A} \in \mathbb{R}^{n \times n}$，$\boldsymbol{A}^*$ 是 $\boldsymbol{A}$ 的伴随矩阵：
> $$R(\boldsymbol{A}^*) = \begin{cases} n, & R(\boldsymbol{A}) = n \\ 1, & R(\boldsymbol{A}) = n-1 \\ 0, & R(\boldsymbol{A}) < n-1 \end{cases}$$
