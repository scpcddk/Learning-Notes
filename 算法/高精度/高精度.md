# **高精度算法笔记**

## 一. **高精度算法是什么**

在 C++ 中，`int`、`long long int` 等存储方式只能计算十几位的整数运算，当需要计算更多位时，就需要用到高精度算法。

### 1.**高精度算法**

是处理大数字的数学计算方法。在一般的科学计算中，经常会算到小数点后几百位或者更多，也可能是几千亿、几百亿的大数字，这类数字统称为**高精度数**。高精度算法是用计算机对超大数据的一种模拟加、减、乘、除等运算。

### 2.**核心思想**

将大数字拆成一位一位的，这样可以输入位数很长的数。将每一位取出，**存入数组**中，最后对数组进行相应的运算。

---

## 二. 高精度运算易错点

### 1.高精度加法

- **倒序输入**
- **倒序输出**:数组高位存在较大的下标，逆序输出才能恢复正常的数字顺序
- **中间是正着运算**:循环从低位（下标1）向高位进行，符合进位方
- **相加之后的进位处理**

### 2.高精度减法

- **考虑结果的正负情况**:竖式减法要求被减数 ≥ 减数，否则要用负数表示，所以先比较大小，如果被减数小就交换并在结果前加负号
- **前导 `0` 的处理**
- **减法的借位处理**:不够减时向高位借1当10

### 3.高精度乘法

- **前导 `0` 的处理（`0` 被相乘的情况）**
- **可以将乘法单个位数相乘再转化成加法的思想**
- 若出现负数，只需判断两个字符串第一位是否为负号，结尾特殊判断即可

### 4.高精度除法（高精度 ÷ 低精度）

- 输入、计算、输出需要同时逆序或同时正序
- **前导 `0` 的处理**
- **不能考虑进位的情况**:除法没有进位，只有余数暂存，下一位计算时要把上一位余数×10加上当前位

## 三. 高精度加法

**易错点**：

- 必须将数字倒序输入，结果倒序输出，中间正序运算；
- 字符串 `s1`、`s2` 下标从 `0` 开始。

### 代码实现

```cpp
#include <iostream>
#include <algorithm>

using namespace std;
const int N = 1e5 + 10;

string s1, s2;
int a[N], b[N], c[N];

int main() {
    cin >> s1 >> s2;
    int j = 1, k = 1; // a、b 数组下标从 1 开始
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';
    for (int i = s2.size() - 1; i >= 0; i--) b[k++] = s2[i] - '0';

    int ma = max(s1.size(), s2.size());
    int ans = 0;
    for (int i = 1; i <= ma; i++) {
        ans = ans + (a[i] + b[i]);
        c[i] = ans % 10;
        ans = ans / 10;
    }

    if (ans) c[++ma] = ans; // 注意最后的进位
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    return 0;
}
```

## 四. 高精度减法

**易错点**：

- 减法的借位处理；
- 相减为负数的处理；
- **前导 `0` 的处理**，容易被忽略。

### 代码实现

```cpp
#include <iostream>
#include <algorithm>

using namespace std;
const int N = 1e5 + 10;

string s1, s2;
int a[N], b[N], c[N], flag = 0;

int main() {
    cin >> s1 >> s2;
    // 比较两个字符串对应数字的大小，保证 s1 更大
    // 先用长度判断，长度相同再转化成整数比较（atoi）
    if (s1.size() < s2.size() || (s1.size() == s2.size() && atoi(s1.c_str()) < atoi(s2.c_str()))) {
        flag = 1;
        swap(s1, s2);
    }
    int j = 1, k = 1;
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';
    for (int i = s2.size() - 1; i >= 0; i--) b[k++] = s2[i] - '0';

    int ma = max(s1.size(), s2.size());
    for (int i = 1; i <= ma; i++) {
        if (a[i] - b[i] < 0) { // 借位
            a[i] += 10;
            a[i + 1]--;
        }
        c[i] = a[i] - b[i];
    }
    while (c[ma] == 0 && ma > 1) ma--; // 去除前导 0
    if (flag == 1) cout << "-";
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    return 0;
}
```

## 五. 高精度乘法

### 1.两个高精度整数相乘

**易错点**：

- **前导 `0` 的处理（`0` 被相乘）**；
- 可将乘法转化为单个位数相乘再累加；
- 若有负数，判断字符串首位是否为负号，结尾特殊判断。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>

using namespace std;
const int N = 1e6 + 10;

string s1, s2;
int a[N], b[N], s[N], c[N];

int main() {
    cin >> s1 >> s2;
    int j = 1, k = 1;
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';
    for (int i = s2.size() - 1; i >= 0; i--) b[k++] = s2[i] - '0';

    for (int i = 1; i <= s1.size(); i++) {
        for (int j = 1; j <= s2.size(); j++) {
            s[i + j - 1] += a[i] * b[j];
        }
    }

    int ma = s1.size() + s2.size() - 1;
    int ans = 0;
    for (int i = 1; i <= ma; i++) {
        ans += s[i];
        c[i] = ans % 10;
        ans /= 10;
    }
    if (ans) c[++ma] = ans;
    while (c[ma] == 0 && ma > 1) ma--;
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    return 0;
}
```

### 2.阶乘（n 个低精度整数相乘，结果为高精度）

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 1e6 + 10;
int n, a[N], ans, x, m, d;

int main() {
    while (cin >> n) {
        a[0] = 1, d = 1;
        for (int i = 1; i <= n; i++) {
            x = 0;
            for (int j = 0; j < d; j++) {
                ans = a[j] * i + x;
                a[j] = ans % 10;
                x = ans / 10;
            }
            while (x != 0) {
                a[d++] = x % 10;
                x /= 10;
            }
        }
        for (int i = d - 1; i >= 0; i--) {
            cout << a[i];
        }
        cout << endl;
    }
    return 0;
}
```

### 3. Hanoi 双塔问题

**思路**：
双塔问题结果为单塔问题的 2 倍，即 `res = 2 × (2^n - 1) = 2^(n+1) - 2`。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>

using namespace std;

const int N = 1e6 + 10;
int n, a[N], d, y = 2;

int main() {
    while (cin >> n) {
        d = 1, a[0] = 1;
        for (int i = 1; i <= n + 1; i++) {
            int x = 0;
            for (int j = 0; j < d; j++) {
                int ans = a[j] * y + x;
                a[j] = ans % 10;
                x = ans / 10;
            }
            while (x != 0) {
                a[d++] = x % 10;
                x /= 10;
            }
        }
        a[0] -= 2; // 2 的 n 次方尾数一定大于等于 2，可直接减
        for (int i = d - 1; i >= 0; i--) {
            cout << a[i];
        }
        cout << endl;
    }
    return 0;
}
```

## 六. 高精度除法

### 1.高精度 ÷ 低精度

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>

using namespace std;
const int N = 1e6 + 10;

string s1;
int a[N], x, c[N];

int main() {
    cin >> s1 >> x; // x 为低精度整数
    int j = 1;
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';

    int ma = s1.size(), ans = 0;
    for (int i = ma; i >= 1; i--) {
        ans = ans * 10 + a[i];
        c[i] = ans / x;
        ans = ans % x;
    }

    while (c[ma] == 0 && ma > 1) ma--; // 去除前导 0
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    cout << endl << ans; // 输出余数
    return 0;
}
```

### 2.高精度 ÷ 高精度

**核心思路**

- 从被除数的高位开始，截取与除数等长（或多一位）的部分，用循环减法求出该位商的最大值
- 被除数减去 商 × 除数 的积，得到余数，继续往后取位重复
- 最终商存在数组里，去除前导0
- 高精度÷高精度不能直接算，必须 “试商” 。每一位商本质上是问：当前截取的被减数可以减去多少个除数？我们通过循环减并计数得到商
- ge 函数判断被除数区间是否 ≥ 除数，注意比较时由于存储是倒序，高位在数组后端，需要特别处理

#### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 比较a的[la, ra]区间表示的数是否 >= b
bool ge(const vector<int> &a, int la, int ra, const vector<int> &b) {
    if (ra - la + 1 != b.size()) return (ra - la + 1 > b.size());
    for (int i = ra; i >= la; i--) {
        if (a[i] != b[ra - i]) return a[i] > b[ra - i];
    }
    return true; // 相等
}

// 高精度减法：a[la..ra]减去b，结果回存到a[la..ra]，假设a≥b
void sub(vector<int> &a, int la, int ra, const vector<int> &b) {
    int borrow = 0;
    for (int i = la, j = 0; i <= ra; i++, j++) {
        int val = a[i] - borrow - (j < b.size() ? b[j] : 0);
        if (val < 0) {
            val += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }
        a[i] = val;
    }
}

int main() {
    string s1, s2;
    cin >> s1 >> s2;
    // 转成倒序数组（个位在0）
    vector<int> a, b, c;
    for (int i = s1.size()-1; i >= 0; i--) a.push_back(s1[i]-'0');
    for (int i = s2.size()-1; i >= 0; i--) b.push_back(s2[i]-'0');

    int len = a.size();
    // 商的长度最多为 len - b.size() + 1
    c.resize(len - b.size() + 1, 0);

    // 从高位开始试商
    for (int i = len - b.size(); i >= 0; i--) {
        // 当前被除数区间 a[i+j] (j 从 0 到 b.size())
        // 用循环减法求当前位的商
        while (ge(a, i, i + b.size() - 1, b)) {
            sub(a, i, i + b.size() - 1, b);
            c[i]++;           // 商对应位+1
        }
    }

    // 去除前导0
    while (c.size() > 1 && c.back() == 0) c.pop_back();
    // 输出商（c也是倒序：个位在c[0]）
    for (int i = c.size()-1; i >= 0; i--) cout << c[i];
    cout << endl;
    // 输出余数（a中剩余非零部分）
    while (a.size() > 1 && a.back() == 0) a.pop_back();
    for (int i = a.size()-1; i >= 0; i--) cout << a[i];
    return 0;
}
```
