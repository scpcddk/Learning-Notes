# 📝 牛顿迭代法学习笔记

## 一、核心思想（一句话概括）

> **用切线近似曲线，不断逼近方程的根。**  
> 在几何上，牛顿法通过迭代，从初始猜测值开始，沿切线方向逐步“滑”向函数与 x 轴的交点。

---

## 二、数学原理推导

**1. 目标**  
求解方程 $f(x) = 0$ 的根。

**2. 推导过程**  
设当前迭代点为 $x_n$，在 $x_n$ 处做切线（泰勒一阶展开）：
$$f(x) \approx f(x_n) + f'(x_n)(x - x_n)$$
令 $f(x) = 0$（即切线与 x 轴交点），解出 $x$：
$$0 = f(x_n) + f'(x_n)(x - x_n)$$
$$x = x_n - \frac{f(x_n)}{f'(x_n)}$$

**3. 迭代公式**  
将新得到的 $x$ 作为下一次迭代起点 $x_{n+1}$：
$$\boxed{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}}$$

---

## 三、针对“求算术平方根”的应用

**1. 构造函数**  
要求非负整数 $a$ 的平方根，即求 $x = \sqrt{a}$。  
a>0 时等价于求方程 $f(x)=x^2-a=0$ 的正数根；a=0 时直接返回0。

**2. 求导**  
$$f'(x) = 2x$$

**3. 代入迭代公式**  
$$\begin{aligned}
x_{n+1} &= x_n - \frac{x_n^2 - a}{2x_n} \\
&= \frac{2x_n^2 - x_n^2 + a}{2x_n} \\
&= \frac{x_n^2 + a}{2x_n}
\end{aligned}$$

**4. 最终简化式（面试可直接套用）**
$$\boxed{x_{n+1} = \frac{x_n + \frac{a}{x_n}}{2}}$$

---

## 四、算法实现步骤（以 Java 为例）

```java
public int mySqrt(int x) {
    if (x < 2) return x;   // 0 和 1 的平方根就是本身
    long r = x;   // 初始值取 x 本身（或取大一点的值）
    while (r * r > x) {
        r = (r + x / r) / 2;
    }
    return (int) r;
}
```

**整数代码的模拟（x=9）**：
- r=9，更新为 `(9+9/9)/2=5`。
- r=5，整数除法 `9/5=1`，更新为 `(5+1)/2=3`。
- 3×3≤9，循环结束，返回3。

若使用浮点数、没有整数截断，则迭代序列为 9→5→3.4→约3.023529→约3.000091554，不能把这条浮点序列当作上面 Java 整数代码的执行过程。

## 五、关键注意事项（避坑指南）

| 问题 | 解决方案 |
| :--- | :--- |
| **整数溢出** | `r * r` 可能超过 `int` 范围（最大 2^31-1）。<br>**必须用 `long` 类型**存放 `r` 并计算乘积。 |
| **初始值选择** | 取 `r = x` 是最安全简单的策略。<br>（若取 `r = x/2`，需单独处理 `x < 2` 的情况） |
| **停止条件** | 因为是求整数部分，迭代到 `r * r <= x` 时停止，此时 `r` 即为答案。<br>（若求精确小数，则设置容差阈值如 `1e-7`） |
| **处理负数** | 题目保证非负整数，无需考虑负数。 |

---

## 六、收敛速度（为什么它很快？）

- **局部二次收敛**：对于足够光滑的函数、导数不为0的单根，且初值充分接近根时，误差具有二次收敛性质。任意可导函数、任意初值并不保证收敛。
- **示例**：求 $\sqrt{2}$，迭代 4~5 次即可达到双精度浮点数的极限精度。  
- **迭代次数**：本例从 r₀=x 开始，远离根的早期迭代主要近似减半，整数模板的次数上界可按 O(log x) 估计；进入根附近后才表现出快速收敛。不能不计初值和精度条件就声称总复杂度为 O(log log x)。

---

## 七、牛顿法 vs. 二分查找（优缺点对比）

| 维度 | 牛顿迭代法 | 二分查找 |
| :--- | :--- | :--- |
| **收敛表现** | 满足条件、接近单根时可二次收敛，初值不当可能失败 | 实数区间二分每次将区间长度减半，收敛可控 |
| **实现复杂度** | 需要数学推导，需注意溢出 | 逻辑简单，不易出错 |
| **适用性** | 迭代点导数须非零，初值和函数性质影响收敛 | 连续函数可在异号端点区间求根；单调判定也可做答案二分 |
| **面试推荐** | 展现数学功底，**加分项** | 稳妥保底，**基础解法** |

---

## 八、总结记忆口诀

> **求根切线迭代快，构造方程求导代；**  
> **平方根用和除二，长整防溢莫忘怀。**

只要记住公式 **`r = (r + x / r) / 2`** 和 **防溢出用 long**，遇到平方根面试题就能实现整数平方根求解。
