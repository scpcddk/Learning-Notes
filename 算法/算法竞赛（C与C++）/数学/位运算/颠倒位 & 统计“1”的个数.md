# 📘 位运算算法笔记：颠倒位 & 统计“1”的个数

## 1. 一眼区分（核心对比表）

| 维度 | **颠倒二进制位 (LeetCode 190)** | **位1的个数 / 汉明权重 (LeetCode 191)** |
| :--- | :--- | :--- |
| **目标** | 把 `0` 和 `1` 的**顺序反过来** | 数一数**有几个 `1`** |
| **核心动作** | **拼接（组装）** 新数字 | **消灭（删除）** 原数字里的 `1` |
| **灵魂操作** | `res = (res << 1) \| (n & 1)` | `n &= (n - 1)` （Brian Kernighan） |
| **循环次数** | 固定 **32 次**（int 是 32 位） | 不固定，等于 **`1` 的个数**（执行次数取决于1的个数） |
| **返回值** | 颠倒后的新整数 | 整数 `1` 的出现次数 |

## 2. 题一：颠倒二进制位（190）

### 核心思想（拼图法）

从原数 `n` 的最右边（低位）开始，一个一个把“位”切下来，拼接到结果 `res` 的最右边。每拼一个，`res` 左移腾出空位，`n` 右移丢掉旧位。

### 标准解法（必背模板）

```java
public int reverseBits(int n) {
    int res = 0;
    for (int i = 0; i < 32; i++) {
        // 1. 左移腾位置  |  2. 取出 n 的最低位拼上去
        res = (res << 1) | (n & 1);
        n >>>= 1; // 无符号右移，处理下一位
    }
    return res;
}
```

**手算模拟（4位示例）**：  
`n=1011` → 取尾数 `1`→`res=0001`，取尾数 `1`→`res=0011`，取尾数 `0`→`res=0110`，取尾数 `1`→`res=1101`。完成！

## 3. 题二：位1的个数（191）

### 解法一：普通扫描（通用，易理解）

```java
public int hammingWeight(int n) {
    int count = 0;
    for (int i = 0; i < 32; i++) {
        count += (n & 1); // 取最低位，累加
        n >>>= 1;
    }
    return count;
}
```

### 解法二：Brian Kernighan 算法（✨ 重点掌握，最优美）

**公式**：`n = n & (n - 1)`  
**效果**：直接**消除** `n` 的二进制中**最右边的那个 `1`**。

- **为什么能消除？（图解记忆法）**

- 以 `n = 101000`（40）为例：
  - `n - 1 = 100111`（最右边的 `1` 变 `0`，右边所有 `0` 变 `1`）
  - `n & (n-1) = 101000 & 100111 = 100000`（完美删除最右 `1`）
- 每执行一次，就砍掉一个 `1`，执行次数 = `1` 的个数。

```java
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1); // 砍掉最右边的 1
        count++;
    }
    return count;
}
```

## 4. `>>>` 与 `>>` 要结合循环条件理解

- `>>` 是算术右移，左边补符号位；`>>>` 是逻辑右移，左边补0。
- 若写 `while (n != 0) { ...; n >>= 1; }`，负数最终变为−1并停留，循环无法结束，应改用 `>>>`。
- 本文两段扫描代码都**固定循环32次**，因此改为 `>>` 也不会死循环；前32次取出的低位仍是原32位，结果相同。使用 `>>>` 是为了清楚表达按无符号位串处理。
- `n &= n-1` 不使用右移，对负数的32位补码也可正确计数，最多循环32次。
- Java 的 int 固定为32位；不能把“int 必定32位”直接推广到所有 C/C++ 平台。

依据：[Java 语言规范：移位运算符](https://docs.oracle.com/javase/specs/jls/se21/html/jls-15.html#jls-15.19)。

## 5. 两道题的“错题本”警示

1. **忘记固定循环次数**：本文直接拼接模板需要循环满32次；若改成 `while(n != 0)`，退出后还必须补足相应的移位，因为原数高位补的 0 也要颠倒成低位，不能丢掉！
2. **括号问题**：位运算优先级低于加减法，`res << 1 | n & 1` 按 Java 优先级本来就等价于 `(res << 1) | (n & 1)`；加括号是为了可读性，并非修复本表达式的逻辑。
3. **类型溢出**：190 题如果中间结果超过 int 范围？不用管，Java 的 int 是 32 位，自动截断，正好符合题目要求。

## 6. 一句话面试秒答（装X必备）

> **问：如何数二进制中的 1？**  
> **答**：用 Brian Kernighan 算法，`n &= (n-1)` 每次消灭最右边的 `1`，消灭几次就有几个 `1`，比遍历 32 位更优雅。

> **问：如何颠倒二进制位？**  
> **答**：把原数的低位逐个取出，通过 `左移` 拼接到结果数的低位，循环 32 次即可，注意用无符号右移。
