# 逆波兰表示法
## 一.一句话记忆
==数入栈，符弹俩算，无括号，靠栈定顺序==
## 二.核心定义
**运算符跟在操作数后面，无括号、无歧义，计算机易计算。**
## 三.对比
- 中缀表达式： a + b * c 
- 逆波兰表达式： a b c * +
## 四.计算规则
1. 数字：入栈
2. 二元运算符：先弹出的数是右操作数 b，后弹出的是左操作数 a，计算 a 运算符 b 后入栈；减法、除法不能颠倒顺序
3. 最终栈顶 = 答案
## 五.转换口诀
1. 数字直接输出
2. 运算符：对 +、−、×、÷ 等左结合运算符，反复弹出栈顶优先级大于或等于当前运算符的运算符，再将当前运算符入栈；遇到左括号停止。不能只弹一次；若扩展右结合运算符，相同优先级时不弹出
3. 左括号入栈，右括号一直弹到左括号，随后丢弃左括号，括号不输出
4. 结束后弹出剩余运算符
## 六.示例
以中缀表达式“3 + 4 × 2”为例：
<br>
1. 转换为逆波兰表示法：3 4 2 × +
2. 计算过程：
- 3、4、2依次入栈，栈内为 [3,4,2]
- 遇到“×”，弹出4和2计算（4×2=8），结果8入栈，栈内变为 [3,8]
- 遇到“+”，弹出3和8计算（3+8=11），最终结果为11

二元运算前须确认栈中至少有两个操作数，结束时应恰剩一个结果；一元负号、函数调用等需要额外解析规则。
