# **高精度算法笔记**

## 一. **高精度算法是什么**

常见平台的32位 int 最大约为 2.1×10⁹，64位 long long 最大约为 9.22×10¹⁸。超出类型可表示范围的整数运算，需要用字符串、数组或大整数库表示。

### 1.**高精度算法**

是处理大数字的数学计算方法。在一般的科学计算中，经常会算到小数点后几百位或者更多，也可能是几千亿、几百亿的大数字，这类数字统称为**高精度数**。高精度算法是用计算机对超大数据的一种模拟加、减、乘、除等运算。

### 2.**核心思想**

将大数字拆成一位一位的，这样可以输入位数很长的数。将每一位取出，**存入数组**中，最后对数组进行相应的运算。

本页代码按十进制**非负整数**实现，除数须为正数。固定数组示例要求输入及结果不超过数组容量；加法须额外预留进位位置，乘法须预留两数位数之和的位置。整数高精度与任意精度小数是不同问题，本页只实现整数运算。

---

## 二. 高精度运算易错点

### 1.高精度加法

- **倒序输入**
- **倒序输出**:数组高位存在较大的下标，逆序输出才能恢复正常的数字顺序
- **中间是正着运算**:循环从低位（下标1）向高位进行，符合进位方
- **相加之后的进位处理**

### 2.高精度减法

- **考虑结果的正负情况**:竖式减法要求被减数 ≥ 减数，否则要用负数表示，所以先比较大小，如果被减数小就交换并在结果前加负号
- **前导 `0` 的处理**
- **减法的借位处理**:不够减时向高位借1当10

### 3.高精度乘法

- **前导 `0` 的处理（`0` 被相乘的情况）**
- **可以将乘法单个位数相乘再转化成加法的思想**
- 若要扩展到负数，须先去掉正负号、记录符号异或，再对绝对值做乘法；结果为0时不输出负号

### 4.高精度除法（高精度 ÷ 低精度）

- 除法按数值的高位向低位处理；若数组倒序存储，就从最大下标向0或1遍历，输出再恢复正常顺序
- **前导 `0` 的处理**
- **不能考虑进位的情况**:除法没有进位，只有余数暂存，下一位计算时要把上一位余数×10加上当前位

## 三. 高精度加法

**易错点**：

- 本示例将低位存入小下标，计算时从低位向高位处理进位，再逆序输出；倒序存储是实现选择，并非唯一表示方法；
- 字符串 `s1`、`s2` 下标从 `0` 开始。

### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>

using namespace std;
const int N = 1e5 + 10;

string s1, s2;
int a[N], b[N], c[N];

int main() {
    cin >> s1 >> s2;
    int j = 1, k = 1; // a、b 数组下标从 1 开始
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';
    for (int i = s2.size() - 1; i >= 0; i--) b[k++] = s2[i] - '0';

    int ma = max(s1.size(), s2.size());
    int ans = 0;
    for (int i = 1; i <= ma; i++) {
        ans = ans + (a[i] + b[i]);
        c[i] = ans % 10;
        ans = ans / 10;
    }

    if (ans) c[++ma] = ans; // 注意最后的进位
    while (ma > 1 && c[ma] == 0) --ma; // 含前导0的输入也统一输出
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    return 0;
}
```

## 四. 高精度减法

**易错点**：

- 减法的借位处理；
- 相减为负数的处理；
- **前导 `0` 的处理**，容易被忽略。

### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>

using namespace std;
const int N = 1e5 + 10;

string s1, s2;
int a[N], b[N], c[N], flag = 0;

int main() {
    cin >> s1 >> s2;
    // 先去掉前导0；等长十进制数字串可以直接按字典序比较。
    auto normalize = [](string value) {
        size_t first = value.find_first_not_of('0');
        return first == string::npos ? string("0") : value.substr(first);
    };
    s1 = normalize(s1);
    s2 = normalize(s2);
    if (s1.size() < s2.size() || (s1.size() == s2.size() && s1 < s2)) {
        flag = 1;
        swap(s1, s2);
    }
    int j = 1, k = 1;
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';
    for (int i = s2.size() - 1; i >= 0; i--) b[k++] = s2[i] - '0';

    int ma = max(s1.size(), s2.size());
    for (int i = 1; i <= ma; i++) {
        if (a[i] - b[i] < 0) { // 借位
            a[i] += 10;
            a[i + 1]--;
        }
        c[i] = a[i] - b[i];
    }
    while (c[ma] == 0 && ma > 1) ma--; // 去除前导 0
    if (flag == 1) cout << "-";
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    return 0;
}
```

## 五. 高精度乘法

### 1.两个高精度整数相乘

**易错点**：

- **前导 `0` 的处理（`0` 被相乘）**；
- 可将乘法转化为单个位数相乘再累加；
- 此处代码处理非负整数；有符号扩展需先分离符号，避免把减号当作数字。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>

using namespace std;
const int N = 1e6 + 10;

string s1, s2;
int a[N], b[N], s[N], c[N];

int main() {
    cin >> s1 >> s2;
    int j = 1, k = 1;
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';
    for (int i = s2.size() - 1; i >= 0; i--) b[k++] = s2[i] - '0';

    for (int i = 1; i <= (int)s1.size(); i++) {
        for (int j = 1; j <= (int)s2.size(); j++) {
            s[i + j - 1] += a[i] * b[j];
        }
    }

    int ma = s1.size() + s2.size() - 1;
    int ans = 0;
    for (int i = 1; i <= ma; i++) {
        ans += s[i];
        c[i] = ans % 10;
        ans /= 10;
    }
    if (ans) c[++ma] = ans;
    while (c[ma] == 0 && ma > 1) ma--;
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    return 0;
}
```

### 2.阶乘（n 个低精度整数相乘，结果为高精度）

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>
#include <cstring>

using namespace std;

const int N = 1e6 + 10;
int n, a[N], d;
long long ans, x; // 单位乘数及进位计算使用64位，避免中间乘积溢出

int main() {
    while (cin >> n) {
        a[0] = 1, d = 1;
        for (int i = 1; i <= n; i++) {
            x = 0;
            for (int j = 0; j < d; j++) {
                ans = a[j] * i + x;
                a[j] = ans % 10;
                x = ans / 10;
            }
            while (x != 0) {
                a[d++] = x % 10;
                x /= 10;
            }
        }
        for (int i = d - 1; i >= 0; i--) {
            cout << a[i];
        }
        cout << endl;
    }
    return 0;
}
```

### 3. Hanoi 双塔问题

**思路**：
双塔问题结果为单塔问题的 2 倍，即 `res = 2 × (2^n - 1) = 2^(n+1) - 2`。

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>
#include <cstring>

using namespace std;

const int N = 1e6 + 10;
int n, a[N], d, y = 2;

int main() {
    while (cin >> n) {
        d = 1, a[0] = 1;
        for (int i = 1; i <= n + 1; i++) {
            int x = 0;
            for (int j = 0; j < d; j++) {
                int ans = a[j] * y + x;
                a[j] = ans % 10;
                x = ans / 10;
            }
            while (x != 0) {
                a[d++] = x % 10;
                x /= 10;
            }
        }
        a[0] -= 2; // 2^(n+1) 的个位为2、4、8或6，此处不需借位
        while (d > 1 && a[d - 1] == 0) --d;
        for (int i = d - 1; i >= 0; i--) {
            cout << a[i];
        }
        cout << endl;
    }
    return 0;
}
```

## 六. 高精度除法

### 1.高精度 ÷ 低精度

#### 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <string>

using namespace std;
const int N = 1e6 + 10;

string s1;
int a[N], x, c[N];

int main() {
    cin >> s1 >> x; // x 为低精度整数
    int j = 1;
    for (int i = s1.size() - 1; i >= 0; i--) a[j++] = s1[i] - '0';

    if (x <= 0) return 1; // 除数必须为正，拒绝除以0
    int ma = (int)s1.size();
    long long ans = 0; // 余数×10可能超过32位，但能放入64位
    for (int i = ma; i >= 1; i--) {
        ans = ans * 10 + a[i];
        c[i] = ans / x;
        ans = ans % x;
    }

    while (c[ma] == 0 && ma > 1) ma--; // 去除前导 0
    for (int i = ma; i >= 1; i--) {
        cout << c[i];
    }
    cout << endl << ans; // 输出余数
    return 0;
}
```

### 2.高精度 ÷ 高精度

**核心思路**

从被除数最高位开始，维护当前余数：`余数 = 余数 × 10 + 当前数字`，再减去若干次除数得到当前商位。上一轮余数小于除数，所以本轮商位始终在0～9之间，最多减9次。

所有数字串先去除前导0，零统一为 `"0"`。比较大小时先比长度，再比字典序；减法只在被减数不小于减数时执行。该写法也能直接处理被除数小于除数、两数相等和商中含0的情况。

#### 代码实现

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

string normalize(const string& value) {
    size_t first = value.find_first_not_of('0');
    return first == string::npos ? "0" : value.substr(first);
}

bool ge(const string& a, const string& b) {
    return a.size() != b.size() ? a.size() > b.size() : a >= b;
}

// a、b 已规范化，且 a >= b；从个位开始借位。
string sub(string a, const string& b) {
    int borrow = 0;
    for (int i = (int)a.size() - 1, j = (int)b.size() - 1; i >= 0; --i, --j) {
        int digit = a[i] - '0' - borrow - (j >= 0 ? b[j] - '0' : 0);
        borrow = digit < 0;
        if (borrow) digit += 10;
        a[i] = char('0' + digit);
    }
    return normalize(a);
}

int main() {
    string a, b;
    if (!(cin >> a >> b)) return 1;
    a = normalize(a);
    b = normalize(b);
    if (b == "0") {
        cerr << "除数不能为0\n";
        return 1;
    }
    string quotient, remainder = "0";
    for (char digit : a) {
        remainder = normalize(remainder + digit);
        int current = 0;
        while (ge(remainder, b)) {
            remainder = sub(remainder, b);
            ++current;
        }
        quotient.push_back(char('0' + current));
    }
    cout << normalize(quotient) << '\n' << remainder << '\n';
    return 0;
}
```

若被除数有 n 位、除数有 m 位，该竖式长除法时间为 O(nm)，额外空间为 O(n+m)。
