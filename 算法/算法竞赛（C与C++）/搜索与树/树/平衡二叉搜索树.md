# 📘 LeetCode 108 学习笔记：有序数组 → 平衡二叉搜索树

## 1. 核心思想（一句话概括）

> [!NOTE]
> **“二分分治，中间作根。”**  
> 对于升序数组，每次取**中间元素**作为根节点，左半段递归构建左子树，右半段递归构建右子树。因为左右段元素数量相差不超过 1，所以结果天然是平衡的。

---

## 2. 代码模板（Java 必背）

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return buildTree(nums, 0, nums.length - 1);
    }

    private TreeNode buildTree(int[] nums, int left, int right) {
        // 递归终止：区间无效
        if (left > right) return null;

        // 找中间位置（防溢出写法）
        int mid = left + (right - left) / 2;
        TreeNode root = new TreeNode(nums[mid]);

        // 左半段：left ~ mid-1
        root.left = buildTree(nums, left, mid - 1);
        // 右半段：mid+1 ~ right
        root.right = buildTree(nums, mid + 1, right);

        return root;
    }
}
```

---

## 3. 手动模拟（彻底搞懂递归过程）

以 `nums = [-10, -3, 0, 5, 9]` 为例：

| 调用范围 | `mid` 值 | 根节点 | 左子树范围 | 右子树范围 |
| :--- | :--- | :--- | :--- | :--- |
| `[0,4]` | 2 → `0` | `0` | `[0,1]`（-10, -3） | `[3,4]`（5, 9） |
| `[0,1]` | 0 → `-10` | `-10` | `[0,-1]`（空） | `[1,1]`（-3） |
| `[1,1]` | 1 → `-3` | `-3` | 空 | 空 |
| `[3,4]` | 3 → `5` | `5` | 空 | `[4,4]`（9） |
| `[4,4]` | 4 → `9` | `9` | 空 | 空 |

**最终树结构（完美平衡）**：

```tree
      0
     / \
   -10  5
     \   \
     -3   9
```

## 4. 复杂度分析

| 维度 | 数值 |
| :--- | :--- |
| **时间复杂度** | **O(n)**：每个数组元素被访问一次，创建为树节点。 |
| **空间复杂度** | **O(log n)**：递归栈深度（平衡树高度），忽略返回树本身的存储。 |

---

## 5. 关键细节与避坑指南（面试必答）

| 要点 | 说明 |
| :--- | :--- |
| **为什么一定能平衡？** | 每次取中点，左右元素数量相差 ≤ 1，递归下去整棵树高度始终为 O(log n)。 |
| **中间位置怎么取？** | 数组长度偶数时，取左中或右中都可以（本题均接受）。 |
| **防溢出写法** | `int mid = left + (right - left) / 2;`<br>❌ 避免写 `(left + right) / 2`，虽然小数据没事，但后者有溢出风险。 |
| **终止条件** | `left > right` 返回 `null`，这是递归的唯一出口。 |

## 6. 变种思考（展现深度）

- **变体 1：有序链表转平衡 BST（LeetCode 109）**  
  不能直接取中间下标，需要用快慢指针找链表中点。

- **变体 2：最小高度树（LeetCode 310）**  
  图论问题，利用“剥洋葱”拓扑排序，与本题思想不同。

- **变体 3：如果数组降序呢？**  
  同样取中间元素，不影响，因为只依赖“大小相对关系”。
