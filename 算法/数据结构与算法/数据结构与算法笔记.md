## 第一章 绪论

### 1.1 基本概念

| 术语 | 含义 |
|---|---|
| 数据 | 计算机处理的信息载体 |
| 数据元素 | 数据的基本单位（记录） |
| 数据项 | 最小单位 |
| 数据对象 | 性质相同的数据元素集合 |
| 数据结构 | \((D, S)\)，D 为数据元素有限集，S 为 D 上关系的有限集 |

### 1.2 逻辑结构四类

| 结构 | 关系 | 典型 |
|---|---|---|
| 集合 | 无关系 | — |
| 线性 | 一对一 | 线性表、栈、队列、串 |
| 树形 | 一对多 | 树、二叉树 |
| 图状 | 多对多 | 图 |

### 1.3 存储结构四种

| 方法 | 特点 |
|---|---|
| 顺序存储 | 地址连续，随机存取 |
| 链式存储 | 指针表示关系 |
| 索引存储 | 附加索引表 |
| 散列存储 | 哈希函数映射 |

### 1.4 算法特性

- **有穷性**：有限步骤内结束
- **确定性**：无二义性，唯一执行路径
- **可行性**：操作可由基本运算实现
- **有输入**：零个或多个输入
- **有输出**：一个或多个输出

### 1.5 时间复杂度

- 大 O 表示法：忽略低阶项和常数，只看最高阶
- 常见关系：  
  \(O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)\)
- 计算方法：取最深层循环内语句的执行次数

### 1.6 空间复杂度

- 只分析辅助空间
- 原地工作：额外空间为常数 \(O(1)\)

## 第二章 线性表

### 2.1 顺序表 vs 链表

| 对比项 | 顺序表 | 单链表 |
|---|---|---|
| 存储 | 连续空间 | 任意空间 + 指针 |
| 按位查找 | \(O(1)\) 随机存取 | \(O(n)\) 顺序存取 |
| 插入/删除 | \(O(n)\) 需移动元素 | \(O(1)\) 改指针（已知位置） |
| 空间 | 预分配，可能浪费 | 动态分配，有指针开销 |
| 适用 | 频繁查找，少增删 | 频繁增删，长度变化大 |

### 2.2 关键操作

- 插入：平均移动 \(n/2\) 个元素
- 删除：平均移动 \((n-1)/2\) 个元素
- 头结点：简化操作，统一空表和非空表处理

### 2.3 循环链表

- 尾结点指针指向头结点
- 判断表尾：`p->next == head`
- 带尾指针的循环链表：表头/表尾插入 \(O(1)\)

### 2.4 双向链表

- 结点含 `prior` 和 `next`
- 插入/删除需修改两个方向指针

### 2.5 静态链表

- 用数组模拟链表，`cur` 代替指针
- 0 表示空指针，第 0 个分量可作头结点

## 第三章 栈和队列

### 3.1 栈（LIFO）

- 操作：`Push`、`Pop`，均在栈顶进行
- 顺序栈 top 约定：
  - 约定 A：top 指向栈顶元素：入栈 `S[++top]=e`，出栈 `e=S[top--]`
  - 约定 B：top 指向栈顶下一位置：入栈 `S[top++]=e`，出栈 `e=S[--top]`
- 链栈：栈顶即链表头，无头结点
- 应用：数制转换、括号匹配、表达式求值、递归实现、迷宫求解

### 3.2 队列（FIFO）

- 操作：`EnQueue`、`DeQueue`
- 循环队列：
  - 队空：`front == rear`
  - 队满（牺牲一个单元）：`(rear+1) % MAXSIZE == front`
  - 入队：`rear = (rear+1) % MAXSIZE`
  - 出队：`front = (front+1) % MAXSIZE`
  - 元素个数：`(rear - front + MAXSIZE) % MAXSIZE`
- 链队列：带头结点，`front` 指向头结点，`rear` 指向尾结点
- 应用：CPU 调度、打印缓冲区、杨辉三角、图的 BFS

### 3.3 递归与栈

- 递归工作栈保存：参数、局部变量、返回地址
- 每进入一层递归：入栈；每退出一层：出栈

## 第四章 串

### 4.1 基本概念

- 串是字符的有限序列
- 子串：串中连续字符组成的子序列
- 模式匹配：在主串 S 中查找模式串 T

### 4.2 朴素匹配算法

- 时间复杂度：最好 \(O(n+m)\)，最坏 \(O(n \times m)\)
- 问题：主串指针回溯，效率低

### 4.3 KMP 算法

- 核心：主串不回溯，模式串右滑
- next[j]：失配时模式串的新比较位置
- 下标约定：
  - 1-based：`next[1]=0`
  - 0-based：`next[0]=-1`
- **手算 next 最快方法**：看失配位置前子串，找最长相同前后缀长度，next 值 = 该长度 + 1（1-based）
- 时间复杂度：\(O(n+m)\)

```c
// 1-based next
void get_next(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;
    while (i < T[0]) {
        if (j == 0 || T[i] == T[j]) {
            ++i; ++j;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}
```

```c
// 1-based nextval（优化）
void get_nextval(SString T, int nextval[]) {
    int i = 1, j = 0;
    nextval[1] = 0;
    while (i < T[0]) {
        if (j == 0 || T[i] == T[j]) {
            ++i; ++j;
            if (T[i] != T[j]) nextval[i] = j;
            else nextval[i] = nextval[j];
        } else {
            j = nextval[j];
        }
    }
}
```

## 第五章 数组与广义表

### 5.1 数组存储

**行优先**：  
\(LOC(i,j)=LOC(0,0)+(i\times n+j)\times L\)  
⚠️ \(n\) = 列数，\(i\) 行号，\(j\) 列号，\(L\) 元素大小。

**列优先**：  
\(LOC(i,j)=LOC(0,0)+(j\times m+i)\times L\)  
⚠️ \(m\) = 行数，\(n\) = 列数。

### 5.2 特殊矩阵压缩

| 矩阵 | 存储方式 | 下标映射 |
|---|---|---|
| 对称矩阵 | 只存下三角 | \(k = i(i+1)/2 + j\) （\(i \ge j\)） |
| 下三角 | 按行存 | \(k = i(i+1)/2 + j\) |
| 上三角 | 按行存 | \(k = (2n-i+1)i/2 + (j-i)\) |
| 对角矩阵 | 只存对角线 | 按带状存储 |
| 稀疏矩阵 | 三元组 \((i, j, value)\) | 行逻辑链接、十字链表 |

### 5.3 广义表

- 表头：第一个元素
- 表尾：除表头外的其余元素组成的表
- 深度：括号重数（原子深度 0，空表深度 1）
- 存储：头尾链表法、子表分析法

## 第六章 树和二叉树

### 6.1 基本术语

- 结点的度：子树个数
- 树的度：最大结点度
- 叶子：度为 0 的结点
- 深度：最大层次

### 6.2 二叉树性质

| 编号 | 性质 |
|---|---|
| 1 | 第 \(i\) 层至多 \(2^{i-1}\) 个结点 |
| 2 | 深度 \(k\) 至多 \(2^k - 1\) 个结点 |
| 3 | \(n_0 = n_2 + 1\) |
| 4 | 完全二叉树深度：\(\lfloor \log_2 n \rfloor + 1\) |
| 5 | 完全二叉树编号：双亲 \(\lfloor i/2 \rfloor\)，左孩子 \(2i\)，右孩子 \(2i+1\) |

**完全二叉树补充**：  
- \(n_1 = 0\) 或 \(1\)  
- \(n_0 = \lceil n/2 \rceil\)，\(n_2 = \lfloor n/2 \rfloor\)

### 6.3 遍历

| 遍历 | 顺序 | 应用 |
|---|---|---|
| 先序 | 根→左→右 | 复制树、建树 |
| 中序 | 左→根→右 | BST 有序输出 |
| 后序 | 左→右→根 | 求深度、释放空间 |
| 层次 | 逐层访问 | 求宽度、判断完全二叉树 |

**构造二叉树**：  
- 先序 + 中序：唯一确定  
- 后序 + 中序：唯一确定  
- 先序 + 后序：不能唯一确定

### 6.4 线索二叉树

- 利用空指针指向前驱/后继
- 标志域：`Link`（指针）/ `Thread`（线索）
- 中序线索化最常用
- **空指针数**：\(n\) 个结点的二叉链表共有 **\(n+1\) 个空指针**（可用于线索化）

### 6.5 树的存储表示

| 表示法 | 结构 | 特点 |
|---|---|---|
| 双亲表示法 | 数组，存双亲下标 | 找双亲快，找孩子慢 |
| 孩子表示法 | 数组 + 孩子链表 | 找孩子快，找双亲慢 |
| 孩子-兄弟表示法 | 二叉链表，左孩子右兄弟 | 树与二叉树转换基础 |

### 6.6 树、森林与二叉树的遍历对应

| 树 | 森林 | 二叉树 |
|---|---|---|
| 先根遍历 | 先序遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 | 中序遍历 |

**转换规则**：左是孩子，右是兄弟。

### 6.7 哈夫曼树

- 带权路径长度 WPL 最小的二叉树
- 构造：每次选两个最小权值合并
- **推论**：
  - 哈夫曼树中**没有度为 1 的结点**
  - \(n\) 个叶子对应**总结点数 \(2n-1\)**
  - 结合 \(n_0 = n_2 + 1\)，可秒杀性质计算题
- 哈夫曼编码：左 0 右 1，前缀编码，用于数据压缩

## 第七章 图

### 7.1 基本概念

- 有向图/无向图、完全图、稀疏/稠密图
- **顶点的度**：与该顶点关联的边数
- **无向图**：所有顶点度之和 \(=2E\)
- **有向图**：
  - 入度：以该顶点为弧头的弧数
  - 出度：以该顶点为弧尾的弧数
  - 度 = 入度 + 出度
  - 所有顶点入度之和 = 所有顶点出度之和 = \(E\)
- **完全图**：
  - 无向完全图边数：\(\frac{n(n-1)}{2}\)
  - 有向完全图弧数：\(n(n-1)\)
- **连通图**：任意两点有路径
- **连通分量**：无向图的极大连通子图
- **强连通图**：有向图中任意两点互相可达
- **强连通分量**：有向图的极大强连通子图（Kosaraju、Tarjan 算法）
- **生成树**：\(n\) 个顶点，\(n-1\) 条边

### 7.2 存储结构

| 结构 | 适用 | 特点 |
|---|---|---|
| 邻接矩阵 | 稠密图 | \(O(n^2)\) 空间，判断边 \(O(1)\) |
| 邻接表 | 稀疏图 | \(O(n+e)\) 空间，找邻接点快；无向图边结点总数 = \(2E\) |
| 逆邻接表 | 有向图 | 方便求入度 |
| 十字链表 | 有向图 | 同时方便找入边和出边 |
| 邻接多重表 | 无向图 | 每条边只存一次 |

### 7.3 遍历

- DFS：栈/递归，类似先序遍历
- BFS：队列，按路径长度递增

### 7.4 最小生成树

| 算法 | 思想 | 复杂度 | 适用 |
|---|---|---|---|
| Prim | 从顶点扩展，选最小边 | \(O(n^2)\) | 稠密图 |
| Kruskal | 选最小边，不构成回路 | \(O(e \log e)\) | 稀疏图 |

**并查集**：Kruskal 的核心支撑，支持 `Find` 和 `Union`；采用**按秩合并 + 路径压缩**后，单次操作均摊 \(O(\alpha(n))\)，近似常数。

### 7.5 最短路径

- **Dijkstra**：单源最短路径，贪心，\(O(n^2)\)，**要求边权非负**；二叉堆优化为 \(O((V+E)\log V)\)
- **Floyd**：每对顶点最短路径，动态规划，\(O(n^3)\)；**可处理负权边，但不能有负权回路**

```c
// Dijkstra 核心
for each v in V: dist[v] = INF; visited[v] = false;
dist[src] = 0;
重复 n-1 次：
    选未访问且 dist 最小的 u;
    visited[u] = true;
    for each v adjacent to u:
        if dist[u] + w(u,v) < dist[v]:
            dist[v] = dist[u] + w(u,v);
```

### 7.6 拓扑排序

- AOV 网：顶点表示活动
- 步骤：选入度为 0 的顶点输出，删除其边，重复
- 用途：判断有向图是否有环

```c
统计入度 indegree[];
入度为 0 的顶点入栈;
while (栈非空) {
    弹出 v，输出，count++;
    for each w adjacent to v:
        indegree[w]--;
        if (indegree[w] == 0) 入栈;
}
if (count < n) 有环;
```

### 7.7 关键路径

- AOE 网：边表示活动，权值表示时间
- ve：最早发生时间（正向递推）
- vl：最迟发生时间（逆向递推）
- 关键活动：\(ee = el\)

## 第八章 查找

### 8.1 静态查找

| 方法 | 存储 | 平均 ASL | 特点 |
|---|---|---|---|
| 顺序查找 | 顺序/链式 | \((n+1)/2\) | 简单，无序 |
| 折半查找 | 有序顺序表 | \(\log_2(n+1)-1\)（等概率、近似） | 高效，需有序 |
| 分块查找 | 分块有序 | 见下方公式 | 块间有序，块内无序 |

**折半查找判定树**：
- \(n\) 个关键字对应 **\(n+1\) 个失败结点**（外部结点）
- 比较次数 ≤ \(\lfloor \log_2 n \rfloor + 1\)

**分块查找 ASL**：  
设 \(n\) 个元素分成 \(b\) 块，每块长 \(s\)，则 \(n=b\cdot s\)。

- 索引表顺序查找，块内顺序查找：  
  \(ASL_{\text{成功}} \approx \frac{b+1}{2}+\frac{s+1}{2}=\frac{b+s}{2}+1\)
- 当 \(b=s=\sqrt n\) 时：  
  \(ASL_{\text{成功}} \approx \sqrt n + 1\)
- 索引表折半查找，块内顺序查找：  
  \(ASL_{\text{成功}} \approx \log_2(b+1)-1+\frac{s+1}{2}\)
- 不成功 ASL 另计。

### 8.2 二叉排序树（BST）

- 性质：左 < 根 < 右
- 查找：类似折半，\(O(\log n) \sim O(n)\)
- 插入：查找失败位置插入
- 删除：
  - 叶子：直接删
  - 单子树：子树替代
  - 双子树：前驱/后继替代

### 8.3 平衡二叉树（AVL）

- 平衡因子：\(|左高 - 右高| \le 1\)
- 旋转：

| 类型 | 插入位置 | 调整方法 |
|---|---|---|
| LL | 左子树的左子树 | 右旋一次 |
| RR | 右子树的右子树 | 左旋一次 |
| LR | 左子树的右子树 | 先左旋后右旋 |
| RL | 右子树的左子树 | 先右旋后左旋 |

- 查找：\(O(\log n)\)

### 8.4 B-树和 B+树

- **B-树**：多路平衡查找树，所有叶子同层
- **B+树**：叶子含全部关键字，链表连接，支持范围查找；查找必到叶子
- **对比**：B+树非叶结点只存索引，不存记录；B-树非叶结点也存记录

### 8.5 哈希表

- 哈希函数：除留余数法 \(H(key) = key \bmod p\)
- 冲突处理：
  - 开放定址：线性探测、二次探测、双散列
  - 链地址法：同地址记录链接
- **装填因子 \(\alpha = n/m\)**：
  - 开放定址法要求 **\(\alpha < 1\)**
  - 链地址法 **\(\alpha\) 可以大于 1**
- **ASL 公式（成功/不成功）**：

| 冲突方法 | 成功 ASL | 不成功 ASL |
|---|---|---|
| 线性探测 | \(\frac12(1+\frac1{1-\alpha})\) | \(\frac12(1+\frac1{(1-\alpha)^2})\) |
| 随机探测 | \(-\frac1\alpha \ln(1-\alpha)\) | \(\frac1{1-\alpha}\) |
| 链地址法 | \(1+\frac\alpha2\) | 见下方说明 |

**链地址法不成功 ASL 计数口径**：

| 计数口径 | 不成功 ASL |
|---|---|
| 不计空指针比较 | \(\approx \alpha\) |
| 计入空指针比较（泊松分布） | \(\approx \alpha + 1\) |

考试以目标教材口径为准，并注明“是否计入空指针比较”。

- 特点：理想情况 \(O(1)\)，适合精确查找，不适合范围查找

## 第九章 排序

### 9.1 排序方法对比

| 方法 | 平均 | 最坏 | 最好 | 空间 | 稳定 | 备注 |
|---|---|---|---|---|---|---|
| 直接插入 | \(O(n^2)\) | \(O(n^2)\) | \(O(n)\) | \(O(1)\) | ✓ | 基本有序时最好 |
| 折半插入 | \(O(n^2)\) | \(O(n^2)\) | \(O(n\log n)\)（比较主导） | \(O(1)\) | ✓ | 移动最好为 0，平均/最坏由移动主导 |
| 希尔排序 | \(O(n^{1.3})\)（经验估计） | 与增量有关 | 与增量有关 | \(O(1)\) | ✗ | 缩小增量 |
| 起泡排序 | \(O(n^2)\) | \(O(n^2)\) | \(O(n)\) | \(O(1)\) | ✓ | 可提前结束 |
| 快速排序 | \(O(n\log n)\) | \(O(n^2)\) | \(O(n\log n)\) | 平均 \(O(\log n)\)，最坏 \(O(n)\) | ✗ | 初始有序易退化 |
| 简单选择 | \(O(n^2)\) | \(O(n^2)\) | \(O(n^2)\) | \(O(1)\) | ✗ | 比较次数固定 |
| 堆排序 | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n\log n)\) | \(O(1)\) | ✗ | 适合大 n |
| 归并排序 | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n\log n)\) | \(O(n)\) | ✓ | 稳定，需辅助空间 |
| 基数排序 | \(O(d(n+rd))\) | \(O(d(n+rd))\) | \(O(d(n+rd))\) | \(O(n+rd)\) | ✓ | 非比较排序 |

**趟数补充**：  
- 起泡排序最多 \(n-1\) 趟  
- 归并排序趟数 \(\lceil \log_2 n \rceil\)，每趟 \(O(n)\)

### 9.2 稳定性判据

- 稳定：直接插入、折半插入、起泡、归并、基数  
- 不稳定：希尔、快速、简单选择、堆  
- **判据**：是否发生跨元素长距离交换或跳跃式交换；若存在，通常不稳定。

### 9.3 核心算法伪代码

**快速排序划分**：
```c
int Partition(R, low, high) {
    pivot = R[low];
    while (low < high) {
        while (low < high && R[high] >= pivot) high--;
        R[low] = R[high];
        while (low < high && R[low] <= pivot) low++;
        R[high] = R[low];
    }
    R[low] = pivot;
    return low;
}
```

**堆调整（大顶堆）**：
```c
void HeapAdjust(R, s, m) {
    rc = R[s];
    for (j = 2*s; j <= m; j *= 2) {
        if (j < m && R[j] < R[j+1]) j++;
        if (rc >= R[j]) break;
        R[s] = R[j];
        s = j;
    }
    R[s] = rc;
}
```

**Kruskal 核心**：
```c
边按权值升序排序;
初始化并查集;
选 n-1 条边:
    若边两端点不在同一集合:
        加入生成树;
        合并集合;
```

### 9.4 堆与优先队列

- 建堆：\(O(n)\)  
- 插入：上调 \(O(\log n)\)  
- 删除堆顶：下调 \(O(\log n)\)  
- 优先队列：用堆实现，常用于 Dijkstra、TopK 等问题

### 9.5 选择建议

| 场景 | 推荐 |
|---|---|
| n 小（<30） | 直接插入排序 |
| n 大、无序 | 快速排序 |
| n 大、基本有序 | 堆排序 / 归并排序 |
| 要求稳定 | 归并排序、直接插入、起泡、基数排序 |
| 关键字位数少、n 大 | 基数排序 |
| 稠密图最小生成树 | Prim |
| 稀疏图最小生成树 | Kruskal |
| 单源最短路径、非负权 | Dijkstra |
| 每对顶点最短路径 | Floyd |
| 精确查找、\(O(1)\) 理想 | 哈希表 |
| 范围查找 | B+ 树、有序表 |

### 9.6 比较排序下界

- 基于比较的排序，最少比较次数 \(\ge \log_2(n!)\approx n\log_2 n\)
- 因此基于比较的排序最快为 \(O(n\log n)\)
- 基数排序不基于比较，不受此下界限制

| 易错点 | 说明 |

| 排序稳定性 | 相等关键字排序前后相对位置是否改变 |
| 哈希删除 | 开放定址法不能直接置空，需做删除标记 |

## 附录 C：解题步骤模板

1. **循环队列计算**  
   - 判空：`front == rear`  
   - 判满：`(rear+1)%M == front`  
   - 元素个数：`(rear - front + M) % M`

2. **二叉树性质计算**  
   - 先求 \(n_1 = 0\) 或 \(1\)（完全二叉树）  
   - 由 \(n = n_0 + n_1 + n_2\) 和 \(n_0 = n_2 + 1\) 联立求解  
   - 哈夫曼树：无度为 1；\(n\) 个叶子对应总结点 \(2n-1\)

3. **遍历序列构造二叉树**  
   - 先序定根，中序分左右；递归处理

4. **DFS/BFS 序列**  
   - 按存储结构（邻接矩阵/邻接表）确定邻接点顺序  
   - 注意访问标志数组初始化

5. **Prim 手算**  
   - 从起点开始，每次选连接已选集合与未选集合的最小边，记录权值和

6. **Kruskal 手算**  
   - 边按权升序，用并查集判环，选 \(n-1\) 条边

7. **Dijkstra 表格法**  
   - 初始化 dist，每轮选最小未访问顶点，松弛邻接点

8. **Floyd 矩阵递推**  
   - \(D^{(k)}[i][j] = \min(D^{(k-1)}[i][j], D^{(k-1)}[i][k] + D^{(k-1)}[k][j])\)

9. **拓扑排序**  
   - 统计入度 → 入度为 0 入栈 → 出栈输出并减邻接点入度 → 重复

10. **关键路径**  
    - 正向求 ve，逆向求 vl，计算 ee 和 el，ee=el 为关键活动

11. **哈希表 ASL**  
    - 构造哈希函数，处理冲突，画表，按成功/不成功分别统计比较次数

12. **排序稳定性判断**  
    - 看是否存在跨元素长距离交换或跳跃式交换

13. **各排序算法一趟结果**  
    - **快排**：按枢轴划分，左侧小右侧大  
    - **堆排**：先建大顶堆，交换堆顶与末尾，再筛选  
    - **归并**：相邻两两合并为有序段  
    - **插入**：前 i 个元素有序，将第 i+1 个插入到正确位置  
    - **起泡**：相邻比较，大者下沉，每趟确定一个最大元素位置
