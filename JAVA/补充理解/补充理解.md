# Java补充理解

## 一.Java 的文件组织规则

### 1.public类

+ 一个 .java 文件最多只能有一个 public 类，且文件名必须和这个 public 类的名字完全一样
+ 改法：
  + 拆成两个文件（推荐）
  + 去掉类名前的public，改成默认访问权限（什么都不写）

## 二.Java Thread

### 1. 什么是线程？

线程是程序内的**独立执行路径**。一个进程可以有多个线程，它们“同时”运行。

### 2. 为什么需要多线程？

避免一个任务阻塞其他任务。  
比如你的游戏：  

- **主线程**负责初始化、等待结束  
- **时钟线程**负责每秒 10 次驱动战场更新

### 3. 传统线程 vs 虚拟线程（JDK 21）

| 类型 | 传统线程 | 虚拟线程 |
| ------ | ---------- | ---------- |
| 创建方式 | `new Thread(task).start()` | `Thread.ofVirtual().start(task)` |
| 资源开销 | 大（操作系统线程） | 极小（JVM 管理） |
| 数量上限 | 几千个 | 轻松几十万个 |
| 适用场景 | 长时间运行的任务 | 高并发、短任务 |

### 4. 关键方法

- `start()`：启动线程，执行 `run()` 方法
- `sleep(ms)`：让当前线程休眠指定毫秒
- `interrupt()`：中断线程

### 5. 一句总结

> **线程 = 分身术，让程序同时做多件事。虚拟线程 = 轻量分身，大厂面试加分项。**
