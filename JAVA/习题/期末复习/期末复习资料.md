## 一、Java 基础机制

### 1. 编译器 vs 解释器 & Java 执行机制 & 跨平台原理

| | 编译器 | 解释器 |
|---|---|---|
| **工作方式** | 一次性全部翻译为机器码，生成可执行文件 | 逐行翻译并执行，不生成目标文件 |
| **代表语言** | C、C++ | 早期 JavaScript、Python |
| **优点** | 执行速度快 | 跨平台性好，开发效率高 |
| **缺点** | 平台依赖（不同系统需重新编译） | 执行速度相对慢 |

**Java 执行过程**：
```
源码(.java) → 编译(javac) → 字节码(.class) → 类加载 → 
解释器逐行解释执行 + JIT编译器(即时编译)将热点代码编译为本地机器码
```

**跨平台原理（Write Once, Run Anywhere）**：
- Java 不直接面对操作系统，而是面对 **JVM（Java虚拟机）**
- 不同平台有不同版本的 JVM，但所有 JVM 都能识别相同的 `.class` 字节码
- **字节码是平台无关的，JVM 是平台相关的**

### 2. 基本数据类型、运算符、流程控制

**8 大基本类型**：

| 类型 | 字节 | 默认值 | 范围 |
|---|---|---|---|
| `byte` | 1 | 0 | -128 ~ 127 |
| `short` | 2 | 0 | -32768 ~ 32767 |
| `int` | 4 | 0 | 约 -21亿 ~ 21亿 |
| `long` | 8 | 0L | 很大 |
| `float` | 4 | 0.0f | 单精度浮点 |
| `double` | 8 | 0.0d | 双精度浮点 |
| `char` | 2 | '\u0000' | 0 ~ 65535（Unicode） |
| `boolean` | 未明确 | `false` | `true` / `false` |

**运算符陷阱**：

| 运算符 | 含义 | 特点 |
|---|---|---|
| `&&` | 短路与 | 左边为 `false`，右边**不执行** |
| `&` | 按位与 / 逻辑与 | 两边**都执行**，可用于位运算 |
| `\|\|` | 短路或 | 左边为 `true`，右边**不执行** |
| `\|` | 按位或 / 逻辑或 | 两边**都执行** |
| `==` | 等于 | 基本类型比**值**，引用类型比**内存地址** |

**流程控制**：
- `if-else`、`switch`、`for`、`while`、`do-while`
- `switch` 支持：`byte`、`short`、`int`、`char`、`String`（JDK7+）、`enum`
- **`switch` 穿透**：没有 `break` 会继续执行下一个 `case`

```java
switch (x) {
    case 1: 
        System.out.println("1");
        // 没有break，会穿透到case 2
    case 2:
        System.out.println("2");
        break;
}
```

## 二、类与对象

### 3. 类的定义、属性、方法 & 局部变量初始化

```java
public class Student {
    // 属性（成员变量）：在类中方法外定义
    int age;        // 系统默认初始化：0
    String name;    // 系统默认初始化：null
    boolean pass;   // 系统默认初始化：false
    
    public void study() {
        // 局部变量：在方法内定义，必须手动初始化
        int count;      // 编译报错！未初始化
        count = 10;     // 正确
        System.out.println(count);
    }
}
```

**成员变量 vs 局部变量**：

| | 成员变量 | 局部变量 |
|---|---|---|
| 定义位置 | 类中方法外 | 方法内或参数列表 |
| 初始化 | 系统默认初始化 | **必须手动初始化** |
| 作用域 | 整个类 | 定义它的代码块 |
| 存储位置 | 堆内存 | 栈内存 |

### 5. 构造方法 & new 运算符

**构造方法特点**：
- 方法名与**类名相同**
- **没有返回值类型**（连 `void` 都没有）
- 用于初始化对象

**默认构造方法**：
- 如果类中**没有定义任何构造方法**，系统提供**无参、方法体为空**的构造方法
- **一旦定义了有参构造，默认构造方法即失效**

```java
public class Student {
    String name;
    
    // 有参构造
    public Student(String name) {
        this.name = name;
    }
    
    // 必须显式定义无参构造，否则 Student s = new Student(); 报错
    public Student() {}
}
```

**new 运算符的作用**：
1. 在**堆**中分配内存
2. 初始化成员变量为**默认值**
3. 执行**构造方法体**

### 6. 组合（Has-A 关系）

在类中定义另一个类的对象作为属性，代表"拥有"关系。

```java
class Engine {
    void start() { }
}

class Car {
    private Engine engine;  // 组合关系
    
    public Car() {
        this.engine = new Engine();  // 初始化组合对象
    }
}
```

### 7. 传值与传引用（极其重要！）

**Java 只有传值（Pass by Value）**。

| 参数类型 | 传递内容 | 形参改变是否影响实参 |
|---|---|---|
| 基本类型 | **数值的副本** | ❌ 不影响 |
| 引用类型 | **引用的副本**（地址的拷贝） | ✅ 修改对象属性会影响外部 |

```java
public class Test {
    void changeValue(int i) {
        i = 10;  // 只改变副本，外部不变
    }
    
    void changeObject(Student s) {
        s.name = "李四";  // 修改的是堆中同一个对象，外部会变
    }
    
    void changeReference(Student s) {
        s = new Student();  // 改变的是副本的指向，外部不变！
        s.name = "王五";
    }
}
```

**内存图理解**：
```
基本类型：        引用类型（修改属性）：      引用类型（修改引用）：
栈                栈          堆              栈          堆
main: a=5        main: s ──→ {name="张三"}   main: s ──→ {name="张三"}
change: i=10     change: s ─→ {name="李四"}   change: s ─→ {name="王五"} (新对象)
                 ↑ 指向同一个对象              ↑ 指向不同对象
```

## 三、包、访问控制与模块化

### 8. 包、导入 & 访问控制权限

**包声明**：`package com.test;` **必须写在第一行**

**导入**：
```java
import java.util.ArrayList;     // 导入具体类
import java.util.*;              // 导入包下所有类（不影响运行时性能，但不导入子包）
```

**访问权限表（必背）**：

| 修饰符 | 同类 | 同包 | 子类(不同包) | 任何地方 |
| :---: | :---: | :---: | :---: | :---: |
| `private` | ✅ | ❌ | ❌ | ❌ |
| `default`（缺省） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

**注意**：
- `protected` 在不同包的子类中，**只能通过继承访问**，不能通过引用访问
- `default`（不写任何修饰符）不是 `default` 关键字

### 9. 方法重载 & 构造方法重载

**重载条件**（必须同时满足）：
- **方法名相同**
- **参数列表不同**（类型、个数、顺序不同）

**与返回值类型和访问修饰符无关**！

```java
public class Calculator {
    // 重载：参数个数不同
    int add(int a, int b) { return a + b; }
    int add(int a, int b, int c) { return a + b + c; }
    
    // 重载：参数类型不同
    double add(double a, double b) { return a + b; }
    
    // 重载：参数顺序不同
    void test(int a, String b) { }
    void test(String b, int a) { }
    
    // 以下不是重载！编译报错
    // int add(int a, int b) { }  // 与第一个方法参数列表相同
}
```

### 10. this 关键字

- 代表**当前对象的引用**
- 用于区分**成员变量和局部变量**（`this.name = name`）
- 使用 `this()` 调用其他构造方法：**必须写在构造方法的第一行，且只能调用一次**

```java
public class Student {
    String name;
    int age;
    
    public Student() {
        this("默认名", 18);  // 调用有参构造，必须是第一行
    }
    
    public Student(String name, int age) {
        this.name = name;    // 区分成员变量和局部变量
        this.age = age;
    }
}
```

## 五、继承与多态

### 14. 继承（Is-A 关系）

- 使用 `extends` 关键字，实现**代码复用**
- 子类自动继承父类中 `public` 和 `protected` 修饰的属性和方法
- `private` 成员对子类**不可见（不可访问）**
- Java **不支持多继承**（一个类只能有一个直接父类）

```java
class Animal {
    protected void eat() { }
}

class Dog extends Animal {
    // 自动继承 eat() 方法
}
```

---

### 15. 向上转型 & `instanceof`

**向上转型（自动）**：子类对象自动转为父类引用
```java
Animal a = new Dog();  // 自动转型，安全
```

**向下转型（强制）**：需要先用 `instanceof` 判断，避免 `ClassCastException`
```java
if (a instanceof Dog) {
    Dog d = (Dog) a;  // 安全向下转型
}
```

### 16. super 关键字 & 父类构造方法调用

- 子类构造方法**默认第一行隐式调用** `super()`（父类无参构造）
- 如果父类**没有无参构造**，子类必须**显式使用 `super(参数)`** 调用父类有参构造，且必须是第一行
- `super` 可用于访问父类被隐藏的属性和被重写的方法

```java
class Animal {
    String name;
    
    public Animal(String name) {  // 只有有参构造
        this.name = name;
    }
}

class Dog extends Animal {
    public Dog() {
        super("动物");  // 必须显式调用父类有参构造
    }
    
    public void test() {
        super.name = "父类名字";  // 访问父类属性
    }
}
```

### 17. 重写（Override）vs 重载（Overload）

| | 重写（Override） | 重载（Overload） |
|---|---|---|
| **位置** | 子类中 | 同一个类中 |
| **方法名** | 相同 | 相同 |
| **参数列表** | **必须相同** | **必须不同** |
| **返回值** | 相同或是其子类 | 无关 |
| **访问权限** | 不能更严格（如父类 `public`，子类不能 `private`） | 无关 |
| **异常** | **受检异常**不能比父类更宽泛 | 无关 |
| **绑定方式** | 运行时绑定（动态） | 编译时绑定（静态） |

```java
class Animal {
    public void shout() throws IOException { }
}

class Dog extends Animal {
    @Override
    public void shout() throws FileNotFoundException {  // 受检异常子类，OK
        System.out.println("汪汪");
    }
}
```

### 18. final 关键字（考点密集）

| 用法 | 说明 |
|---|---|
| `final` 类 | 不能被继承（如 `String`、`Math`） |
| `final` 方法 | 不能被子类重写 |
| `final` 变量 | 一旦赋值不可更改 |
| `final` 参数 | 方法内部不能修改该参数的值 |

**`final` 引用类型**：
- 引用地址不可变，但对象内部属性**可以变**

```java
final Student s = new Student("张三");
s.name = "李四";      // ✅ 可以，修改的是对象属性
s = new Student();    // ❌ 编译报错，不能改变引用指向
```

### 19. equals 和 toString（来自 Object 类）

| 方法 | 默认行为 | 通常做法 |
|---|---|---|
| `toString()` | 返回 `类名@哈希码` | **重写**以便打印对象信息 |
| `equals()` | 等价于 `==`，比较内存地址 | **重写**以实现内容比较 |
| `hashCode()` | 返回对象的哈希码 | 重写 `equals` 时必须同时重写，保持一致 |

```java
String s1 = new String("a");
String s2 = new String("a");

s1.equals(s2);  // true（String 已重写，比较内容）
s1 == s2;       // false（比较地址，两个不同对象）
```

**`equals` 重写规范**：
```java
@Override
public boolean equals(Object obj) {
    if (this == obj) return true;
    if (obj == null || getClass() != obj.getClass()) return false;
    Student student = (Student) obj;
    return age == student.age && Objects.equals(name, student.name);
}

@Override
public int hashCode() {
    return Objects.hash(name, age);
}
```

### 21. 多态（运行时绑定）

**条件**（三者缺一不可）：
1. **继承**
2. **重写**
3. **父类引用指向子类对象**

**效果**：调用重写方法时，运行时决定调用**子类**的版本（动态绑定）

```java
Animal a = new Cat();
a.shout();  // 调用猫的叫声，不是动物叫声

// 编译时类型：Animal
// 运行时类型：Cat
// 调用方法时看运行时类型
```

**多态的局限**：
- 父类引用**不能调用子类特有方法**（除非向下转型）

## 六、抽象类、接口与静态

### 22. 抽象类、接口、static

**抽象类**：
- 含 `abstract` 修饰
- 可有抽象方法（无方法体）和具体方法
- **不能实例化**
- 子类必须实现所有抽象方法，否则子类也必须是抽象类

**接口**：
- JDK 8 前：全是常量（`public static final`）+ 抽象方法（`public abstract`）
- JDK 8 开始：可有 `default` 方法和 `static` 方法
- 类通过 `implements` 实现**多接口**

```java
interface Flyable {
    void fly();  // 默认 public abstract
    
    default void test() {  // JDK8+ 默认方法
        System.out.println("默认实现");
    }
}
```

**static**：
- 属于**类级别**，不属于对象
- **静态方法不能直接访问非静态成员**（但可以通过创建对象访问）
- 静态属性被**所有对象共享**

```java
class Student {
    static int count = 0;  // 所有对象共享
    
    public Student() {
        count++;  // 每创建一个对象，计数+1
    }
    
    static void showCount() {
        // name = "张三";  // ❌ 不能直接访问非静态成员
        new Student().name = "张三";  // ✅ 通过对象访问
        System.out.println(count);
    }
}
```

## 七、设计模式

### 23. 设计模式（高频简答/代码题）

**单例模式（饿汉式）**：
```java
class Singleton {
    // 类加载时就创建实例（线程安全）
    private static final Singleton INSTANCE = new Singleton();
    
    // 构造方法私有，防止外部创建
    private Singleton() {}
    
    // 提供公共获取方法
    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

**单例模式（懒汉式 — 线程安全版）**：
```java
class Singleton {
    private static volatile Singleton instance;
    
    private Singleton() {}
    
    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

**策略模式**：
- 定义一系列算法，把它们一个个封装起来，并且使它们可互相替换
- 示例：支付方式选择（支付宝/微信/银行卡）

## 八、异常处理

### 24. 异常处理（必须写对 try-catch-finally）

**异常分类**：

| 类型 | 说明 | 示例 | 处理要求 |
|---|---|---|---|
| **运行时异常（未检查）** | `RuntimeException` 的子类 | `NullPointerException`、`ArithmeticException`、`ArrayIndexOutOfBoundsException` | 编译时不强制处理 |
| **非运行时异常（已检查）** | `Exception` 的子类但不是 `RuntimeException` | `IOException`、`SQLException`、`ClassNotFoundException` | **必须**使用 `try-catch` 或 `throws` 处理 |

**异常处理结构**：
```java
try {
    // 可能抛出异常的代码
} catch (NullPointerException e) {
    // 处理空指针异常
} catch (Exception e) {
    // 处理其他异常
} finally {
    // 无论是否异常，都会执行
    // 常用于释放资源
}
```

**finally 执行时机**：
- 无论是否异常，`finally` 都会执行
- **除非**遇到 `System.exit(0)` 或 JVM 崩溃

**try-with-resources（JDK7+，推荐写法）**：
```java
try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
    String line = br.readLine();
} catch (IOException e) {
    e.printStackTrace();
}
// 自动调用 close()，无需 finally
```

## 九、I/O 流

### 25. I/O 流（文件读写）

**字符流（文本文件）**：
- `FileReader`（读）、`FileWriter`（写）
- 建议用 `BufferedReader` / `BufferedWriter` 包装提高效率
- **注意**：`FileReader` 默认使用系统编码，处理中文可能乱码

**字节流（二进制文件）**：
- `FileInputStream`（读）、`FileOutputStream`（写）
- 用于图片、音频、视频等

**标准写法（try-with-resources）**：
```java
// 字符流
try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

// 字节流
try (FileInputStream fis = new FileInputStream("image.jpg")) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = fis.read(buffer)) != -1) {
        // 处理读取的数据
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

## 十、终极应试提醒

### 高频陷阱清单

| 陷阱 | 正确理解 |
|---|---|
| `==` vs `equals` | 基本类型用 `==` 比值，引用类型 `==` 比地址，`equals` 看是否重写 |
| 传值 vs 传引用 | Java **只有传值**，引用类型传的是地址的**副本** |
| 对象数组初始化 | `new Student[3]` 创建的是 3 个 `null`，必须逐个 `new` |
| 默认构造方法 | 一旦定义有参构造，默认无参构造**立即失效** |
| `this()` 位置 | 必须是构造方法的**第一行**，且只能出现**一次** |
| `super()` 位置 | 必须是子类构造方法的**第一行** |
| 静态方法访问限制 | **不能直接访问非静态成员**，但可以通过对象访问 |
| `final` 引用类型 | 地址不能变，但**对象属性可以变** |
| 重写异常规则 | **受检异常**不能比父类更宽泛，运行时异常不受限制 |
| `switch` 穿透 | 没有 `break` 会继续执行下一个 `case` |

### 代码规范（占分！）

- **类名**：首字母大写，驼峰命名（`StudentInfo`）
- **方法名/变量名**：首字母小写，驼峰命名（`getStudentName`）
- **常量**：全大写，下划线分隔（`MAX_SIZE`）
- **大括号**：风格统一（建议 K&R 风格或 Allman 风格）
- **缩进**：4 个空格（或统一使用 Tab）
