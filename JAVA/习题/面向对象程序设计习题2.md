## 习题

### 第一轮：基础内功与执行机制（约8分钟）

#### **Q1：（主题1 & 2）综合辨析题**

看下面这段代码，并回答三个小问：

```java
int i = 0;
if ( (++i > 0) | (i++ > 1) ) { 
    System.out.println("条件为真，i=" + i);
}
System.out.println("最终i=" + i);
```

- （1）这段代码最终输出什么？（考察运算符优先级和`|`与`||`的本质区别）
- （2）如果我把 `|` 换成 `||`，输出结果会变吗？为什么？
- （3）基于这个问题，请简述Java程序从编写到运行，JVM（Java虚拟机）是如何让这段代码在Windows和Linux上跑出相同结果的？（串联跨平台）

> **⏸️ 思考时间（约2分钟）... 下面揭晓答案**

**参考答案与踩分点**：

- **输出**：`条件为真，i=2` 和 `最终i=2`。因为 `|` 不短路，左边 `++i` 使 i=1（真），右边 `i++` 依然执行使 i=2（后置++先取值1，但`|`不短路，自增照跑），所以结果为真。
- **换成 `||`**：输出变成 `条件为真，i=1` 和 `最终i=1`。因为短路，左边为真，右边被跳过了。
- **跨平台**：`.java` 文件经 `javac` 编译成**平台无关的 `.class` 字节码**，不同平台的 **JVM（依赖具体OS实现）** 将同一份字节码解释/编译（JIT）为对应平台的机器码。**踩分点**：必须提到“JVM是平台相关的，字节码是平台无关的”。

### 第二轮：面向对象定义与内存布局（约10分钟）

#### **Q2：（主题3、4、5）构造方法与初始化陷阱**

请看这段代码，它编译会报错吗？如果报错，错在哪一行？如果不报错，输出是什么？

```java
class Demo {
    int x;
    String y;
    public Demo(int a) { x = a; }
    public void show() {
        int z;
        System.out.println("x=" + x + ", y=" + y + ", z=" + z);
    }
}
public class Test {
    public static void main(String[] args) {
        Demo d;          // 行①
        d = new Demo(5); // 行②
        d.show();
    }
}
```

> **⏸️ 思考时间（约2分钟）...**

**参考答案与踩分点**：

- **编译报错位置**：`System.out.println(... z)` 这一行。因为 `z` 是**局部变量**，没有赋初值，编译期就报错（`Variable 'z' might not have been initialized`）。
- **关于 `d`**：行①只声明，不报错；行② `new` 触发了有参构造。
- **关于属性**：`x` 被构造器赋值为5；`y` 没赋值，但有**默认初始化**（`null`），输出 `x=5, y=null`。
- **追问挖坑**：如果我把 `Demo d;` 改成 `Demo d = null;`，再把 `d.show();` 去掉，换成 `System.out.println(d.x);`，会怎样？**答**：编译通过，但运行抛 `NullPointerException`，因为 `d` 指向空，没有对象实例。

#### ==**Q3：（主题6、7）组合与传参“死亡陷阱”**==

现有两个类：

```java
class Wallet { int money = 100; }
class Person { 
    String name; 
    Wallet wallet; // 组合
    public Person(String n, Wallet w) { name = n; wallet = w; }
}
```

在 `main` 方法中执行以下代码，请问三段 `println` 分别输出什么？

```java
Wallet w = new Wallet();
Person p1 = new Person("张三", w);
Person p2 = new Person("李四", w);

p1.wallet.money = 999;

System.out.println(w.money);        // 第1个输出
System.out.println(p2.wallet.money); // 第2个输出

change(p1, p2);
System.out.println(p1.name + ":" + p1.wallet.money); // 第3个输出

public static void change(Person a, Person b) {
    a.wallet = new Wallet(); // 给张三换了个新钱包
    a.wallet.money = 1;
    b = a; // 企图把李四也指向张三
}
```

> **⏸️ 思考时间（约3分钟）... 这是全场最易错的题**

**参考答案与踩分点**：

- **第1、2个输出**：都是 **999**。因为 `p1` 和 `p2` 及外部变量 `w`，指向**堆内存中的同一个 `Wallet` 对象**。任何一个引用修改属性，全部改变。
- **第3个输出**：`张三:1`。关键点：`a.wallet = new Wallet();` 修改了 `p1` 指向的对象的属性（把钱包指针改了），所以输出1。
- **终极迷惑**：`b = a;` 只在方法栈里改了形参 `b` 的指向，`p2` 外部引用依然指向原来的钱包（money=999），所以`p2`没变。**踩分金句**：**Java只有传值（传地址的副本）**，形参重新赋值不影响外部实参。

### 第三轮：包、访问控制、重载与集合（约12分钟）

#### **Q4：（主题8、9、10）重载与 `this` 调用**

请写出一个 `Student` 类，要求：

- 有 `name` 和 `age` 两个私有属性；
- 提供无参构造、一个参数（只传name）构造、两个参数构造；
- 在无参构造中，通过 `this` 调用两个参数的构造，传入默认值 `"未知"` 和 `0`；
- 说明：如果我只定义了一个有参构造 `public Student(int a) { age = a; }`，那么 `new Student()` 还能用吗？为什么？

> **⏸️ 思考时间（约3分钟）...**

**参考答案与踩分点**：

- **代码核心**：

```java
public Student() { this("未知", 0); }
public Student(String n) { this(n, 0); }
public Student(String n, int a) { this.name = n; this.age = a; }
```

- **`this()` 铁律**：必须写在构造方法的第一行。
- **默认构造消失**：如果手动定义了 `public Student(int a)`，编译器**不再赠送**无参构造。此时 `new Student()` 编译报错。**踩分点**：记住“提供了有参，无参就没了”。

#### **Q5：（主题11）多重性与集合实战**

在设计“学校管理系统”时：

- （1）一个学生可以选修多门课程，一门课程可以有多个学生，这属于什么多重性关系？用 `ArrayList` 怎么在 `Student` 类中定义这个属性？
- （2）`ArrayList` 和 `Vector` 在**线程安全**上有什么区别？现在写新代码应该用哪个？
- （3）在 `main` 方法中，如何往这个集合里添加一门课（调用什么方法）？如何遍历并打印出所有课程名称（调用什么方法取值）？

> **⏸️ 思考时间（约3分钟）...**

**参考答案与踩分点**：

- **多重性**：**多对多（\*..\*）**。定义：`List<Course> courses = new ArrayList<>();`（面向接口编程，加分项）。
- **线程安全**：`Vector` 的方法是 `synchronized` 修饰（线程安全，但效率低），`ArrayList` 不安全但更快。**现在绝对优先用 `ArrayList`**。
- **操作**：添加用 `add(课程对象)`；遍历用 `for (Course c : courses) { System.out.println(c.getName()); }` 或 `courses.get(i)`。

#### **Q6：（主题12、13）数组与匿名对象**

- （1）写下创建包含3个 `Student` 对象的一维数组的**完整正确代码**（要求：既要有数组空间，又要有对象实例）。
- （2）如果我写成 `Student[] s = new Student[3];` 然后直接 `s[0].name = "Tom";` 会发生什么？为什么？
- （3）什么情况下会用到**匿名对象**？请针对数组场景举一个例子。

> **⏸️ 思考时间（约3分钟）...**

**参考答案与踩分点**：

- **（1）正确代码**：

```java
Student[] students = new Student[3];
students[0] = new Student("A");
students[1] = new Student("B");
students[2] = new Student("C");
// 或者静态初始化：Student[] s = {new Student("A"), new Student("B"), new Student("C")};
```

- **（2）报错**：抛 `NullPointerException`。因为 `new Student[3]` 只开辟了存放引用的数组空间，每个元素默认是 `null`，还没指向具体的 `Student` 对象。
- **（3）匿名对象**：没有名字的对象，如 `new Student("临时生").show();`。在数组中的场景：直接往数组里塞，如 `studentList.add(new Student("新来的"));`，这个对象没有变量名，只能被集合持有。**特点**：只能使用一次，用完即垃圾（GC候选）。

### 最后30秒：终极挑战（附加题）

#### **Q7：**

如果父类在 `com.a` 包中有一个 `protected void method(){}`，子类在 `com.b` 包中，子类能否通过 `super.method()` 调用它？如果是在子类的 `main` 方法中 `new 子类().method()` 呢？

**参考答案**：

编译结果如下：

- **`super.method()`**（子类内部）→ ✅ **编译通过**（子类继承特权）
- **`new 子类().method()`**（子类的 `main` 方法中）→ ✅ **编译通过**

- 为什么 `main` 方法里调用也能通过？

`main` 方法虽然静态，但它**写在子类的 `{}` 大括号里**，属于子类“内部员工”。只要满足以下两条铁律，编译器就放行：

1. **调用代码必须写在子类的类体中**（你写在 `Child` 里，符合）
2. **点号左边的引用类型必须是子类本身**（你写 `new Child()`，类型是 `Child`，符合）

- 什么情况会报错？（帮你避坑）

| 写法 | 结果 | 原因 |
| :--- | :--- | :--- |
| `Parent p = new Child();` <br> `p.method();` | ❌ **报错** | 点号左边是 **父类类型** `Parent`，不合规。 |
| 在 `com.b` 包的**无关类**中：<br> `new Child().method();` | ❌ **报错** | 调用代码不在子类 `Child` 的类体内部，无继承特权。 |

- 三秒记忆口诀

> **跨包 `protected`：只有子类内部（`{}`）能用，且点号左边必须是子类类型（或 `super`）。**
> 你引用的“参考答案”说 `main` 里会报错——**那个答案是错的**，你理解的是对的。
