# Java杂项笔记

## 1.final修饰的变量里面的内容无法发生改变

+ final 基本类型 vs 引用类型：
基本类型：数值本身不可变。
引用类型：引用地址不可变（即不能再指向其他对象），但对象内部的状态是可以改变的。

## 2.枚举

- 每一个枚举项，都是该枚举类的对象
- 枚举项在底层其实就是常量，默认用 `public static final` 修饰
- 枚举类的第一行上必须是枚举项，枚举项之间用逗号隔开，以分号作为结尾
- 枚举类的构造方法必须是 `private` 修饰，不让外界创建本类的对象
- 编译器会给枚举类新增两个默认存在的方法：`values()`、`valueOf()`

---

## 3.方法重写注意事项和要求

+ 重写方法的名称、形参列表必须与父类中的一致，方法体按照实际需求书写。
+ **了解**：子类重写父类方法时，访问权限子类必须大于等于父类（空着不写 < protected < public）
+ **了解**：子类重写父类方法时，返回值类型子类必须小于等于父类
+ **建议**：重写的方法申明和父类保持一致即可
+ final修饰类为最终类，里面所有的方法不能被重写
+ private私有方法、static静态方法、final最终方法不能被重写

## 5.try-catch —— 防崩安全网

```java
try {
    // 1. 尝试执行：可能出问题的代码
} catch (要捕获的异常类型 变量名) {
    // 2. 如果真出问题了：执行这里的补救代码
}
```

+ try 块：放你要执行的代码
+ catch 块：如果 try 里的代码抛出了 `InterruptedException`，就跳到这里来“善后”
+ 变量名：捕获到的异常对象，里面有出错信息
+ InterruptedException：线程被中断时抛出的异常类型

## 7.Math.floor

JavaScript 的內建數學方法，用於向下取整：返回小於或等於給定數字的最大整數

### (1)语法

`Math.floor(x)`

+ 負數向下取整：Math.floor(-4.1) 返回 -5，因為 -5 < -4.1，這是「向下」的數學意義（往更小的整數方向）
+ 若參數已是整數，則返回原值
+ 若參數為 NaN，返回 NaN
+ 若參數為 Infinity / -Infinity，返回對應的無窮大值

### (2)與相似方法的區別

| 方法 | 行為 | 範例 (3.7 →) | 範例 (-3.7 →) |
| ------ | ------ | ---------------- | ------------------ |
| `Math.floor()` | 向下取整 | `3` | `-4` |
| `Math.ceil()` | 向上取整 | `4` | `-3` |
| `Math.round()` | 四捨五入 | `4` | `-4` |
| `Math.trunc()` | 截斷小數部分 | `3` | `-3` |

## 8.@FunctionalInterface

### (1)定义

`@FunctionalInterface`：**函数式接口注解**，Java8新特性

### (2)核心规则

1. 接口内**有且仅有一个抽象方法**
2. 允许存在：`default`默认方法、`static`静态方法
3. 允许重写Object类公有方法
4. 编译期强制校验，违反直接报错

### (3)与普通接口区别

| 对比项 | 普通接口 | 函数式接口 |
| ---- | ---- | ---- |
| 抽象方法 | 不限数量 | 只能1个 |
| 注解 | 无强制注解 | 必须标注该注解 |
| 实现方式 | 匿名内部类 | 支持Lambda表达式 |
| 用途 | 定义多种行为 | 单一行为、回调、流式编程 |

### (4)基础代码示例

```java
@FunctionalInterface
public interface FuncDemo {
    // 唯一抽象方法
    void run();
}
```

### (5)Java四大内置常用函数式接口
 
1. Consumer<T> ：消费型 → 有参无返回
2. Supplier<T> ：供给型 → 无参有返回
3. Function<T,R> ：函数型 → 有参有返回
4. Predicate<T> ：断言型 → 有参返回布尔值

## 9.return String

**`return String`**

- 方法把字符串**交给调用者**，可以存、拼、传。
- `return` 是**传递数据**，`String` 是返回类型。

**`System.out.println`**

- 只把内容**打印到控制台**，调用者**拿不到**这个字符串。
- 输出后数据消失，**无法复用**。

**核心区别**

- `return`：厨师把菜**端给你**（你可以再加工）。
- `println`：厨师自己**吃掉**，你只是看到。

**一句话**  
需要把结果给别人用 → `return`。  
只想看看结果 → `println`。
