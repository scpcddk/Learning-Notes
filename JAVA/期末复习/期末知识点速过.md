## 一、Java语言基础

### 1.1 变量与数据类型

| 类型 | 说明 | 注意点 |
| ------ | ------ | -------- |
| `byte, short, int, long` | 整数 | `long`需加`L`后缀 |
| `float, double` | 浮点 | `float`需加`F`后缀；默认`double` |
| `char` | 16位Unicode字符 | 单引号`' '` |
| `boolean` | `true/false` | **不能**用数字作为布尔值 |

**命名规则**：字母开头，驼峰命名（`currentGear`），区分大小写，避开关键字

### 1.2 运算符

- **算术**：`+ - * / %`
- **关系**：`== != > < >= <=`
- **逻辑**：`&& || !`（短路特性：`&&`前假后不判，`||`前真后不判）
- **位运算**：`& | ^ ~ << >> >>>`（了解即可）
- **类型转换**：
  - 自动提升：小→大（`int`→`double`）
  - 强制转换：`(int) x / y`（可能丢失精度）

### 1.3 控制结构

```java
// if-else
if (cond) { } else if (cond2) { } else { }

// 三元运算符
int max = (a > b) ? a : b;

// switch（Java 7+ 支持String）
switch(expr) {
    case value1: ...; break;
    case value2: ...; break;
    default: ...;
}

// 循环
while(cond) { }      // 先判后执行
do { } while(cond);  // 至少执行一次
for(init; cond; update) { }

// 跳转
break;     // 跳出循环
continue;  // 进入下一次迭代
```

### 1.4 数组

```java
// 声明与创建
int[] arr = new int[10];
String[] names = {"Alice", "Bob"};

// 关键特性
// - 下标从0开始
// - length属性获取长度
// - 不能resize，但可重新赋值引用
// - 数组是对象！

// 排序（选择排序/冒泡排序）
public static void sort(int[] a) {
    for(int i = 0; i < a.length; i++) {
        for(int j = a.length - 1; j > i; j--) {
            if(a[j] < a[j-1]) {
                int temp = a[j];
                a[j] = a[j-1];
                a[j-1] = temp;
            }
        }
    }
}

// 查找
public static int search(int[] a, int key) {
    for(int i = 0; i < a.length; i++) {
        if(a[i] == key) return i;
    }
    return -1;
}
```

## 二、面向对象核心概念

### 2.1 类与对象

```java
public class BankAccount {
    // 属性（字段）- 描述状态
    private int balance;  // 私有，信息隐藏
    
    // 构造方法 - 创建对象时初始化
    public BankAccount() { this.balance = 0; }
    public BankAccount(int initialBalance) { this.balance = initialBalance; }
    
    // 方法 - 描述行为
    public int getBalance() { return this.balance; }
    public void deposit(int amount) { this.balance += amount; }
}
```

**创建与使用**：

```java
BankAccount acct = new BankAccount();  // 必须new，否则NullPointerException!
acct.deposit(100);
```

### 2.2 方法重载 (Overloading)

- **定义**：同一类中，方法名相同，**参数列表不同**（类型、个数、顺序）
- **注意**：返回值不同**不构成**重载！

```java
void print(String fileName) { }
void print(int detailLevel) { }
void print(int detailLevel, String fileName) { }
```

### 2.3 构造方法重载

```java
public Student() { this.ssn = "?"; }
public Student(String s) { this.setSsn(s); }
public Student(String s, String n, int i) {
    this.setSsn(s);
    this.setName(n);
    this.setAge(i);
}
```

⚠️ **重要陷阱**：如果自定义了任何构造方法，编译器**不再提供**默认无参构造！

### 2.4 `this` 关键字

- 引用当前对象
- 区分成员变量与局部变量：`this.balance = balance;`
- 调用同类其他构造：`this(...)`（必须是构造方法第一行）

## 三、对象交互与信息隐藏

### 3.1 **参数传递**

- **基本类型**：值传递（方法内修改不影响原值）
- **对象类型**：引用传递（方法内修改对象**状态**会影响原对象，但**重新赋值**引用不影响原引用）

```java
public void myMethod(BankAccount one, BankAccount two) {
    one.deposit(50);   // 原对象余额改变！
    two = one;         // 仅改变局部引用，原引用不变
}
```

### 3.2 信息隐藏 (Information Hiding)

| 修饰符 | 可见范围 |
| -------- | ---------- |
| `private` | 仅本类 |
| 默认（无） | 同包 |
| `protected` | 同包 + 所有子类 |
| `public` | 所有类 |

**核心原则**：

- 属性通常设为`private`
- 通过`public`的getter/setter访问
- 在setter中加入数据校验逻辑，保证数据完整性

### 3.3 消息传递

- 对象间通过**方法调用**（消息）协作
- 使用 **点号`.`** 发送消息：`obj.method()`
- 获取对象引用的方式：
  1. 作为属性持有
  2. 通过方法参数传入
  3. 通过第三方对象获取
  4. 全局可用（不推荐）

## 四、对象间关系

### 4.1 关联 (Association) 与多重性

| 多重性 | 含义 | 代码表示 |
| -------- | ------ | ---------- |
| 1:1 | 一对一 | 双方各持一个引用 |
| 1:m | 一对多 | 一方持数组/集合 |
| m:m | 多对多 | 双方各持集合 |

```java
// 1:1 双向关联
public class Student {
    private Transcript t;
    public void setTranscript(Transcript t) { this.t = t; }
}
public class Transcript {
    private Student owner;
    public void setStudent(Student s) { this.owner = s; }
}
```

### 4.2 聚合 (Aggregation) vs 组合 (Composition)

- **聚合**："has-a"，部分可独立存在（如大学与学院）
- **组合**：强聚合，部分不能脱离整体存在（如书与章节）

### 4.3 集合类

```java
// ArrayList - 动态数组
ArrayList<Student> list = new ArrayList<>();
list.add(new Student("John"));
Student s = list.get(0);
list.remove(0);

// 遍历方式
// 1. for-each（最常用）
for (Student s : list) { ... }

// 2. Iterator
Iterator<Student> it = list.iterator();
while (it.hasNext()) {
    Student s = it.next();
}
```

## 五、继承 (Inheritance)

### 5.1 基础语法

```java
public class Student extends Person {
    private String degree;
    
    public Student(String name, String id, String degree) {
        super(name, id);  // 调用父类构造，必须是第一行！
        this.degree = degree;
    }
}
```

### 5.2 关键规则

- **"is a" 关系**：子类是父类的特化
- 子类继承父类所有非`private`成员
- **构造方法不继承**，但子类构造默认第一行隐式调用`super()`（若父类无无参构造，必须显式调用）
- 父类引用可以指向子类对象：`Person p = new Student(...);`

### 5.3 类型转换

```java
Person p = new Student("John", "id", "SE", "CS");
// p.getDegree();  // 编译错误！父类引用看不到子类特有方法

// 向下转型（需判断）
if (p instanceof Student) {
    String degree = ((Student) p).getDegree();
}
```

⚠️ **注意**：`instanceof`左边为`null`时返回`false`。盲目强转可能抛出`ClassCastException`

### 5.4 方法重写 (Overriding)

- 子类重新定义父类方法，**签名完全相同**
- 返回值类型必须兼容（协变返回）
- 访问权限不能更严格

```java
public class Shape {
    public double calculateArea() { return 0; }
}
public class Circle extends Shape {
    private double radius;
    @Override
    public double calculateArea() {
        return Math.PI * radius * radius;
    }
}
```

### 5.5 `super` 关键字

- `super(...)`：调用父类构造
- `super.method()`：调用父类被重写的方法

```java
public String toString() {
    return super.toString() + "_" + this.degree;
}
```

### 5.6 `equals()` 与 `toString()`

**`toString()`**：

- 默认返回：`ClassName@hashCode`
- **建议所有类重写**，提供有意义描述

**`equals()`**：

- 默认比较引用地址（`==`）
- 重写时应比较对象内容

```java
@Override
public boolean equals(Object obj) {
    if (obj instanceof Point) {
        Point p = (Point) obj;
        return this.x == p.x && this.y == p.y;
    }
    return false;
}
```

## 六、多态 (Polymorphism)

### 6.1 概念

同一消息，不同对象产生不同行为。依赖**继承 + 方法重写**

```java
Container[] containers = new Container[3];
containers[0] = new Wagon(1, 2, 3);
containers[1] = new Tank(1, 3);
containers[2] = new Container();

for (Container c : containers) {
    System.out.println(c.computeVolume());  // 多态调用！
}
```

### 6.2 优势

- 消除`if-else`类型判断（避免"意大利面条"代码）
- 新增子类无需修改客户端代码（开闭原则）

## 七、抽象类与接口

### 7.1 抽象类 (Abstract Class)

- **不能实例化**
- 可包含抽象方法（无方法体）和具体方法
- 子类必须实现所有抽象方法，否则子类也必须声明为抽象类

```java
public abstract class Container {
    public abstract double computeVolume();  // 抽象方法
    public void print() { ... }  // 具体方法
}
```

### 7.2 接口 (Interface)

- 更纯粹的抽象，只声明方法签名（Java 8前）
- 类可以实现**多个**接口（弥补Java单继承）
- 接口之间可以多继承

```java
public interface Teacher {
    void agreeToTeach(Course c);
    Syllabus defineSyllabus(Course c);
}

public class Professor implements Teacher, Administrator {
    // 必须实现所有接口方法
}
```

### 7.3 抽象程度对比

- **接口 > 抽象类 > 普通类**

| 特性 | 抽象类 | 接口 |
| ------ | -------- | ------ |
| 实例化 | ❌ | ❌ |
| 构造方法 | ✅ | ❌ |
| 多继承 | ❌ | ✅ |
| 方法实现 | 可包含 | Java 8前不可 |
| 属性 | 可有实例变量 | 仅常量（`public static final`） |

### 7.4 接口引用

```java
Teacher t = new Professor();  // OK
t.agreeToTeach(c);            // OK
// t.getName();               // 编译错误！Teacher接口未声明此方法
```

## 八、静态特性 (Static)

### 8.1 静态属性

- 属于**类**，不属于对象
- 所有实例共享一份

```java
class Student {
    private static int totalStudents = 0;
    public Student() { totalStudents++; }
    public static int getTotalStudents() { return totalStudents; }
}

// 调用
Student.getTotalStudents();  // 推荐
s1.getTotalStudents();       // 也可，但会报警告
```

### 8.2 静态方法

- 只能访问**静态成员**（不能访问实例变量/方法）
- **原因**：静态方法不依赖对象存在，调用时可能还没有对象创建

### 8.3 `main` 为什么是静态的？

JVM启动时先加载类，此时没有对象存在，**必须通过类名调用**`main`，所以必须是`static`

### 8.4 工具类

如`java.lang.Math`，全是静态方法和常量，**无需实例化**

## 九、设计模式

### 9.1 单例模式 (Singleton)

**目的**：确保类只有一个实例，提供全局访问点

```java
public class PrintSpooler {
    private static PrintSpooler instance = null;
    
    private PrintSpooler() { }  // 私有构造！
    
    public static PrintSpooler getInstance() {
        if (instance == null) {
            instance = new PrintSpooler();
        }
        return instance;
    }
}
```

**关键点**：

1. 构造方法`private`
2. 静态私有实例引用
3. 公共静态获取方法

### 9.2 策略模式 (Strategy)

**目的**：定义算法族，分别封装，让它们可互相替换。

```java
// 策略接口
public interface TaxCalculate {
    double calculateTax(double amount);
}

// 具体策略
public class USTaxCalculate implements TaxCalculate { ... }
public class CanadaTaxCalculate implements TaxCalculate { ... }

// 客户端
TaxCalculate tax = new USTaxCalculate();
tax.calculateTax(100000);
tax = new CanadaTaxCalculate();  // 动态替换
tax.calculateTax(100000);
```

## 十、异常处理 (Exception Handling)

### 10.1 异常层次

```text
Throwable
├── Error（严重错误，不处理）
└── Exception
    ├── RuntimeException（非受检/运行时异常）
    │   ├── NullPointerException
    │   ├── ArrayIndexOutOfBoundsException
    │   ├── IllegalArgumentException
    │   ├── NumberFormatException
    │   └── InputMismatchException
    └── 其他受检异常（Checked）
        ├── IOException
        └── FileNotFoundException
```

### 10.2 Checked vs Unchecked

| 类型 | 受检时机 | 处理要求 | 场景 |
| ------ | ---------- | ---------- | ------ |
| **Checked** | 编译期 | 必须处理或声明`throws` | 外部资源（文件、网络） |
| **Unchecked** | 运行期 | 不强制 | 编程错误（空指针、越界） |

### 10.3 try-catch-finally

```java
try {
    // 可能抛出异常的代码
    FileReader reader = new FileReader("file.txt");
    Scanner in = new Scanner(reader);
    readData(in);
} catch (FileNotFoundException e) {
    System.out.println("文件未找到");
} catch (IOException e) {
    e.printStackTrace();
} finally {
    // 无论是否异常，都会执行
    // 常用于关闭资源
    if (reader != null) reader.close();
}
```

**执行路径**：

1. 无异常 → 执行try → 执行finally → 继续
2. 有匹配catch → 执行try（到异常点）→ 执行catch → 执行finally → 继续
3. 无匹配catch → 执行try（到异常点）→ 执行finally → 异常向上抛出

### 10.4 throw / throws

```java
// 方法内抛出异常
throw new IllegalArgumentException("金额超过余额");

// 方法声明可能抛出的异常
public void read(String filename) throws IOException, BadDataException {
    ...
}
```

**规则**：

- 子类重写方法时，声明的异常不能比父类更宽泛
- 可以声明多个，用逗号分隔
- 若存在继承关系，只需声明父类异常

### 10.5 自定义异常

```java
// 受检异常（继承Exception）
public class BadDataException extends Exception {
    public BadDataException() { }
    public BadDataException(String message) { super(message); }
}

// 非受检异常（继承RuntimeException）
public class InsufficientFundsException extends RuntimeException {
    public InsufficientFundsException(String message) { super(message); }
}
```

## 十一、文件I/O (File I/O)

### 11.1 文本文件读写

```java
import java.io.*;
import java.util.Scanner;

// 读文本
FileReader reader = new FileReader("input.txt");
Scanner in = new Scanner(reader);
while (in.hasNextLine()) {
    String line = in.nextLine();
}
reader.close();

// 写文本
PrintWriter out = new PrintWriter("output.txt");
out.println("Hello");
out.close();  // 必须关闭，否则可能丢失数据！
```

### 11.2 二进制文件读写

```java
// 读
FileInputStream in = new FileInputStream("input.bin");
int next = in.read();  // 返回int，-1表示EOF
byte b = (byte) next;

// 写
FileOutputStream out = new FileOutputStream("output.bin");
out.write(b);
```

**为什么`read()`返回`int`而非`byte`？**

- 需要`-1`作为EOF标志，而`byte`范围是-128~127，无法区分合法数据与EOF

### 11.3 文本 vs 二进制

| 特性 | 文本 | 二进制 |
| ------ | ------ | -------- |
| 可读性 | 人类可读 | 不可读 |
| 存储 | 字符序列 | 字节序列 |
| 类 | Reader/Writer | InputStream/OutputStream |
| 效率 | 较低 | 紧凑高效 |
| 适用 | 配置文件、日志 | 图片、对象序列化 |

### 11.4 随机访问文件 (RandomAccessFile)

```java
RandomAccessFile f = new RandomAccessFile("bank.dat", "rw");
f.seek(n * RECORD_SIZE);      // 定位到第n条记录
long pos = f.getFilePointer(); // 获取当前位置
long len = f.length();          // 文件长度

// 读写基本类型
f.writeInt(accountNumber);     // 4字节
f.writeDouble(balance);        // 8字节
int num = f.readInt();
double bal = f.readDouble();
```

**关键概念**：

- `"r"`只读，`"rw"`读写
- 记录大小固定（如`RECORD_SIZE = 12`），才能通过`seek`直接定位
- 二进制格式保证固定长度，便于随机修改

### 11.5 缓冲区

- `BufferedInputStream` / `BufferedOutputStream`
- 减少磁盘访问次数，提升性能

## 十二、类设计方法（大题/设计题重点）

### 12.1 识别类的步骤

1. **提取名词**：从需求描述中找出所有名词
2. **筛选**：
   - 复数变单数

3. **确定关联**：用n×n表格分析"is a"（继承）和"has a"（关联）

- `LibrarySystem`：系统入口

- `BorrowerItems`：借阅物品集合
- `BorrowerDatabase`：借阅者数据库

**关键操作**：

- 显示目录/借阅者
- 借出（Check out）：加入借阅者列表
- 归还（Check in）：从借阅者列表移除

## 十三、高频考点与易错点总结

### 🔴 必考陷阱

1. **默认构造方法**：一旦自定义构造，系统不再提供无参构造；子类构造默认调`super()`，若父类无无参构造则编译错误
2. **静态方法限制**：不能访问非静态成员；`main`方法中不能直接调用实例变量
3. **参数传递**：对象参数传的是引用副本，方法内修改对象状态有效，但重新赋值引用无效
4. **多态调用**：`Person p = new Student(); p.getDegree()`编译失败，因为编译时看左边类型
5. **异常匹配**：catch只匹配第一个符合条件的，子类异常应放在父类前面
6. **文件覆盖**：`PrintWriter`创建时会清空已有文件，输入输出同名文件会导致数据丢失！

### 🟢 记忆口诀

- **封装**：属性私有，访问公开
- **继承**：`is a` 关系，单继承，构造不继承
- **多态**：父类引用，子类对象，重写方法，动态绑定
- **抽象类**：有得有失（可有成员变量，不能多继承）
- **接口**：纯契约，多实现，解耦合
- **异常**：Checked必须抓，Unchecked看情况，finally必执行

### 🟡 代码题常见模式

1. **继承 + 重写 + 多态**（Shape/Circle/Rectangle）
2. **异常处理**（try-catch-finally，自定义异常）
3. **文件读写**（LineNumberer，Encryptor）
4. **随机访问**（BankData，固定记录大小）
5. **单例模式**（私有构造 + 静态实例 + 静态获取）
