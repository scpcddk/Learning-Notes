# Spring Core知识点速查

## 一、IOC 核心

| 要点 | 一句话 |
| ------ | -------- |
| **核心思想** | 控制权反转：不再 `new`，向容器"要"对象 |
| **两种注册方式** | 自己写的类 → `@ComponentScan` + `@Component`；第三方类 → `@Configuration` + `@Bean` |
| **注入方式** | 字段（最方便）/ 构造器（最规范，`final`）/ Setter（可选依赖） |
| **循环依赖** | 三级缓存解决：成品 → 半成品 → 工厂。**构造器注入❌ prototype❌** |
| **生命周期** | 实例化 → 注入 → Aware → PostProcessor前置 → 初始化 → PostProcessor后置 → 销毁 |

**常用注解速记**：`@Autowired` 按类型 → `@Qualifier` 按名称 → `@Primary` 首选 → `@Resource` 按名称(JSR-250)

---

## 二、AOP 核心

| 要点 | 一句话 |
| ------ | -------- |
| **代理选择** | 有接口 → JDK动态代理；无接口 → CGLIB继承代理 |
| **五大通知顺序** | `@Before` → `@Around` → 目标方法 → `@Around` → `@AfterReturning`/`@AfterThrowing` → `@After` |
| **切点表达式** | `execution(* com.service.*.*(..))` — `*`任意，`..`子包/任意参数 |
| **自调用失效** | `this.method()` 不走代理 → 用 `AopContext.currentProxy()` 或注入自身 |
| **AOP vs Event** | AOP是"一刀切"（垂直增强N个类）；Event是"大喇叭"（水平广播解耦） |

## 三、事务核心 ⭐面试必问

**传播行为速查**：

| 行为 | 有事务 | 无事务 | 口诀 |
| ------ | -------- | -------- | ------ |
| `REQUIRED` | 加入 | 新建 | **同生共死**（默认） |
| `REQUIRES_NEW` | 挂起当前，新建独立 | 新建 | **独立王国**（日志/审计必成功） |
| `NESTED` | 嵌套savepoint | 新建 | **部分回滚** |

**事务失效清单**：非公(public) | 自调(this) | 吃掉异常 | 类型不对(非Runtime) | final方法 | 多线程 | 未进容器 | static

**设计原则**：边界要小、不做IO、不计算、异常要抛、只读标`readOnly`

## 四、条件装配 & 自动配置

- `@SpringBootApplication` = `@Configuration` + `@EnableAutoConfiguration` + `@ComponentScan`
- 自动配置：`META-INF/spring/...imports` → 条件过滤(`@ConditionalOnClass`等) → 注册Bean
- 多环境：`@Profile("dev")` + `spring.profiles.active=dev`

## 六、核心口诀（面试速记）

| 主题 | 口诀 |
| ------ | ------ |
| IOC注册 | **自己写的扫描，三方的@Bean** |
| 注入方式 | **构造规范，字段方便，Setter可选** |
| AOP代理 | **有接口JDK，无接口CGLIB** |
| 事务失效 | **非公、自调、吃掉、类型不对、final、多线程** |
| 生命周期 | **实例化→注入→Aware→PostProcessor前→初始化→PostProcessor后→销毁** |
| 循环依赖 | **三级缓存：成品→半成品→工厂** |
| 传播行为 | **REQUIRED同生共死，REQUIRES_NEW独立王国，NESTED部分回滚** |

## 七、避坑TOP5

1. **`@Autowired`为null** → 类没进容器（没加`@Service`）或手动`new`
2. **AOP/事务不生效** → 同类`this`调用绕过代理 → 用代理对象或抽离到另一个Bean
3. **单例注入Prototype** → 只创建一次 → `@Scope(proxyMode=TARGET_CLASS)` 或 `ObjectFactory`
4. **`@Bean`互调重复创建** → `@Configuration`必须用CGLIB代理，不能用`@Component`
5. **`@Around`忘`proceed()`** → 目标方法"消失"
