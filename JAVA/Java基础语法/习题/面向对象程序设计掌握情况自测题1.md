# 第1题：基础语法 + 面向对象封装

**题目：**
创建一个 `Student` 类，包含私有属性 `name`（String）和 `score`（double）。要求：

- 提供构造方法，可同时初始化两个属性
- 提供 `get`/`set` 方法，其中 `setScore` 需检查分数是否在 0~100 之间，否则打印提示并拒绝设置
- 提供一个 `displayInfo()` 方法，打印格式：`姓名：张三，成绩：85.5`
- 编写 `main` 方法测试：创建一个学生对象，用 `setScore` 尝试设120分，再设置85分，最后调用 `displayInfo()` 输出

**预期输出：**

```java
分数不合法，设置失败
姓名：张三，成绩：85.0
```

**考察点：** 类的定义、私有成员、构造方法、this关键字、封装思想、条件判断、基本输出。

# 第2题：继承与多态

**题目：**
定义一个父类 `Animal`，包含一个方法 `sound()`，输出 `动物发出声音`。
再定义两个子类 `Dog` 和 `Cat`，分别重写 `sound()`，输出 `小狗汪汪叫` 和 `小猫喵喵叫`。
在 `main` 方法中：

- 创建一个 `Animal` 类型的数组，包含两个元素，分别放一个 `Dog` 对象和一个 `Cat` 对象
- 用增强for循环遍历数组，调用每个对象的 `sound()` 方法

**预期输出：**

```java
小狗汪汪叫
小猫喵喵叫
```

**考察点：** 继承（extends）、方法重写（@Override）、向上转型、多态的动态绑定。

# 第3题：集合框架 + 泛型

**题目：**
使用 `ArrayList<String>` 存储多个城市名称（至少4个），完成以下操作：

- 添加：北京、上海、广州、深圳
- 在索引1位置插入“杭州”
- 删除“广州”
- 使用**迭代器**遍历并打印所有城市
- 判断集合是否包含“深圳”，打印结果

**预期输出（顺序需保证）：**

```java
北京
杭州
上海
深圳
是否包含深圳：true
```

**考察点：** List接口、ArrayList常用方法、泛型约束、Iterator遍历、自动装箱/拆箱（这里涉及String，但泛型概念一致）。

# 第4题：异常处理（自定义异常）

**题目：**
自定义一个异常类 `AgeException`，继承 `Exception`，包含构造方法传递异常信息。
编写一个方法 `checkAge(int age)`，当年龄小于0或大于150时抛出 `AgeException`，异常信息为“非法年龄：xxx”。
在 `main` 方法中调用 `checkAge`，分别测试200和25，捕获并打印异常堆栈，同时保证程序能继续运行并输出“检查完毕”。

**预期输出大致为：**

```java
非法年龄：200
at ... (异常栈)
检查完毕
```

**考察点：** 自定义异常、throw/throws、try-catch-finally（可用finally保证输出）、异常传播。

# 第5题：综合应用——文件读写与多线程

**题目：**
编写一个程序，完成以下任务：

1. 创建一个文本文件 `test.txt`，写入多行数字（每个数字单独一行），例如：
10
20
30
40
2. 启动一个新线程，在该线程中读取文件内容，计算所有数字的总和，并打印“线程[线程名]计算的总和：xxx”。
主线程同时在文件读取期间，每隔0.5秒打印一次“主线程正在等待...”，等到子线程结束后，主线程打印“计算完成，程序结束”。

**提示：**

- 使用 `BufferedWriter` / `FileWriter` 写文件
- 使用 `BufferedReader` / `FileReader` 读文件
- 让子线程实现 `Runnable` 或继承 `Thread`
- 主线程通过 `join()` 等待子线程，或使用 `Thread.sleep` 模拟等待

**预期输出示例：**

```java
主线程正在等待...
主线程正在等待...
线程[Thread-0]计算的总和：100
计算完成，程序结束
```

**考察点：** 文件IO、多线程创建与启动、线程安全（本题不涉及冲突，但建立概念）、线程协调（join）、字符串解析与基本运算。

# **基于这些题的学习框架建议**

做完这些题后，你大概率会发现几个薄弱点，正好可以对应到你的学习框架里：

| 题目暴露的问题 | 对应应补的知识模块 |
|---------------|-------------------|
| 记不住方法签名、乱拼单词 | Java API常用类（String、Math、集合）的熟练查阅 |
| 不知道何时用接口/抽象类 | 面向对象高级：抽象类 vs 接口，设计模式入门 |
| 对集合选型茫然 | 集合框架全貌：List/Set/Map及实现类对比 |
| 异常只会printStackTrace | 异常最佳实践：日志、资源释放、try-with-resources |
| 多线程代码写不出 | 多线程核心：线程生命周期、同步、线程池、Callable |
| IO流方向混淆 | IO流体系：字节/字符、输入/输出、装饰器模式 |
