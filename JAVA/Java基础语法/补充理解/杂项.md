# Java杂项笔记

## 1.final修饰的变量里面的内容无法发生改变

+ final 基本类型 vs 引用类型：
  + **基本类型**：数值本身不可变
  + **引用类型**：引用地址不可变（即不能再指向其他对象），但对象内部的状态是可以改变的

## 2.枚举

+ 每一个枚举项，都是该枚举类的**对象**
+ 枚举项在底层其实就是常量，默认用 `public static final` 修饰
+ 枚举类的第一行上必须是枚举项，枚举项之间用逗号隔开，以分号作为结尾
+ 枚举类的构造方法必须是 `private` 修饰，不让外界创建本类的对象
+ 编译器会给枚举类新增两个默认存在的方法：`values()`、`valueOf()`

---

## 3.方法重写注意事项和要求

+ 重写方法的名称、形参列表必须与父类中的一致，方法体按照实际需求书写
+ **了解**：子类重写父类方法时，访问权限子类必须大于等于父类（空着不写 < protected < public）
+ **了解**：子类重写父类方法时，返回值类型子类必须小于等于父类
+ **建议**：重写的方法申明和父类保持一致即可
+ final修饰类为最终类，里面所有的方法不能被重写
+ private私有方法、static静态方法、final最终方法不能被重写

## 5.try-catch —— 防崩安全网

```java
try {
    // 1. 尝试执行：可能出问题的代码
} catch (要捕获的异常类型 变量名) {
    // 2. 如果真出问题了：执行这里的补救代码
}
```

+ try 块：放你要执行的代码
+ catch 块：如果 try 里的代码抛出了 `InterruptedException`，就跳到这里来“善后”
+ 变量名：捕获到的异常对象，里面有出错信息
+ InterruptedException：线程被中断时抛出的异常类型

## 7.Math.floor

JavaScript 的內建數學方法，用於向下取整：返回小於或等於給定數字的最大整數

### (1)语法

`Math.floor(x)`

+ 負數向下取整：Math.floor(-4.1) 返回 -5，因為 -5 < -4.1，這是「向下」的數學意義（往更小的整數方向）
+ 若參數已是整數，則返回原值
+ 若參數為 NaN，返回 NaN
+ 若參數為 Infinity / -Infinity，返回對應的無窮大值

### (2)與相似方法的區別

| 方法 | 行為 | 範例 (3.7 →) | 範例 (-3.7 →) |
| ------ | ------ | ---------------- | ------------------ |
| `Math.floor()` | 向下取整 | `3` | `-4` |
| `Math.ceil()` | 向上取整 | `4` | `-3` |
| `Math.round()` | 四捨五入 | `4` | `-4` |
| `Math.trunc()` | 截斷小數部分 | `3` | `-3` |

## 8.@FunctionalInterface

### (1)定义

`@FunctionalInterface`：**函数式接口注解**，Java8新特性

### (2)核心规则

1. 接口内**有且仅有一个抽象方法**
2. 允许存在：`default`默认方法、`static`静态方法
3. 允许重写Object类公有方法
4. 编译期强制校验，违反直接报错

### (3)与普通接口区别

| 对比项 | 普通接口 | 函数式接口 |
| ---- | ---- | ---- |
| 抽象方法 | 不限数量 | 只能1个 |
| 注解 | 无强制注解 | 必须标注该注解 |
| 实现方式 | 匿名内部类 | 支持Lambda表达式 |
| 用途 | 定义多种行为 | 单一行为、回调、流式编程 |

### (4)基础代码示例

```java
@FunctionalInterface
public interface FuncDemo {
    // 唯一抽象方法
    void run();
}
```

### (5)Java四大内置常用函数式接口

1. Consumer\<T> ：消费型 → 有参无返回
2. Supplier\<T> ：供给型 → 无参有返回
3. Function<T,R> ：函数型 → 有参有返回
4. Predicate\<T> ：断言型 → 有参返回布尔值

## 9.return String

+ **`return String`**
  + 方法把字符串**交给调用者**，可以存、拼、传
  + `return`是**传递数据**，`String`是返回类型
+ **`System.out.println`**
  + 只把内容**打印到控制台**，调用者**拿不到**这个字符串
  + 输出后数据消失，**无法复用**
+ **核心区别**
  + `return`：厨师把菜**端给你**（你可以再加工）
  + `println`：厨师自己**吃掉**，你只是看到
+ **一句话**  
  + 需要把结果给别人用 → `return`
  + 只想看看结果 → `println`

## 10.@Component 注解笔记

### 1.作用

+ **把类的创建和管理权交给 Spring 容器**，无需手动`new`
+ Spring 自动创建实例（默认单例），并在需要的地方注入依赖

### 2.对比

| 场景 | 不加 @Component | 加 @Component |
| ------ | ---------------- | --------------- |
| 创建对象 | 手动 `new` | Spring 自动创建 |
| 多处理 | 自己处理单例或传参 | Spring 保证单例，按需注入 |
| 依赖注入 | 手动 `new` 或 `setter` 传入 | Spring 自动注入（构造器/@Autowired） |

### 3.示例

```java
@Component
public class ElixirManager { ... }

@Component
public class BattleField {
    private final ElixirManager elixirManager;

    public BattleField(ElixirManager elixirManager) { // 自动注入
        this.elixirManager = elixirManager;
    }
}
// 使用：无需任何 new 代码，直接用 @Autowired 取
```

## 11.`synchronized`关键字

> [!TIP]
> 让多线程排队执行，防止同时操作共享数据时出错

### (1)三种用法

| 用法 | 代码 | 锁对象 |
| ------ | ------ | -------- |
| 实例方法 | `public synchronized void m()` | `this` |
| 静态方法 | `public static synchronized void m()` | `Class` 对象 |
| 代码块 | `synchronized(obj) {}` | 指定对象 |

### (2)核心特性

+ **互斥性**：同一时刻只有一个线程进入临界区
+ **可见性**：解锁前将变量刷新到主内存
+ **可重入性**：同一线程可多次获取同一把锁

### (3)底层原理

+ 基于**Monitor**监视器锁
+ 字节码指令：`monitorenter` / `monitorexit`
+ 对象头**Mark Word**存储锁状态

### (4)锁升级（JDK 6+）

无锁 → 偏向锁 → 轻量级锁 → 重量级锁

| 状态 | 触发条件 | 机制 |
| ------ | ---------- | ------ |
| 偏向锁 | 只有一个线程访问 | 记录线程 ID，无 CAS |
| 轻量级锁 | 线程交替执行（低竞争） | 自旋 CAS |
| 重量级锁 | 多线程同时竞争 | 操作系统 Mutex，线程阻塞 |

> 锁只能升级，不能降级

### (5)与`ReentrantLock`对比

| 维度 | `synchronized` | `ReentrantLock` |
| ------ | --------------- | ----------------- |
| 实现 | JVM 内置 | API 手动控制 |
| 释放 | 自动（异常也释放） | 手动`unlock()` |
| 高级功能 | 无 | 可中断、超时、公平锁、多条件变量 |
| 性能 | JDK 6+ 优化后接近 | 高竞争略优 |

### (6)注意事项

1. **锁对象要`final`**，避免引用改变
2. **不用基本类型包装类**（`Integer`、`String` 常量池）
3. **缩小同步范围**，降低粒度
4. **避免嵌套锁**，防止死锁

### (7)代码示例

```java
public class Counter {
    private final Object lock = new Object();
    private int count;

    // 推荐：同步代码块，粒度可控
    public void increment() {
        synchronized (lock) {
            count++;
        }
    }
}
```

## 12.transient — 序列化时跳过

+ **被修饰的字段不参与序列化，对象存盘/网络传输时直接忽略**

### (1)用途

+ 敏感数据（密码、密钥、Token）
+ 临时/派生数据（缓存、计算结果）
+ 不可序列化的对象（Thread、InputStream）

### (2)注意

+ 反序列化后值为默认值（null / 0 / false）
+ 与 static 一起用无意义（静态字段本来就不序列化）

### (3)示例

```java
复制
public class User implements Serializable {
    private String username;
    private transient String password;  // 不存盘
    private transient int age;         // 反序列化后为 0
}
```

## 13.volatile — 线程间实时可见

+ **强制线程从主内存读写，保证一个线程修改后其他线程立即可见**

### (1)核心特性

+ ✅ 可见性：修改立刻对所有线程可见
+ ❌ 非原子性：i++ 仍不安全（需配合 synchronized 或 AtomicInteger）
+ ✅ 禁止指令重排：建立内存屏障

### (2)适用场景

+ 状态标志位（如 running、stop、active）

### (3) 示例

```java
复制
public class Task {
    private volatile boolean running = true;

    public void shutdown() {
        running = false;  // 线程 B 修改
    }

    public void run() {
        while (running) {  // 线程 A 能立刻看到变化
            // 执行任务
        }
    }
}
```

## 14.StringBuilder

StringBuilder是用于高效处理可变字符串的类，它的核心作用是**避免频繁创建字**符串对象，从而提升性能

### (1)为什么需要它

普通字符串`String`是不可变的。每次拼接、修改都会创建新对象,如果操作频繁（如循环拼接），会产生大量垃圾对象,StringBuilder 通过维护可变字符数组解决这个问题

### (2)语法

```java
StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.append(" ");
sb.append("World");
sb.insert(5, ",");           // 在索引5处插入
sb.delete(5, 6);             // 删除索引5到6的字符
sb.reverse();                // 反转
String result = sb.toString(); // "dlroW olleH"
```

+ 非线程安全（比 StringBuffer 快）
+ 默认初始容量 16 字符，自动扩容（扩容有开销，预估容量更高效）
