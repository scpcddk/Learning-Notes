二、基础语法速查

2.1 包与导入

  • package 必须第一行；目录结构必须与包名一致
  • import 只影响编译期，零性能损耗；java.lang 自动导入
  • import static java.lang.Math.PI; 只导入常量（推荐）
编译运行：javac -d . *.java 自动生成包目录；运行用全限定名 java com.game.main.Main

2.3 参数传递 核心

三、类与对象

3.1 new 创建对象流程 7步

  1. 加载 .class 到方法区
  2. 栈中声明引用变量（初始 null）
  3. 堆中开辟空间
  4. 默认初始化（0 / false / null）
  5. 显式初始化（定义处赋值、初始化块）
  6. 构造方法初始化
  7. 地址赋给引用变量

3.2 成员变量 vs 局部变量

维度成员变量局部变量
位置类内方法外方法/代码块内
默认值有无，必须手动初始化
存储堆栈
修饰符可用 public/private/static不能用访问修饰符

3.3 构造方法

  • 方法名 = 类名，无返回值（void 也不能写）
  • 无显式构造时，编译器自动送无参构造；一旦写了有参，默认构造消失
  • this(...) / super(...) 必须在构造方法第一行，且互斥

3.4 static 核心

特性实例成员static 成员
归属对象类
内存堆（每个对象一份）方法区（全类一份）
this✅ 有❌ 无
访问实例变量✅❌
调用方式对象.成员类名.成员
陷阱：静态方法不能直接访问实例变量/this；用对象调静态成员语法允许但极不推荐

3.5 代码块执行顺序

static 代码块（类加载，仅一次）→ 构造代码块（每次 new 前）→ 构造方法

3.6 final

修饰目标作用
final class不可继承（String、System、Math）
final method不可重写
final 变量只能赋值一次；引用类型不能换地址，但可改属性
final 参数方法内不可修改

四、面向对象三大特性

4.1 封装

private 属性 + public getter/setter；可在 setter 中加校验逻辑

4.2 继承 extends

  • Java 单继承，支持多层继承；顶级父类是 java.lang.Object
  • 子类构造默认隐含 super()；若父类无无参构造，子类必须手动 super(参数)
  • 成员变量：就近原则；this.name 本类，super.name 父类

4.3 方法重写 Override

  • 方法名、参数列表、返回值必须相同（返回值可为子类型）
  • 访问权限不能更严格；不能抛更宽泛受检异常
  • private、static、final 方法不可重写
  • 用 @Override 注解校验

4.4 多态 核心

前提：继承/实现关系 + 父类引用指向子类对象 + 方法重写

调用类型编译运行
变量看左边（父类）看左边（父类）
方法看左边（父类）看右边（子类重写）
口诀：变量编译运行都看左，方法编译看左运行看右

4.5 向下转型

// Java 14+ 模式匹配（推荐）
if (animal instanceof Dog d) {
    d.bark();  // d 直接可用
}
// 旧写法
if (animal instanceof Dog) {
    Dog d = (Dog) animal;
    d.bark();
}
注意：必须先 instanceof 判断，否则可能 ClassCastException

五、抽象类与接口

5.1 抽象类 abstract

  • 不能实例化，可有成员变量、构造方法、普通方法
  • 子类必须重写所有抽象方法，否则子类也为抽象类
  • 构造方法供子类 super() 使用

5.2 接口 interface

  • 不能实例化，无构造方法
  • JDK7-：只有 public abstract 方法 + public static final 常量
  • JDK8：默认方法(default)、静态方法(static)
  • JDK9：私有方法(private)

5.3 关系总结

关系规则
类与类单继承，多层继承
类与接口多实现；可继承类同时实现多个接口
接口与接口多继承

5.4 默认/静态/私有方法（JDK8+）

interface MyInterface {
    default void foo() { }      // 不强制重写；多接口冲突时必须重写
    static void bar() { }      // 只能接口名调用
    private void helper() { }   // JDK9+；供默认/静态方法复用
}

七、String & 集合

7.1 String 不可变

  • == 比地址，equals 比内容；常量池复用，new String 在堆
  • 所有修改操作（replace/substring/trim）返回新字符串，原串不变
  • 频繁修改用 StringBuilder（线程不安全）或 StringBuffer（线程安全）

7.2 StringBuilder 常用

StringBuilder sb = new StringBuilder("hello");
sb.append(" world").reverse();  // 链式调用
String result = sb.toString();

7.3 数组

  • 动态：int[] arr = new int[5]; 静态：int[] arr = {1,2,3};
  • 对象数组初始化后元素全为 null，必须逐个 new
  • 遍历：普通 for / 增强 for（只读）

7.4 ArrayList 泛型

ArrayList<String> list = new ArrayList<>();
list.add("a"); list.add(0, "b");     // 增
list.remove("a"); list.remove(0);    // 删
list.set(0, "c");                    // 改
list.get(0); list.size();            // 查
注意：集合只能存引用类型，基本类型自动装箱（JDK5+）

八、异常与 IO

8.1 异常体系

类型继承处理要求典型
受检异常Exception（非 Runtime）必须处理（try-catch / throws）IOException, SQLException
运行时异常RuntimeException不强制，代码避免NullPointerException, ArrayIndexOutOfBounds

8.2 try-with-resources（推荐）

try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

8.3 IO 流选择

场景使用
文本文件读写FileReader / FileWriter（字符流）
二进制文件（图片/视频）FileInputStream / FileOutputStream（字节流）
高效缓冲BufferedReader / BufferedInputStream
指定编码InputStreamReader / OutputStreamWriter
字节流不要直接读文本转字符串，会乱码；字符流不要处理二进制文件

九、C++ 转 Java 避坑指南

9.1 == vs equals 高频错误

场景正确错误
基本类型==无 equals
字符串内容"abc".equals(s)（常量在前防 NPE）s == "abc"
对象内容obj1.equals(obj2)（需重写）obj1 == obj2
包装类equals()==（-128~127 缓存区间外失效）
判 nulls == nulls.equals(null)（NPE！）
枚举==（单例安全）equals 也可，但 == 更高效

9.2 equals + hashCode 必须成对重写

铁律：重写 equals 必须同步重写 hashCode。HashSet/HashMap 先按 hashCode 定位桶，再 equals 比较。hashCode 不等则永远不会触发 equals，导致去重失败。
@Override public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof User)) return false;
    return id == ((User)o).id;
}
@Override public int hashCode() {
    return Objects.hash(id);
}

9.3 其他陷阱

  • 没有指针运算：不能 p++
  • 没有析构函数：GC 自动回收，可用 try-finally 或 try-with-resources
  • 没有 goto（保留字但不可用）
  • 文件名 = public 类名，大小写敏感
  • String 不可变：所有修改返回新对象，忘接返回值等于白改
