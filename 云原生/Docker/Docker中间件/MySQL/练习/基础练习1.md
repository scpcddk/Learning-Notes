# 第一阶段：MySQL 入门练习

我们先只用一张表：

```sql
student
```

表结构：

| 字段         | 含义   |
| ---------- | ---- |
| id         | 学生编号 |
| name       | 姓名   |
| age        | 年龄   |
| gender     | 性别   |
| score      | 成绩   |
| class_name | 班级   |

你可以先创建数据库和表：

```sql
CREATE DATABASE school;

USE school;

CREATE TABLE student (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20),
    age INT,
    gender VARCHAR(10),
    score INT,
    class_name VARCHAR(20)
);
```

然后插入一些数据：

```sql
INSERT INTO student (name, age, gender, score, class_name)
VALUES
('张三', 18, '男', 85, '一班'),
('李四', 19, '女', 92, '一班'),
('王五', 18, '男', 76, '二班'),
('赵六', 20, '女', 88, '二班'),
('孙七', 19, '男', 95, '一班'),
('周八', 18, '女', 63, '三班'),
('吴九', 20, '男', 72, '三班'),
```
