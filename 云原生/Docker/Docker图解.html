🐳 Docker 速查复习笔记

面向 Spring Boot 项目 | 简洁版

一、核心概念

镜像（Image）：只读模板，包含运行环境（JDK + jar）
容器（Container）：镜像的运行实例，可启停删，相互隔离
仓库（Repository）：存放镜像的地方，如 Docker Hub

二、常用命令速查

命令作用
docker run -d -p 8080:8080 --name app 镜像后台启动容器，端口映射
docker ps / ps -a查看运行中 / 所有容器
docker build -t my-image .构建镜像
docker images列出本地镜像
docker pull/push 镜像拉取 / 推送镜像
docker exec -it 容器 bash进入容器交互终端
docker start/stop/restart 容器启停重启容器
docker rm / rmi删除容器 / 镜像
docker logs -f 容器查看日志
docker-compose up -d后台启动多服务
docker-compose down停止并删除 compose 服务
常用选项：-d 后台运行 | -p 宿主机:容器 端口映射 | -v 挂载卷 | --name 命名 | --restart=always 自动重启

三、Dockerfile 核心指令

指令作用
FROM指定基础镜像
WORKDIR设置工作目录
COPY复制文件到镜像（推荐用 COPY，不用 ADD）
RUN构建时执行命令
ENV设置环境变量
EXPOSE声明端口（仅文档作用）
CMD容器启动默认命令，可被覆盖
ENTRYPOINT入口命令，不会被覆盖，可追加参数
CMD vs ENTRYPOINT：Spring Boot 推荐只用 ENTRYPOINT，避免误覆盖启动命令。组合用法：ENTRYPOINT 固定命令 + CMD 提供默认参数。

多阶段构建（Java 项目必用）

构建阶段用 Maven + JDK 编译 → 运行阶段只保留 JRE + jar
效果：镜像体积从 600MB+ 降至 200MB 以内

生产级 Dockerfile 要点

  • 用 eclipse-temurin:21-jre-alpine 等轻量基础镜像
  • 多阶段构建，编译与运行分离
  • 创建非 root 用户运行（USER app）
  • 设置时区 Asia/Shanghai
  • 添加 HEALTHCHECK 健康检查（配合 Actuator）
  • JVM 参数通过 ENV JAVA_OPTS 注入

四、docker-compose 核心

字段作用
services定义所有服务
ports端口映射 "8080:8080"
volumes数据挂载持久化
networks自定义网络，容器间用服务名互访
depends_on控制启动顺序（不保证服务就绪）
environment注入环境变量
restart重启策略，推荐 unless-stopped

数据挂载三种方式

  • 匿名卷：- /app/logs（Docker 自动管理）
  • 命名卷：- app-logs:/app/logs（方便备份共享）
  • 宿主机目录：- ./logs:/app/logs（开发调试最常用）
同一网络内容器直接用服务名作为域名通信，如 http://inference:5000/predict，不要硬编码 IP

五、镜像优化技巧

  • 优先用 alpine / slim 版本，避免 latest 完整版
  • 多阶段构建分离编译与运行
  • 合并 RUN 命令，减少层数，及时清理缓存
  • 添加 .dockerignore 排除无关文件
  • 固定依赖版本，利用构建缓存

六、落地注意事项

注意点说明
jar 名称固定pom.xml 中设置 <finalName>app</finalName>，避免 COPY 多文件报错
非 root 运行务必创建普通用户并 USER 切换，降低安全风险
时区设置Alpine 默认 UTC，需手动设置 Asia/Shanghai
日志持久化用 volumes 挂载到宿主机，容器删除数据不丢
访问宿主机容器内 localhost 指向自身；Win/Mac 用 host.docker.internal；Linux 需加 extra_hosts
优雅停机Spring Boot 配置 server.shutdown=graceful，配合 SIGTERM
大数字精度JS 解析大整数会丢失，后端 Long 转字符串传输
Compose 版本V2 不再需要 version 字段，写上可能报警告
安全：禁止用 eval() 解析 JSON；定期 docker build --pull 更新基础镜像；生产环境限制 CPU/内存资源
