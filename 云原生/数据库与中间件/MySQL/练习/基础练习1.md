你可以先创建数据库和表：

```sql
-- 创建独立数据库作为练习范围，后续建表前核对当前库。
CREATE DATABASE school;

USE school;

CREATE TABLE student (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20),
    age INT,
    gender VARCHAR(10),
    score INT,
    class_name VARCHAR(20)
);
```
