# 云原生笔记勘误记录

核对日期：2026-10-26。修订直接写入原笔记，重复部署手册中的相同问题同步修改。

| 范围 | 主要修正 |
|---|---|
| Git、Maven | 修复远程地址命令；澄清 stash、分支参数、JAR/WAR、依赖打包、多阶段镜像与构建/运行 profile 的区别 |
| Docker | 修正镜像与容器、分层与元数据、启动顺序与就绪、健康检查与自动重启；修复 JAR 被 dockerignore 排除、Python 缺 curl、JVM 内存及停机等待时间冲突、CI 缺 Buildx 的示例 |
| MQTT、EMQX | 修正 SUBSCRIBE 标志、心跳、会话过期、QoS 交付边界、HTTP 认证响应、TLS 配置路径、集群演示的容错范围与 CLI/监听端口含义 |
| MinIO | 修正 Console 变化及版本说明、SDK 无效调用、元数据、纠删码与 quorum、配额/IAM 备份、监控 JWT、审计回调、预签名 URL 可重复使用等错误 |
| MySQL | 修正 SQL 语法、数据类型存储大小、精确数值运算、联合索引、唯一键记录锁、ReadView、COUNT、EXPLAIN、Online DDL、半同步复制及连接池公式等；去掉多处缺少条件的绝对规则 |
| MySQL 系统手册 | 修正 WSL systemd、Java 认证插件、RENAME USER、权限刷新、Windows 共享内存登录及密码恢复流程 |
| Nginx、SRS | 修正 location 顺序、超时/重试、限流 burst、指令上下文、只读挂载、WebSocket 握手、SRS 信令/DVR 说明和 shell 续行语法 |
| 部署与排障 | 修正“HTTP 000 就是 IP 变化”、shell 对 BCrypt 的展开、静态 200 代替后端健康、含省略号的恢复脚本、备份完整性与乱码因果判断 |

保留了项目实录的环境和观察记录；证据不足的根因改为待验证，不把此次文档修订写成服务器复测结果。空白占位笔记未补写，PDF/PPTX 及截图等参考附件未修改。

验证包括：5 个完整 Compose 示例通过 `docker compose config`；完整 Maven POM 通过 XML 解析；修改文件中的 Python 代码块通过语法解析；核对 Markdown 代码围栏与本地链接。没有在实际服务器执行部署、数据库更新或恢复操作，配置解析也不等于服务运行验收。
