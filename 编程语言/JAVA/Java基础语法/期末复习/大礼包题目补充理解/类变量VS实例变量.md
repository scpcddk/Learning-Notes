# 📘 类变量（静态变量）vs 实例变量 · 专项拆解笔记

> 适用场景：遇到“哪个不是类变量特征”、“静态变量内存有几份”、“静态方法能否访问实例变量”等变种题时，直接查阅本节

---

## 1. 核心定义对比（一表定乾坤）

| 对比维度 | **类变量（Class Variable）** | **实例变量（Instance Variable）** |
| :--- | :--- | :--- |
| **修饰关键字** | **`static`** | **无 `static`** |
| **所属关系** | 属于 **类本身**（类级别） | 属于 **对象实例**（对象级别） |
| **内存存储位置** | **方法区（Metaspace）**，只有 **一份** 拷贝 | **堆内存（Heap）**，每个对象 **各有一份** |
| **生命周期** | 随 **类加载** 而创建，随 **类卸载** 而消亡 | 随 **对象创建** 而创建，随 **对象回收** 而消亡 |
| **访问方式** | 推荐使用 **类名.变量名** 访问（如 `Student.count`） | 必须使用 **对象名.变量名** 访问（如 `s1.age`） |
| **对象共享性** | **所有对象共享**（改一处，处处变） | **对象间相互独立**（互不影响） |

---

## 2. 代码反例验证（一眼看穿）

```java
class Student {
    static String school = "北京大学";  // 类变量（所有学生共享）
    String name;                       // 实例变量（每个学生自己的）
}

Student s1 = new Student();
Student s2 = new Student();

s1.name = "张三";
s2.name = "李四";
System.out.println(s1.name); // 张三
System.out.println(s2.name); // 李四（各是各的）

// 修改类变量
s1.school = "清华大学";  // 不推荐这样写，但语法允许
System.out.println(s2.school); // 输出：清华大学（s2 也被改了！因为共享一份）
```

---

## 3. 你必须记住的“3 个 Yes & 3 个 No”

### ✅ 类变量（静态变量）可以做到

1. **被非静态方法访问**（实例方法可以修改类变量，因为类变量在类加载时就有了）。
2. **被静态方法访问**（同类静态方法当然能访问自己的静态变量）。
3. **不创建对象直接访问**（通过 `类名.变量名` 访问，比如 `Math.PI`）。

### ❌ 实例变量（非静态变量）绝对做不到

1. **被静态方法直接访问**（静态方法中不能直接使用 `this`，也不能直接访问 `name`，除非先创建对象 `new Student().name`）。
2. **被多个对象共享**（每个对象都有自己的副本）。
3. **在没有对象时存在**（实例变量必须等 `new` 出对象后才分配内存）。

---

## 4. 延伸陷阱（考试变种题必看）

### 陷阱 A：静态方法中访问实例变量

```java
class Demo {
    int a = 10;          // 实例变量
    static void show() {
        System.out.println(a); // ❌ 编译报错！静态方法不能直接访问非静态变量
    }
}
```

**修复方法**：要么把`a`变成 `static`，要么在静态方法里 `new Demo().a`

---

### 陷阱 B：用对象引用访问静态变量（语法行，但极不推荐）

```java
Demo d = new Demo();
System.out.println(d.count); // 语法上可行，但 IDEA 会警告
```

**标准写法**：必须使用 `Demo.count`（类名访问）。如果考试问“哪种访问方式最佳”，选“类名访问”。

---

### 陷阱 C：`static final` 常量（既是类变量又是只读）

- `static final int MAX = 100;` 兼具“类变量（一份）”和“只读（不可改）”特性。
- 如果选项里同时出现“静态数据字段”和“只读变量”，看题目问的是“类变量”的同义词，优先选 **“静态数据字段”**（因为 `final` 不一定是 `static`，但 `static` 一定是类变量）。

---

## 5. 秒杀口诀（背完直接做题）

> **“类变量，加 static；内存里，仅一份；所有对象共分享；类名点，直接访；静态方法，别碰实例变。”**

---

## 6. 做题自查清单（遇到“不正确的”就对照这 3 条）

| 说法 | 判断 | 原因 |
| :--- | :--- | :--- |
| “所有对象都有自己的副本” | ❌ 错误 | 这是实例变量的特征，类变量只有一份 |
| “必须用 static 修饰” | ✅ 正确 | 没有 static 就是实例变量 |
| “非静态方法可以访问” | ✅ 正确 | 实例方法可以访问类变量 |
| “访问时不需要对象引用” | ✅ 正确 | 可以用类名直接访问 |
