# C++杂项笔记

## 1. 128 位整数

`__int128` 是 GCC、Clang 在支持该扩展的目标平台上提供的 128 位有符号整数类型。[GCC 扩展文档](https://gcc.gnu.org/onlinedocs/gcc/_005f_005fint128.html)

- 有符号 `__int128` 的范围为 −2¹²⁷ 至 2¹²⁷−1，约为 ±1.7×10³⁸。
- 无符号 `unsigned __int128` 的范围为 0 至 2¹²⁸−1，上限约为 3.4×10³⁸。
- 常见实现中，32 位 `int` 约为 ±21 亿，64 位 `long long` 约为 ±9.2×10¹⁸。

## 2.自定义比较器

用于排序的比较器应满足严格弱序。当第一个参数排在第二个参数之前时返回 `true`。例如按数值升序比较时用 `a < b`。

## 3.避免野指针

+ 用 `nullptr` 初始化暂未指向对象的指针。
+ 解引用前确认对象仍在生存期内，并且下标或指针偏移在有效范围内。
+ 释放对象后，所有指向它的指针都会悬空。将其中一个指针设为 `nullptr` 只会修改这个指针，其他别名需要分别处理。

## 4.binary_search 是 C++ 标准库中用于在有序区间内进行二分查找的函数

```cpp
bool found = std::binary_search(values.begin(), values.end(), target);
```

+ 常见用法是按与查找相同的比较规则排序，以满足二分查找对区间划分的前提。
+ 存在与目标等价的元素时返回 `true`。需要位置时，有序区间可用 `std::lower_bound` 并检查匹配，无序区间可用 `std::find`。[C++ 标准草案](https://eel.is/c++draft/alg.binary.search)

## 6.范围 for 循环

```cpp
for (declaration : range_expression) {
    // 循环体
}
```

+ declaration：声明一个变量来接收每个元素（可以是 auto、引用、const 等）
+ range_expression：要遍历的容器/数组/初始化列表

```cpp
// 范围 for 循环
for (int v : graph[u]) {
    // 处理 v
}

// 等价于传统循环
for (int idx = 0; idx < graph[u].size(); idx++) {
    int v = graph[u][idx];
    // 处理 v
}

// 也等价于迭代器
for (vector<int>::iterator it = graph[u].begin(); it != graph[u].end(); it++) {
    int v = *it;
    // 处理 v
}
```

## 7.Ceil 

+ 定义:
  `std::ceil(x)` 向上取整，返回 **大于或等于** `x` 的最小整数值，结果仍为浮点类型。
+ 语法（C++）:

```cpp
#include <cmath>
double ceil(double x);
float ceil(float x);
long double ceil(long double x);
```

+ 与 floor 的区别：
  + floor：向下取整（≤ x 的最大整数）
  + ceil：向上取整（≥ x 的最小整数）
