# 位运算

> [!IMPORTANT]
> 1. 位运算作用于整数提升和必要类型转换后的二进制位，与源码采用十进制、八进制还是十六进制书写无关。
> 2. 整数字面量的进制与后缀会影响其类型选择；处理位掩码时优先使用无符号类型。

## 一.& 按位与 （AND）

+ **和0做与运算为清零运算，和1做与运算保持不变**

## 二.| 按位或 （OR）

+ **和1做或运算为置1操作，和0做或运算保持不变**

## 三.^ 按位异或 （XOR）

1.**相同为0，不同为1**
2.**与0做异或运算结果不变，与1做异或运算结果取反**
3.两个相同数异或运算结果为0

+ 例如交换两个整型变量的值

```cpp
char a=3,b=4;
a=a^b;//a=3^4=7
b=b^a;//b=4^7=3
a=a^b;//a=7^3=4;
```

## 四.<< 左移    >> 右移

移位数必须非负，且小于左操作数经整数提升后的类型位宽，否则行为未定义。以下规则针对提升后仍为无符号类型的操作数。

+ 无符号数左移（ << ）
  + 规则：左移时，右边补0，高位直接移出（溢出舍弃）。
  + 效果：左移 n 位，相当于乘以 2^n （前提是没有溢出）

+ 无符号数右移（ >> ）
  + 规则：右移时，左边补0，低位直接移出。
  + 效果：右移 n 位，相当于除以 2^n （向下取整）

## 五.~ 按位求反 （一元运算符）

1.符号位也取反
2.对采用补码表示的有符号整数，`~x = -x - 1`；对 N 位无符号整数，`~x = (2^N - 1) - x`。较窄的整数类型（如 `char`）会先进行整数提升。

## 六.运用

以下技巧仅适用于 ASCII 编码的英文字母；处理一般字符时应使用 `<ctype.h>` 中的 `toupper()` / `tolower()`。

1. 小写字母转大写：ch = ch & (~32)
2. 大写字母转小写：ch = ch | 32
3.大小写字母互相转换：ch = ch ^ 32
